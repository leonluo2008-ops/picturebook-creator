# B676 ladder · 理解推进结构

目标单词: ladder
中文释义: 梯子
角色: 爷爷（银白发，草帽，深蓝布衫）+ 孙子（约5岁，圆脸，黄色T恤）
场景: 自家小果园，摘高枝上的桃子
立意线索: 通过「想摘桃子→抬梯子→架稳→爬梯子→摘到啦」的动作链，让孩子认出梯子是用来够高处的工具。

## 页面结构表

| 页码 | 类型 | 教学内容 | 视觉要素 |
|---|---|---|---|
| 封面 | 认知页 | 建立 "ladder = 梯子" 的第一印象 | 爷爷和孙子站在梯子旁，超大目标单词 Ladder |
| P1 | 语境页 | 发现高处的桃子，产生需求 | 抬头看高枝上的大桃子，意识到够不到 |
| P2 | 语境页 | 抬来梯子，认读 ladder | 爷爷和孙子一起把梯子抬过来 |
| P3 | 语语页 | 架稳梯子，强调安全 | 爷爷扶稳梯子，孙子准备爬 |
| P4 | 语境页 | 一级一级爬，认读 ladder | 孙子在爷爷扶持下向上爬 |
| P5 | 语境页 | 终于够到了，认读 ladder | 孙子伸手摘到大桃子 |
| P6 | 语境页 | 稳稳下来，认读 ladder | 孙子爬下来，把桃子交给爷爷 |
| P7 | 语境页 | 分享快乐，认读 ladder | 祖孙俩开心地吃桃子，梯子在旁边 |
| P8 | 互动练习页 | 辨认梯子 | 干扰物：木梯 / 四脚小凳 / 秋千 |

## 理解递进自检
- 孩子在 P1 意识到“够不到”，P2 引入工具 $\rightarrow$ P3-P6 经历使用过程 $\rightarrow$ P7 获得结果。
- 认知路径：需求 $\rightarrow$ 工具出现 $\rightarrow$ 操作 $\rightarrow$ 达成感。
- P8 互动页通过对比「有横档的梯子」与「无横档的凳子/绳索」强化形态认知。
