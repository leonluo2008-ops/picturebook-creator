# B678 遥控器 · L2+L3

## 一、标题

选定标题：遥控器，Remote Control / Remote Control

量词取舍：本书核心体验是「对着电视按 $\rightarrow$ 画面改变」，这是一个关于功能操作的连续体验。念「一个遥控器」会将其对象化为静态物品，而直接用「遥控器」能更自然地将重心引导至其操作功能上，符合儿童绘本的引导逻辑。

## 二、简介

选定简介：找找遥控器在哪儿，对着电视按一按，画面就变啦！遥控器，remote control！
