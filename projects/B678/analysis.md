# B678 remote control 创作分析

## 1. 核心词与义项锁定
- 目标单词: remote control
- 中文释义: 遥控器
- 词型: 名词
- 义项锁定: 指用于控制电视等电器的无线遥控装置。

## 2. 立意线索（孩子凭什么认出）
- 认出路径: **「一个动作带来看得见的结果」** $\rightarrow$ 按一下 $\rightarrow$ 画面变了。
- 核心体验: 按键的因果律（雪花屏 $\rightarrow$ 动画 $\rightarrow$ 换台）。通过「按$\rightarrow$变」的即时反馈，让孩子明白 remote control 的功能。

## 3. 理解推进结构（连续推进型）
- 结构: 找遥控器 $\rightarrow$ 找到 $\rightarrow$ 对准电视 $\rightarrow$ 按一按 $\rightarrow$ 画面变啦 $\rightarrow$ 用完放回去。
- 页面分布（内页 8 页）:
    - 封面: 认知页。男孩与遥控器，建立 remote control = 遥控器 的第一印象。
    - P1: 语境页。找遥控器（在沙发缝里/茶几下）。
    - P2: 语境页。找到啦！男孩踮脚从茶几够到 remote control。
    - P3: 语境页。对准电视，准备按按。
    - P4: 语境页。按一下，电视从雪花屏变成彩色动画。
    - P5: 语境页。再按一下，换到另一个有趣的动画。
    - P6: 语境页。看动画太开心，男孩端正坐姿。
    - P7: 语境页。动画结束，把 remote control 放回茶几原处（好习惯）。
    - P8: 互动练习页。辨认 remote control（干扰物：手机、座机电话）。
