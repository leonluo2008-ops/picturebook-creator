# B678 自复读清理记录

## 1. 标题核对
- 暂定：遥控器，remote control / Remote Control
- 念读：顺口，直给，无量词更自然。通过。

## 2. 旁白连读三诊
- P1 $\rightarrow$ P2: 「在哪里呀？」$\rightarrow$ 「找到啦！」逻辑顺畅。
- P2 $\rightarrow$ P3: 「找到啦」$\rightarrow$ 「对准电视」，动作衔接自然。
- P3 $\rightarrow$ P4: 「对准」$\rightarrow$ 「按一按 $\rightarrow$ 画面变了」，因果关系成立。
- P4 $\rightarrow$ P5: 「变成动画」$\rightarrow$ 「再按一下 $\rightarrow$ 换个节目」，递进自然。
- P5 $\rightarrow$ P6: 「换了节目」$\rightarrow$ 「坐端正认真看」，从兴奋到静心，符合居家引导。
- P6 $\rightarrow$ P7: 「认真看」$\rightarrow$ 「看完了放回去」，收尾完整。
- P7 $\rightarrow$ P8: 「放回去」$\rightarrow$ 「辨认练习」。通过。

## 3. 简介清理
- 候选 1：「找找遥控器在哪儿，对着电视按一按，画面就变啦！遥控器，remote control！」
- 念读：节奏轻快，没有书面词，像在招呼孩子一起玩。通过。
