【页面结构设计】
目标单词: spring roll
页面数: 封面 + 8 内页

| 页序 | 类型 | 教学内容 | 视觉要素 |
|------|------|---------|---------|
| 封面 | 认知页 | 建立"spring roll=春卷"的第一印象 | 奶奶与孙女在桌前，超大目标单词 |
| P1 | 语境页 | 奶奶铺开春卷皮，认读 spring roll | 桌上铺着圆圆的皮，旁立彩色目标词 |
| P2 | 语境页 | 孙女在皮上放蔬菜，认读 spring roll | 孙女用小手放胡萝卜丝，目标词在旁 |
| P3 | 语境页 | 奶奶教孙女卷起来，认读 spring roll | 两人一起卷皮，目标词融入卷曲动作 |
| P4 | 语境页 | 卷好的春卷整齐排在盘里 | 一排白净的卷，目标词在盘边 |
| P5 | 语境页 | 奶奶把春卷放入热油锅 | 锅中滋滋作响，目标词在背景墙上 |
| P6 | 语境页 | 春卷在锅里变金黄，认读 spring roll | 金灿灿的卷在油中翻滚，目标词在旁 |
| P7 | 语境页 | 咔嚓！咬一口脆脆的春卷 | 孙女开心地咬一口，目标词在盘子旁 |
| P8 | 互动练习页 | 辨认长条形的春卷 | 春卷、薯条、蛋卷酥并排，认读 spring roll |

理解推进结构：连续推进（动作链：铺菜→卷起来→下锅→变金黄→咔嚓咬一口）。
最想翻页的一处：P5→P6，从下锅到瞬间变色（金黄），视觉冲击力强，期待结果。
参考排产号：B054 (9页), B711 (9页) -> 本本 8 页 (内页)。
角色确认：人类奶奶（银灰发髻，深红毛衣，围裙）+ 孙女（4岁，两个小辫，粉棉袄）。关系：祖孙（自然成立）。
安全纪律：油锅由奶奶操作，孙女只看，无溅油危险。
