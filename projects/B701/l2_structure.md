【页面结构设计】
目标单词: ketchup
页面数: 9页 (封面 + 8内页)

| 页码 | 类型 | 教学内容 | 视觉要素 |
|------|------|---------|---------|
| 封面 | 认知页 | 建立"ketchup=番茄酱"的第一印象 | 呼乎与爸爸在野餐，一个醒目的番茄酱瓶子 + 标题 |
| P1 | 语境页 | 爸爸从野餐篮里拿出番茄酱 | 红色挤酱瓶出现，认读 ketchup |
| P2 | 语境页 | 拧开瓶盖的动作 | 拧开盖子，认读 ketchup |
| P3 | 语境页 | 挤出红红的酱液 | 酱液挤在盘子里，认读 ketchup |
| P4 | 语境页 | 准备好金黄的薯条 | 盘子里堆着薯条，准备蘸酱 |
| P5 | 语境页 | 薯条蘸进酱里 | 一根薯条蘸满红酱，认读 ketchup |
| P6 | 语境页 | 尝到酸酸甜甜的味道 | 呼乎吃掉薯条，满足表情 |
| P7 | 语境页 | 分享给爸爸尝尝 | 爸爸也蘸了一根，两人开心 |
| P8 | 互动练习页 | 找找哪个是番茄酱瓶 | 红番茄酱瓶(尖嘴) vs 红苹果(圆果带叶) vs 红果酱罐(广口带勺)，认读 ketchup |

复核记录：
1. 角色：小狐狸呼乎 (橙红绒毛, 白围嘴, 蓬蓬尾巴) + 狐狸爸爸 (深红马甲)。同种动物亲子，关系自然成立。
2. 动作清单：
   - P1: 拿出 (爸爸) - 抓握 ✓
   - P2: 拧开 (爸爸) - 旋转/抓握 ✓
   - P3: 挤出 (爸爸) - 压力/抓握 ✓
   - P4: 摆放 (爸爸/呼乎) - 抓握 ✓
   - P5: 蘸取 (呼乎) - 抓握 ✓
   - P6: 咀嚼/品味 (呼乎) - 嘴部 ✓
   - P7: 递给/分享 (呼乎) - 抓握 ✓
   - P8: 指认/辨认 (呼乎) - 指向 ✓
   - 结论：狐狸前爪圆爪可抓握，所有动作可行。
3. 理解推进：拧开 → 挤出 → 蘸薯条 → 尝味。连续推进结构，孩子跟随动作链认识 ketchup。
4. 页数：封面 + 8内页。符合 B701 设定。
5. 干扰物：P8 设计红番茄酱瓶(尖嘴)、红苹果(圆果带叶)、红果酱罐(广口带勺)，形态可辨，满足约束。
