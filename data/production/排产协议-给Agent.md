# 排产清单执行协议（给创作 Agent 看的作业指导）

> 配套文件：`排产台账-3个月300册.csv`（本目录）。本协议 = 台账每行怎么变成一本绘本的完整作业流。
> 规则单源：一切创作规则以 `picturebook-creator` skill 为准，本协议只定义「台账 → skill 调用」的对接，不覆盖任何 skill 规则。

## 你是谁、怎么用这份台账

你是按台账批量生产领读绘本的创作 Agent。每次作业流程：

1. **领取批次**：从台账 `状态=待产` 的行里取连续 5-10 行（**同批次内链形建议不得重复**，相邻两本链形必须不同）
2. **加载 skill**：`~/.hermes/skills/picturebook-creator/SKILL.md`，领读模式路径 A/B
3. **逐册执行 L1→L4**，每册的输入从台账行读：

## 台账列 → 作业参数对照

| 台账列 | 用途 | 作业规则 |
|---|---|---|
| 排产号 | 册唯一 ID（B001-B300） | 写入该册所有产物文件名与 memory 日志 |
| 月 | 排产月份 M1/M2/M3 | 仅进度管理 |
| 核心词 | 本册唯一教学目标词 | 全部旁白规则围绕它：绑定形态唯一性、中文同现率 |
| 词型分类 | 决定链形与画面策略 | 名词=画面可指认；动词=动作链；疑问/人称=场景对话 |
| 绑定形态 | 全书中文末尾只绑这一块 | 见 anchor「绑定形态唯一性」；禁情态拼装/变体三连 |
| 标题草案 | **默认主标题** | 格式已合规（`《正译 · Word》`，§3.1 标题内容铁律）；L4 封面大小写按 l4-page-count-checklist 分级行 |
| 备选标题草案 | **仅当「库内撞名」列非空时启用** | 启用时必须过 §3.1 回译测试 + 大声读终检，不过就自拟合规变体（变体≤1） |
| 库内撞名 | 现有绘本库已有同词书 | 非空 = 换用备选标题，避免库内同名 |
| 链形建议 | 本册旁白递进链的起点方向 | 链形是**功能检查表不是填空模板**：可缺站、可换序、禁止凑站；相邻册禁同链形；实际使用链形若偏离建议，回写台账（见回写协议） |
| 画风建议 | L4 全局风格默认值 | 可被用户指令覆盖；同批次建议同一画风族（降低切换成本） |
| 状态 | 生产状态机 | 待产 → L3过 → L4过 → 已交付（每步回写） |

## 每册质量闸门（顺序执行，全过才算完成）

1. **L3 旁白**：8-12 句，全套 anchor 规则（五站链/禁介绍站/三许可/绑定形态唯一性/中文核心词同现率/中英对齐/问后必有真答案/结束感·落幕句）
2. **机械诊断**：`bin/narration_quality_check.py` 跑本册，必须全过（人工确认级提示可带章注明）
3. **自然语境终检**：整册大声读，「中国人会对孩子这么说吗」——任何铁律与自然语冲突，自然语赢
4. **批量反模板自检**：本批次内任意两册的链形实现、开头句式、落幕型不得相同；与上一批次末 3 册也不得同
5. **L4 生图提示词**：模型全局控制行（图片 5.0 Lite）、封面 3:4 / 内页 16:9、标题大小写分级行

## 回写协议（生产后必须回写台账行）

- `状态`：推进到实际到达的闸门
- 新增两列值（在行尾追加，不破坏原列序）：
  - `实际链形`：与建议不同时必填
  - `实际标题`：与草案不同时必填（含备选启用原因）
- 产物路径按 `references/huiben-project-layout.md`：`/home/luo/huiben-v2/<排产号>_<核心词>/` 目录，内含 `*_旁白.md`、`*_生图提示词.txt`

## 批量纪律

- 每个作业 session 只领 5-10 册，全部过完闸门并回写后再领下一批
- 同月内每条链形建议最多被「实现」6 次；实现时若发现某链形已在该月用满，主动换未用满的链形并回写
- 词库储备：`data/vocab/`（dolch.csv + fry_1-300.csv，共 422 词，台账用 300，剩 107 词为 M4+ 储备 + 15 个功能词不单独成册、走载体册浸泡）

## 红线（违反 = 本批作废重做）

- 禁跳过机械诊断直接交付
- 禁两册连续同链形同结构（换皮 = 模板化，用户一票否决项）
- 禁擅自改绑定形态列（那是按词型定好的教学锚点；确有更好的整块，先回写提案等人工确认）
- 禁在标题里扩展成句子/口号（§3.1 铁律 2，历史病灶《我会做》《样样都来做》已翻车）
