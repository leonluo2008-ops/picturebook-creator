我会使用 picturebook-creator 绘本创作技能，从需求确认开始。

这本采用**多场景整词领读**，让孩子跟着跳跳虎，在不同地方发现“空”。沿用你已给定的设定：

| 项目 | 本书设定 |
| --- | --- |
| 核心词 | **empty：空的，里面没有东西**，聚焦能直接看见的状态，不延伸到“心里空空”等抽象含义 |
| 年龄 | 4–5 岁 |
| 主角 | 跳跳虎 |
| 画风 | 柔和水彩 |
| 组织方式 | 不同场景独立呈现，不串成连续故事 |
| 领读方式 | 整词认读，自然重复 empty，不拆字母、不设拼读页；封面后直接进入场景 |

**篇幅建议：封面＋10 页内页。**可以用打开盒子看里面、把空桶倒过来、俯看空篮子等不同观察与动作，让“空”清楚可见，避免每页只换一个物件、重复同一句话。末页可安排一次找出空容器的小互动。

按这个词义范围和“封面＋10 页内页”来做，可以吗？确认后，我会给你包含封面和全部内页的逐页结构与具体画面。
