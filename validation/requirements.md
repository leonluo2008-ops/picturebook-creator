# 验收依据

来源优先顺序：用户当前要求及其提供的实际会话 > 本项目已确认创作交付约定 > 旧文件。题材名称仅用于测试，不成为通用规则。

| 编号 | 来源 | 抽取规则 | 验收方法 |
| --- | --- | --- | --- |
| R01 | 本聊天甲方最新整词要求 | 删除独立字母念读、词内拆读页；封面后直接语境 | 未见拆读页或为其保留的占位页 |
| R02 | 最新配色要求 | 单色或自由装饰色均可；不映射字母位置、词块或音节 | 审阅整本提示词，配色无字母级清单 |
| R03 | 批量出图约定 | 封面及内页一次完整输出，一段代码块 | 页面齐全，无分批单页指令 |
| R04 | wing 旁白讨论 | 英文按语法使用屈折；中文认读及独立标签用选定词头 | 复数语境不改成病句，标签不误加 s |
| R05 | empty 多场景、thirsty 状态讨论 | 按词义选择连续行动或多场景；相邻页状态有依据 | 不强塞情节；缓解不写成完全消失 |
| R06 | 重复开头及儿童用词反馈 | 动作、观察、声音自然起句；有意义反复可留；部位用儿童口语 | 连读全书，不是替换名词的填空题 |
| R07 | 标题及简介反馈 | 状态中性；简介取材定稿画面，不强制正面感受、问句、固定修辞 | 有真实页面依据，无虚构活动或效果承诺 |
| R08 | B293 导出消息 50、用户纠偏 | 完整定稿包含已选标题、封面行及全部旁白，展示后确认 → 简介选择 → 整本提示词确认 → 写 Notion | 多轮追踪，任何一轮不得合并跨越这些确认点 |
| R09 | B293 消息 33–49 | Agent 内部写完、文件存在、摘要展示不算用户已看全文 | 未展示文本时先补全文，不能用“已确认”标签前进 |
| R10 | B293 消息 24–25 | 跳过选项不算确认；明确“其余你安排”仅覆盖被授权事项 | 保存原始授权范围，不能推断成全阶段授权 |
| R11 | B293 消息 14 | 教学理解优先，不硬套“发现真好玩”的情绪 | 位置词需求表没有强制第一感觉字段 |
| R12 | B293 消息 14 篇幅选择 | 内页短 8–10、中 11–14、长 15–16；已有确切页数沿用 | 封面独立计数；新规格缺失时给建议供确认 |
| R13 | 既有 Notion 修订要求 | 读取完整原稿与备注；就地修订、保留附件及无关字段、独立回读 | 模拟错行/并发修改/部分失败；生产写入另实测 |
| R14 | 标准交付约定 | 授权生图且验收后完成打包、上传、状态与回读 | 无工具时报告缺口；提示词完成不称成图交付 |
| R15 | 本轮重构要求 | 标准技能目录、自包含、无历史规则副本，无生产环境硬编码 | 安装清单、相对引用和禁用路径检查 |

## 不作普遍规则的内容

单个角色、固定颜色、某本的 9 页、固定牌子与站位、固定开场和句式均只属于具体书。模型名、工作站路径、远程机器、SSH 通道和派活器技能不进入创作规则。
