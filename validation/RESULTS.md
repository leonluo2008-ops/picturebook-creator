## 修复依据

实际输出推动了这些一般性修正：中文认读词用小写词头并落在完整意群末尾；不逐页附同一句词义解释；未命名角色用自然名词称谓；状态改变有动作依据；互动有清楚行动邀请；L4 纯代码块在入口和对应参考明确，使用结构工具核对。没有把 Behind、Wing 或具体颜色写成技能规则。

台账工具测试覆盖分页、错行、并发文本/关联变化、表格宽度、保留英文/附件/状态、重复追加拦截、服务端无效写入、长文本合并回读，以及正文回读失败时不得推进状态。生产 API 和附件上传未在本任务运行。
