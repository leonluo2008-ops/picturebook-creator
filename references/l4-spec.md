# L4 生图提示词规格

> 输入：已确认的旁白表 + L1 锁定的风格锚点 + 参考图约定。输出：**一个**纯代码块。
> 依据：一致性两档〔裁定 R1〕；站位机位按需〔裁定 R3〕；旁白行双语〔裁定 R8〕；块序软硬见 §3（分布数字为〔假设〕，H7）。

## §1 输出形态（硬约束）

- **整篇提示词是一个连续不断的代码块**：开头一个围栏、结尾一个围栏，全文共两个三反引号围栏，一个不多一个不少。
- **代码块外不写任何文字**：无过渡句、无页数统计、无收尾说明。〔裁定〕
- 页与页之间只用**一个空行**分隔，不用其它分隔符；代码块内部不出现三反引号行、不写字号分隔线；内容再长也不许拆。
- **提示词正文里不出现任何链接 / URL / 取图说明**——生图方整块复制使用，混入即污染。参考图指路信息走归档页面的独立提及块（L5 `--asset`），永远不进提示词文本。〔裁定〕
- 不写 `--ar --style raw --v 6` 这类参数。

## §2 代码块内容结构（段落骨架）

> 对齐已交付样本（B633 / penguin，2026-11-13 归档）：整块提示词由**四个必备段落 + 若干按需段**组成，段与段之间空一行；段后接逐页记录。〔裁定·2026-11-23 所有者指定按 B633 结构对齐〕

### 段一：指令头（必备，固定 4 行）

任务定义 + 禁令 + 文字图形指令 + 一致性指令。**4 行句式逐字保留**，只替换书名、目标词、主角与场景名：

```
我会给你一段文字，是领读文案和对应的生图提示词，请提取生图提示词，按封面、P1至P8的顺序生成图片。
旁白供领读参考，中文翻译和内页英文整句不入画。封面只渲染正式英文标题，内页只渲染完整目标词 <word>。
目标词是大型彩色拼贴图形，整词连写、自然字距，作为插画的一部分，不作为小字幕。
每次生成前回看已生成页面，保持同一<主角>、同一<核心场景>与一致画风。
```

（第 1 行的「P1至P8」按本书实际页数写。）

### 段二：【全局设计约定】（必备，9 个字段）

| # | 字段 | 写到什么程度 |
|---|---|---|
| 1 | `目标单词:` | 核心词，小写 |
| 2 | `中文释义:` | 标准义项（与 L1 锁定的一致） |
| 3 | `目标年龄:` | 如 `3–4岁` |
| 4 | `画面风格:` | **材质级**：风格名 + 技法材质（如「染色纸剪贴、可见刷痕与纸边」）+ 整体色彩氛围，不只写风格编号名 |
| 5 | `文字风格:` | 字体形态 + 完整词大小写 + 长词载体策略 |
| 6 | `主角外观:` | 统一外观描述（体型/毛色分区/五官/肢体），声明全书固定；有参考图时按 §3 第 5 类两档写 |
| 7 | `动作约定:` | 主角能做的动作清单 + 不做的事（如「不持物，不添加人类手掌」） |
| 8 | `站位约定:` | 各典型动作下身体与载体/地面的接触关系 |
| 9 | `机位约定:` | 与主体同高平视/侧视、俯仰角度上限、关键部位完整可辨 |

### 段三：【全书文字与配色】（必备）

每页入画文字规则（只出现完整词、字色与载体对比、不按字母位置分色）+ 封面文字焦点规则 + 无中文/音标/拆字/教学说明。

### 段四：【主要场景锚点】（必备，3–5 个）

覆盖文案中所有出现场景；同一间屋子/同一条街只立一个锚点，别拆成多个。每个锚点写「场景名：外观细节 + 与其它锚点的空间关系」。

### 按需段

- **【参考图约定】**（有定妆参考图时才加）：

```
【参考图约定】
图像1 = 用户传回的[角色名]定妆参考图，是角色一致性的最终依据；图像2 = 第二个角色（如有）。
外观特征: [从定妆图提炼 2–4 个关键特征，每页的「角色一致性」行复用同一串]
排除项: 定妆图里的道具 / 文字 / 标识 / 背景一律不入书——除非本书目标动作正好要用那件道具，此时写明「本书核心道具即图像1中的 X，从封面起登场，全书同一外观与大小」
```

- **【站位与机位约定】**（按需，见 §4）：全局约定段；与 §4 的关系是——这段是全局版，§4 要求「要写就全局加约定 + 当页正文再写一遍站位」，两处配套，只写全局、页内不写会漏。

### 逐页记录模板

```
页序: 封面
旁白: 封面（[中文标题] / [英文标题]）
比例: 3:4
页面类型: 认知页
入画英文: ["<封面入画的英文，即书名>"]
生图提示词: [完整提示词，按 §6 封面要求；末段写「构图要求: …」收尾]

页序: P1
旁白: [英文文案] / [中文文案]
比例: 16:9
页面类型: [认知页 / 语境页 / 词族拓展页 / 互动练习页]
入画英文: ["<本页入画英文词>"]
生图提示词: [完整提示词，末段写「构图要求: …」收尾]

[以此类推，每页一条记录]
```

字段说明：

- **`入画英文:` 逐页必备**：给生图端做文字开关用（中控台「常用指令」口径：只渲染每页入画英文数组中的字符串；另见 B615 / pen，2026-11-22 归档样本）。**注意：`入画英文` 没有任何脚本解析**，不是机检项，靠人工核对。
- **`页序:` 逐页必备**（`页序: 封面` / `页序: P1` …）：封面与每页都要写，便于人工对页与逐页定位。〔裁定·2026-11-23 所有者指定「每本都带 页序: P1」〕**注意：`页序` 没有任何脚本解析**，不是机检项，靠人工核对。
- **`构图要求:` 不是独立一行**：它是该页 `生图提示词:` 这一段话的**结尾分句**，写在同一行末尾（机检 `scripts/l4_presence_check.py:72-73` 在「构图要求」处切分取场景段、`scripts/notion_verify.py:190` 按每页恰好 1 次计数，写在同一行照样解析）。不要教它单独占一行。

### 段落必备清单

| 段落 | 必备还是按需 | 缺了会怎样 |
|---|---|---|
| 指令头（4 行） | 必备 | 生图端拿不到任务定义、禁令与一致性指令，跨页一致性无约束 |
| 【全局设计约定】9 字段 | 必备（9 个字段都要） | 缺中文释义/动作/站位/机位字段时，生图端对动作与机位自由发挥，跨页漂移 |
| 【全书文字与配色】 | 必备 | 文字呈现与配色无全书口径，逐页随机 |
| 【主要场景锚点】（3–5 个） | 必备 | 场景无锚点，跨页场景不一致 |
| 【参考图约定】 | 按需（有定妆图才加） | 缺失时 §3 第 5 类退到「无参考图」档 |
| 【站位与机位约定】 | 按需（见 §4 判定） | 涉及水平面/够高/遮挡的页会站错位 |
| 逐页 `入画英文:` | 必备（逐页） | 生图端文字开关无依据；机检不校验，漏了靠人工核 |
| 逐页 `页序:`（`封面` / `P1` …） | 必备（逐页） | 人工对页与逐页定位无依据；机检不校验，漏了靠人工核 |
| 逐页 `构图要求:`（在生图提示词行末） | 必备（逐页） | `notion_verify.py:190` 每页恰 1 次断言失败；无安全区约束 |

### 机检兼容说明（2026-11-23 实测，写规范时据此对齐）

- `scripts/notion_archive.py:567` 用 `场景锚点[:：]\s*([^\n，,]+)` 抓锚点（锚点名后紧跟逗号会被截断）；`:571` 依次按 `旁白[:：]`、`构图要求[:：]`、`比例[:：]` 三标签解析。
- `scripts/l4_presence_check.py:72-73` 在「构图要求」处切开，取**前半段**做目标词「在不在」检查——所以 `构图要求:` 写在 `生图提示词:` 同一行末尾不影响解析。
- `scripts/notion_verify.py:190` 数每页 `构图要求[:：]` 出现次数，要求**每页恰好 1 次**——一页写两次构图要求会挂回读。
- **`入画英文` 与 `页序` 没有任何脚本解析**（全仓 `*.py` grep 零命中，2026-11-23 实测）：它们是给人和生图端用的，不是机检项。

### 字段格式（三处易错）

- **`旁白:` 行必须「英文 / 中文」双语**：英文在前、中文在后，用 ` / ` 分隔。例：`旁白: This coin is money. / 这枚小硬币是钱，coin。` **纯英文行不合规**；机审按 `/` 前为英文、`/` 后为中文解析。〔裁定 R8〕
- **封面行例外**：写成 `封面（[中文标题] / [英文标题]）`——中文在前、英文在后（与内页相反），脚本按此解析。〔裁定 R8〕
- **`旁白:` 与 `页面类型:` 行都不写页码前缀**：页码由 `页序:` 行体现（该行逐页必备）；`页面类型:` 只写四种页型之一。〔裁定〕

## §3 每条提示词内部结构（六类 + 构图要求；块存在性必查，顺序不强制）

> **硬的是「六类信息（下面 1–6）每类都要写到 + 每条末尾必须带『构图要求』（第 7 项，单独计，不属于六类）」，软的是排列顺序**——按当页可读性安排，不为凑顺序牺牲句子通顺。〔假设〕块序分布：「完整块序（角色一致性 → 场景一致性 → 构图要求）」133/243（单轮盘点，未在证据文件复核，详见 `rules.md` §10 H7）；含「角色一致性」135/243、含「场景一致性」144/243。

1. **镜头类型 + 视角**：简洁明确（平视近景 / 中景 / 俯角 ≤15°…）。
2. **场景描述**：主体、动作、环境。
3. **全局风格锚点**：来自 L1 确认的风格，每条都写，不用固定文字。
4. **目标词图形化**：目标词作为大型彩色图形元素融入画面（字体、颜色、大小、位置、与场景的融合方式），文字即图形。每页写出**实际入画的完整词、载体和排法**；画面有多个词时按词安排载体或留白。
5. **角色一致性（两档，按本书有没有定妆参考图决定，不混用）** 〔裁定 R1〕：
   - **有定妆参考图**（【参考图约定】锚了图像1/图像2）：**不重复长外观描写**，写「图像引用 + 2–4 个关键特征串」——`角色一致性: 严格以图像1为准（关键特征：圆耳 / 橘色短毛 / 白肚皮）`；多角色写「角色1以图像1为准（…）、角色2以图像2为准（…）」。关键特征只取该角色**最容易被画错的 2–4 项**（耳形、毛色分区、有无角/翅/尾、服装标志），不抄全身描述——外观的完整描述只在【全局设计约定】写一次；每页再抄一遍等于给模型多一个改设定的入口。关键特征串有两个作用：跨页防漂移，以及图挂掉时退化成纯文字锚。
   - **无参考图**：**每页必须写统一外观描述**（体型/毛色/五官/服装），否则跨页必崩。
6. **场景一致性**：同样两档——有参考图且场景由该图锁定时，写 `场景一致性: 延续图像1的场景设定，本页为<场景锚点编号/名>`；无参考图时逐页点名场景锚点（`场景一致性: 锚点1 洗手间`）。
7. **构图要求（每条末尾，单独计，不属于六类）**：固定句式与三要素见 `rules.md` §8；高危部位按当页主体点名。

## §4 站位、机位与动作指代（按需 · 布局自洽）〔裁定 R3〕

场景里只有台面/桌面/架面时，那一面就是画面里唯一的水平面——不写角色站在哪儿，模型就把角色摆到那个面上。布局不是风格问题，它在提示词层面就能预防。

- **不是每页都必写**：只有当页涉及「台面/水盆/架面等水平面、角色需要踮脚或够高够远、同框多主体、角色与道具存在高度或前后遮挡关系」时才写；纯空景、单主体大场景可以不写。判定问法：这一页的动作要它完成时，脚踩在哪、手够不够得着——答不上来就必须写。
- **要写就全局加「站位约定」＋「机位约定」，并在当页正文再写一遍站位**。站位约定写清：角色站在什么载体上（地面/矮凳/椅子）、明确不站在哪些面上（台面、水盆、架子）、站直时与目标物件的高度关系、落在画面左三分之一或右三分之一。机位约定写：与被摄主体同高平视，上下浮动不超过 15 度，不俯拍角色头顶、不仰拍台面底部。只写全局、页内不写，模型会在个别页漏掉。
- **可达性先验**：Q 版头身比 1:1 的角色站地上够不到台面、水盆，先给它垫脚载体（矮凳、脚凳），把凳子写进场景锚点，并在每页构图要求的危险点里点名凳腿（最低点）。
- **不用相对指代**：「另一只圆爪」「原来贴着的那一面」「左边那个」依赖前文，模型看不到前文只能猜。改写方向：只写动作真正用到的那只爪（「一只圆爪按住勺柄」）；需要两只时用对称写法（「两只圆爪一左一右包住苹果」）；指位置锚画面（「画面右侧的台面」），指物件自身锚它自己的方位（「苹果朝下的那一面」）。
- **不用否定式指令**：「朝向画面外侧、不指向任何一件东西」会被反向执行成「指着某件东西」。改写成正向可画的描述：「抬起的圆爪停在半空、掌心朝向镜头」。
- **俯拍会压扁 Q 版头身**：桌面/台面页容易顺手写「俯视 30 度」，出来角色只剩一个头顶。要交代桌面内容就压到 15 度以内，靠物件自身的位置关系交代布局。
- 布局与 `rules.md` §8 是一套的两半：安全区管主体别被裁掉，站位机位管主体在场景里站得住。

## §5 文字融入图（文字即图形）

目标词出现在内页的方式是**画面的视觉元素**，不是字幕：文字＝和角色、草地、帽子一样的「图」；大而醒目、色彩鲜明、有设计感；呈现方式与整体画风融合（Eric Carle 拼贴风里，字母本身就是彩色几何色块）。

| 页面类型 | 目标词呈现方式 |
|---|---|
| 封面 | 核心词作为场景化设计概念的视觉焦点（见 §6），与角色发生互动，不是飘在画面顶部的大字 |
| 语境页 | 目标词以大型图形元素自然融入场景（竖立在草地上的彩色字母牌、拼贴在角色身上的字母等） |
| 词族拓展页 | 各完整词配小图；英文列是词表，可用易读装饰色，不单独标示词尾 |
| 互动练习页 | 目标词以图形元素入画；画面同时给出干扰物，让读者靠细节找出答案 |

### 画面文字形态门禁（每页必查）

**画面英文采用当页确认的完整词形和大小写。**

| 位置 | 文稿形态 | 画面形态 |
|---|---|---|
| 封面（完整词形） | Title Case（Floor / Rabbit） | 跟随正式英文书名 |
| 语境页 / 互动页 | 小写 water | 小写，禁 WATER |
| 词族页词标签（door / floor） | 小写 | 小写——独立展示的标签取词典词头形态，不因「标签」而大写 |

写法纪律：

- 整词图形页，提示词里的词**从当页旁白行复制**，不凭记忆敲——凭记忆敲出来的常是「印象中的大写醒目形态」。
- **每页提示词必须写出目标词的字面形态**（照抄当页旁白行的小写词），不许用「小写字形」「整词字形」这类占位描述代替：生成模型只渲染写出来的字母，占位描述骗得过机审、画面却拿不到要画的词。
- **颜色服务画风和可读性**：完整词可以单色，也可以多彩字面装饰；提示词只写整体色彩效果与可读性，避开按字母位置、音节、拼读块或词尾分色；多彩字形始终保持完整词的自然字距和清楚轮廓。
- **特写页也要给目标词一个落脚载体**：桌面/台面特写没有立大字的空间时，把词落到一件小载体上（桌上的小纸牌、瓶身标签、工具柄），并在当页把载体写死——只写「画面里有 fold」而不说词写在哪儿，模型常常整页一个字母都不给。
- 中文列夹用的目标词跟随英文列同形态（封面 Title Case 行跟随，普通句夹用一律小写）。

> **形态 ≠ 存在**：门禁只校「这个词出现的地方形对不对」，整页压根没写目标词时照样能过。所以另有一道逐页「在不在」检查（`gates.md` §2 第 3 道）：取每页「生图提示词:」到「构图要求:」之间的**场景描述段**（不含安全区句，那里提到词不算入画），断言里面出现目标词字面；封面按书名行人工核对。

## §6 封面

封面是整本的门面，单独一套规范：**视觉层级 → 文字与场景共同设计 → 背景与一致性 → 提示词组织顺序 → 出图验收与停止条件**，见 `cover-design.md`。

L4 封面条只多两条硬要求：

- 「旁白：」行写 `封面（中文标题 / 英文标题）`——只写核心词本身、不标明是封面页、不带标题，会误导生图模型。〔裁定〕
- 封面主文字是**英文标题，且必须用引号包裹才渲染**（为什么：见 §7）；封面不出现任何中文字样，中文标题只留台账档案与 `旁白:` 行。〔裁定〕
- **核心词 = 场景化设计概念，不是排版要求清单**：写成「标题醒目 + 核心词超大」的要求清单，模型会交出「顶部横幅 + 大字 + 居中角色」的标准识字卡构图。为封面设计一个核心词融入场景的画面概念，让字母与角色发生互动（字母当装置：堆成拱门框住自己、挂在字母架上、排成正在跨越的桥；字母当环境：长在花茎顶端的字母花、被角色推着的字母船；标题找场景载体：大白云、木质招牌、角色拉开的横幅）。概念必须过角色可行性——封面动作也要在 L1 动作清单的覆盖范围内。

## §7 即梦引号机制

- **引号包裹的文字会被逐字渲染到画面**；不包裹的文字会被当成描述性指令。这条决定两处写法：
  - **封面英文标题必须用引号包裹**。裸写「英文标题 XXX 作为封面主文字」会被模型当描述略过，画面只剩核心词图形。正确写法：`英文标题"<英文标题全文>"以手绘感圆润字体写在<场景载体>上`。
  - **内页目标词用描述性语言**表达，不要用引号包裹（「画面中央有一个超大 cat 彩色拼贴图形，字形随当页旁白形态」）。
- 反例：用引号包裹完整句子 → 字幕式文字被渲染到画面。

## §8 写法示例（片段的形态，不是模板）

```
旁白: A little cat on a mat. / 小猫咪坐在垫子上，cat。
比例: 16:9
页面类型: 语境页
入画英文: ["cat"]
生图提示词: 平视近景。小猫蜷在蓝色圆垫上打盹，旁边的浅色宽木牌写完整小写 "cat"。文字用柔和的多彩拼贴装饰，整词一行连写、字距自然，字与木牌对比清楚。构图要求: 小猫、圆垫和木牌都完整入画，四边留出净空，背景地面与墙面自然延伸填充到画面边缘。
```

一句一页、五字段齐全（含 `入画英文:`）、`构图要求:` 作为 `生图提示词:` 行的末段写在同一行，就是合格形态；词、颜色、画面仅用于说明写法。
