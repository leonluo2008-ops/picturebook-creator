# 领读绘本·常用短语系列批量模式

> 2026-06-04 建立，基于 Excuse me / Let go / Me too / My god / Come on / Come down / Happy birthday / Stop / Hold on / See you / Well done 实战经验。

## 系列特点

- 无词族：短语类目标词不适用词族扩展页，全部用语境页
- 核心词放置：中文旁白中核心词的位置必须符合中文语境自然读法（2026-06-04 用户反复纠正）
- 多场景语境：同一个短语在不同场景中出现，展示其多种用法
- 统一中文核心词：每个短语选一个固定的中文释义作为核心词，在旁白中统一使用

## 核心词中文放置规则（2026-06-04 反复纠正提炼）

### 问题
用户在 Me too、Stop、Hold on、See you、Well done 等多本中反复纠正："核心词出现的位置要符合中文语境，不能读起来别扭"。

### 根因
把英文短语机械翻译成中文塞进句尾，导致中文句子不通顺。

### 规则
1. **先写流畅的中文句子**，再把英文核心短语自然附加在句尾
2. **大声读一遍测试**：如果读起来打磕巴或不通顺，就调整位置
3. **短语核心词可以灵活变通位置**：不一定要在句尾，可以在句中、句首，只要中文本身流畅
4. ❌ "慢慢 go！" / "我的 lion！" / 硬塞进不自然位置
5. ✅ 先保证中文完整流畅 → 英文核心词作为自然补充

### 示例

| 短语 | ❌ 不自然 | ✅ 自然 |
|------|----------|--------|
| Me too | 你也喜欢吗？me too！ | 你也喜欢吗？我也是！me too！ |
| Stop | 红灯啦，Stop！ | 红灯啦，要停！Stop！ |
| Hold on | 抓紧，Hold on！ | 别松手，等一等！Hold on！ |
| Well done | 我做到了！Well done！ | 我做到啦，做得好！Well done！ |

## 结尾页设计偏好轮换

避免连续多本用同一种结尾类型。轮换顺序参考：
- 互动型 → 惊喜型 → 感叹型 → 数数型 → 鼓励型 → 情感型 → 寻找型 → ……

## ⚠️ 填空式结尾页的中文核心词陷阱（2026-06-04 实测纠正）

**问题**：当结尾页使用填空模式（如 My name is ___! / I like ___!）时，容易只写英文填空而**忘记中文核心词也要出现**。

**错误示例**：
> "你叫什么名字呢？该你了——My name is ___!"（中文缺"我叫"❌）

**正确做法**：
> "你叫什么名字呢？该你了——我叫___！My name is ___!"（中文核心词"我叫"保留✓）

**规则**：填空式结尾的中文旁白，**中文核心词必须出现在填空前**（如"我叫___"），英文短语同样填空。双语同现规则在填空页同样适用。
