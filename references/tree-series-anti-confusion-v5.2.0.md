## 一、为什么需要本文件

主题树系列（L4 反混淆铁律）是用户反复反馈的关键铁律。每种树都有 2-3 个"非它不可"的视觉特征，AI 模型默认画树是"棕干+绿叶球+圆冠"的通用模板，导致：

- 榕树 → 被画成普通圆冠乔木（缺下垂气根）
- 白桦 → 被画成粗褐树干（缺白色底+黑皮孔）
- 椰子树 → 被画成笔直棕榈（缺弯曲细干+羽状大叶）
- 山楂 → 被画成苹果树（缺尖刺+裂叶）

→ 必须在 L4 ⚠️ 反混淆铁律段显式列 3-4 条核心标志防画错。

## 二、17 棵树的反混淆铁律速查表

### 1. 樟树 Camphor Tree
- **常绿大乔木**（秋冬不落叶）
- 圆球状墨绿色大冠
- 叶有清香
- 红红色小浆果挂枝头

### 2. 榕树 Banyan Tree
- 粗褐色主干
- 宽展浅绿圆冠
- **下垂气根（多条从枝条垂下的须状根，部分落地形成"次生干"）**
- "独木成林"形态（一棵主树周围有气根落地形成的小树阵）

### 3. 白桦树 Birch Tree
- **白色树干**（不是粗褐色）
- **黑色横向斑点纹路（皮孔）密布**（像眉毛一样）
- 树干**纤细挺立**（不粗壮）
- 三角/卵三角形锯齿叶
- 秋色金黄

### 4. 桂花树 Osmanthus Tree
- 圆头冠形（不收尖成塔形）
- **满簇橙黄色小花**（不是白色/粉红/红色）
- **小花 4 瓣聚生**（豆粒大小）
- 常绿不落叶

### 5. 杉树 Chinese Fir
- **宝塔形/三角锥形树冠**（自下而上明显收尖成圆锥尖头）
- 红褐色笔直树干（粗壮笔直不弯曲）
- **长条深绿针叶**（短硬密生）
- 树皮有纵向裂纹肌理

### 6. 椰子树 Coconut Tree
- **细长弯曲树干**（带 S 形弯曲，不笔直挺立）
- 顶端一束 **6-8 片羽状大复叶**（不是单片大叶，呈长条羽状分裂）
- 长圆形/近圆球形大椰果（褐色粗糙外壳）
- 常绿乔木，热带海岸线

### 7. 橄榄树 Olive Tree
- **灰白色粗壮扭曲树干**（常带拧结扭转，不笔直）
- **银绿色细长椭圆叶片**（叶面银绿，叶背银白，两面色差明显）
- 椭圆形小橄榄果（绿色未熟/紫黑色已熟）
- 地中海岸典型常绿小乔木

### 8. 桃树 Peach Tree
- 张开姿态树形（树冠开阔不收尖）
- 翠绿**披针形细长叶**
- **粉色五瓣桃花**（花叶同枝）
- **毛茸茸圆形桃果**（粉红/红色带绒毛）

### 9. 梨树 Pear Tree
- 张开姿态树形（树冠有层次不收尖成塔形）
- **翠绿卵形/椭圆形大叶**（比桃叶大而圆，边缘细锯齿）
- 白色五瓣梨花（伞形花序）
- **葫芦形/倒卵形梨果**（底部常有凹陷，黄绿/金黄色）

### 10. 柿子树 Persimmon Tree
- 张开姿态树形
- 卵形/椭圆形大叶（叶面有光泽）
- **夏绿秋红叶色变化**（核心时序特征）
- **橙红色扁圆形大柿果**（顶端有 4 瓣花萼宿存，底部扁平）

### 11. 苹果树 Apple Tree
- 张开姿态树形（树冠开阔有层次）
- 翠绿卵形/椭圆形大叶（叶缘细锯齿）
- 粉白色五瓣苹果花
- **圆形红苹果**（顶端花萼凹陷明显，底部有花梗突出）

### 12. 樱桃树 Cherry Tree
- 张开姿态树形
- 翠绿卵形/椭圆形大叶（**叶柄常有腺体**）
- 粉色/白色五瓣樱花（伞房/总状花序）
- **红色小圆樱桃**（带长果梗，每颗常成对挂枝）

### 13. 橙子树 Orange Tree
- **常绿小乔木**（一年四季不落叶）
- 张开姿态的圆球形树冠
- 深绿卵形/椭圆形大叶（叶面有光泽）
- 白色五瓣小花（花香浓郁）
- **圆形橙黄色柑橘果**（带短果梗，皮有细点肌理）

### 14. 山楂树 Hawthorn Tree
- 张开姿态小乔木
- **枝条木质茎上有红褐色尖刺**（核心识别标志）
- **深绿裂叶**（叶片有 3-7 道深裂缺口）
- 白色五瓣小花成簇开（伞房花序）
- **红色小圆球状山楂果**（成簇挂枝，每颗 1-2 厘米）

### 15. 石榴树 Pomegranate Tree
- 张开姿态小乔木或灌木
- **嫩绿披针形叶**（细长椭圆，不是圆/椭圆整叶）
- **火红/橙红皱瓣花**（花瓣皱缩像皱纹纸）
- 圆形石榴果（顶端 4-6 裂萼片宿存像皇冠）
- 果内密布红色透明多汁籽粒

### 16. 香蕉树 Banana Tree
- **高大粗壮绿色假茎**（不是木质树干，是叶鞘抱合形成，可见横向年轮状纹理）
- 顶端一束**长椭圆形大绿叶**（每片大到 2-3 米长）
- **紫红色大花苞下垂**（像倒挂的紫红心形）
- **成串弯月形金黄香蕉**（放射状梳齿排列，从中央下垂果梗长出）
- 注：实际是热带大型多年生草本"树"，不是真木本

### 17. 荔枝树 Lychee Tree
- 常绿小乔木，张开姿态
- **偶数羽状复叶**（小叶对生，2-4 对小叶组成）
- 米黄小花穗（细长圆锥花序）
- **红色粗糙外壳小圆形果**（外皮有软刺状凸起）
- 果肉白色半透明

## 三、L4 ⚠️ 反混淆铁律标准格式

每本主题树绘本的 L4 输出，必须包含以下标准格式的 ⚠️ 段（直接套用上面的 3-4 条核心标志）：

```
⚠️ 反混淆铁律（请严格执行）：与一般[植物类型]区别：[树名]必须呈
① [特征 1]
② [特征 2]
③ [特征 3]
④ [特征 4]
四个核心标志；不可画成 [反模式 1] / [反模式 2] / [反模式 3] / [反模式 4]。
```

### 范例（apple tree）
```
⚠️ 反混淆铁律（请严格执行）：与一般阔叶乔木区别：苹果树必须呈
① "张开姿态树形（树冠开阔有层次，不收尖成塔形）"
② "翠绿卵形/椭圆形大叶（叶面有光泽，叶缘细锯齿）"
③ "粉白色五瓣苹果花（花序成簇，先花后叶或花叶同枝）"
④ "圆形红苹果（顶端花萼凹陷与花梗突出明显，底部常有花萼残存）"
四个核心标志；不可画成圆球密冠或宝塔形树冠；不可画成披针细长桃叶；不可画成葫芦形梨果；不可画成扁圆形柿果。
```

## 四、3 棵易混树的快速对照

### 桃 vs 梨 vs 苹果（都是温带果树 + 椭圆/卵形大叶 + 春季白花）
| 特征 | 桃树 | 梨树 | 苹果树 |
|------|------|------|---------|
| 树形 | 张开不收尖 | 张开有层次 | 张开有层次 |
| 叶形 | 披针细长 | 椭圆/卵形（比桃叶大） | 椭圆/卵形 |
| 花色 | 粉色 5 瓣 | 白色 5 瓣 | 粉白色 5 瓣 |
| 果形 | 圆球（带绒毛） | 葫芦/倒卵（底部凹陷） | 正圆（顶端花萼凹陷） |

### 柑橘类快速对照（橙子/柠檬/橘子）
- 共同：常绿 + 圆球树冠 + 白色小花 + 圆形柑橘果
- 区分主要靠果色（橙/黄/绿）和果形（圆/椭圆/扁）

### 桦树 vs 樱树 vs 桃树（都是白花 + 椭圆叶）
| 特征 | 桦树 | 樱树 | 桃树 |
|------|------|------|------|
| 树皮 | **白色+黑皮孔** | 红褐/灰褐 | 灰褐 |
| 树形 | 笔直高大 | 张开小乔木 | 张开小乔木 |
| 叶形 | 三角锯齿 | 椭圆细长 | 披针细长 |
| 花色 | 黄绿色柔荑花序 | 粉/白 5 瓣 | 粉 5 瓣 |

## 五、风格适配（蜡笔/S14 波普）

反混淆铁律在三档风格下都生效：
- **蜡笔手绘童趣风**：肌理/色彩/形状都按上面的特征画，蜡笔笔触保持
- **S14 波普艺术**：色块平涂 + 半色调网点 + 高对比撞色，但**形状/轮廓仍按反混淆铁律**（半色调化处理但不变形）
- **S06 Eric Carle 拼贴风**：色块剪贴 + 简单图形，**识别标志仍要保留**

## 六、新主题树补充流程

新主题树绘本开始 L4 时：

1. **查表**：本表是否已收录？是 → 直接套用本文件
2. **新词**：本表未收录 → 用 web 搜索该树的 3-4 个核心识别标志（树形/叶/花/果/树皮）
3. **写 ⚠️ 段**：按标准格式输出
4. **L4 自检**：在生图提示词字段内多次复述反混淆标志（"红褐色尖刺明显""白色树干+黑皮孔"等）
