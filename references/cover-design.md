# 儿童领读绘本封面设计规范 · Codex

适用：领读绘本 L4 封面及用户要求的封面重设计。依据用户认可的 B328 paint 封面提炼；这是本项目的设计约定，位置比例是构图起点，不是通用审美定律。

## 视觉层级

先设计封面，再组织文字和人物。封面需要在缩略图中传达书名、核心词与动作主题，不能直接把一张内页加上标题。

1. 第一眼：英文书名和核心词。
2. 第二眼：主角与目标词含义相关的动作。
3. 第三眼：场景和必要道具。

主标题默认落在画面上半部，视觉中心以距顶约35%—45%为起点；核心词应是书名中最醒目的部分。标题字形的实际重心比载体中心更重要；根据词长、角色与载体调整，不强求精确38.2%。避免标题被放到下方桌面、透视压扁或被角色遮住。

## 文字与场景共同设计

完整英文标题放进一个与主题相关的载体：画布、书页、风筝、树牌等。载体应提供清楚、正对或接近正对的可读面。按主题选，不固定每本都用画架。

标题可以自然分成两行：短引导语较小，核心词较大；优先让完整书名中的核心词承担主视觉，不额外重复一个同样巨大的核心词。标题与画面采用一致的描线、材质与色彩语言。封面保持纯英文，中文标题仅留在文稿与台账；提示词明确写出并用引号包裹完整英文书名。

角色通常位于下半部或侧下方，以视线、手势、工具方向把读者引向标题。互动必须表现核心词含义，而不是单纯站在字旁边。角色可小于标题载体，但五官和动作仍须辨认清楚。

## 背景与一致性

角色采用已确认参考，鼻子、嘴巴等已有五官必须保留；检查发型、服装、体型是否属于同一个角色。定妆参考的白底只服务于外形识别，正文与封面背景按场景独立设计。

背景服务于标题和动作。只保留能解释主题、建立空间或支持动作的物件；不为填空增加墙饰、圆形色卡等无关装饰。背景自然铺满四边，标题和角色周围保留呼吸空间。

所有关键元素处于中央约80%安全区，四边约10%余量由背景延伸填充。具体点名标题两端、载体边角、人物最高点和脚部等易裁切位置。

## 提示词组织顺序

封面用途与比例 → 主题视觉概念 → 标题全文及层级 → 标题载体、位置与尺度 → 角色位置及与文字的互动 → 已确认外观和五官 → 必要场景与道具 → 画风 → 裁切安全区。

关键布局使用相对画面的位置和比例表达，但不把整幅画机械切成固定网格。只写当本需要的约束；字母配色为参考，不因轻微色差反复重出。

## 出图验收与停止条件

把图缩到约200—300像素宽检查：能否先读出书名和核心词，再看清主题动作？再看全图：标题是否被压到底部、人物五官是否完整、是否出现无关装饰、是否有裁切和遮挡。

拼写和关键词形、角色一致性、完整五官、主题动作可理解、主要视觉层级是检查重点。机器 PASS 不代表封面设计合格。通过后保留，不因细微配色或动作接触点偏差反复重出；用户有具体要求时按该项修正。

## 已验证构图示例：paint

一张竖立的大画布承载两行书名，上行 Let’s，下行超大 Paint!；标题位于上半部。小女孩在左下方拿画笔朝画布伸出，以动作连接主题和字形。画架与少量颜料杯交代绘画场景，米色墙和木地板完整铺边。复用其视觉层级、主题互动与干净背景，不复刻每个坐标、道具或配色。
