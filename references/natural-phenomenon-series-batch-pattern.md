# 自然现象类领读绘本批量模式参考

> 适用目标词：sunshine（阳光）/ storm（暴风雨）/ dew（露珠）/ rain（雨）/ wind（风）/ snow（雪）/ cloud（云）/ fog（雾）/ thunder（雷）/ lightning（闪电）/ breeze（微风）/ frost（霜）/ mist（薄雾）等。
>
> **核心特征**：这些词都是**抽象自然现象**（不是具体物品/动物/人物），无固定角色出镜，无明确词族，每页 = 该现象的一种场景/形态/状态。

---

## 1. 路径选择（默认走 B 无人称路线）

> 用户实测触发（sunshine/storm 2026-07-19）：用户从未要求固定角色，每页主体 = 现象本身或其场景。

| 目标词 | 推荐路线 | 主体 |
|------|--------|------|
| sunshine / rainbow | B 无人称 | 太阳光线 + 各种洒光场景（草地/窗户/海面） |
| storm / thunder / lightning | B 无人称 | 乌云 + 闪电 + 雨滴 + 风线 |
| dew / frost / mist / fog | B 无人称 | 露珠 + 各种承载物（叶尖/花瓣/草尖/蜘蛛网） |
| rain / snow | B 无人称 | 雨滴/雪花 + 各种场景（窗户/伞/海面） |
| wind / breeze | B 无人称 | 风线 + 被风吹动的事物（树叶/风车/头发/旗帜） |
| cloud | B 无人称 | 云朵 + 各种形态（卷云/积云/乌云/云海） |

**例外**：当用户明确要求"加一只小动物 / 小朋友"作为观察者时，可在结尾页或情感型语境页出镜 1 只作为尺度对比。

## 2. L2 页面结构（默认 10 页 = 1 封面 + 9 内页）

> 与 scenery 系列（10 页公式）相同。每页 = 现象的**一种状态/场景**。

```
| 页码 | 类型 | 教学内容 | 视觉要素 |
|------|------|---------|---------|
| 封面 | 封面页 | 标题 + 现象主视觉 | 现象最具辨识度的形态（如太阳+光芒、乌云+闪电） |
| P1   | 认知页 | "现象=词" 第一印象 | 超大目标词 + 现象核心图形 |
| P2-P8 | 语境页 × 7 | 现象的 7 种不同状态/场景 | 每页一种新形态或新场景 |
| P9   | 结尾互动页 | 寻找 / 对比 / 收束 | 多种现象形态集合 |
```

**场景选材维度**（避免模板化，每个目标词从 5 维度里挑 7 个组合）：
1. **时间**：清晨 / 正午 / 黄昏 / 夜晚
2. **空间**：户外 / 室内 / 水面 / 高空 / 城市 / 自然
3. **状态**：出现 / 持续 / 消散 / 结束
4. **承载物**：草地 / 花朵 / 树叶 / 窗户 / 海面 / 山顶 / 屋顶
5. **情感**：温暖 / 热闹 / 安静 / 神秘 / 猛烈

**已验证示例（sunshine 实测 2026-07-19）**：
- P2 草地光斑 / P3 花瓣光 / P4 清晨窗户 / P5 雨后彩虹 / P6 晒太阳的猫 / P7 海面波光 / P8 拥抱阳光 / P9 找一找

**已验证示例（storm 实测 2026-07-19）**：
- P2 黑乌云 / P3 闪电 / P4 大雨 / P5 大风 / P6 海面风暴 / P7 风暴走远 / P8 雨后彩虹 / P9 找一找

## 3. L3 旁白铁律（实测高优先级 · P48 + P49 通用铁律）

### 3.1 中文核心词贯穿密度铁律（P49 · 🔴 P0）

- **每一句中文旁白都必须显式包含目标词的中文标准译名**（不只是英文目标词）
- storm 实测：原版"黑乌云来了" → 修正为"暴风雨带来黑乌云"
- sunshine 实测：原版"黄色的阳光" → 修正为"金色的阳光"（金色+阳光双词共现）
- **修复路径**：
  1. 中文核心词作为主语（"暴风雨带来黑乌云"）
  2. 中文核心词作为介词短语主语（"暴风雨里有闪电"）
  3. 中文核心词作为句首引领词（"暴风雨啊，闪电亮"）

### 3.2 中文旁白末尾只留核心词铁律（P48 · 🔴 P0）

- **末尾 = `[完整中文翻译] + 逗号 + 核心词 + 中文标点`**
- ❌ `金色的阳光，golden sunshine。` → ✅ `金色的阳光，sunshine。`
- ❌ `暴风雨里闪电闪，lightning in the storm。` → ✅ `暴风雨里闪电亮，storm。`
- **中英文标点严格对应**：`.` → `。` / `!` → `！` / `?` → `？`

### 3.3 中文核心词标准化铁律

- 目标词的中文译名全书 9 句必须一致（不能 5+4 混搭）
- storm → 全用"暴风雨"（不混"风暴""风雨""暴风雨儿"）
- sunshine → 全用"阳光"（不混"日光""太阳光"）
- dew → 全用"露珠"（不混"露水""露"）

### 3.4 句式多样性（避免 9 句模板化）

**禁止全用一种骨架**（如 9 句全"X带来Y"）：
- 推荐骨架混搭：
  - "X带来Y"（2-3 句）
  - "X里/上/中有 Y"（2 句）
  - "Y 让 X" 或 "X 让 Y"（1-2 句）
  - "X 慢慢 Y"（1 句，用于消散/结束型）
  - 末句"找一找 X"互动型（1 句）

**storm 实测最佳骨架组合**：
1. "暴风雨 STORM！"（封面）
2. "暴风雨带来黑乌云，storm。"（P2）
3. "暴风雨里闪电亮，storm。"（P3）
4. "暴风雨哗哗下大雨，storm。"（P4）
5. "暴风雨呼呼吹大风，storm。"（P5）
6. "暴风雨扑向大海，storm。"（P6）
7. "暴风雨慢慢走远了，storm。"（P7）
8. "暴风雨后挂起彩虹，storm。"（P8）
9. "找一找暴风雨，storm。"（P9）

## 4. L4 生图提示词约定

### 4.1 主体描述（无固定角色）

- 不需要"主角外观"字段
- 每页主体就是现象本身或其场景
- 风格锚点 = Eric Carle 拼贴风（色块鲜明）

### 4.2 配色调性

| 目标词 | 主色调 | 强调色 |
|------|------|------|
| sunshine | 暖金 + 柠檬黄 + 暖橙 | 浅蓝天空、翠绿草地 |
| storm | 深灰 + 黑色 + 亮黄闪电 | 深灰紫天空 |
| dew | 浅绿 + 银白 + 透明 | 翠绿叶、粉花瓣 |
| rain | 蓝色 + 深蓝 + 灰 | 灰云、绿草地 |
| snow | 纯白 + 浅蓝 + 灰 | 暗绿树、暖橙屋顶 |
| wind | 灰白 + 浅蓝 + 翠绿 | 飘飞叶子 |
| cloud | 白 + 浅灰 + 浅蓝 | 各种天空色 |
| fog | 浅灰 + 白 + 透明 | 模糊背景 |

### 4.3 反文字污染（必须）

- 全局约定 + 每条末尾加"绝对禁止其他文字"声明
- 字母数 ≤ 6（sunshine 8 / storm 5 / dew 3 / rain 4）→ sunshine 是高风险，需最强警告
