# 台账（Notion）运维 · 写入与改稿的坑

配套脚本：`scripts/notion_archive.py`（归档）、`scripts/notion_verify.py`（独立回读）、`scripts/asset_ref.py`（资产关联）。本文件只记**写台账时**的工具层规矩，创作口径见 SKILL.md。

## 1. PATCH 表格行：cells 必须给满列

- 载荷形状是「每格一个 rich_text 数组」的数组：`{"table_row":{"cells":[[{"type":"text","text":{"content":"P3"}}],[...英文...],[...中文...]]}}`
- **cells 数量必须等于表格宽度**，没改的列也要原样带上（`页码`/`英文`/`中文` 三列的表就写三个）。少给一格 → 400 `validation_error: Number of cells in table row must match the table width`。
- 每格多套一层数组 → 400 `cells[0][0] should be an object`。
- 只改某一页的中文时，先把该行现有英文/页码读出来再拼载荷，别凭记忆重写别的列。

## 2. 长代码块只改几个字：按原分段重建，不整块重写

L4 全文通常是一个 code 块（5000+ 字符，内部已切成多段 rich_text）。做「改标题 / 改封面字母形态」这类小改时：

1. 读块，取每段 `plain_text` 拼成全文；
2. 在全文上做字符串替换；
3. 按**原各段长度**重新切片；
4. 每段带上各自原来的 `annotations`，再 PATCH `code.rich_text`。

整块重写成单段会撞 Notion 单段长度上限，并丢掉段尾换行造成粘行。

## 3. 残留断言要落到位置，别对整篇做子串否定

替换后验证「改干净了」时，整篇 `assert "旧词" not in 全文` 会误报——旧词可能合法地留在场景描述里（旧地名仍可作画面设定）。断言写成位置化的：

- `assert "<新封面旁白行>" in 全文`（新值确实进去了）
- `assert "<旧英文标题字符串>" not in 全文`（只对标题这类唯一字符串做清零断言）

## 4. 状态推进失败 ≠ 归档失败：不要重跑归档

归档脚本最后一步「状态 → 待生图」可能因网络瞬断抛异常、脚本以非 0 退出，但**正文块与回读校验早已成功**。此时：

- 不要重跑归档（会写出重复的 code 块 / 表格，形成两份并排的老新段落）；
- 单独 PATCH `状态` 并回读确认；再跑一次 `notion_verify.py --word <词> --pages <页数>` 做独立回读。

## 5. 改稿与终止的动作口径

- 只改用户点名的项，不顺手改相邻页/相邻句（越权改稿会被打回）。
- `备注` 整段覆盖，不追加历史；状态 `修改中` = 打回待改，改完仍留 `修改中` 等复审。
- 放弃一本：状态置 `弃用`（select 选项里已有）+ 备注写终止原因；不删页面，排产号保留、不占生产队列。
- **简介与旁白中文列都不进画面**：改它们不需要重做已生成的图，状态可以留在 `已制作`。改了封面英文标题/画面文字形态才涉及重做。

## 6. 批量写一律带重试

一次会话要打几十次 API 时，把 `api()` 包成 3–5 次重试、退避 1.5s×n 再跑；瞬时 SSL/URLError 在这条链路上是常态，重试即可通过。一次性的清块/归档脚本单独跑，输出读全量（不要接 `| head` / `| tail`）。

## 7. 资产行改名：脚本没有 rename，走 PATCH 标题

`scripts/asset_ref.py` 只有 `--list / --name / --download / --link-word`，改名直接调它的 `_req`（老版头 `ASSET_API_VERSION` 已内置）：

```python
import asset_ref as ar
ar._req(f"/v1/pages/{pid}", "PATCH",
        {"properties": {"资产名称": {"title": [{"type": "text", "text": {"content": "新名"}}]}}})
```

- **改名即改匹配键**：`--name` 按「资产名称」精确匹配，改完旧名查不到、新名才查得到；relation 挂在 page id 上，改名不影响已挂的排产行，回读 `--list` 确认「关联排产」仍在。
- 发现错别字**先改名再归档/挂链**——错名一旦写进交付说明或归档记录，之后每本都要跟着解释一遍。
