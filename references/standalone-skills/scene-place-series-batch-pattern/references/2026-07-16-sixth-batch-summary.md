## 6 个新反模式

### 反模式 #17：中文旁白拗口语化修复铁律（2026-07-16 island + cinema 实测触发）

> 用户原话："旁白拗口" / "修改旁白拗口的短发" / "旁白不好"。

**触发信号**：用户说"拗口/别扭/不自然/口齿不清" → 整本中文旁白必须做拗口修复。

**5 步拗口修复法**：

1. **大声朗读每行中文旁白** → 找出具体不顺耳的音节位置
2. **避免"形容词+量词+名词"倒装**：
   - ❌ "岛屿阳光真好" → 主谓不清 → ✅ "岛屿阳光明媚"
   - ❌ "沙漠星空闪亮" → 缺主语 → ✅ 保留主语在句首
3. **避免生硬短语拼凑**：
   - ❌ "小船靠岸" + "小动物在跑" + 多个简单堆叠 → ✅ 整句主谓宾清晰
4. **加入具体动词代替抽象形容**：
   - ❌ "岛屿阳光明媚"（静态）→ ✅ "岛屿阳光明媚"（已 OK，无需动词）
   - ❌ "沙漠黄黄的"（叠词）→ ✅ "黄色的沙漠"（主语+形容词）
5. **末句必须有动作收束或具体形容词收束**：
   - ❌ "岛屿真好玩"（任意） → ✅ 保留具体形容词"阳光明媚"

**正反对照表（island 实测）**：

| 第一版（拗口）| 第二版（拗口修复）|
|------|--------|
| "岛屿在海里"（生硬）| "岛屿坐在大海里"（拟人化） |
| "岛上有树"（短促）| "岛屿上有高高的树"（主语完整+形容词） |
| "岛上有沙滩"（短促）| "岛屿上有软软的沙"（主语完整+形容词） |
| "海浪拍打小岛"（与核心词不一）| "海浪拍打岛屿"（核心词统一） |
| "小岛阳光明媚"（小岛与核心词不一）| "岛屿阳光明媚"（核心词统一） |

### 反模式 #18：末句双收束模式 A+B 组合（2026-07-16 多本实测沉淀）

> 当一本场景类领读绘本的最后一句想同时表达"美感形容词收束"+"互动引导收束"两种功能时，传统的"挑一句做结尾"会让两种功能都丢失。**解决方案：双收束模式 (A型+ B型)**。

**A+B 双收束模式**：

| 模式 | 英文 | 中文 | 功能 |
|------|------|------|------|
| **A 型：形容词氛围收束** | The X is adj. | X 真 adj | 静态美感 |
| **B 型：互动引导收束** | Find the X! | 找一找 X 在哪里 | 引导小孩翻找 |

**实测案例**：

- **woodland**（无角色本）：A 型 P8 "The woodland is quiet" + B 型 P9 "找一找林地里有什么"
- **airport**（无角色本）：A 型 P8 "The airport is busy" + B 型 P9 "找一找飞机在哪里"
- **school**（有角色本）：A 型 P8 "I love school" + B 型 P9 "找一找学校在哪里"
- **factory**（有少量角色）：A 型 P8 "The factory is very big" + B 型 P9 "找一找工厂在哪里"
- **mansion**（无角色豪宅型）：A 型 P7 "What a beautiful mansion" + B 型 P8 "找一找大厦在哪里"
- **cave**（无角色型）：A 型 P7 "The cave is cool" + B 型 P8 "找一找洞穴在哪里"
- **waterfall**（无角色型）：A 型 P7 "The waterfall is beautiful" + B 型 P8 "找一找瀑布在哪里"

**判断标准**：如果用户说"再要一个互动结尾"或"结尾互动感不强" → 在 A 型前加一个 B 型（找一找页），让 A+B 双型收束成为本本标配。

### 反模式 #19：抽象感官形容词必须视觉化（2026-07-16 waterfall + cave + desert 多本实测触发）

> 用户原话："哗啦啦流下" + "声音响" + "热热的" + "凉凉的" → 旁白里有大量抽象感官形容词时，**即梦 AI 会画出"模糊色块小人"或"无耳朵/无烟囱结构"**。

**触发信号**：L3 旁白里有"声音响/真吵闹/哗啦啦/热热的/凉凉的/风轻轻"等抽象感官形容词。

**修复方案**：把抽象感官**视觉化**为可识别的图形符号。

| 抽象感官 | 视觉化符号 |
|---------|-----------|
| **声音响/真吵闹** | 金黄色色块音乐符号 + 白色色块声音波纹 + 橙色色块喇叭状扩散 |
| **哗啦啦流下** | 大量白色色块飞溅水花向上跳 |
| **起水雾** | 白色和浅蓝色色块蓬松雾气向上升起像棉花糖 |
| **热热的** | 几根橙红色色块热浪线条从沙面升起扭曲画面 |
| **凉凉的** | 白色和浅蓝色色块小星点（凉意符号）从洞口向外飞 |
| **暗暗的** | 洞内深蓝色+深灰色+深紫色调对比，仅洞口射入浅黄色阳光 |

**L4 提示词写法（waterfall P2-P3 实测）**：

```
画面中央是浅蓝色和白色色块拼接的水流从山顶急速冲下来的特写——
白色色块飞溅水花从水帘与水面交界处飞散，几只鲜艳的浅蓝色和白色色块水点向上跳，
金黄色色块"哗啦"声音符号点缀在画面中，体现了"哗啦啦流下"的动感。
```

**判断标准**：L4 提示词中要找 "loud/noisy/quiet/cool/hot" 之类的词 → 必须把每一种抽象形容词在画面描述里转化为可视的几何图形（线条/波纹/星点/飞溅），避免 AI 走"模糊色块"路线。

### 反模式 #21：多介词切换打破模板化（2026-07-16 island + mansion 实测触发）

> 用户连续反馈"模板化" → 即使每句旁白都用了不同的主谓结构，如果所有"X of/in/on/at + 目标词"介词短语都用同一介词（如"in the X"用 7 次），仍会读起来模板化。

**触发场景**：L3 旁白用了 ≥3 个"介词 + the X"句式且所有介词相同 → 必须切换介词轮换。

**推荐介词轮换表**：

| 英文介词 | 中文译法 | 适用场景 |
|---------|---------|---------|
| **in the X** | 在 X 里 / X 里 | 内部空间 |
| **of the X** | X 的 | 所属关系 |
| **on the X** | 在 X 上 | 表面/顶部 |
| **at the X** | 在 X 处 | 方位/位置 |
| **by the X** | 在 X 边 | 旁边 |
| **around the X** | 绕着 X | 环绕 |
| **through the X** | 穿过 X | 穿越 |
| **over the X** | 飞过 X | 上空 |
| **at the front of the X** | 在 X 前 | 前方 |

**island 第一版（"in the X"全用）vs 第二版（5 种介词轮换）**：

| 第一版（同一介词 in）| 第二版（多介词切换）|
|------|--------|
| Boats stop in the island | Boats stop at the island（停泊处 at） |
| Fish swim in the island | Fish swim around the island（环绕 around） |
| Birds fly in the island | Birds fly over the island（上空 over） |
| Waves lap in the island | Waves lap around the island（环绕 around） |
| Trees grow in the island | Trees grow on the island（表面 on） |

**L3 自检升级**：每张表输出后 → 数不同介词数量 → ≥3 种介词 = 通过；<3 种 = 触发反模板化重写。

## 实测要点速查

### 1. mansion 反模式 #14 核心词融入铁律（每句必现）
所有 9 句旁白 = 9 次 mansion 出现 + 中文"大厦"也出现 9 次 = 100% 双同现。L3 输出前逐行圈核心词核对。

### 2. mansion 反模式 #15 模板化重写触发（5 维检测 + 5 维句式多样）
5 维检测（形态/静态动态/物体社交/形容词/末句独立）+ 5 维句式多样（感叹/陈述/祈使/主语/句首）= 整本重写触发条件。

### 3. mansion 反模式 #16 用户指定维度重写（"请从大厦的形状特征来写"）
6 维形状特征矩阵 = 整体大小 / 顶部形状 / 墙面元素 / 入口形状 / 支撑结构 / 连接方式 / 氛围收束。每个维度对应 1 页旁白。

### 4. quay vs harbor 易混淆规则（2026-07-16 实测沉淀）
- **quay** = 栈桥式码头（栈桥从岸边伸入海面 + 系缆桩 + 缆绳 + 彩旗 + 上下客货）
- **harbor** = 海港综合体（航站楼 + 集装箱 + 吊车 + 灯塔 + 多种大船）

### 5. cave 灯光氛围处理（cave 实测新沉淀）
洞穴内部以深蓝/深灰/深紫为主调，仅洞口射入浅黄色阳光——这是 cave 区隔于其他自然景观的独有灯光氛围，不能简单套用 woodland 或 mountain 的明亮配色。

### 6. waterfall 鱼角色完整性铁律（waterfall P6 实测新沉淀）
> 反模式 #12 已沉淀"鸟类/松鼠 4 部件完整" + "飞机 5 部件" + "建筑 4 部件"，waterfall 新增"鱼 3 件套"（圆身子+大尾巴+三对小鱼鳍）。

### 7. waterfall 飞溅水花 + 声音波纹视觉化（waterfall P3 实测触发）
水流从上冲下的页面 = 必须有大量白色色块飞溅水花 + 金黄色色块"哗啦"声音符号点缀，把抽象声音"哗啦啦"视觉化为几何图形。

### 8. cave 钟乳石/石笋安全滤镜规则（cave 实测触发）
钟乳石用"尖尖的"不写"锋利的"——这是 cave 实测强化版反 AI 过滤词的反馈，避免即梦拦截。

### 9. desert 白天/夜晚双调（desert 实测新沉淀）
白天：亮黄沙+橙红太阳+亮蓝天空；夜晚：深蓝+深紫色块夜空+亮黄色块星星。两种调性出现在同一本里 = 既有生机又有安静氛围。

### 10. island 反模式 #20 中文核心词"小+X"变体禁用铁律
启用本批新增的统一核心词铁律，所有场景类绘本立刻可复用。
