# 场景/地点/自然景物领读系列批量模式

> 2026-07-12 起：场景类目标词（水景/山景/基础设施/室内空间）的标准化批量模式。
> 与 flower-series / furniture-series / animal-series 并列的子类批量模式。

## 子类划分

| 子类 | 目标词示例 | 共性 |
|------|----------|------|
| **水景** | river / lake / stream / waterfall / pond | 蓝绿色蜡笔色块 + 流动感 + 岸边生态 |
| **山景/自然景观** | mountain / forest / sky / woodland / desert / cave / island / jungle | 大场景全景 + 多层色块 + 远景元素 |
| **基础设施** | path / bridge / road / quay | 人工建造物 + 功能性 + 互动场景 |
| **室内空间** | room / living room / bedroom / kitchen / bathroom / bookstore | 房间内景 + 家具/物品罗列 + 角色互动 |
| **校园/公共建筑** | farm / zoo / canteen / restaurant / gymnasium / art room + 疑问类 What / Who + 形容词类 tall / long + cinema / school / library / airport | 全景→多物件罗列→全景热闹→找一找结尾 4 段式；The X has a Y 句式 + The X is fun 收束模板 |
| **交通/集散枢纽型** | airport / harbor / station / quay | 大空间 + 双向进出（来/去）+ 标志性锚点（塔台/灯塔/钟楼/系缆桩）+ 远景透视展开 |
| **工业/工艺型** | factory | 工人 4 件套 + 声音波纹视觉化 + "运转"动作 + 安全/温和滤镜 |
| **居住建筑-豪宅/特殊型** | mansion | 6 维形状特征矩阵 + 反模式 #14 核心词融入铁律 + 反模式 #18 末句双收束模式 |

（详细 63 本完整表格已迁移至 references/2026-07-16-sixth-batch-summary.md）

> **子类 5 真实归属说明**：What / Who 疑问词逻辑上是疑问副词而非建筑，但都跑在"公共场景 + 多物件罗列"模板里，归到子类 5 的**疑问场景型**。tall / long 是形容词而非建筑，但同样跑了"全景→多景罗列→找一找对比"结构，归到子类 5 的**形容词场景型**。
>
> **子类 6 详解**：airport / harbor / station / quay 三个独有特征 = 双向进出动作 + 标志性锚点 + 远景透视展开。
>
> **子类 7 详解**：factory 独有特征 = 工人 4 件套（黄色安全帽+深蓝背带裤+橙黄上衣+圆滚滚身子）+ 声音波纹视觉化 + 多步生产链展示。
>
> **子类 8 详解**：mansion 独有特征 = 6 维形状特征矩阵（整体/顶部/墙面/入口/支撑/连接）+ 反模式 #14 核心词融入铁律 + 反模式 #18 末句双收束。

## 设计要点（四大子类通用）

### 子类 1：水景

**共同特征**：水面 = 浅蓝绿色蜡笔色块 + 白色水波纹 + 鹅卵石 + 水中动物

**独有特征**（避免模板化）：
| 目标词 | 独有特征 | 必做特色页 |
|--------|---------|-----------|
| river | 宽+长+船+鸭 | 流动远景+船+鸭 |
| lake | 蓝+平静+荷叶+天鹅 | 蓝+倒映青山+天鹅 |
| stream | 窄+清澈+桥+蝴蝶芦苇 | 窄/清澈对比+桥+蝴蝶 |
| waterfall | 高+白色水流+飞溅+彩虹+小鱼 + 飞溅水花 + 金黄声波视觉化 | 仰视水流+起雾+彩虹+小鱼水潭下 |

**易混淆点**：river ≠ lake：river 长而流动，lake 圆而平静；stream ≠ river：stream 窄而流，river 宽而流；lake ≠ pond：lake 大且蓝，pond 小且有荷叶。

### 子类 2：山景/自然景观

**独有特征**：
| 目标词 | 独有特征 | 必做特色页 |
|--------|---------|-----------|
| mountain | 高+尖顶+绿+雪+登山 | 高+绿+雪+登山+看风景 |
| forest | 树多+蘑菇+动物脚印 | 树/蘑菇/鸟/松鼠/落叶/小鹿/脚印 |
| sky | 蓝+白天夜晚双场景 | 蓝/云/太阳/月亮/星星/彩虹/鸟 |
| woodland | 绿绿的+大树+蘑菇+花+鸟+松鼠 | 一棵粗壮树干+蘑菇+花+鸟+松鼠 |
| cave | 暗暗+大洞口+钟乳石+石笋+蝙蝠+大熊 | 暗厅+洞口射入阳光+钟乳石/石笋+蝙蝠+大熊 |
| desert | 黄黄+沙丘+热+仙人掌+骆驼+夜晚星空 | 黄沙+沙丘+仙人掌+骆驼+夜晚星空+绿洲 |
| island | 海中+树+沙滩+海鸟+小鱼+阳光 | 岛屿坐海中央+高树+软沙+海浪+海鸟+小鱼+阳光 |
| jungle | 茂密大树+藤蔓+鸟+猴子+老虎+小河 | 大树+藤蔓+鸟唱歌+猴荡秋千+虎走路+小河 |

**易混淆点**：mountain ≠ hill；forest ≠ jungle；sky ≠ ceiling；cave 灯光氛围独有；desert ≠ jungle 仙人掌/热带植物；island ≠ jungle。

### 子类 3：基础设施（path/bridge/road/quay）

**quay vs harbor 易混淆**：quay = 栈桥式码头（栈桥+系缆桩+缆绳+彩旗），harbor = 海港综合体（航站楼+集装箱+吊车+灯塔+多种大船）。

### 子类 4：室内空间（room/living room/bedroom/kitchen/bathroom/bookstore）

以室内场景 + 家具/物品特写为主。kitchen ≠ bedroom / bathroom ≠ bedroom 等易混淆。

### ⚠️ 反模式 #11：场景类"无固定主角"路线选择铁律（2026-07-16 woodland / airport 实测沉淀）

> **本会话实测**：woodland（自然景观）和 airport（公共建筑）两本场景类波普艺术绘本，用户全程没有对"无固定主角"提出异议，默认接受"每页物体 / 风景元素自己当主体"。

**默认铁律（2026-07-16 why 实测强化）**：
- **场景类目标词默认无固定角色**：除非用户在 L1/L2 明示"用 X 当主角"，否则**让"景物+符号元素"做主体**，不放小狐狸/小朋友/小动物贯穿全书
- **抽象疑问词更要走无角色路线**：why / how / when 等疑问副词的"P3-P8 提问页" = 不要硬塞提问者小动物，让"自然现象本身+大问号符号"承担画面
- 替代方案：用大面积色调 + 大符号（问号/花朵/建筑）替代小角色的视觉权重

**判断标准**：
- 用户 L1/L2 中**没说**"主角是 X"/没指定角色 → 不放角色
- 用户 L1/L2 **说了**"用橙色小狐狸当主角"/"用小朋友做主角" → 走有角色路径

**决策矩阵**（L2 设计前必跑）：

| 目标词特征 | 推荐路线 | 示例 |
|----------|--------|------|
| **自然景观**（林地/田野/森林/海滩/山谷/草原）| **无固定主角** | woodland/forest/fields/crops |
| **大型公共空间**（机场/海港/火车站/公园/广场）| **无固定主角** | airport/harbor/station |
| **抽象疑问词**（why/how/when/where）| **无固定主角** + 符号元素（问号）贯穿 | why |
| **室内商业空间**（电影院/超市/餐厅/书店/商场）| **少量角色互动**（P7-P8 出 1 个小动物）| cinema/restaurant |
| **教育/医疗/服务类**（学校/医院/图书馆/美术馆）| **1-2 个固定角色**（学生+老师/医生+病人）| school/library |
| **居住建筑**（家/公寓/别墅）| **无人出镜** | apartment/house |
| **小村庄/小镇** | **无人出镜 + 多建筑并排** | village/small town |

### ⚠️ 反模式 #12：场景类"主角完整性 + 元素完整性"双轨铁律（2026-07-16 实测强化）

**陷阱 A：鸟类/小型动物 = 色块化无细节（woodland P6 实测）**

> ❌ AI 输出："几只鲜艳撞色色块小鸟" → 全是纯色块圆点
> ✅ 修复 L4 提示词模板：
> ```
> 亮蓝色和黄色色块羽毛的小鸟（圆身子+小尖嘴+两对小翅膀+细长小脚完整可见），停在棕色色块树枝上
> ```

**陷阱 B：飞机 = 5 部件缺失（airport P3-P9 实测）**

> ❌ AI 输出："鲜艳的小飞机停在跑道" → 只有机身没机翼/尾翼/机轮/舷窗
> ✅ 修复 L4 提示词模板（**5 部件缺一不可**）：
> ```
> 红色和白色色块拼贴的机身（圆筒形）+ 小三角机翼 + 小巧的尾翼 + 两只小机轮 + 一排小舷窗完整可见
> ```

**陷阱 C：建筑 = 缺门窗/屋顶（school P2 实测）**

> ❌ AI 输出："彩色校舍建筑" → 只有墙面没有屋顶/门窗细节
> ✅ 修复 L4 提示词模板（**建筑 4 件套**）：
> ```
> 完整墙面 + [颜色] 色块三角形屋顶 + 白色色块大窗户 + 深蓝色色块大门 + 几个小窗
> ```

**L4 全局约定必加字段**：

```
⚠️⚠️ 元素完整性铁律：
- 鸟类 = 圆身子 + 小尖嘴 + 两对小翅膀 + 细长小脚 完整可见
- 松鼠/小动物 = 圆身子 + 两只小耳朵 + 两只大眼睛 + 四只小爪子 + 蓬松大尾巴 完整可见
- 飞机 = 圆筒机身 + 三角机翼 + 尾翼 + 两只机轮 + 一排舷窗 完整可见
- 建筑 = 完整墙面 + 屋顶 + 大窗户 + 大门 + 小窗 完整可见
禁止出现纯色块/无细节/缺部件的主体。
```

### ⚠️ 反模式 #13：场景类"老师/医生/馆员"角色 4 件套铁律（2026-07-16 school 实测触发）

**L4 全局约定必加字段**：

```
⚠️ 专业人士角色一致性：
- 老师 = 圆脸 + 圆框黑色边框眼镜 + 棕色色块络腮胡子 + 深蓝色色块西装外套 + 橙黄色色块衬衫（4 件套不可少）
- 医生 = 圆脸 + 鲜白色医生大褂 + 鲜蓝色衬衫 + 灰色裤子 + 白色鞋子
- 馆员 = 圆脸 + 鲜绿色围裙或工作服 + 米白色衬衫
- 厨师 = 圆脸 + 白色高顶帽 + 白色大褂 + 红色围巾 + 棕色鞋子
- 司机 = 圆脸 + 鸭舌帽 + 深蓝色制服 + 黑色手套
```

**表情分页差异化**：同一位专业人士出镜 2 页及以上时，每页的表情和动作必须不同。

### ⚠️ 反模式 #14：每一句旁白都要融入核心词铁律（2026-07-16 mansion 实测新增 · 最高优先级）

> 用户原话："每一句旁白都要融入核心词"

**目标词的"双同现"判定标准**：
1. **英文同现**：每行英文旁白包含完整英文目标词（mansion 不能缩成 the big house）
2. **中文同现**：每行中文旁白包含完整中文释义（"大厦"——不能被"它/这里/那里"替换）
3. **逐行核对**：用方框圈出每行的目标词 → 1:1 对应 = 通过

**修复策略（A 或 B 二选一）**：
- **A. 主语化**：The mansion is tall. → 大厦高高的
- **B. 介词短语化**：The big door of the mansion stands wide. → 大厦的大门敞开着

**修复案例（mansion 第二版 vs 第一版）**：
- "The mansion has many windows." → "So many windows in the mansion!"
- "The mansion has a big door." → "The big door of the mansion stands wide."

### ⚠️ 反模式 #15：场景类旁白"模板化"重写触发铁律（2026-07-16 cinema + mansion 连续实测）

> 用户原话："旁白有些模板化" / "格式不对" / "请重写"

**触发信号（任何一条 = 立即重写）**：
- ✅ "旁白模板化" / "太机械"
- ✅ "格式不对" / "格式没对"
- ✅ "请重写" / "重新组织语言"
- ✅ "再说一遍" / "重新来"
- ✅ 连续 2 轮用户还在反馈不够好 = 立即整本重做

**5 维反模板化重写法**：
1. 形态 vs 颜色 vs 触觉
2. 静态 vs 动态 vs 动作
3. 物体 vs 社交 vs 场景
4. 形容词总量（≤3 处）
5. 结尾独立维度

### ⚠️ 反模式 #16：用户指定维度重写规则（2026-07-16 harbor + mansion 实测新增）

> 触发信号：用户在 L3 阶段明示"请从 XXX 特点/作用/形状来写"

**强制规则**：
1. 明确识别用户指定的维度（特点/作用/形状/颜色/声音/触感）
2. 每页旁白必须从该维度出发
3. 维度子项矩阵化展开
4. 每个子项对应一页旁白
5. 末句用维度的总体收束

### ⚠️ 反模式 #17：中文旁白拗口语化修复铁律（2026-07-16 island 实测触发 · 第六波新增）

> 用户原话："旁白拗口" / "修改旁白拗口的短发" / "旁白不好"

**5 步拗口修复法**：
1. **大声朗读每行中文旁白** → 找出不顺耳音节
2. **避免"形容词+量词+名词"倒装**：❌ "岛屿阳光真好" → ✅ "岛屿阳光明媚"
3. **避免生硬短语拼凑**：❌ "小船靠岸 + 小动物在跑" → ✅ 整句主谓宾清晰
4. **加入具体动词代替抽象形容**：❌ "沙漠黄黄的"（叠词）→ ✅ "黄色的沙漠"（主语+形容词）
5. **末句必须有动作收束或具体形容词收束**

**正反对照表（island 实测）**：

| 第一版（拗口）| 第二版（拗口修复）|
|------|--------|
| "岛屿在海里"（生硬）| "岛屿坐在大海里"（拟人化） |
| "岛上有树"（短促）| "岛屿上有高高的树"（主语完整+形容词） |
| "海浪拍打小岛"（与核心词不一）| "海浪拍打岛屿"（核心词统一） |

### ⚠️ 反模式 #18：末句双收束模式 A+B（2026-07-16 第六波新增）

> 当一本场景类领读绘本的最后一句想同时表达"美感形容词收束"+"互动引导收束"两种功能时的解决方案。

**A+B 双收束模式**：
| 模式 | 英文 | 中文 | 功能 |
|------|------|------|------|
| **A 型：形容词氛围收束** | The X is adj. | X 真 adj | 静态美感 |
| **B 型：互动引导收束** | Find the X! | 找一找 X 在哪里 | 引导小孩翻找 |

**实测案例**（8 本稳定复用）：woodland/airport/school/factory/mansion/cave/waterfall/island 等都走 A+B 双型收束。

### ⚠️ 反模式 #19：抽象感官形容词必须视觉化（2026-07-16 waterfall/cave/desert 实测触发）

> 触发信号：L3 旁白里有"声音响/真吵闹/哗啦啦/热热的/凉凉的/风轻轻"等抽象感官形容词

**视觉化对照表**：

| 抽象感官 | 视觉化符号 |
|---------|-----------|
| 声音响/真吵闹 | 金黄音乐符号 + 白色声波 + 橙色喇叭状扩散 |
| 哗啦啦流下 | 大量白色飞溅水花向上跳 |
| 起水雾 | 白色+浅蓝色蓬松雾气像棉花糖 |
| 热热的 | 橙红色热浪线条从沙面升起扭曲画面 |
| 凉凉的 | 白色+浅蓝色小星点（凉意符号）从洞口向外飞 |
| 暗暗的 | 洞内深蓝+深灰+深紫色调对比，洞口射入浅黄色阳光 |

**L4 提示词写法（waterfall P2-P3 实测）**：

```
画面中央是浅蓝色和白色色块拼接的水流从山顶急速冲下来的特写——
白色色块飞溅水花从水帘与水面交界处飞散，几只鲜艳的浅蓝色和白色色块水点向上跳，
金黄色色块"哗啦"声音符号点缀在画面中，体现了"哗啦啦流下"的动感。
```

### ⚠️ 反模式 #20：中文核心词"小+X"变体禁用铁律（2026-07-16 island 实测触发 · 反模式 #5 升级版）

> 反模式 #5 锁定"核心词中文译名每句必现"。**反模式 #20 新增：核心词中文译名不允许出现"小+X"等变体**。

**禁用清单**：

| 目标词（中文标准译名）| ❌ 禁用变体 |
|------|------|
| island 岛屿 | 小岛 |
| cave 洞穴 | 小洞/小山洞 |
| mountain 山 | 小山 |
| lake 湖泊 | 小湖 |
| forest 森林 | 小树林 |
| waterfall 瀑布 | 小瀑布 |
| desert 沙漠 | 小沙漠 |
| jungle 丛林 | 小丛林 |

**L3 自检升级**：每行中文旁白出来后 → 圈出该行核心词中文译名 → 对照禁用清单逐项核对 → 不一致 = 立即替换。

### ⚠️ 反模式 #21：多介词切换打破模板化（2026-07-16 island + mansion 实测触发）

> 即使每句主谓结构不同，所有 "of/in/on/at + 目标词" 介词都用同一介词（如全用 in）→ 仍会模板化。

**推荐介词轮换表**：in / of / on / at / by / around / through / over / at the front of

**island 第一版（"in the X"全用）vs 第二版（5 种介词轮换）**：
| 第一版 | 第二版 |
|------|--------|
| Boats stop in the island | Boats stop at the island（停泊处 at） |
| Fish swim in the island | Fish swim around the island（环绕 around） |
| Birds fly in the island | Birds fly over the island（上空 over） |
| Trees grow in the island | Trees grow on the island（表面 on） |

**L3 自检升级**：每张表输出后 → 数不同介词数量 → ≥3 种介词 = 通过；<3 种 = 触发反模板化重写。

## ⚠️ 人物出镜规则（场景类实测强化）

**不出镜页面（默认）**：封面、认知页、纯展示物体/家具/风景特征的页面。

**出镜页面（仅必要时）**：互动/动作页、需要角色与场景互动的页面。

**⚠️ 出镜人物完整性铁律（2026-07-15 busy 实测触发）**：每张含人物的页面都必须遵守 11 项完整描述（头/眼/耳/鼻/口/身/双臂/双手/双腿/双脚/服装），禁止无头/无手/无脚/色块化/模糊化。

## ⚠️ 安全场景铁律

- **road**：孩子过马路必须有人牵手
- **kitchen**：孩子不能炒菜，必须大人操作
- **bridge**：孩子过桥必须有人牵（桥上无栏杆时）
- **bathroom**：孩子洗澡必须有大人陪同
- **mountain**：登山场景必须有人陪同
- **cave**：钟乳石用"尖尖的"不写"锋利的"
- **waterfall**：飞溅水花 + 声音波纹视觉化反 AI 跑偏

## 简介创作模式（场景类通用）

### 紧扣旁白原则（用户 2026-07-12 强化）

> 用户反馈"简介太过模板化""没有紧扣旁白" → 简介必须从旁白的核心元素中提取，不能套通用模板。

**模板**：
```
[目标词] [中文]

[旁白 P2/P3 核心特征 1]、[旁白 P4/P5 核心特征 2]——[结尾旁白关键词]真[形容词]！
```

**示例**：
- lake：「蓝蓝的湖水，湖泊倒映着青山，湖泊真美丽！」
- mountain：「高高的山、绿绿的山坡、登山顶、看风景——mountain 真雄伟！」
- road：「斑马线、红绿灯——我们一起安全过马路！」

### ⚠️ L3.5 简介工作流节点（2026-07-16 mansion 实测新增）

> 触发场景：用户在选完标题之后、进入 L4 之前明示"根据旁白写出故事简介"

**强制规则**：简介紧扣已确认旁白（公式）+ 备选 3 条（不重复方向）+ 不允许出现旁白外的元素 + 输出后让用户再次确认。

## 用户偏好：本子类的可观察信号

- **"The X has a Y + X is fun" 模板可稳定复用**：本会话 6 本公共建筑类全部沿用此结构、用户 6 次选标题+简介没有一次改句式，说明用户默许此句式为标准
- **无固定角色版更受欢迎**：用户纠错"不需要有固定角色小狐狸出镜的就不要有"后立即被采纳（见 long 改稿）
- **每页加"实物外观约定"防 AI 跑偏**：场景类公共建筑常有食物/家具混淆陷阱（rice≠饭团、soup≠意面、scissors≠尖头）
- **⚠️ 居住/商业建筑类不要全用"has"（2026-07-14 apartment 实测）**：用户原话"我感觉整个旁白有些太低智"
- **⚠️ "我不想要有人物" = 立即改无主句（2026-07-14 apartment 实测）**
- **⚠️ 用户说"重写组织语言"指多句而非单句（2026-07-14 apartment 实测）**：用户原话"第6句，第8句，第9句重写组织语言"是同时改 3 句
- **⚠️ 当用户说"请看我上面的指令"时必须回查历史内容（2026-07-14 gymnasium 实测教训）**：必须回查历史内容（用 session_search 或回头找对话）
- **⚠️ "找一找 X 在哪里？" = 本子类固定结尾模板（2026-07-14 farm 起 33 本稳定复用）**：已成本子类标准模板
- **⚠️ "全部/整体场景调整"触发整本重做（2026-07-14 gymnasium 实测触发）**：用户说"全部都.../我们就.../换 X 主题" → 这是整本书主题方向调整
