### P32 · 动物主线选择 4 选 1 决策树

**为什么需要这个文件**：本会话 dragonfly/caterpillar/seagull 都触发了"动物选哪个主线方向"，但 P29 只覆盖了"动物默认 A 路线"，没覆盖 A 路线**内**的 4 选 1。

**4 个动物主线维度**（实测验证）：

| 维度 | 示例目标词 | 主线关键词 |
|------|----------|-----------|
| A 动作姿态 | cat/dog/bird | 爬、跳、跑、飞 |
| B 色彩外观 | ladybug/butterfly/fish | 红黑、白灰、彩色 |
| C 生态场景 | dragonfly/seagull/snail | 池塘、海边、花园 |
| D 文化习性 | caterpillar/magpie/cuckoo | 生命周期、报喜、寄居 |

**默认决策**：C 生态场景（适用面最广，画面感最强）
**例外**：Eric Carle IP 类（如 caterpillar）→ D 文化习性

### P33 · 旁白结构检测 + 修复 A/B/C 路径

**为什么需要这个文件**：本会话反复触发"agent 检测到旁白模板化问题 → 主动提供 A/B/C 让用户 1 秒选"。

**5 维检测项**（触发任一即提供 A/B/C）：

| 检测项 | 触发场景 | 修复路径 |
|-------|---------|---------|
| 连续感叹号收束 | P3/P9 都是"!" | B 改陈述句 / C 改疑问句 |
| 连续同维度 | P3/P4 都是形状 | B 改交叉维度 / C 接受 + 输出时预警 |
| 连续问句收束 | P3/P9 都是"?" | B 改感叹 / C 改陈述 |
| 末句撞型 | 末句与近 5 本同型 | B 换新末句 / C 接受 |
| 介词短语模板化 | 连续"在 X 里" | B 换动作 / C 接受 |

**A/B/C 选项格式标准化**：
- A. 接受现状（默认走 A）
- B. [具体修复方案 1]（1-2 行说明）
- C. [具体修复方案 2]（1-2 行说明）

**反例**：展开大段反模板化分析 → 浪费用户耐心

## v3 实测推翻的旧规则

### P23 v2 标题无 `!` 规则被推翻

**v2 规则**（2026-07-17 上午）：封面 + 认知页都不带 `!`
**v3 实测推翻证据**：
- 本会话 dragonfly/caterpillar/seagull/magpie 4 本认知页**全部带 `!`**（`DRAGONFLY!` / `CATERPILLAR!` / `SEAGULL!`）
- 用户没有任何反馈要求去掉 `!`
- 视觉上"封面不带 + 认知页带"反而更有视觉差

**v3 修正**：
- 封面（P1 cover）首字母大写，**不带 `!`**（如 `Dragonfly`）
- 认知页（P1）全大写，**带 `!`**（如 `DRAGONFLY!`）—— 视觉强化
- 内页（P2-Pn）小写，**不带 `!`**（如 `dragonfly`）

**为什么 v2 错了**：v2 把 P1 认知页的"全大写视觉强化"误等同于"不带 `!`"，实际即梦生图时 `!` 能产生更强的视觉冲击，用户体感是认知页应该有 `!`。

**沉淀位置**：SKILL.md L4「⚠️⚠️⚠️ 大小写 3 档核对」段二次修正
