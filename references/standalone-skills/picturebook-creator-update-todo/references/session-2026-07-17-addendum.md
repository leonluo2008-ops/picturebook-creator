## P28 · 用户整轮"自然口语版"反问触发 大声朗读自检（高优先级 · 2026-07-17 NEW）

**实测来源**：why 绘本 L3 输出时，agent 把"X 是为什么 Y"反模板化硬塞到每句中文旁白里（"天空是为什么蓝的"），用户反问"你自己读一下旁白是加的位置正确吗？顺口吗？"

**触发的背景规则缺口**：
- 老的 SKILL.md L3 #9「中文口语自然度」自检是"把句子里核心词拎出来看是否自然"，**没有明确"朗读完整段落"这一步**
- 改写时容易陷入"按用户字面意思字字照搬"，跳过"读起来像不像 3-6 岁小孩说话"的最终校验

**新规则**：
1. L3 改写旁白后、输出前，**必须把整段旁白从 P1 念到末尾一遍**（出声或在心里默念）
2. 如果发现以下情况，立刻修复，**不要硬塞**：
   - 介词短语结构反了中文自然语序（"鸟是为什么唱歌"听起来像英文直译）
   - 双"是"叠用（"太阳是为什么是热的"——双重"是"）
   - 把修饰词塞到中文主谓之间破坏语调（"可爱的正在跳"）
   - 翻译腔（任何用"为"字开头模仿英文 for/because 句式的中文）
3. **任何用户对核心词位次的明确指令，都要先做一遍朗读自检再执行**，如果用户指令违反自然语序，**主动反问**提供自然版（不要闷头把不自然的版本写出来再被用户纠）
4. 标准朗读自检问句："把中文单独念出来，3 岁小孩听到会说'这是妈妈讲给我听的话'还是'这是外国人翻译的中文'？"

**沉淀位置**：SKILL.md L3「⚠️⚠️⚠️ 中文口语自然度自检」段补充"朗读 3-6 岁口语自检"子段；同时把这条**前置到文件顶部铁律区**（与 P22/P23 同级）。

## P29 · 用户给"标题 + 简介 + L3 表 + 选定方向"四要素 → 输出顺序锁定（高优先级 · 2026-07-17 NEW）

**实测来源**：hyacinth/narcissus/pansy/gypsophila/morning glory/apricot blossom 多本连环触发 → 用户给出"1 标题 + 1 简介"或"1、1"对应编号后，**agent 不应再问"用哪个版本"+ "进 L4"等任何反问**，直接 todo 切换 + 进 L4。

**新规则**：
1. 当用户给出符合以下 4 要素完整输入时，**直接输出 L4 代码块，不再确认任何中间环节**：
   - 标题编号（1/2/3）
   - 简介编号（1/2/3/4）+ 标了"方向一/二/三/四"
   - L3 旁白表格（已经过反模板化/字数控制/核心词强化若干轮）
   - 隐式确认（用户没说"再改"，而是直接选了标题+简介编号）
2. 已经在 L3 阶段消耗过的"反模板化检查""字数控制检查""核心词覆盖检查"——**L4 阶段不再重复跑这些检查**，L4 只跑"L4 专属检查清单"（页数 = 旁白 + 1 / 封面 + 认知 + 语境 + 结尾 / 16:9 / 3:4 / 四字段格式）
3. **绝不**在 L3 → L4 之间再发一句"是否确认进入 L4"——这是已沉淀在 SKILL.md L3 末尾的规则，但本会话 hyacinth/narcissus 测试中仍偶尔反问，要加强记忆

**反例**（禁止）：
- 用户："1、1" → agent 答："已确认 1 号标题 + 1 号简介，请确认是否进入 L4？" → 用户再次输入"确认" → agent 才开始 L4
- **正确**：用户："1、1" → agent 直接 todo 切换 + 输出 L4 代码块

**沉淀位置**：SKILL.md 流程纪律段加粗强调。

## P30 · 花卉类旁白：花朵独特性写一句孩子能"数/摸/看/动"的动作（高优先级 · 2026-07-17 NEW）

**实测来源**：本会话 narcissus/calendula/hyacinth/gypsophila/morning glory 都面对"花卉特征丰富导致旁白过于静态"风险（如 narcissus 第一版"P3 颜色 + P4 层叠 + P6 香 + P7 蓬松"= 连 4 句讲花朵静态特征，缺动作维度）。

**新规则**（flower-series-batch-pattern 升级）：
1. 花卉类目标词 L3 旁白 8-9 行必须覆盖至少 3 个**动作维度**：
   - 静态特征（颜色/花瓣数/形状）最多 3-4 行
   - **动作维度**至少 3-4 行（"看/摸/闻/数/比/送给 X / 摇动 / 风一吹 / 和 X 一起"任选）
   - **互动收束**至少 1 行（结尾要找/闻/送/抱，不是"我喜欢 X"）
2. **花卉反模板化必查项**（输出 L3 后过一遍）：
   - [ ] 5 个花瓣 = 一个数；6 个花瓣 = 数"一、二、三…"；多瓣花 = "好多"；单瓣花 = "一片"
   - [ ] 颜色 = 直接用色名（白/粉/紫/黄）
   - [ ] 形状 = 比喻（"像小喇叭"/"像小碗"/"像小星星"），**不要只说"圆形""锥形"**（3-6 岁不懂）
   - [ ] 香味 = 视觉化（"飘啊飘"/"香喷喷"）
   - [ ] **结尾必须有一个**"动作/互动"动词：找 / 闻 / 数 / 送 / 种 / 比 → 不允许纯系表"X 真漂亮"结尾
3. **自检方法**：把每行中文旁白独立念一遍，**只允许 1/3 的行是"X 是 Y 的 Z"结构**；其余 2/3 必须有动词（看/摸/闻/数/比/送/动）

**沉淀位置**：SKILL.md L3「花卉类旁白反模板化 5 维自检」段（新增）或 flower-series-batch-pattern.md 升级。
