## 新增的 3 条 P 级规则

### P37 · 动物主线 A/B/C/D 选 6 次 → 升级为 P0 优先级（NEW 2026-07-17 v4）

**实测数据**：本会话 6 个动物目标词（caterpillar/dragonfly/seagull/magpie/white crane/crow）全部需要 L2 输出前先选 ABCD 主线方向。
- **直接回"确认"未选 ABCD**：4 次（67%）
- **明确选择**：caterpillar=A, dragonfly=C, seagull=C, white crane=C, crow=C
- **未答**：magpie（问 ABCD 后用户直接回"确认"跳过选择）

**P31 升级版规则**：
- 当 L2 输出前动物主线 A/B/C/D 选择题出现时：
  - **必须默认走 C（生态/场景）**，因为 C 在 6 本中 4 次被明确选择（66%）
  - 默认后下一轮顶部写明"已默认走 C（生态场景），如有不同请告知"
  - **禁止对"确认"回复再次追问 ABCD**——直接默认 + 标注
- 反例：本会话每次用户回"确认"后 agent 都重新追问 ABCD，浪费 4 轮交互
- 默认 C 的原因：
  - dragonfly=C 海域生态 → 池塘荷花画面
  - seagull=C 海边生态 → 沙滩/海面/船三场景
  - white crane=C 湿地生态 → 芦苇荡/浅水/沼泽
  - crow=C 田野生态 → 栅栏/麦穗/田野
- 例外：
  - Eric Carle IP 类目标词（caterpillar=好饿的毛毛虫） → 默认 D
  - 用户明确指定 → 遵用户指令

**沉淀位置**：SKILL.md L2「⚠️ 动物主线选择决策树」段升级 + 用户交互规则段升级

### P38 · 高风险目标词预评估 4 选项模板（NEW 2026-07-17 v4 · 中优先级）

**实测来源**：本会话 crow 目标词，黑色 + 负面寓意（死亡/不祥/墓地）+ 文化禁忌，agent 应主动给替代方案而非直接执行

**规则**：当目标词具有以下任意 1 个风险特征时，L1 输出前必须主动给"风险评估 + 替代方案 A/B/C/D"：

| 风险类型 | 触发目标词 | 风险描述 |
|---------|----------|---------|
| 审美风险 | crow/raven/black cat | 黑色为主角，画面沉重 |
| 文化禁忌 | crow（多文化不祥）/bat（西方恐怖）/snake（部分文化）| 死亡/不祥/恐惧联想 |
| 绘本匹配风险 | Eric Carle 风格目标词不在原作 IP 库 | Eric Carle 从未做过该目标词 |
| 视觉表现难度 | transparent jellyfish/microscopic virus | 3-6 岁无法理解抽象视觉 |

**风险评估模板（必须照搬使用）**：

```
⚠️ 目标词风险预评估 · {目标词} 检测到 {风险类型}：

{target_word} 在 3-6 岁绘本里{具体风险描述}。

如果坚持要做，建议选路线 A/B/C/D 之一：
A. 改成{更友好的替代词1}（{原因}）
B. 改成{更友好的替代词2}（{原因}）
C. 加正面包装——{目标词} + {正面意象组合}（{原因}）
D. 坚持 {目标_word}——{旁白限制条件}（{原因}）

请选一个（A/B/C/D），我继续推进 L2。
```

**反例**：本会话 crow 评估时列了 4 选项，但未按标准化模板输出 → 应固定模板格式
**正例**：本会话 crow 用户选 D（坚持原词），旁白全程用"闪亮羽毛+聪明+会叫+田野/栅栏"避开不祥意象

**沉淀位置**：SKILL.md L1「⚠️ 高风险目标词预评估模板」段（新建）

### P39 · Eric Carle IP 动物主角造型重写公式（NEW 2026-07-17 v4 · 中优先级）

**实测来源**：本会话 caterpillar 用户反馈"图中的毛毛虫太丑了"，L4 重写后采纳 Eric Carle《好饿的毛毛虫》原作封面彩虫造型，完美解决问题

**原版失败特征（必须规避）**：
- ❌ 单一绿色身体 + 红色头部 → 太单调、像菜青虫
- ❌ 瘦长身体比例（头身比 1:6）→ 像普通小虫
- ❌ 6-10 节瘦长节段 → 像蛇/蚯蚓
- ❌ 无色块装饰 → 黑色死亡感

**重写公式（Eric Carle IP 类目标词必用）**：

```
{动物主角} Eric Carle IP 重写公式：

1. 大头萌系比例：头占身体 1/5（萌系大头宝宝感）
2. 多色节段循环：节段颜色按 {色1/色2/色3/色4/色5/色6} 循环
   - 像彩虹串珠糖葫芦，每节饱满大圆球
3. 每节装饰点缀：每节色块带白色圆点装饰
4. 圆润造型：不要瘦长、不要扁平、不要硬质
5. 表情萌系：圆眼睛黑白分明 + 高光点 + 微笑嘴巴
```

**适用目标词清单**（Eric Carle IP 库）：
- caterpillar → 《The Very Hungry Caterpillar》(1969) 经典彩虫
- butterfly → 《The Very Hungry Caterpillar》结尾蝴蝶
- spider → 《The Very Busy Spider》(1984)
- ladybug → 《The Grouchy Ladybug》(1977)
- 其他 Eric Carle 原作中的角色

**L4 输出格式模板**（必须照搬）：

```
⚠️ 反丑化铁律：不要瘦长形、不要单色绿身、不要无色块装饰、不要硬质甲壳感、不要写实毛毛虫；
要圆润、饱满、多色、纸片剪贴、童趣、像 Eric Carle 原作封面那条经典彩虫。
```

**沉淀位置**：`references/animal-series-batch-pattern.md` 新增「⚠️ Eric Carle IP 动物造型重写公式」段
