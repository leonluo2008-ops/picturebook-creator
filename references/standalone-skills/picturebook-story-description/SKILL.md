# 儿童绘本 40 字故事简介写作工艺（v3.0）

## ⚠️⚠️⚠️ v3.0 教学型简介铁律（2026-09-15 Brush Teeth/Cute 双实测 · 顶部置顶）

> **用户原话**：
> ①「这是教孩子认识单词的英文单词绘本，所以这个简介要重写」（否纯故事描述+说教句版）
> ②「太拖沓，太冗长，而且强行凑数的感觉，很烦人。你要用小孩子的语境」（否 douyin 运营公式版）

**铁律 0（一票否决）：教学型单词书简介必须出现英文核心词。** 缺核心词 = 家长看不出这本教什么 = 重写。

**铁律 1：小孩子语境一句话式。** 公式（原理，每本用自己的词）：

```
<叠词动作钩子>！+ <主角 + 叠词结果> —— <核心词英文>，<叠词短收尾>！
```

**定稿范例（逐字收录，勿改）：**
- Brush Teeth：`刷呀刷！小猫咪刷出亮晶晶的小白牙——brush teeth，天天刷，笑哈哈！`
- Cute：`毛茸茸的小兔，圆圆的小鸡，布娃娃笑眯眯——大家都好可爱好可爱，cute！`

**节气类变体**（芒种定稿，用户未否）：`<主题>到啦！+ 叠词景×3 + —— + 核心词 + 收尾！`
- Grain in Ear：`芒种到啦！麦子黄澄澄，秧苗绿油油，梅雨哗哗下——Grain in Ear，最忙碌的节气到啦！`

**两次被否记录（勿回退）：**
1. ❌ 纯故事描述 + 说教句——病灶：缺核心词 / 写结果态不写过程（旁白全是动作线）/ 说教句隐含比较 / 「咧嘴」生硬。
2. ❌ 运营公式（跟着绘本学 + 场景列举 + 磨耳朵学习价值 + 互动引导）——运营话术塞进孩子语境 = 凑数感。

**简介病灶分析框架**（用户问「简介有什么问题」时按此答）：缺核心词 / 结果态vs过程 / 说教句 / 生硬用词 / 运营话术凑数。

**与 v2.0 的关系**：教学型单词书（Brush Teeth/Cute 类）以本节小孩子语境式为**唯一权威**；v2.0 一句话叙事四要素（性格主角/连接词/比喻/故事化收尾）继续管故事型、节气型书（猎豹/油松类）。两公式共同反元素列举排比，不冲突。

- [ ] 收尾是叠词短句（笑哈哈/真可爱）还是感叹口号（真棒！）/说教句？后者 = 重写

- "写出来的简介根本没有儿童韵味，生硬，成人语境过重，不活泼"（油松·动词清单版）
- "简介生硬"（猎豹·四字短语报特征版）

- "脸上的黑线像眼泪印，这种比喻是没有问题的"（比喻 = 加分项）
- ✅ 合格："金色猎豹是草原上跑得最快的猫，脸上两道黑线像眼泪印，跑累了就在大树下喘口气。"
- ✅ 合格："高山上住着油松爷爷，穿红褐衣裳、捧着松球果，仙鹤都爱来陪他，一百年也不显老呀！"

## 一句话核心
简介 = **一个有性格的主角过的一件小事**（一句话故事），
不是 **旁白特征的压缩清单**（大嘎大嘎排比）。

## ⚠️ 历代被否写法（全部实际跑通过，别再跑）

### 类型一：元素列举体（"X、Y、Z——真形容词！"）
病根：逗号/顿号把 3+ 个"名词+动词短语"机械连排，句与句零连接 = "大嘎大嘎大嘎大"。

### 类型二：动词任务清单体（摸/看/找/数）
例："去高山找油松：摸红褐树皮、看长针叶、数松球果…"
病根：孩子视角的"考察任务单"，成人语境重。

### 类型三：书面四字短语凝练腔
例："披黑斑花衣，挂小泪痕，迈长腿追风跑，跑累了树下喘口气"
病根：为压字数凝练成四字格，变成大人的书面腔，口语叙事感消失。

## ✅ 合格句式四要素（原理不是模板）
1. **主角有性格/身份**：油松爷爷 / 草原上跑得最快的猫 / 飞毛腿——不是干巴巴的"金色猎豹"
2. **连接词串事件链**：句与句必须有承接——"就/又/请/都/住着…都爱/…了…就"，
   让元素"发生"而不是"被报出"：
   - ✅ "跑累了**就**在大树下喘口气"（因果承接）
   - ✅ "捧着松球果**请**仙鹤来做客"（动作带去向）
   - ❌ "披红褐树皮，甩长针叶，捧着松球果"（三连排比）
3. **比喻给画面感**：黑线像眼泪印 / 叶子像细细的缝衣针——比喻是加分项，
   画面感靠比喻，不靠形容词堆砌
4. **收尾落在故事里**："一百年也不显老呀！""跑累了在大树下喘口气"——
   收在主角一天的小结尾，不收在"——真X！"感叹口号上

## 40 字公式（原理，每本用自己的话写）
[有性格的主角] + [一句身份/住处引入] + [连接词串起 2-3 个旁白元素成事件链] + [故事化小结尾]

## 自检清单（一票否决制）
- [ ] 句中有没有至少 1 个连接词/承接结构（就/又/请/都/住着…都爱）？没有 = 排比嫌疑，重写
- [ ] 数一数：逗号/顿号隔开的"名词+动词短语"是否 ≥3 个连排？是 = 大嘎大嘎，重写
- [ ] 有没有"——真[形容词]！"式列举收尾？有 = 重写
- [ ] 有没有摸/看/找/数式任务清单？有 = 重写
- [ ] 主角有没有性格/身份（不只是"金色的猎豹"）？
- [ ] 有没有至少 1 个比喻或具象画面？
- [ ] 收尾落在故事里（一个小结尾），不在感叹口号上？
- [ ] ≤40 字（含标点）？
