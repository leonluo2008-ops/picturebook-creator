# 儿童绘本 40 字故事简介创作公式

## 总纲：简介与旁白的关系

**旁白 = 唯一素材源与事实边界；简介 = 从旁白收拢出的一条事件线。**

- **素材源（单向）**：简介的主体/事件/物件/情绪全部来自旁白，零发明；简介对旁白只有选择权没有改编权——选哪条线、取哪几个物件是自由的，每个零件必须是旁白的零件
- **收拢（多→一）**：旁白是逐页并列的短句清单，本身没有叙事结构；简介把这条平铺清单收拢成一条事件线（这些是什么 → 是好朋友 → 送给你 → 我好喜欢）。简介不是旁白的压缩清单——抽画面 ≠ 提主线
- **功能分工**：旁白管逐页教学（核心词逐句重复曝光，每页一个场景）；简介管门面（3 秒答出这本书教什么、讲了什么事、值不值得翻开）。两者的共同中心 = 核心词——旁白是核心词的重复曝光机，简介是核心词的语境说明书
- **形态差异**：旁白句短、叠词密、每句独立成立；简介一句话承载全书，要疏朗、口语叙述。旁白的叠词密度规则不迁移到简介
- **验证方向（简介→旁白）**：简介写完，逐项回旁白找出处，找不到 = 删；旁白后续改版，简介重查一致性

一句话：**简介是一句话故事预告——整句为核心词而写，听完能答出「这本书讲了什么」。**

## 第〇层 · 铁律：核心词是整句话题

- 英文核心词必须出现（缺 = 家长看不出这本教什么 = 重写）；中文核心词同现且语义贯穿
- 每个小句围绕核心词转：直接说它 / 写它的动作 / 指代回扣；塞在破折号后当装饰 = 重写
- 语法上不必是主语（Brush Teeth 定稿主角是小猫咪，但整句说的都是刷牙）

## 第一层 · 内容四定（写什么，全部从旁白推导）

1. **定主体**：逐行看旁白谁在行动——核心词被拟人化 = 核心词化身；物品名核心词 = 物品化身；寒暄/评价类 = 行为主体；无单一主角 = 集体主语；例证物单行场景禁升主角
2. **定事件**：主体的一件完整事（谁 + 做了什么 + 结果怎样）；钩子宣告的事件 = 全书主线事件，错位 = 重写。**节气/时令类书豁免**：节名宣告（芒种到啦！）+ 景列 + 收束回扣主题 = 事件闭环（景×3 为典型描述非硬门槛，景数不足不按拼贴误判），不按拼贴判（判别式：首句=宣告句 + 尾句=回扣主题）；景列仅限此形态，非节气书禁用
3. **定出处**：每个动作/物品/评价必须在旁白原文找到出处；找不到 = 删
4. **定钩子**：主体自己的动作或状态，主语落地；禁对读者的互动指令（指一指/摘一摘/找一找/拍拍手/猜猜看）——那是运营话术，不是故事

## 第二层 · 形状自由（怎么连，按题材自选）

- 上面四定是硬骨头；句子形状按题材自选，**不锁格填空**——题材和格子不匹配时，格子不是助力是逼良为娼
- 有动作的书用动作钩子；无动作的书用状态/罗列钩子；节气书用宣告+景列
- 连接词（就/又/都/请）让元素「发生」而不是「被报出」
- 连排罗列仅限：服务核心词 + 每项出自旁白；为凑覆盖堆名词 = 大嘎大嘎
- **适口性 > 词藻量**：宁可朴素叙述句，不塞「叠词+连动」压缩包（「认识了新朋友」优于「蹦蹦跳跳交朋友」）

## 第三层 · 收尾三段论（怎么收）

1. **回扣核心词（硬性）**：收尾的对象/动作/状态必须锚死核心词——「这些我都好喜欢」✓（对象=这些）；悬空情绪尾巴（喜欢的对象没说、情绪没来由）= 病灶。**情感收束例外**：寒暄/情绪类核心词（nice to meet you 类）锚点已在前句（认识了新朋友）时，收尾可只做情绪落点（笑哈哈）
2. **孩子嘴里说得出（硬性）= 自然语境终检，最高优先级**：整句大声读，问「这句话在真实亲子口语里存在吗」——书面成语腔（「笑开怀」）= 重写；**成分逐项合规但整句不存在于自然语境同样 = 重写**（「壮壮的笑眯眯」「壮壮实实笑眯眯」型：叠词✓回扣✓字数✓但中国人不会说，MILK 实测）；**本文件全部铁律**（叠词化/回扣/字数/钩子）与自然语冲突时，自然语赢
3. **叠词（可选）**：语感参照，不进规则
- **调性对齐**：核心词是克制/低调语（not bad 类）时，禁「多 + 形容词短语 + 呀」感叹句式（多开心呀/多好的一天呀）——病灶在调不在词，换词不换调照样否；单短评价落点（今天真棒呀）与表情/状态收尾（大家都笑眯眯）合法（Not Bad 定稿口径）

## 第四层 · 边界

- ≤40 字。计数细则：中文字符与标点全计（含破折号——与引号）；英文核心词整串不计（nice to meet you / Mid-Autumn Festival 整串不计）；非核心词英文/数字按字符计。示例：THESE「橡果圆滚滚，苹果红通通，这些都是我的好朋友——these，送给你，这些我都好喜欢！」= 36 ✓；Brush Teeth = 27 ✓；I'm Back（多词短语整串不计）= 38 ✓
- 禁运营话术（跟着绘本学/磨耳朵/互动引导/学习价值）、说教句、感叹口号（真棒！）、四字书面凝练腔
- 旁白英文列同步自查：无主语表语 fragment（`Strong and happy every day!` 类）禁入——中文被迫直译 fragment 是「壮壮的笑眯眯」型病句的直接上游

## 定稿范例（逐字收录，勿改）

- Brush Teeth：`刷呀刷！小猫咪刷出亮晶晶的小白牙——brush teeth，天天刷，笑哈哈！`（动作钩子形态；收尾「天天刷」回扣核心词动作）
- Cute：`毛茸茸的小兔，圆圆的小鸡，布娃娃笑眯眯——大家都好可爱好可爱，cute！`（无动作书用罗列钩子形态；收尾回扣核心词语义）
- Balloon：`吹呀吹，大红气球鼓起来，飞呀飞上蓝天——balloon，越飞越高真开心！`
- Not Bad（无单一主角取集体主语）：`小动物们样样自己来——not bad，今天真棒呀！`
- I'm Back（短语类）：`我回来啦！小熊提着小鱼桶蹦进门，一家人香香甜甜吃晚饭——I'm back，回家的声音最好听！`（收尾回扣核心词=回家这个事件的声音）
- Nice to Meet You：`握握小爪子！小兔认识了新朋友——nice to meet you，笑哈哈！`（寒暄类核心词，收尾=见面事件的情绪收束）
- Time：`时间跑呀跑，从清晨跑到夜晚，小种子也长成了甜果子——time，天天陪我们长大，好宝贵呀！`（核心词拟人化身主角）
- Year：`四季转一圈，蜡烛点亮又添一岁——year，开心一整年！`
- 芒种（节气类）：`芒种到啦！麦子黄澄澄，秧苗绿油油，梅雨哗哗下——Grain in Ear，最忙碌的节气到啦！`
- Mid-Autumn（短语类节气）：`中秋节月亮圆圆的，月饼甜甜的，玉兔蹦蹦跳——Mid-Autumn Festival，团团圆圆过中秋啦！`

范例只证明「五层全过」的句子长什么样，不是要每本都套同一个形状。范例中的笑哈哈/笑眯眯仅是可选语感参照，**非合格要件**——非叠词收尾同样合法（评价落点：今天真棒呀；情绪叙述：这些我都好喜欢；状态：大家都笑眯眯），勿因范例强度把「叠词短收尾」学回默认形状。

## 被否记录（一句病灶，勿回退）

- 纯故事描述+说教句：缺核心词、写定局不说动作、说教腔
- 运营公式（场景列举+学习价值+互动引导）：凑数感
- 互动指令钩子+物品罗列+凑数收尾：钩子无主语、无主角无事件、发明旁白外内容、核心词塞而不展开
- 数数腔（「一个说好，两个说好…」）：机械数数凑排比，无叙事
- 叠词焊接非自然语（「壮壮的笑眯眯」「壮壮实实笑眯眯」）：格子全勾但整句不存在于真实亲子口语——公式化模板化病灶，判据=自然语境终检
- 悬空情绪尾巴：「这些送给你，我好喜欢」——喜欢的对象没说，收尾与核心词断钩

## 病灶速查（用户问「简介有什么问题」时按此答）

缺核心词 / 核心词塞而不展开 / 互动指令钩子（对读者下指令、无主语）/ 无主角无事件（画面罗列）/ 发明旁白没有的内容 / 结果态不写过程 / 说教句 / 运营话术凑数 / 主语漂移 / 收尾不回扣核心词（悬空情绪尾巴）/ 书面成语腔收尾 / 叠词堆砌赶节奏（适口性>词藻量）/ 钩子与全书主线错位 / 收尾调性与核心词声线错位 / 主角错位·例证升主角 / 叠词焊接成非句（「的」接状态词·非自然口语）/ 英文 fragment 直译硬凑 / 生硬书面腔·四字格凝练腔

## 自检清单（提示项——判定权在闸门，不过关由语义审查定）

- [ ] 英文核心词出现且整句围绕它展开？中文核心词同现？
- [ ] 钩子是主体自己的动作/状态（有主语），不是对读者的指令？
- [ ] 一句话 = 一个完整事件，能答出这本书讲什么？
- [ ] 每个内容能在旁白找到出处？
- [ ] 收尾回扣核心词（对象/动作/状态居一）？
- [ ] 收尾孩子嘴里说得出？调性与核心词对齐？
- [ ] ≤40 字？无运营话术/说教/口号？

## 审查闸门

- 字面套路检查全部降级为提示项，**判定权 = 独立反对者读全文语义审查**（多轮直到无致命/严重；能 spawn 必 spawn，不可用降级自审并注明）
- 声称「与旁白一致」「收尾呼应」时，逐条回旁白原文验证，防「我以为对位了」
