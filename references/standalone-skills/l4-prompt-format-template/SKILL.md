# L4 生图提示词严格格式模板

> **触发场景：** 用户发范例图（如 hexagon 范例）说"格式不对，应该是如图这样的"或"请严格按照skill规范输出生图提示词"。
> **核心原则：** L4 输出 = 纯代码块，代码块外无任何文字。代码块内分 3 层结构。

## 第 1 层 · 引导语段（代码块最顶部）

```
plain text

我会给你一段文字，是领读文案和对应的生图提示词，请提取出生图提示词，并生成图片；
注意：不要在图片中显示领读文案中的中文翻译，这些仅供参考；
目标单词（如X）需要作为大型彩色图形元素出现在画面中，文字即图形，不要以小字等形式出现；
这一组领读绘本图片，请保持风格和角色一致性；

重要要求（请严格执行）：你必须根据文案，主动保持整本书的视觉一致性。同一个角色/物件一旦出现，后续页面必须保持外观一致。生成每张图前请回看前后页，确保连贯。构图时主体始终居中，远离画面左右边缘，预留裁剪空间。
重要要求（请严格执行）：整本绘本统一使用 [当前风格锚点]

⚠️ 文字严格控制（请严格执行）：每张图只允许出现这 2 个文字（英文核心词 X 在上、中文释义 紧贴其正下方），除此之外画面中绝对禁止出现任何其他英文或中文文字，禁止拆字、禁止装饰性字幕、禁止多语言标签、禁止完整句子外露。

⚠️ 视角动态变化（请严格执行）：每个场景必须使用不同的镜头视角/景别/构图方式，禁止连续多页用同一视角。封面倾斜站立动态构图；P1 认知页仰视居中；P2-P8 轮换侧面/俯视/顶部/平视/远景展开。
```

## 第 2 层 · 【全局设计约定】+ 【主要场景锚点】

```markdown
【全局设计约定】

目标单词：X
目标年龄：X岁
文字风格：场景图仅出现两个文字——英文核心词"X / X / X!"作为大型彩色图形元素（封面：Title Case；认知页：全大写；内页：小写），紧挨英文正下方固定配对中文释义"X"，中英形成醒目文字块，不以小字/字幕出现。
风格锚点：[当前风格锚点]

【主要场景锚点】

1) [场景1]:[1行描述]
2) [场景2]:[1行描述]
...
```

## 第 3 层 · 每页 4 字段（严格顺序，换行分隔）

```
旁白：[对应页面文案]

比例：3:4（封面）| 16:9（内页）

页面类型：封面页 | 认知页 | 语境页 | 总结语境收束页

生图提示词：[完整提示词，内含：视角 + 主体外观 + 场景元素 + 文字要求 + 风格锚点 + "画面中只允许出现这 2 个文字"重复声明]
```

## 末尾 1 行精简（代码块最后一行）

```
每张图只允许出现这 2 个文字（英文 X 在上、中文 Y 紧贴其正下方）。
```

## 反模式清单

| 反模式 | 正确做法 |
|--------|----------|
| 代码块外有任何文字（"以下/结构/备注"等） | 代码块外严禁任何文字 |
| 引导语段省略 ⚠️ 文字严格控制段 | 必须包含完整 2 个 ⚠️ 段 |
| 引导语段省略 ⚠️ 视角动态变化段 | 必须包含完整 2 个 ⚠️ 段 |
| 每页字段用反斜杠分隔（`旁白 / 比例 / 页面类型 / 生图提示词`） | 必须用换行分隔 |
| 末尾写成 50+ 字符长说明 | 必须 1 行精简 |
| 生图提示词不嵌入"中英文字块"描述 | 每页提示词内嵌文字块描述 |
| 反混淆/反丑化铁律放在生图提示词字段之后 | 应在引导语段 |
