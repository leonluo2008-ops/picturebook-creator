# L4 生图文字铁律(2026-07-21 实测沉淀)

> 来源:Many / Must / Mooncake 三本绘本连续实测,用户**三次冒火纠正**后沉淀。
> 加载本文件的触发:每次进入 L4 输出前(任何领读绘本),必须自检本铁律。
> 完整 skill 见:`ld-picturebook-l4-user-ironrule`

## ⚠️ 硬铁律(违反任意一条,用户会冒火)

### 1. 每张图只允许 2 个文字(顶格)

**只允许出现 2 个文字:**
1. 英文核心词(认知页全大写无 `!` / 封面首字母大写可带 `!` / 内页小写无 `!`)
2. 对应中文(单色,字号略小于英文,横向排列)

**绝对禁止:**
- ❌ 任何完整短语(`many balloons` / `get the apple` / `mid-autumn festival must eat mooncake`)
- ❌ 任何中文译文("很多气球" / "小猫拿到一个毛线球" / "中秋节要吃月饼")
- ❌ 任何标点符号(`,` `.` `!` `?` `、` `;` `:` `"` `""` `《》` `——` `……`)
- ❌ 任何其他英文单词 / 中文 / 数字 / 装饰小点 / Logo

### 2. 中文末尾独立绑定核心词(2026-07-21 mooncake 用户原话)

> 用户原话:"中文旁白后面只要突显核心词 Mooncake,不用整句英文,例:小猫拿到一个毛线球, Get。"

**L3 旁白表的中文行末尾,只需绑定一个独立英文核心词,不用整句英文翻译。**

正例(Get 绘本):
```
1 GET! 拿到,GET!
2 Cat gets a yarn ball. 小猫拿到一个毛线球, Get。
3 Rabbit gets a carrot. 小兔子拿到一根胡萝卜, Get。
...
9 Every animal gets a treat! 每个小动物都拿到了一份礼物, Get!
```

规律:
- 中文末尾绑定一个独立英文核心词(`Get` / `Mooncake` / `Many`)
- 不用把整句英文翻在中文后
- 标点正确对应:英文 `.` 对应中文 `,`,英文 `!` 对应中文 `!`

### 3. L3 旁白与 L4 生图文字严格分离(常见陷阱)

| 字段 | 内容 | 例子 |
|------|------|------|
| L3 旁白英文 | 完整自然短句 | `Cat gets a yarn ball.` |
| L3 旁白中文 | 中文完整短句 + 末尾独立核心词 | `小猫拿到一个毛线球, Get。` |
| L4 生图提示词"画面文字" | **只写核心词 + 对应中文** | 画面文字 = `Get` + `拿到` |

⚠️ **关键陷阱**:L3 旁白里英文可以写完整句,但 L4 生图提示词里**画面文字只写核心词+中文**。两套必须分离。

### 4. 简明句式"X 拿到 Y"主谓宾范式(2026-07-21 get 绘本)

用户原话:"可以这样写,例:小猫拿到一个毛线球"

- ✅ 主谓宾 = `X 拿到 Y`(像 4 岁小孩口语)
- ❌ 复杂修饰 = `伸长手臂,拿到树上的苹果`(过度修辞)

### 5. L3 旁白"每句都要有核心词"约束

用户原话:"每一句旁白都要有核心词 X"

- 英文每行必须包含核心词
- 中文每行必须显式出现核心词(不能用同义词/指代词替换)
- L3 输出前必须自检 8/8 或 9/9 命中

## L4 生图提示词正确模板

每条生图提示词结尾固定话术:

> **画面中只有 2 个文字:英文核心词 XXXXXX 位于画面中上方居中作为大字彩色拼贴文字块,紧贴其正下方紧接 = 中文 X 作为大字彩色文字块(单色、字号略小于英文、横向 2 字并排)。画面严禁任何标点符号。画面严禁除 X 和 Y 之外的任何其他文字/数字/符号。**

参考图特征(用户发 village 范例图要求对齐):
- 英文:每个字母独立颜色(如 v-i-l-l-a-g-e 七色)
- 中文:单色(红色),字号略小于英文
- 字母排列:横排,字母间留有空白间隙
- 中文:横向 2 字并排
- 英中两字:几乎相连,严格垂直居中
- 零其他文字/数字/装饰
- 零标点符号
