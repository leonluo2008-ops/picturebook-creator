## 本会话新触发信号

### 信号 11:核心词中文锁定(最高优先级 · 用户实测会冒火)

- 触发:用户原话"**核心词用正方形**" / "**核心词用 X**"
- 识别:用户要锁定核心词的中文措辞,要求全书统一
- 处理:
  1. **立即全表改核心词中文**(L3 表格 + L4 提示词)
  2. 不要追问"是否需要全表统一"
  3. 不要在 L1/L2 阶段"先确认一下"
- 失败案例:正方形绘本 agent 混用"方方的/方形/方块"被用户纠正
- 范围:几何系列所有目标词必须全表统一核心词中文

**核心词中文对照表(几何系列必查):**

| 英文 | 中文(统一) | ❌ 不要混用 |
|------|----------|-----------|
| Square | 正方形 | 方方/方形/方块/正方 |
| Rectangle | 长方形 | 长方/长条形/扁方形 |
| Circle | 圆形 | 圆/圆圈/圈 |
| Triangle | 三角形 | 三角/尖角形 |

### 信号 12:目标词安全预检(高风险词必查)

- 触发:用户给 `parallelogram` (平行四边形,14 字母)
- 识别:词长 12+ 字母 / 3+ 音节 / 抽象几何概念 = 3-6 岁高风险
- 处理:
  1. **L1 立即触发预检**(在 L2/L3/L4 之前)
  2. 给 4 个候选(A 改同系列友好词 / B 改同系列稍难词 / C 改感性几何词 / D 坚持原词)
  3. 等用户选词,不要自动推进
- 失败案例:parallelogram 触发预检后用户说"确认" → agent 走默认 A = Triangle → 但用户随后明确说"改成 Trapezoid 梯形" → 重新走流程

### 信号 13:"USER 直接给标题+简介"模式

- 触发:用户发 `椭圆形 Oval` `糖豆、饼干、纽扣、橘子——圆圆的 circle 真有趣!`
- 识别:USER 已经做完 L3 决策,**直接发最终版本**
- 处理:
  1. **直接采用并锁定**(不要追问"是否需要修改")
  2. 立即出 L3 终版表格 + 终版自检
  3. 立即预告 L4
- 失败案例:追问"请问标题需要修改吗?" = 浪费用户耐心 = 用户实测会冒火

### 信号 14:几何系列"末句模板化"换语境

- 触发:用户说"**第N句模板化了**" / "**最后一句模板化**" / "**第N句模板化了,请重新组织语言**"
- 识别:`Everything is X!` 句式在前 4 本几何系列中稳定,但**第 5+ 本必须破除**
- 处理:
  1. 给 4 个候选(A 几何特征型 / B 节奏童谣型 / C 联想类比型 / D 情感共鸣型)
  2. 用户选一个后,直接应用
  3. 末句变化表(几何系列):

| 形状 | 末句风格 |
|------|----------|
| Square | 升维到全景 `Everything is square!` |
| Rectangle | 升维到数量 `So many rectangles!` |
| Circle | 升维到全景 `Everything is circle!` |
| Triangle | 几何特征 `Triangle has three sides!` |
| Oval | 情感共鸣 `Oval is friendly shape!` |
| Rhombus | 几何特征 `Four corners, four sides!` |
| Star-shaped | 几何特征 `Star-shaped has five sharp points!` |
| Trapezoid | 几何特征 `Trapezoid has two parallel sides!` |

### 信号 15:颜色配方轮换(防系列内视觉同质化)

- 触发:同一系列连续做多本时
- 处理:每本用不同主色调(暖橙 → 棕黄 → 鲜粉 → 蓝绿 → 浅粉 → 鲜橙红 → 金黄 → 紫色)
- 失败案例:连续两本用相似暖色 → 视觉雷同 → 用户不会显式指出但满意度下降

### 信号 16:8 本几何系列并行沉淀

- 触发:用户连续给 8 个几何类目标词(Square → Rectangle → Circle → Triangle → Oval → Rhombus → Star-shaped → Trapezoid)
- 识别:**几何系列是用户的稳定批量生产模式**
- 处理:每次新几何词时,**自动应用**主系表句式 / 末句几何特征型 / 颜色配方轮换 / 核心词中文锁定 / 8 行结构

## 后续 agent 自检清单(v1.2)

每次新会话开始,跑一遍:
- [ ] 当前是 L1/L2/L3/L4 哪一步?
- [ ] 上一步用户是否已确认?
- [ ] 当前问题是"确认型"还是"选择题"?
- [ ] 用户回"确认"——是确认还是跳过了选择题?(默认走 A + 标注)
- [ ] 是否有中途风格切换(含 L4 前切换)?
- [ ] **目标词是否在高风险清单?(词长 12+ / 音节 3+ / 抽象几何概念)**
- [ ] 是否有主线方向选择?
- [ ] 修改指令是 4 种里的哪一种?(改中文 / 换一种表达方式 / 换语境 / 末句模板化)
- [ ] 用户是否说了"模板化了"?=100% 等同换语境,给 4 候选
- [ ] 用户是否说了"核心词用 X"?=立即全表锁定 X
- [ ] 用户是否回复"算了/不换了"?=保留原句立即推进
- [ ] **用户消息是否直接给了标题+简介? → 直接采用不追问**
- [ ] **目标词是否在几何系列(Square/Rectangle/Circle/Triangle/Oval/Rhombus/Star-shaped/Trapezoid)? → 应用几何系列模式**
- [ ] **是否应用了核心词中文全表统一铁律?**
- [ ] **是否应用了颜色配方轮换(连续几何系列时)?**
