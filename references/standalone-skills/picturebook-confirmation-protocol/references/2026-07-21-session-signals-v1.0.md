### 信号 13：L3 旁白"末尾独立绑定核心词"句式

- 触发：many/mooncake/quiet/study/visit 5+ 本
- 用户原话：**"中文旁白后面只要突显核心词 Mooncake,不用整句英文,例：小猫拿到一个毛线球, Get。"**
- 格式：`中文语句,核心词。`/`中文语句,核心词!`
- 关键：末尾绑定独立核心词 = 末尾标点 = 中文 `。`/`!`（**不是 `,`**！）

### 信号 14：L3 标点严格对应

- 英文 `.` 对应中文 `。`
- 英文 `!` 对应中文 `!`
- 用户实测原话（quiet 末句）："最后一句英文翻译不准确,中文旁白最后的'。'错误。英文旁白也应该有对应的标点符号。"

### 信号 17：village 参考图样式铁律

- 触发：many 绘本用户发 village/村庄参考图
- 要求：
  - 英文核心词横排，每个字母独立颜色
  - 中文对应翻译在英文正下方紧贴，单色
  - 中文横向 2 字并排，字号略小于英文
  - 字母间留有空白间隙
  - 英中两字距离极近、几乎相连、严格垂直居中
  - 零其他文字/数字/装饰/标点

## 后续 agent 自检清单（v1.0）

每次新会话开始，跑一遍：
- [ ] 当前是 L1/L2/L3/L4 哪一步？
- [ ] 上一步用户是否已确认？
- [ ] 当前问题是"确认型"还是"选择题"？
- [ ] 用户回"确认"——是确认还是跳过了选择题？（默认走 A + 标注）
- [ ] 是否有中途风格切换（含 L4 前切换）？
- [ ] 目标词是否在高风险清单？
- [ ] 修改指令是 4 种里的哪一种？（改中文 / 换一种表达方式 / 换语境 / 末句总结收束）
- [ ] 用户是否说了"模板化了"？=100% 等同换语境
- [ ] 用户是否回复"算了/不换了"？=保留原句立即推进
- [ ] 用户消息是否含完整旁白表格？→ 跳 L1-L3 直接 L4
- [ ] 旁白是否 9 行？→ 询问 A/B 后默认 A
- [ ] L3 三子模块格式对齐？（标题 1/2/3 +《中文 · English》；简介 1/2/3/4 + 方向；旁白中文逗号在前）
- [ ] L3 末句是否给候选 A/B/C/D？（信号 12）
- [ ] L3 每行中文末尾是否独立绑定核心词？标点 `。`/`!`？（信号 13+14）
- [ ] L3 风格是"末尾绑定"还是"突显"？（信号 15）
