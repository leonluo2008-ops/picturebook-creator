## 1. 几何系列第 11 本:Hexagon 六边形

### 用户触发路径
- 用户给"目标单词:hexagon"
- agent L1 输出目标词安全预检(词长 7 字母,中等难度,可做)
- 用户"确认" → 推进 L2
- L2 9 页结构(1 封面+1 认知+7 语境)+ 7 种六边形物体(蜂巢/雪花/饼干/螺丝帽/龟壳/风筝+全景)

### 实测踩坑:R.1.1 第 7 句主体重复

**第一版 L3 旁白**(agent 默认):
```
7 Hexagon is full of cells!  六边形像蜂巢,Hexagon.
```

**用户反馈原文**:
> "第7句与前面重复了请换语境"

**根因**:
- 第 2 句主体 = 蜂巢(`Beehive is hexagon.`)
- 第 7 句默认也用蜂巢(`Hexagon is full of cells!`)→ 主体重复
- 用户实测会立刻识别并要求换

**正确处理**:
- 给 4 候选让用户选
- 候选 A 小蜜蜂视角 / B 视觉魅力型 / C 联想雪花型 / D 总结规律型
- 用户选 A → `Bee loves hexagon home!` / `小蜜蜂喜欢六边形,Hexagon.`
- 关键:把"蜂巢"(物)换为"小蜜蜂"(角色) → 角色维度区分避免主体重复

**沉淀铁律(附录 R.5)**:
- 8 行旁白中 8 个主体必须完全不同
- 如果主体容易重复(如"蜂巢"两次),立即换"角色/动作/场景"维度
- "六边形像蜂巢"这种"比喻型"也属于主体重复(因为是用蜂巢作比喻)

## 2. 几何系列第 12 本:Heart shape 心形的(短语类第 2 本)

### 用户触发路径
- 用户给"目标单词:heart shape" + 年龄 + 风格
- agent L1 输出(短语类整体认读,不可拆分 heart + shape)
- 用户"确认" → 推进 L2
- L2 9 页结构 + 7 种心形物体(饼干/气球/糖果/蛋糕/贴纸/花瓣+全景)

### 用户新指令模式(2026-07-22 实测)

**L3 输出后,用户原话**:
> "像这样写,例:心形的饼干,最后一句换语境"

**指令解析**:
- "像这样写,例:心形的 X" → 用户用"心形的饼干"作为中文格式范例
- "最后一句换语境" → 末句必须给 4 候选让用户选

**实测处理**:
- L3 旁白中文化:从 `Cookie is heart shape.` / `饼干是心形的,Heart shape.` 角度 → 用户认可主系表句式
- 末句 4 候选:几何特征/情感共鸣/节奏童谣/价值升华
- 用户选 D 情感共鸣型 → `Heart shape is full of love!` / `心形满满的爱,Heart shape!`

**沉淀铁律**:
- 用户示范"心形的 X" = 暗示中文化标准,**不强制改英文句式**
- "换语境"= 立即给 4 候选,不要二次澄清
- D 情感共鸣型适合"非边数类"形状(oval/heart/penagon)

### Heart shape vs Star-shaped 短语类对照

| 维度 | Star-shaped(第 7 本) | Heart shape(第 12 本) |
|------|------------------------|------------------------|
| 中文 | "星形的" | "心形的" |
| 物体类型 | 几何形状(标准五角星) | 情感符号(爱/温暖) |
| 末句风格 | 几何特征型(`five sharp points`) | 情感共鸣型(`full of love`) |
| 颜色配方 | 金黄闪亮 | 暖粉玫红 |
| 教学侧重 | 几何(五个尖角) | 情感(爱) |

## 3. 高风险词预检"用户回确认=默认 A"路径(parallelogram 实测)

### 完整流程

**Step 1**:用户给"目标单词:parallelogram"
- agent L1 触发高风险词预检(附录 N)
- 给出 4 选项:
  - A = 改 Triangle(系列已做,3-6 岁友好)
  - B = 改 Trapezoid(延伸几何词,4 字母)
  - C = 改 Pentagon(延伸几何词,7 字母)
  - D = 坚持 parallelogram(不推荐,14 字母)

**Step 2**:用户回"确认"
- 按 picturebook-confirmation-protocol 情况 4:用户回"确认"= 默认 A 方案
- 但**不能默默做 A**,要给用户机会修正(因为 parallelogram 4 选 1 仍可能踩坑)

**Step 3**:agent 输出
```
⚠️ 你回的是"确认",我默认走 A 方案 = 改 Triangle
如有不同请下一轮告知,否则我继续推进 L2
```

**Step 4**:用户随后说"改成 Trapezoid 梯形" → 覆盖 A 选项
- agent 立即重置流程,从 L1 开始,目标词 = Trapezoid

**Step 5**:agent 报"我之前说 Trapezoid 是不是?确认进入 L2"
- 用户"确认" → 进入 L2(L1 重做)

### 沉淀铁律(附录 R.6)

| 步骤 | 行为 | 反例 |
|------|------|------|
| 1. 用户给高风险词 | 立即预检 + 4 选项 | ❌ 直接做 parallelogram |
| 2. 用户回"确认" | 默认 A + 报"已默认走 A" | ❌ 二次澄清"请选 A/B/C/D" |
| 3. 报默认 A 后 | 留出窗口让用户修正 | ❌ 默默做 A 不告知 |
| 4. 用户给新指令 | 立即覆盖,重置流程 | ❌ 强行做 A 不允许覆盖 |
| 5. 收到覆盖后再次确认 | 再次确认目标词再进 L2 | ❌ 跳过 L1 直接做 |

### 反模式(实测会被用户冒火)

- ❌ "用户回'确认' = 直接做 parallelogram"(不做预检)
- ❌ "用户回'确认' = 二次澄清'请选 A/B/C/D'"(违反情况 4 协议)
- ❌ "用户回'确认' = 默默做 parallelogram 跳过预检"
- ❌ "用户给新词 = 不允许修改,继续按 A 做"
- ❌ "用户给新词 = 跳过 L1 直接做新词"

## 4. 末句"换语境"协议统一(2026-07-22 多本实测)

### 触发信号汇总

| 用户原话 | 触发路径 |
|----------|----------|
| "最后一句换语境" | 4 候选让用户选 |
| "末句换语境" | 同上 |
| "第 N 句换语境" | 同上(N 句 4 候选) |
| "最后一句模板化了" | 同上(同路径) |
| "最后一句重新组织语言" | 同上(同路径) |

### 4 候选固定维度

**针对几何/形状类目标词**:
- A 几何特征型:`N corners, N sides!`(教学价值最高)
- B 节奏童谣型:`X and X, shape!`(适合抽象形容词)
- C 联想类比型:`X looks like Y!`(适合 oval/heart 类)
- D 情感共鸣型:`X is full of Y!`(适合非"边数类"形状)

### 实测采纳案例

| 绘本 | 末句用户选择 | 类型 |
|------|--------------|------|
| Heart shape | D 情感共鸣型 `Heart shape is full of love!` | D |
| Hexagon 第 7 句 | A 小蜜蜂视角(避主体重复) | A(自定义) |
| Oval | D 情感共鸣型 `Oval is friendly shape!` | D |
| Rhombus | A 几何特征型 `Four corners, four sides!` | A |
| Triangle | A 几何特征型 `Triangle has three sides!` | A |

### 默认推荐 A(教学价值高)

实测 A 几何特征型用得最多(5/12),因为:
- 教孩子记"几条边"(三角形 3、菱形 4、梯形 2 平行、星形 5、六边形 6)
- 教学价值高,孩子能学到核心知识点
- 不会被模板化("X has N sides!" 句式很稳定)

### 反例

- ❌ 用户说"换语境"= agent 直接给一句(用户实测会纠正"我没有选默认 A 之外的")
- ❌ 用户说"换语境"= agent 二次澄清"你想要 A/B/C/D 哪种"(浪费用户耐心)
- ❌ 用户说"换语境"= agent 默默按 A 方案做(不告知选项)

## 5. 第 7 句主体不重复防同型铁律(Hexagon 实测沉淀)

### 陷阱模式

**场景**:系列绘本的中间页(第 4-7 句)需要换主体避免与前后重复。

**实测触发**:
- Hexagon 第 2 句 `Beehive is hexagon.`
- Hexagon 第 7 句默认 `Hexagon is full of cells!` / `六边形像蜂巢,Hexagon.`
- 主体都用了"蜂巢" → 重复

### 通用检查表

- [ ] 8 行旁白中,8 个主体是否完全不同(物/人/角色/动作/场景任一维度区分)?
- [ ] 如果用"主系表"句式,7 张内页的"X is Y" 中 X 是否全部不同?
- [ ] 如果遇到 X 容易重复(如"蜂巢"两次),立即换"角色/动作/场景"维度
- [ ] 比喻型主体(如"六边形像蜂巢")也算主体重复,因为是用 X 作比喻

### 主体维度换法

| 维度 | 实测 |
|------|------|
| 物 → 物 | 蜂巢 → 雪花 / 饼干 / 螺丝帽 / 龟壳 |
| 物 → 角色 | 蜂巢 → 小蜜蜂(跳出"物"维度) |
| 物 → 动作 | 蜂巢 → "蜂巢飞起来"(给物加动作) |
| 物 → 场景 | 蜂巢 → "夜晚的蜂巢"(加场景) |

**推荐**:第 7 句这种"总结收束位置"优先用"物 → 角色"维度换(跳出 7 张内页的"物"主线)

## 6. 短语类目标词续作模式(Star-shaped + Heart shape 沉淀)

### 短语类与名词类的本质区别

| 维度 | 名词类 | 短语类 |
|------|--------|--------|
| 教学重点 | 让孩子指认事物 | 让孩子理解短语含义 |
| 页面结构 | 7 种"X 物体"+ 总结 | 7 种场景中"使用 X 短语" |
| 主体 | 物体本身 | 场景中的人/物做某事 |
| 中文呈现 | 完整名词 | 短语在中文里的自然表达 |
| L1 提示 | 单词性质=名词 | 单词性质=复合形容词,整体认读,不可拆分 |

### 短语类目标词清单(已沉淀 + 待扩展)

| 短语 | 中文 | 适用场景 | 状态 |
|------|------|----------|------|
| star-shaped | 星形的 | 几何/食物/装饰 | ✅ 已沉淀 |
| heart shape | 心形的 | 情感/食物/装饰 | ✅ 已沉淀 |
| happy birthday | 生日快乐 | 庆祝/情感 | ⏳ 候选 |
| let go | 松手 | 动作对比 | ⏳ 候选 |
| excuse me | 打扰一下 | 社交礼貌 | ⏳ 候选 |
| me too | 我也是 | 回应共鸣 | ⏳ 候选 |
| come on | 加油/来吧 | 鼓励邀请 | ⏳ 候选 |

### 短语类 L1 关键提示(必须明示)

> 复合词,作为整体认读,不可拆分为 X + Y

→ 用户 L1 即知道这是短语,L2/L3/L4 不会拆词

## 9. 几何系列末句 5 风格统计(更新到 12 本)

| 风格 | 使用次数 | 实测本(累计) |
|------|----------|----------------|
| 升维到全景 | 2 | Square, Circle(系列前 2 本用) |
| 升维到数量 | 1 | Rectangle |
| 几何特征型 | 5 | Triangle, Rhombus, Star-shaped, Trapezoid, Hexagon |
| 情感共鸣型 | 3 | Oval, Pentagon, Heart shape |
| 复数防同型 | 1 | Semicircle |

**统计结论**:
- 几何特征型(5/12)= 42% 用得最多 → 教学价值高(教孩子记"几条边")
- 情感共鸣型(3/12)= 25% 次之 → 适合"非边数类"形状(oval/heart/penagon)
- 升维到全景(2/12)= 17% → 只用在前 2 本(系列初期)
- **末句模板化专项破除铁律(实测已建立)**:每本必须用与前本不同的收束类型,即使同一系列第 N+1 本也要换
