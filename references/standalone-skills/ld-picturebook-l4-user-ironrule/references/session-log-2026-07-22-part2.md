## 1. 末句占位符铁律(2026-07-22 pine L3 实测 · 终极铁律)

### 用户实测两次反馈

**第一次**(用户):
> 「**为什么第 9 句总是不显示出来呢,请你不要我提醒,直接生成完整旁白。**」

**第二次**(用户进一步明确):
> 「**请你在接出来的绘本创作中直接将最后一页生成显示出来,ok?**」

### 反模式 → 正模式

**反模式**(被两次反馈):
```
| 9 | (末句直接生成好) | (末句直接生成好) |
```

**正模式**(必须):
```
| 9 | Pine trees grow tall and strong! | 松树长得又高又壮,Pine! |
```

### 根因诊断

agent 习惯在表格前已经说过"末句直接生成好了"+ 表格里写占位符 → 用户每次都要手动提醒显示。

**反模式 / 正模式 表**:
| ❌ 反例 | ✅ 正例 |
|---------|---------|
| `(末句直接生成好)` | `The X stand tall and strong!` |
| `(待选)` | `The X goes up!` |
| `(生成中)` | `The X stand green all year!` |
| `[待补全]` | `The X stand in a row!` |
| `...` | `The X dance by the river!` |
| 表格前已说明 + 表格占位符 | 表格前可说明 + 表格必填实际内容 |

### 此铁律成为独立铁律 10 的理由

铁律 9 讲"是否给 4 候选"(决策维度)= → 已选的末句是否还需要让用户选 → 讲的是决策。
铁律 10 讲"已决定的末句必须显示在表格"(呈现维度)= → 表格第 9 行怎么填 → 讲的是呈现。

两个独立维度,易混淆。用户两次反馈都是"表格不显示"(铁律 10),不是"又给 4 候选"(铁律 9)。

## 2. 反"蜡笔小宝宝/小朋友/孩子"铁律(2026-07-22 arrow L3 实测 · 永久应用)

### 用户实测原话

**arrow 绘本 L3**:
> 「**不要蜡笔小宝宝**」

### 沉淀为铁律的原因

- 用户在后续会话每次绘本(动物/物体/植物)都强调"不要小朋友"
- 一开始是"arrow 末句"局部要求 → 后扩展为"全部绘本反小宝宝"
- 铁律级别:HIGH(必须加到 L4 提示词固定话术中)

### 反例 → 正例

| ❌ 反例(小朋友) | ✅ 正例(动物替代) |
|----------------|-------------------|
| `The child holds a ball.` | `The bear holds a ball.` |
| `Children play outside.` | `Animals play outside.` |
| `我排在最前面` | `The leader is in front!` |
| `I can shoot an arrow.` | `The bear can shoot an arrow.`(无具体小朋友) |
| `Children make willow whistles.` | `The willow makes a soft whistle.`(拟人替代) |

### L4 固定话术(必加)

```
反"蜡笔小宝宝/小朋友"铁律(用户最新要求):全书 9 张图严禁出现蜡笔小宝宝/小朋友/孩子/具体人形象;所有主角必须是动物/物体/植物/景观。
```

### 例外情况

- 身体部位特写可出现(手/脚/眼/耳)
- 不允许出现完整人物(头+身体+四肢+表情)

## 3. L4 反混淆铁律(2026-07-22 willow L4 实测 · 反馈重写)

### 用户实测反馈

**willow L4 生成后**:
> 「**这是刚刚生成的场景7图片,与文稿不符,写的是柳絮的声音,不是笛子。请修改提示词**」

### 问题分析

**旁白原文**:`The willow makes a soft whistle.` / `柳条能吹出软软的笛声,Willow.`

**模型错误**:把"软软的"误关联到"柳絮"(catkins 也软软毛茸茸),生成出柳絮飘落的画面。

**根因**:生图模型对"软软+柳树"联想到"柳絮",而不是"笛声"。

### 反混淆铁律固定话术

```
**反混淆铁律(必按·本张图特殊强化)**:
- ❌ 严禁出现「联想元素 A」/「联想元素 B」/「联想元素 C」
- ❌ 严禁出现「画面主体歧义联想」
- ✅ 画面必须严格表现「主体 A」 + 「元素 B」 + 「元素 C」
- ✅ 画面只能出现:1 个 <元素1> + 1 个 <元素2> + <元素3>(代表...)
```

### willow P7 重写过程(3 个版本迭代)

**V1 (错)**:
> 画面中央 1 根蜡笔柳条横切面特写 + 1 个蜡笔小柳笛成品 + 2 颗鹅黄音符
> → 模型生成出"柳絮飘落"

**V2 (改)**:
> 用户要求"一棵柳树被风吹起,发出沙沙的声音,用音符代替,不要笛子"
> → 改为"柳树+风线+音符"3 件套
> → 但仍有"笛子"残留描述

**V3 (最终正确)**:
```
**反混淆铁律(必按·V3 强化)**:
- ❌ 严禁出现「笛子/whistle/管状乐器/按孔/笛口」任何与笛子相关的元素
- ❌ 严禁出现「柳絮/catkins/白色绒毛/蓬松绒球」任何与柳絮相关的元素
- ❌ 严禁出现「柳树、树冠、叶子、整棵柳树」任何柳树相关元素(本张图)
- ✅ 画面必须严格表现「1 棵柳树被风吹 + 柳条飘动 + 音符飘出」的声音场景
- ✅ 画面只能出现:1 棵柳树(垂枝被风吹) + 3-5 道风线(表示风) + 5-7 颗音符(代表柳条被风吹的沙沙声)
```

### 反混淆自检 checklist

```
[ ] L4 提示词是否有"反混淆铁律"段?
[ ] ❌ 严禁是否列出可能的"联想元素"清单?
[ ] ✅ 必按是否列出"画面只能出现"的元素清单?
[ ] "整体氛围"是否明示(避免模型理解错核心场景)?
[ ] 数字是否具体(1 棵 + 3 道 + 5 颗,不是模糊描述)?
```

### 用户反馈重写 4 步流程

当用户反馈"页面与文稿不符"时:

1. **第一步**:确认用户描述(他看到的画面 vs 文稿原文)
2. **第二步**:列出可能的"误联想点"(模型把哪个词关联错了)
3. **第三步**:重写时**强化反混淆铁律段**,列出所有"严禁"的联想元素
4. **第四步**:明确"整体氛围",避免再次误联想

### 4.2 镜像对照沉淀(2 组)

**inside + outside**:
- inside 末句:`Inside and outside!` Inside 绑定
- outside 末句:`Inside and outside!` Outside 绑定
- 两本句式同但绑定词不同 = 系列化呼应,允许

**left + right**:
- left 末句:`The left hand goes up!` 左手
- right 末句:`The right hand goes up!` 右手
- 两本主系表镜像,只在 left/right 词替换

**front + behind**:
- front 末句:`The leader is in front!` 领头羊
- behind 末句:`The rabbit hides behind the bush!` 小兔
- 两本主体对比:前=领头(领导者),后=躲藏(被遮蔽)

**above + under**:
- above 末句:`Look up! The sky is above!` 抬头看
- under 末句:`Everything is under the sky!` 天空下面
- 两本"天空"在同一句:"above 天空 / under 天空"完全互补

**middle 自成体系**(位置最佳型,无镜像):
- 中间位置在所有方位中最特殊,自成一类

### 4.3 left vs right 主体差异化实测

| left 主体 | right 主体 |
|-----------|-----------|
| 左手 | 笔右(铅笔在书的右边) |
| 左鞋 | 椅右(椅在桌右) |
| 左眼 | 桥右(桥在河右) |
| 左耳 | 树右(树在花右) |
| 路标箭头左 | 鸭右(鸭在兔右) |
| 面包店左 | 黄右(黄在绿右) |

**为什么 right 不直接用身体部位**:用物体相对位置("在...右边")更口语化,避免罗列"右脚右眼右耳"。left 用身体(更绝对),right 用物体(更相对)。

### 4.4 方位系列易错点

1. **over vs above**:over 表示"斜上方/可接触",above 是"垂直正上方不接触"。本系列专注 above。
2. **below vs under**:below 是"任何方向下方",under 是"垂直正下方不接触"。本系列专注 under。
3. **inside vs inner**:inside 强调"被容器包住"(已实现),inner 是形容词"内部的"(不用)。
4. **outside vs out**:outside 强调"在外部"(已实现),out 是动词"出去"(不用)。

## 11. 末句 "Look up! The sky is above!" 起手语言沉淀

**为什么 above 末句用"Look up! The sky is above!"而不是"Everything is above!"?**

因为:
1. "Look up" 动作型让 3-6 岁孩子能直接做(L1 学习目标)
2. "Sky is above" 升维到全景但保留核心词 above
3. "!" 情感共鸣,有兴奋感(仰望天空)
4. 与系列呼应:under 末句是 "Everything is under the sky!" → 完全对称

**起手语言模板**(其他动作词可用):
- 方位类可用"Look up/Look down/Look around!"
- 植物类可用"Look at the + tree!"
- 拟人类可用"Come and see/Let's + V!"
