# 病灶分析报告 — forget 册「故事线东拉西扯」（2026-09-22 用户定性：整个故事线东拉西扯）

## 一、病灶还原（故事线逐页拆解）

书的核心事件本应是「埋骨头→忘埋哪儿→找→挖出」一条线，实际 L2：

| 页 | 教学内容 | 判定 |
|---|---|---|
| P2 | 骨头埋哪儿了？忘记啦 | ✓ 主线成立（埋骨→忘记） |
| P3 | 出门忘带小水壶 | ✗ 离线：与骨头无关，整页岔开 |
| P4 | 忘了和小兔的约定 | ✗ 又岔一页；且图文矛盾（「忘了约定」却画「小狗小兔面对面」——忘了就不该碰面） |
| P5 | 闻一闻，想起来啦 | ✗ 与 P4 无因果硬跳回骨头线；「想起来啦」与该行旁白（还在找）节拍错位 |
| P6 | 挖出骨头 | ✓ 收回主线 |

一条主线开三条收两条不收；P4→P5 叙事断崖（物理换景存在，叙事因果为零）。

## 二、为什么 wait 修复后仍复发（五根因）

1. **L2 只定「方向」不定「事件线」**（规范层）：l1-l4-strict-format-template.md L2 节 v5.6.0 只要求内部定推进链方向（近→远/小→大/物→人）——方向是维度不是故事；且 L2 纪律「表格外无段落」使事件线无承诺物、无验证物。用户确认的是一张各自成立的孤立节拍表。
2. **唯一 L2 范例是列举型书**（范例偏置）：严格模板唯一完整示例 many（星/鱼/叶/气球…平行场景）把「语境扩展页=再举一例」的形状泄漏给叙事型词。
3. **列举何时非法无判据**（词类盲区）：wait 修复把列举合法化（清单链+统一观察者），未回答反面。判据补齐：**因果债务**——某页开了后果/悬念（丢了/忘了/许了），后文必须安排收回页；无债务的平行列举（many/颜色/节气型）仍合法，勿逼改成故事书。
4. **「一句话事件线」检查存在但放在下游**：narration-review 简介四步流程第 1 步即「一句话概括全书事件」，但在 L3 简介环节才跑，L2 锁定时病灶已固化。旁证：本册 4 条简介各讲各的故事（骨头线/水壶约定线/闻挖线/宽慰线）——备选互相打架 = L2 未定线的暴露信号，但简介自检只查「形状互异」未查「同讲一个故事」。
5. **审修清单零覆盖**：narration-review 审修闸门=格式层+单句层+简介层，无「先通读当故事讲」步骤——检查表驱动注意力，清单外零覆盖。本轮首审 10 条修正全部句子层、逐项达标、整体断线，与 wait「5 闸全放行」同型失败。L3 自检表「场景切换有过渡」只验物理换景不验叙事因果，太弱。

## 三、修复（本分支 fix-20260922-storyline）

1. L2 节内部执行说明追加：一句话事件线（每页=线上一站）+ 朗读测试验线 + 因果债务收回判据 + 列举型合法声明——全部语义判据，零输出格式变更（l1-l4-strict-format-template.md）。
