# 身体部位领读系列批量模式参考（2026-07-12 实测沉淀）

> **覆盖 7 本已做**：foot / head / face / hair / nose / mouth / ear
> **风格**：蜡笔手绘童趣风 或 Eric Carle 拼贴风（用户二选一）
> **目标年龄**：3-6 岁
> **核心特征**：围绕"身体部位+功能/特征/动作"设计

---

## 一、页面结构公式（强约束，本系列统一）

```
总图数 = 旁白行数 N + 1
└── 封面页（3:4, 1 张）
└── 认知页（16:9 全大写, 1 张）← 必须独立，不能合并到封面
└── 语境页（16:9 小写, N-2 张）
└── 结尾互动页（16:9 小写, 1 张）
```

**旁白行数建议**：8-10 行（与海产/水生系列 8-9 行一致）

| 旁白 N | 语境页 | 结尾页 | 总图数 |
|---|---|---|---|
| 8 | 6 | 1 | 9 |
| 9 | 7 | 1 | 10 |
| 10 | 8 | 1 | 11 |

**用户原话（2026-07-12 face 绘本）**："旁白一共是9个场景，图片也应该有9张加上封面一共是10张图片。"——这是硬性页数 = N+1，必须严格命中。

## 二、认知页反模式（最严重翻车点）

### ❌ 翻车案例（实测）
- foot/head/nose/hair 连续 4 本漏掉认知页，用户 4 次反馈"你缺少了一页认知页的生图提示词"
- foot 第一版：只画一只孤零零的脚（鸭子脚/鸡爪特写）→ 用户反馈"很诡异"

### ✅ 正确做法（已验证）
1. **认知页必须独立存在**，不能合并到封面（封面 3:4 竖版，认知页 16:9 横版，比例不同）
2. **认知页文字大小写**：目标词**全大写**（如 `FOOT!` `HEAD!` `NOSE!`），与封面**仅首字母大写**（如 `Foot` `Head` `Nose`）严格区分
3. **认知页画面**：身体部位 + 完整角色（半身或全身），不能只展示部位

### 部位孤立展示"诡异感"反模式（2026-07-12 head 实测新增）

> 当目标词是身体部位（head/foot/hand/eye/ear/nose/mouth/hair/face 等）时，生图提示词**禁止只展示孤零零的部位**（如画面中央只放一个漂浮的头/一只漂浮的脚），AI 容易画出"无身头颅""漂浮断肢"等恐怖谷效果。

| 目标词 | ❌ 错误画法 | ✅ 正确画法 |
|---|---|---|
| head | 只画一个圆脸漂浮 | 半身像（头+肩膀+衣服） |
| foot | 只画一只孤脚 | 完整人物的脚（裤腿+袜子+站立场景） |
| hand | 只画一只孤手 | 完整人物的手（手臂+袖子+握物场景） |
| eye/ear/nose | 只画一只眼睛 | 人物面部（脸部+五官整体） |
| hair | 只画一缕头发 | 完整人物头像（头+发+脸） |
| mouth | 只画一张嘴 | 完整人物的脸部 |
| face | 只画一张脸 | 半身像或全身像 |

**判断标准**：把生图提示词描述的画面单独拿出来看，主体有没有身体承接？场景能不能解释为什么这个部位会出现在画面里？

## 三、旁白通顺自检（大声朗读法 · 2026-07-12 多本实测强化）

> **3-6 岁旁白口语化铁律**：写完后必须大声读一遍，听起来像 3-6 岁小孩指着画面说的话，不是儿歌词也不是英文直译。

### 本系列实测翻车的 3 大反模式

| ❌ 反模式 | 触发案例（用户原话） | ✅ 正确写法 |
|---|---|---|
| **形容词+量词+名词倒装**（"弯弯一只虾"） | shrimp 用户："语句不通顺" | **主语+形容词**（"虾弯弯的"） |
| **叠词儿歌化代替介词短语**（"游啊游"/"跳呀跳"） | shrimp/fish 用户："核心词位置要符合中文语境" | **主语+在+地点+动词**（"在水里游"） |
| **空喊情感型无具体动作**（"我爱 X"） | shrimp 用户末句反复改 3 次 | **情感+具体动词**（"我爱吃 X"） |

### 实测通过的旁白风格（foot/head/face/hair/nose/mouth/ear 已确认）

**foot 范例**（用户满意）：这是脚，foot / 这是鸭子的脚，foot / 这是小鸡的脚，foot / 这是小猫的脚，foot / 这是兔子的脚，foot / 这是大象的脚，foot / 这是马的脚，foot / 这些脚都不一样，foot

**face 范例**（用户满意）：圆圆的脸，face / 长长的脸，face / 毛茸茸的脸，face / 开心的脸，face / 生气的脸，face / 微笑的脸，face / 嘟嘴的脸，face / 各种表情的脸，face

**特征**：
- 主语在句首自然位置（"这是 X 的脚"）
- 形容词贴主语（"圆圆的脸"而非"圆圆一张脸"）
- 没有儿歌化叠词（不用"游啊游"）
- 核心词"foot/face"统一在末尾作焦点

## 四、目标词大小写三档区分（强制）

| 页面 | 大小写 | 示例 |
|---|---|---|
| **封面（3:4）** | 仅首字母大写 | `Foot` / `Head` / `Face` / `Hair` / `Nose` / `Mouth` / `Ear` |
| **认知页（16:9）** | 全大写 | `FOOT!` / `HEAD!` / `FACE!` / `HAIR!` / `NOSE!` / `MOUTH!` / `EAR!` |
| **正文内页（16:9）** | 正常小写 | `foot` / `head` / `face` / `hair` / `nose` / `mouth` / `ear` |

**用户实测触发（2026-07-12 shrimp/head）**：连续两本用户要求"封面改首字母大写"——意味着这个区分必须前置到 L4 输出前自检，不是事后修补。

## 六、视角动态变化（本系列通用 · 2026-07-03 铁律）

> **禁止所有页面用同一个视角**（foot/nose 多本实测触发用户"画面要有动态"反馈）

| 页码 | 推荐视角 |
|---|---|
| 封面 | 倾斜站立或动感构图（不要死板正面） |
| 认知页 | 仰视特写或大特写（视觉冲击） |
| 语境页 P2-Pn | 依次轮换：侧面45度 / 俯视 / 顶部特写 / 仰视 / 极近景 / 平视 |
| 结尾互动页 | 全景展开或互动视角 |

## 十、失败教训（不要再犯）

1. ❌ **漏认知页**：foot/head/nose/hair 连续 4 本犯此错 → 必须前置 L4 输出前自检（页数 = N+1）
2. ❌ **部位孤立展示诡异感**：foot 第一版只画孤脚 → 用户立刻反馈
3. ❌ **中文不通顺**："弯弯一只虾"/"游啊游"/"我爱虾"反复触发用户纠正 → 必须大声朗读自检
4. ❌ **封面/认知页大小写混用**：封面 SHRIMP!/认知页 Shrimp 反复触发 → 严格三档区分
5. ❌ **"我爱 X"空喊情感型**：shrimp 末句改 3 次才通过 → 情感型必须带具体动词（吃/摸/看）

## 附：核心词中文变体禁用清单（已编入主 SKILL.md L3 自检）

本系列实测触发的禁用变体：
- 脚 → ❌ 小脚/脚儿/脚脚
- 头 → ❌ 小头/头儿
- 脸 → ❌ 小脸/脸儿
- 头发 → ❌ 发儿/发发
- 鼻子 → ❌ 小鼻子/鼻儿
- 嘴巴 → ❌ 小嘴巴/嘴儿
- 耳朵 → ❌ 小耳朵/耳儿

唯一例外：英文原文含 little/small 时可保留翻译（如 "A little foot" → "小脚"），但中文旁白末句仍只用标准译名。
