# 属性扇出模式 · 领读绘本 L2/L3 批量复用

> 适用范围：目标词天然有多种属性变体（颜色/形状/大小/种类），用属性扇出结构设计 8-11 页的领读绘本。
> 已沉淀样本：dragonfly（颜色变体 + 主体一致）、shell（形状/颜色双扇出）。
> 核心思路：把目标词的属性拆成"颜色/形状/结构/环境/汇总"5 个维度，每页讲 1 个维度，避免模板化。

---

## ⚠️ 触发条件

适合**属性扇出**的目标词类型：

| 类型 | 代表样本 | 扇出维度 |
|------|---------|---------|
| 多彩昆虫 | dragonfly、butterfly、ladybug | 颜色变体（蓝/绿/红/紫...） |
| 多形贝壳 | shell、stone、leaf | 形状变体（扇形/螺旋/圆形...） |
| 多种花卉 | rose、tulip、daisy | 颜色+形状（红玫瑰/黄玫瑰...） |
| 多变天气 | cloud、rainbow | 颜色+形态（白云/乌云/彩虹...） |
| 多季节水果 | apple、cherry | 颜色变体（红/青/黄...） |

不适合：cat/dog 这种特征单一的目标词。

---

## ⚠️ 5 维扇出结构（核心方法论）

| 维度 | 页面类型 | dragonfly 示例 | shell 示例 |
|------|---------|--------------|-----------|
| **颜色扇出**（3 页） | 同形状不同颜色 | 蓝色蜻蜓 → 绿色蜻蜓 → 红色蜻蜓 | 粉色贝壳 → 橙色贝壳 → 条纹贝壳 |
| **形状扇出**（2 页） | 同颜色不同形状 | （N/A 蜻蜓形状固定） | 扇形贝壳 → 螺旋贝壳 |
| **结构**（1-2 页） | 身体的标志部件 | 大眼睛 → 四片翅膀 | （融入形状页） |
| **环境**（1 页） | 在哪里 | 在池塘上飞 | （融入场景） |
| **汇总**（1 页） | 多种同时出现 | 好多彩色蜻蜓 | 好多种形状的贝壳 |

**页数计算公式**：3 颜色 + 1-2 形状 + 1-2 结构 + 1 环境 + 1 汇总 = **7-9 张语境页** + 1 封面 + 1 认知 + 1 结尾 = **10-12 张图**

---

## ⚠️ 模式 A：颜色变体 + 主体一致（dragonfly 验证）

**核心铁律**：身体颜色按本页指定变化，但**身体形状/眼睛/翅膀保持完全一致**。

```
P3: 蓝色 dragonfly
P4: 绿色 dragonfly
P5: 红色 dragonfly
```

L4 全局约定模板：
```
蜻蜓主角外观一致性（路径B-无参考图，每页文字重复）：
- 细长彩色身体 [按本页指定蓝/绿/红]
- 巨大圆眼睛占满头部（多色块拼贴大眼睛带白色高光）
- 4 片半透明翅膀（2 对，每片有浅色网纹脉路）
- 细长尾巴
- 短触角
```

**L4 每页写法**：
- 主体外观描述完全重复（颜色部分变化，其他不变）
- 颜色变化的部分用 `+ 蓝色金属色身体` / `+ 绿色金属色身体` 这样的标注方式锁定本帧颜色
- AI 即使每张独立生成也能锁定身体形状/眼睛/翅膀的一致性

---

## ⚠️ 模式 B：形状/颜色双扇出（shell 验证）

**核心铁律**：每页都是不同形状+不同颜色的贝壳，**每页都需要重新描述贝壳类型**（扇贝/海螺/笠贝等），不能用同一份外观描述复用。

```
P3: 像扇子一样的贝壳（扇贝壳造型 + 浅黄色放射肋）
P4: 像螺旋一样的贝壳（海螺壳造型 + 浅棕色螺旋纹）
P5: 粉色的贝壳（圆锥形 + 粉红色）
P6: 橙色的贝壳（圆锥形 + 橙红色）
P7: 带条纹的贝壳（笠贝造型 + 白粉/白蓝条纹）
P8: 好多种形状的贝壳（5-6 种同框汇总）
```

**L4 全局约定模板**：
```
贝壳主体（按页指定）：
- 扇形贝壳：浅黄色和白色色块扇形外壳 + 浅黄色色块 8-10 条放射肋
- 螺旋贝壳：浅棕色和白色色块螺旋形外壳 + 浅棕色色块螺旋纹路
- 粉色贝壳：粉红色和浅粉色色块圆锥形
- 橙色贝壳：橙红色和浅橙色色块圆锥形
- 条纹贝壳：白色和粉红色或白色和浅蓝色色块交替条纹圆锥形
```

**L4 每页写法**：
- 主体外观描述**按本页指定的类型写**，不重复其他类型
- 主体反混淆必须每页都写（区别于其他贝壳形状）
- 5-6 只同框汇总页（P8）才把所有类型放一起

## ⚠️ 模式 C：属性扇出的 L3 旁白编排路径

**反模板化铁律**（2026-07-17 shell 实测触发）：用户要求"从贝壳的形状颜色来写旁白"，所以整本旁白围绕形状/颜色展开。L3 自检时必须检查：

| 检查项 | 通过 | 不通过 |
|------|------|--------|
| 颜色页连续 2-3 句是否同维度 | 蓝/绿/红交错或连色 | 蓝/红/粉连续 3 句 |
| 形状页连续 2-3 句是否同维度 | 扇形/螺旋/圆锥交错或连形 | 全部"扇形" |
| 颜色→形状是否清晰分组 | 前 3 颜色后 2 形状 | 颜色和形状交替混乱 |

**修复三件套**（已验证）：
1. **分维度集中**：先讲完所有颜色再讲所有形状（shell 模式 B）
2. **分维度交替**：颜色-形状-颜色-形状交错（dragonfly 模式 A 变体）
3. **加混合维度页**：P7 "带条纹的贝壳" = 颜色+形状组合，破除同维度连续

## ⚠️ 模式 A vs B 选择决策表

| 决策点 | 选 A（颜色变体） | 选 B（形状扇出） |
|--------|---------------|---------------|
| 目标词主体形状是否单一 | ✅ 单一（蜻蜓都是一种形状） | ❌ 多种（贝壳有扇形/螺旋/圆锥） |
| 目标词颜色是否多样 | ✅ 多彩（蜻蜓多种金属色） | 可能单一也可能多彩 |
| 是否有反混淆挑战 | 中（颜色描述锁定） | 高（每页都要反混淆） |
| 适用子类 | dragonfly / butterfly / ladybug / apple / cherry | shell / stone / leaf / pebble |
| 配合主线 | 颜色鲜艳主线最契合 | 形状/外观主线最契合 |

---

## L4 输出注意事项（属性扇出模式专用）

1. **每页都要重新核对全局约定**：颜色变体模式下，**身体形状/眼睛/翅膀的描述必须完全重复**，只有颜色部分变化
2. **形状扇出模式下，主体描述每页都不同**：每页都要重新描述该类型的形状特征 + 反混淆描述
3. **P末"汇总"页是核心页**：必须把所有变体都画在同一画面（5-6 只蜻蜓/5-6 只贝壳），展示多样性
4. **生图反混淆必须每页都写**：防 AI 把本页的扇贝壳画成海螺、把蓝蜻蜓画成绿蜻蜓

## 反模板化检测（输出前 5 问）

1. ✅ 我设计的页面是不是都围绕目标词的不同属性展开？
2. ✅ 连续 3 页有没有在讲同一属性？
3. ✅ "汇总页"是不是把所有变体都收束在一起？
4. ✅ L4 全局约定是否锁定了一致性字段（身体形状/眼睛/翅膀等）？
5. ✅ 反混淆描述是否每页都写？

任一答"否" → 重新设计。

---

## 与其他模式的关系

- **动物主角模式**：属性扇出模式是动物主角模式的子类（动物 + 多属性）
- **花卉系列模式**：色彩鲜艳主线 = 颜色变体；多形状主线 = 形状扇出
- **场景类模式**：与属性扇出互补，场景类讲"在哪里"，属性扇出讲"是什么样子"
