## §1 L1 需求确认

> 本步的创作部分（立意线索、角色与风格提案）由**创作子代理**产出（`executor.md` §0.1：先问所有者本次创作用哪个模型，默认上次指定）；主模型负责对话、记录、机检，不代笔。

### 输出模板

```
【领读绘本需求确认】
目标单词: [英文单词]
中文释义: [中文含义]
立意线索: [一句话——孩子凭什么认出这个词：从哪种熟悉的经验/情境/结果认出，全书选材由它派生]
目标年龄: [3-4岁 / 4-5岁 / 5-6岁]
领读方式: 整词跟读
画面风格: [推荐风格，见 references/style-library.md]
→ 请确认以上信息并选择风格，确认后进入页面结构设计
```

### 中文释义口径（L1 锁定，后面全程照此执行）

- **多义词先定义项**：light 取「光」还是「轻的」、mine 取「我的」还是「矿井」——L1 定死本本教哪个义项，旁白/标题/简介全程只用这一个义项。〔裁定〕
- **锁义项，不锁句式**：名词可作主语、宾语或称呼（`I pick up the soap.` / `Thank you, soap.`），不能把目标词当动词用（`Soap the hands.`）。动形词同样按真实词性审。句式为当页动作服务，不把名词页统一写成 on / in 位置清单；中英文讲同一动作或状态。
- **台账里的说明性文字不是创作约束**：行内「绘本切入 / 核心词义 / 主题关联 / 备注」多是 Notion AI 自补记录，只作背景参考——不据此改剧情、道具、标题，也不必回头同步备注。〔裁定〕参与义项对齐的只有「词型」这一列结构化属性。
- **教哪个义项先跟台账「词型」对齐**：动笔前 `python scripts/notion_archive.py --word <核心词> --locate` 拿到行，看「词型」（名词／动作动词／形容词）；本本义项必须与它一致。冲突在 L1 端出来拍板（改词型 or 换义项），别等 L5 才发现文字与分类打架。改词型走 `python scripts/notion_verify.py --word <核心词> --set-word-type 名词`——「词型」是 rich_text 属性，按 select 写必 400。
- **台账「词型」与简介立意视角表不是一套**：台账是名词 / 动作动词 / 形容词（结构化分类），立意视角表是感官 / 动作 / 功能·社会 / 维度 / 关系（`rules.md` §2 的词型参考视角，2026-11-24 起仅为参考非强制映射）；两者只对齐义项，不互相套用。
- **中文口语词必须是孩子嘴里真实会说的话**：避开书面词，按义项选口语表达（表示年龄的 young → 「还小」）。
- **不与系列已有核心词的中文释义撞车**：开新本前核对候选译法在本系列的使用情况；会被同一译法混淆的，按当前义项换词或换角度。
- **不锁死不构成教学差异的选择**：单颗还是一整串、盘里摆几个、背景放什么物件——交给画面；只守一条：旁白与画面形态对齐（画面是整串，旁白就写复数）。

### 选词可教性审查（核心词被质疑「不太好」时）

用户丢来核心词说「这个词不太好」是选题评估，不是语气偏好。既不附和换掉，也不硬顶保留——跑三审、拿台账数据说话，最后给唯一推荐。

1. **整词可认读性**：项目口音下的自然读法、儿童常用义、口语例句；优先可听懂且画面可辨认的词。
2. **语境支撑**：目标词能否在几个清楚、适龄的场景里自然复现。
3. **可画性与区分度**：抽象质感（粗糙/光滑）出图必被画成「旧、脏、空」，且与 hard 这类关联词在画面上分不开，教学对比价值归零；动作词、听觉词、有形物件词明显更好画。
4. **候选从台账来**：`query 状态=已筛查` 取同批候选，逐词列对比表（义项 / 语境支撑 / 可画性 / 推荐度）再给唯一推荐——给表，不给开放式选项。
5. **换词不擅动台账**：被否掉的原词保持原状态；用户点头换词后按新词重跑 L1。换主角或换词都顺手核一遍与系列既有本的一致性（主角、画风），不一致用一行提示，不硬顶。
6. **释义语体分层**：标准译法可直接用在「中文释义」和台账词义；旁白/简介的文字必须是孩子嘴里会说的口语（「粗糙」→「糙糙的、扎手」）。**标题例外**：按 `rules.md` §1 走「释义逐字 + 量词/口语虚词白名单」，不做口语改写。〔裁定 R13〕

### 年龄与文字密度

| 年龄 | 每页文字量 | 核心能力 |
|---|---|---|
| 3岁 | 1–2 个词 | 看图指物，模仿发音 |
| 4岁 | 2–5 个词 | 看图认读完整词，跟读短语 |
| 5岁 | 1 个短句（5–8 词） | 在简短句子中认读常见词 |

### 参考图：先处理，再进 L2

**先查资产再处理**：L1 处理参考图时先查 Eagle 素材库（主库）有没有同类资产 → 有则复用；Notion 图库只查链接与复用说明（见 `notion-ops.md` §7），再走下面三步。

**三步走，不跳**：① 图下载到本地 → ② 压缩（长边 ≤1024、转 RGB、JPG quality 85–90，PIL 两行）→ ③ 再进视觉识别。直接把 Notion 链接或大原图丢给视觉工具会超时。签名 URL 只支持 GET，要图就当场下载，不存档隔天再用。〔裁定〕

**画风锚定**：角色来自参考图时，画风一律以该图为准——锚点提取与替换规则见 `rules.md` §5。

**参考图按需补，缺什么补什么〔裁定 2026-11-23；同日所有者改口径：默认走生图端自产参考图〕**：**无参考图的新书默认不再单独产出定妆图提示词**——L4 指令头第 2 行的批次指令（「请你先生成角色参考图，然后再生成封面和P1的图片，我确认没问题后，再生成剩下的。」）让生图端自己先生成并使用角色参考图，一致性由它锁定；比单独写提示词单独出参考图更高效，且分批出图能在第 1 批就发现画风问题，避免整本废稿。**旧方法的定妆图/比例尺提示词模板仅在所有者明确要求「先把参考图单独做出来」时使用**：

```
[角色名] 多视图定妆照提示词（每个角色单独出一张）:
请横向并排、等大、脚底对齐地排布以下三个视角:
1. 正面全身：正面站立，表情[描述]，双手[姿态]，能看到完整手臂与腿部
2. 四分之三侧全身：身体转约 45 度、面部朝向镜头，能看清另一侧耳朵与身体轮廓
3. 背面全身：背面全貌，背部与尾巴细节清楚，双手自然下垂
可选(仅当角色有抓握、攀爬、坐蹲等特殊动作时): 追加 1–2 格该动作姿态，同底、同风格、同尺寸
风格: [L1 确认的风格锚点]
重要: 三视角外观高度一致（毛色、眼睛、耳朵形状、服装）；纯浅色背景；画面里不出现文字、标注、边框、道具
参考图: [角色原始参考图的简要描述]
```

**双角色就出两张**（各自一张三视角图，同底、同风格、同尺寸）；只有一个角色就只出一张。若真正缺的是「两个角色之间的相对大小 / 道具与角色的比例」，别再各出一张定妆图，改出下面这张**比例尺场景图**：

```
[角色A] 与 [角色B] 比例尺场景图提示词:
画面: [角色A] 与 [角色B] 同框，处在同一平面、同一水平线；[角色A] 正用[爪/手]操作[目标道具]，[目标道具]旁边放着[第二道具]。
必须遵守的比例关系: [例：目标道具长约等于[角色A]前爪长度的两倍；纸的宽度约为道具长的四倍；道具立起时高度低于[角色A]的鼻子]；两角色身高关系[例：B 略高于 A]。
风格: [L1 确认的风格锚点]
重要: 两个角色的外观与各自定妆图一致；画面里不出现任何文字、字母、水印、标注、箭头；环境道具只作比例参考、不喧宾夺主。
比例: 16:9
```

**两类参考图不能混用验收**：定妆图必须**空手、无道具**；比例尺场景图**允许有道具与场景**，但它只作比例依据，图里的家具陈设要写进【参考图约定】的排除项。

规格口径〔裁定〕：**多视角参考图**——默认三视角（正面/四分之三侧/背面），有特殊动作可扩成姿态表；纯白或浅灰背景、各视角等大脚底对齐、全部清晰无景深虚化；**画面里只画这一个角色本身：空手站姿，不带道具、家具、文字、标识、边框、脚下投影、渐变底色**；带字标注的变体设定表不能当参考图用。用户传回后走视觉分析逐项核（视角一致性 / 风格质感 / 结构硬伤 / 多余物件），发现的瑕疵在 L4 用文字比例约束与【参考图约定】排除项补掉，不强求重生成。

### 生图后迭代（出图 → 回看 → 定位 → 单页改 → 复验）〔裁定 2026-11-23〕

出图由所有者完成，agent 不假装能"自己回看尚未回传的图"。责任分工写死在这里：

| 环节 | 谁做 | 产物 / 判据 |
|---|---|---|
| 核参考图够不够用（视角一致性 / 结构硬伤 / 多余物件 / 画风） | agent | 「可用」结论，或一张补图清单 |
| 写 L4 | agent | L4 文本 + 三道门禁绿 |
| 生成图片 | **所有者**（即梦，按提示词挂参考图、逐张切比例） | 整本或抽样的成图 |
| 反馈"哪页别扭" | **所有者**（可以只说一句，不必定位到行） | 一句话 + 截图 |
| 把反馈定位到具体页、给最小修改 | agent | 「改哪页哪句 → 改成什么」 |
| 判断新图是否修好 | **所有者拍板**；agent 只给复核清单 | 通过 / 再改 |
| 停止条件 | **所有者说"可以"** | 进入 L5 归档 |

**回看五类**（按出现频率排，逐页扫）：

1. **人手 / 手指**——角色应是四趾爪，不是人的手；
2. **比例**——道具与角色、道具与道具的大小关系；
3. **画面多出英文字母**——不该有词的页冒出词，或该有词的页没有；
4. **叙事道具被印字**——纸条、署名、缎带、门牌上冒出目标词；
5. **图文不符**——画面动作与当页旁白说的不是同一件事。

**改的纪律**：

- 只改**对应页**的 `生图提示词`（必要时连带改 `入画英文`），不重写整本；
- 改完重跑三道门禁；**门禁只证明文字层合规，不证明图已修好**；
- 输出「需重生图的页」清单（页号 + 一句话原因），不得谎称已改好；
- **同一页改 3 轮仍不对** → 停下报阻塞，改设计（换载体 / 换构图 / 换页型）；继续微调提示词是浪费。

### 角色可行性审查（选角色时一次，L4 出提示词前再核一次）

**选角顺序（2026-11-25 所有者裁定，先选人再谈复用）：每本书先根据题材、关键动作和人物关系选角色，再判断是否适合复用已有角色。**上一册角色和现成参考图只是**候选**，不是默认答案——复用要过「本书题材×动作×关系」三问，问不过就换。只有本书实际确定的角色才写入「已确认材料」；候选未采纳的不写。

**人物关系自然成立审查（与动作清单并列，收稿复核同一判据）**：故事里写明的关系（父子/母女/店员与顾客/朋友）必须能从角色搭配上自然成立。判例〔B572 实测〕：普通睡前家庭故事里，「熊爸爸 + 兔儿子」跨物种拼父子 → **退回**；换成人类父子或同种动物父子 → **通过**。口径：普通家庭故事自然选人类亲子或**同种**动物亲子；故事有明确设定支撑时（魔法、拟人世界观由文本交代）也允许其他关系。判据是「读者不看设定说明，能不能从画面直接读出这层关系」。

**先列动作，再选角色。** 角色必须能完成全书每一页的动作，不是只完成封面那一张。

1. **列动作清单**：九页结构定稿后，逐页写出角色必须做的动作，动词后注明用到哪个身体部位（抓/握/举/踮/攀/够/指向/递）。
2. **对肢体**：逐条核对身体条件——有没有能抓握的手或爪？能不能踮脚站立？能不能攀爬？能不能把肢体举过头顶？体形够不够得着目标物？
3. **有一页做不到就改**：换角色，或者改这一页的动作。不靠「看起来差不多」糊过去。

| 角色类型 | 抓握持物 | 举过头顶 | 攀爬 | 出图风险 |
|---|---|---|---|---|
| 人类儿童 | ✓ | ✓ | ✓ | 最稳，手部结构清楚 |
| 灵长类 / 浣熊 / 松鼠等有前爪 | ✓ | ✓ | ✓ | 写「前爪」比写「手」更稳 |
| 蹄类（鹿/马/牛/长颈鹿） | ✗ | ✗ | ✗ | 蹄子夹不住线，举手类动作必崩 |
| 象 | 仅鼻端可卷 | ✗ | ✗ | 能卷不能捏 |
| 鸟类 / 有鳍的 | ✗ | ✗ | ✗ | 翅膀和鳍无法持物 |
| 无肢（鱼/蛇） | ✗ | ✗ | ✗ | 只能贴附或缠绕 |

**出图稳定性二审（角色审完肢体，再审「模型画不画得稳」；假设，详见 `rules.md` §10 H6）**

- **复合持物动作是高危姿态**：「卷起 X、举起 Y、凑到嘴边」这类连续精细动作（两个以上肢体动作叠加 + 持物 + 对准身体部位）极易画崩：肢体扭曲、物件穿模、对不上位。
- **按角色类型匹配「谁用容器、谁用自然场景」**：有手/前爪、拟人化高的角色（人类儿童、灵长类、浣熊、熊类）端杯喝水、拿壶倒水完全成立；没有抓握肢体、靠口鼻直接接触的角色（象鼻、鸟喙），喝水才去河边/池塘自然场景，不对人工容器做精准对准。判据是**这个动作对这个角色是不是日常可信的姿势**。
- **动作清单逐条标「本能/习得」**：本能动作直接写；习得动作（拟人化持物、工具使用）必须过「生成模型画得稳吗」这一审，不稳就改写成本能动作或把物件挪进环境。
- **连指圆爪角色持物写「包覆」不写「握」**：无手指分化的 mitten 圆爪（Q 版猫/熊常见），持物一律写「圆爪弧形包覆住物体表面（桨柄/线轴/扶手）」——写「握/抓」模型会补出分叉手指。
- **审查范围含配角**：配角不是背景板，每个登场的动物都过同样的动作清单。

**用户点名要的角色过不了清单时：改动作，不改角色选择。** 用户对角色类型的直觉偏好优先于 checklist——把它做不到的动作从故事里设计掉（唱歌本全书零持物：唱歌＝张嘴＋音符飘出，打拍子＝展翅轻挥，写「翅膀」不写「手」），给用户「适配后的动作方案＋可行性结论」，不是拒绝。硬顶「换浣熊」是错的。

### 换角色 / 换画风 / 补参考图的整本同步

允许在 L4 起草后换角色、换画风或补参考图，但必须整本同步，不许只改封面——文字与画面对不上等于白改。同步三处：①【全局设计约定】的「主角外观」行；②【参考图约定】块；③**每页**提示词的「角色一致性」行。**还有两处旧版要求常被漏掉**：④ 简介 / 旁白里写死的身体动作（伸长脖子、用鼻子卷这类）要按新角色重写——文字写的是旧角色的肢体，画出来必然对不上；⑤ 词族页 / 互动页里指名旧角色的小格配图要与新角色同换，别只换主角大图、把小图留在旧角色上。改完 grep 旧描述/旧锚点词，残留必须为 0，再重跑门禁。块写法见 `l4-spec.md` §2–§3。

## §2 L2 页面结构设计

> 理解推进结构与页面结构的起草由**创作子代理**完成（`executor.md` §0.1），主模型负责与所有者确认与落盘。

### 标准页面类型（内页 8–16 页，封面不计入内页）

| 页码 | 页面类型 | 教学目标 | 视觉要素 |
|---|---|---|---|
| 封面 | **认知页** | 建立单词与图像的第一印象 | 大图展示目标事物 + 超大目标单词 |
| P1–P(n-2) | **语境页** | 在简单句子中反复见到目标词 | 目标词按旁白需要出现；出现时用独立装饰载体，配不同场景插图 |
| P(n-1) | **词族拓展页**（可选） | 认读适龄的完整词族词 | 每个完整单词配小图；英文列用**词表** |
| Pn | **互动练习页** | 主动回忆与输出 | 可辨认干扰物，答案藏在细节里；只提问不解答 |

页型只有这四种〔裁定〕。旧术语「语境重复页」作废。〔裁定〕

### 词族拓展页执行细则〔裁定〕

**词族页不是强制的**：只在条件合规（有适龄、可画、同尾族的拓展词）时才接入；无合适拓展词就整页换成语境页（见第 7 条）。

1. **英文列用词表**：逗号分隔的单词，如 `Pot, hot, dot, cot.`——**不写成句子、不加引导句**（不写 `Read them with me!`），朗读节奏优先。
2. **词族词数量**：常规 **2–3 个拓展词**，**最多 4 个**（含核心词本身）。
3. **核心词本身是词族成员时**（pot 之于 pot/hot/dot/cot）必须列为成员、放第一位。
4. **主角可缺席**：该页教学载体是词族词，主角可以不出现；缺席时「角色一致性」写 `角色一致性: 本页无角色——教学载体是词族词`，不得空着。
5. **配色**：同一页多个词可以各词一色，但每个词仍须单色整词、不逐字母分色。
6. **只用同尾族**（rime）：每个词共享同一词尾，**≥2 字符、字形与发音都一致**；**首音族不采用**（r- 开头那一类）。输出结构表前逐项核对。
7. **无合适拓展时换语境页**（判断口径：拓展词不适龄或不可画）。
8. **中文列必须带中文释义**〔2026-11-24 所有者定〕：中文旁白里只要出现拓展词（含核心词本身），**每个拓展词都必须配中文释义**（如 `饭盒 lunchbox，盒子 box，狐狸 fox。`），不许只列英文词表。核心词按 R16 口径出现中文释义；拓展词逐一跟在英文词前或后，孩子能对上号。
9. **连读接得上**〔2026-11-24 创作方法更新〕：词族页放进全书顺读一遍——从上一页的情境跳到词族词，孩子跟得上吗？（B683 判例：从早餐桌上的松饼跳到湖和蛇，形式上六条全过，但打断了正在展开的早餐体验 → 该页换素材：改成「松饼切开的样子」，让孩子多看清一个特征。）接不上就换这一页的素材（旁白与分镜一起改，并同步更新页面结构表、一句话回报所有者）；**接得上、也确实帮助孩子认词的词族页就保留**——判例带题材限定，不是「词族页默认换掉」。

### 整词领读〔裁定〕

封面后直接进入第一个有内容的语境页。不设字母拆解、不做词内拼读，也不为原环节保留固定页位；P1、P2 只是页码。需要凑页数时用有独立画面和语义的语境页补足。完整目标词随画面和自然短句复现，停顿落在词与词之间或句意边界。

### 语境页设计规则

- **让画面决定旁白开头**：从当页可见的动作、声音、物件、关系或变化起句，让完整目标词自然进句；有意设计的儿歌式反复可以保留，但语境页不套同一个开头。
- **每页配不同场景**，主角外观一致。
- **先想孩子理解这个词的过程，再分页面**：孩子在哪里第一次把词和画面对上？后来又多懂了什么？整本书在哪里收住？据此决定哪些画面值得独立成页、在哪里翻过去能看到一个变化。全书组织方式由题材决定：**连续推进**（卷笔刀式：铅笔钝了→转一转→看看画出的线，页面承接上一页的结果）与**情境并列**（手帕式：擦汗、捂鼻、递给哭了的朋友，同一件东西在不同情境派上用场）都合法，不允许并列的书不硬造因果链。方向难以取舍时，先试写不同方向的关键页，哪一版更能让孩子自己看懂就选哪版继续展开（试写过程不端给所有者，择优结果写进骨架）。不为凑页临时加掉落、寻找、重来等岔路；一页删掉不影响理解/节奏/情绪，就合并或重排；**加一页之前反过来先想（Codex 交接包 01:原话一）：这一页给孩子带来了什么新发现？答不出就别加**。
- 内页 8–16：先根据内容决定需要留多少页，再参考台账同系列近作的页数分布；连续几本同一页数时，回看本书是否真的需要这么多页。需要停一下看变化的画面可以留一页；重复提供同样信息的页面合并。相同页数有充分理由时保留。
- **骨架必须指出「最想翻页的一处」（Codex 交接包 00:14、01:原话三）**：结构表交出去时要能说清——孩子在哪一页最想翻页、翻过去会发现什么（连续型=推进了一步，并列型=多认得一种情境）；说不清 ⇒ 骨架未成，回炉。每页在全书中的作用（推进 / 停一下看变化 / 靠重复让孩子参与 / 认出刚才见过的东西）按整本连读读起来的效果决定（方法见 §3 第二步「整本一次领读与连读三诊」），不由页型预设。
- **切入点先内想几个再择优（Codex 交接包 01:原话一）**：起草前在内部想几个真正不同的切入点（换角色或换地点，但孩子做的事、发现的事一样 = 还是同一个方向），选最能展开的一个写进骨架；择优过程不必端给所有者。
- **交骨架前列出实际参考的排产号**：看中控台前后已创作作品，说明参考了哪些排产号和实际内页数；内页数由本书内容决定，相邻作品可以同页数，每本说清拆页、合页理由。
- **可画瞬间服务于连续体验**：从真实动作中选可辨认的反应（搓出泡泡、折出折痕），不要求每页都制造即时反应。拿起、放回、等待、完成也可以成页，只要承担必要的衔接或收尾；简介从实际页面取材，不反过来驱动页面凑热闹。

### L2 输出前结构核对（硬规则，逐条自检）

- 词族拓展页在 P(n-1)（无拓展则换语境页）；互动练习页在 Pn；语境页占 P1–P(n-2)。
- 页面类型只用四种写法，无第五类、无前缀。
- 封面 3:4，内页 16:9。
- 每页都有可跟读 / 可指读 / 可互动的落点。
- 互动练习页的问题**只有一个正确答案**：动作词问「哪里要 X」时，画面里只留一处在等着做这个动作（四处都还能做就是四个答案 → 改问辨认，让答案落在唯一那件成品上）；名词词才问「哪一个是 X」。
- 一页一概念：每页只教目标词一个词，不夹带第二个新概念。
- **目标词按旁白需要出现，不强制每页**（2026-11-23 所有者改口径）：该页叙事情节方便承载就出现，不方便就不出现，不许硬加。一旦出现，必须写出实际入画的完整词、载体与排法（封面按书名形态，内页按整词形态）。**载体纪律**：载体跟当页情节走——故事道具（纸条、署名、礼盒缎带、信封、门牌）默认保持素净；如果情节本身适合承载，可以承载。**这一条不是硬条款，机检不判，人工核。**〔2026-11-23 所有者裁定〕重复次数口径见 `rules.md` §3（该统计现仅作历史分布参考）。
- **理解递进自检**：孩子翻到最后一页，比第一页多懂了什么？（连续型=推进了一步；并列型=多认得一种情境）答不出 ⇒ 结构未成，回炉。

## §3 L3 标题 → 双语旁白 → 简介

**顺序是硬的**〔裁定〕：标题（唯一形态，所有者确认义项）→ 双语旁白（先过 L3.5 与 `grammar_check`）→ 简介（3 备选，逐条对回刚定稿的旁白页面）。旁白先定稿，简介才有真实页面可对；反过来先写简介，简介里的动作必然对不上旁白，是返工头号来源。

### 第一步：标题（唯一形态，不出备选）〔裁定 R13〕

**先做「义项可见性核对」（人工核，不可机检）**：封面叫出来的这个义项，孩子在正文里真的看得出来吗？多义词尤其要核对——教 light 的「轻」，书里应有能看出重量差别的动作或画面；如果画面一直在表现灯亮了，回到立意或分镜检查选义。义项确认后，按系列格式出标题。

```
【标题】

高，high / English: High
```

要求与判据见 `rules.md` §1。

### 第二步：双语旁白

**整本一次领读：先像讲给孩子听，再落到每一页。** 写旁白前，先顺着分镜把这本书从头讲一遍。想象你坐在孩子旁边，每次翻页只给他看眼前这一页——到这一刻，孩子已经知道什么？这一页值得他再看一眼、听一句或跟着做什么？可以直接叫出名字，也可以让孩子看一会儿变化、等一下结果、跟着说一句，或认出刚才见过的东西。有的页用来推进，有的页用来停一下，有的页靠重复让孩子参与——每页的作用按全书读起来的效果决定（§2 骨架的「最想翻页的一处」从这里长出来）。

叙述形态指引〔2026-11-24 创作方法更新〕：
- **每一页必须有旁白**（互动页的提问即为该页旁白）；
- 第一次需要认名字时，直接叫出来就很好（「这是一把干草」）；
- 有的页面适合让孩子听见人物开口（对白），有的适合念出画面里值得留意的变化（叙述），有的可以靠重复让孩子自己跟着说（领读）——**叙述、对白和提问都可以用，切换时让孩子听得出谁在说、对谁说**；
- 目标词在再次出现能帮助孩子辨认、理解新用法或参与领读时念回来（出现规则仍按 L2 口径：按旁白需要，不强制每页）。

**连读三诊**〔2026-11-24 创作方法更新；写完旁白后执行，替换旧的「听到哪句直接改那句」口径〕：成稿后，中英文各自按页连读（两边都要适合念给孩子听，并与同一页的画面、动作和义项对齐）。遇到想停下来补解释的地方，**先诊断缺的是什么，再动手**：

- **诊一 · 缺一句话**：孩子已经知道的事，直接往下讲，不让他重新猜。判例（B683）：P1 已说锅里是面糊，P2 的「这是什么呀？」让孩子重新猜名字 → 改「快看，冒泡泡了！」一句把注意力接到正发生的变化上。写问句前，先听听孩子此刻真的会想知道什么。
- **诊二 · 缺一个画面**：旁白说到了，分镜没画到——补的是画面过程。判据句：复核时留意人物、物件、数量、地点和说话人有没有在翻页时悄悄变掉。例：上一页只有一张饼，下一页说「把它们叠起来」，连读时找不到「它们」→ 旁白补「再煎几张，叠起来」，分镜同步画出一张变几张。**诊二旁白与分镜一起改，并同步更新页面结构表、一句话回报所有者（改前→改后），不静默改。**（诊二暂无成书判例，以判据为准。）
- **诊三 · 页本身选错了素材**：一页单独看合规，放在全书连读里却打断了正在展开的体验——换这一页的内容。判例（B683）：词族页形式上全过，但从早餐桌跳到湖和蛇，打断了这本书正在讲的早餐 → 换成「松饼切开的样子」让孩子多看清一个特征。别的题材里，词族页若读起来接得上、也帮助孩子认词，就保留（细则见 §2 词族拓展页执行细则第 9 条）。**诊三分镜与旁白一起改**，并同步更新页面结构表、回报所有者。

三诊的定位问句（帮助判断改旁白还是改分镜还是换素材）：我念到这里时，孩子会看哪儿、想到什么？他凭前几页和眼前这幅图，能跟上我说的话吗？如果这页听着多余、跳得太快或需要我额外解释——该改的是旁白，还是分镜，还是这一页本身？

诊断是为了改对地方：连读发现真实问题就修——必要时说明孩子原来在哪儿跟不上、改了什么。验证或需要展示效果时，用明确的改前→改后呈现。机检继续核对页数、每页有旁白、双语表格式等硬要求；段落是否顺、词什么时候出现、词族页是否值得保留，用实际连读和图文对照来判断。

**纯 Markdown 表格（`|` 分隔），不用代码块包裹**〔裁定〕；只有 L4 生图提示词才用代码块。

```
【双语旁白】

| 页码 | 英文 | 中文 | 领读 |
|------|------|------|------|
| 封面 | Cat | 猫咪 Cat | 可带读 Cat |
| P1 | The cat jumps onto the mat. | 小猫跳上垫子，cat。 | — |
| P2 | The cat curls up. | 小猫把身子蜷起来，cat。 | 停一下，让孩子先指猫 |

第四列「领读」写给带读的成人（口径见 rules.md §3）：`可带读 <词>` / `停一下…` / `—`；孩子读物正文不出现成人指令。
```

封面行 = 用户选定的标题（中文列 + 英文列逐字照抄，不缩写不改写）；封面是标题唯一出现的地方。格式与判据见 `rules.md` §3。

### 第三步：简介 3 备选

**起草一律走创作子代理**（`executor.md` §0.1：先问所有者本次创作用哪个模型，默认上次指定；现行默认 `ollama-cloud / gemma4:31b`），主模型不代笔。**写法走 rules.md §2「创作方法」**（2026-11-24 所有者方法论：先看整本书带孩子经历了什么，再判断全书组织方式、参照蓝本选写法——饭盒=单瞬间、手帕=动作排比均为蓝本参照而非固定映射，疑问/发现/变化由书的内容定；细则与创作 Agent 指令模板见 `rules.md` §2），不是逐条套判据硬凑。**素材来源**：简介从已定稿的页面结构表与双语旁白表取材（先旁白后简介是硬顺序，上一节）；简介之前先确认本书立意线索（L1），立意给选材锚定方向（详见 rules.md §2「立意」与「创作方法」的叠加关系）。

### L3 执行前强制检查清单（每次逐项核对后再输出）

| 检查项 | 核对内容 |
|---|---|
| 标题规则 | 目标词是不是标题的主角（中文自含词义、目标词自然落点）？有没有方法论括注？有没有用「有画面感」套话代替点题？**义项可见性核对过了吗**（封面叫出的义项正文里看得出来，人工核）？ |
| 简介规则 | 立意锚点孩子听到能否对上他见过的情形？一句一个信息？开头有没有写场景布置（摆/放/挂＋物体存在）？叠词是否带「的」且最多一个？动作是否对回当页旁白？目标词是否只在句尾一次？ |
| 整词口径 | 中英旁白都用完整词；没有拆读环节、字母念读、词内停顿、词尾拆读。 |
| 旁白表格式 | 纯 Markdown 表格、没用代码块包裹。 |
| 旁白表内容 | 四列齐全（页码 + 英文 + 中文 + 领读）；英文列含目标词的行，中文列必须同现该词（封面行豁免）；物件从**当本**故事主线长出来。 |
| 语法与文字规范 | 标题、简介、旁白三处都过 `rules.md` §4；出声读一遍核目标词落点。 |
| 旁白机审 | 旁白表存临时文件跑 `grammar_check.py`，EXIT=0 才端给用户。 |
| 标题判据 | 标题过 E1–E5 + G1/G2/P1（`title_intro_check --gloss --pos` EXIT=0），且所有者已确认义项——否则停。 |
| 简介备选 | 简介 3 条，用户**已明确选定**——否则停。 |
| 角色可行性 | 动作清单逐条对过肢体，做不到的页已改。**人物关系自然成立**（2026-11-25）：故事写明的关系（父子/母女/店客/朋友）能从角色搭配直接读出——普通家庭故事的人类亲子或同种动物亲子过，跨物种拼亲属且无设定支撑的退回（判例 B572：熊爸爸+兔儿子退回，人类父子通过）；上一册角色/参考图只是候选，复用须过本书题材×动作×关系三问，只有本书实际确定的角色进「已确认材料」。 |
| 封面对齐标题 | 旁白表封面行逐字等于选定标题；L4 封面英文书名与之一致（含大小写、标点、引号）；封面按 `l4-spec.md` §6 执行。 |

### 批量模式（连续下单）

用户一次只丢一个核心词、中间不再重复年龄/风格/页数。这是**减少用户输入**，不是减少确认环节。

照做的：年龄、风格、九页结构、核心词小写、旁白落点按默认值直接定，不问。默认值取**同词群的最近一本**（不是全库最近一本）：词群写在台账备注里（「词群：家庭清洁 / 游戏手工 / 物体感官对比…」），一本一个词群换一套主角与画风是常态；跨词群抄会把上一词群的主角、画风搬到新题材上。定位新本时先把同词群的已制作/待生图行拉出来比对，再决定沿用哪套。用户说「角色还用上一本那只」时直接复用上一本的【参考图约定】块与图像1锚定句式（外观串逐字照抄，不凭记忆重写），只按当本改道具与场景。

一步都不能省的：**标题必须过判据并让所有者确认义项**（不出备选、不许自拟释义）；**简介必须完整写 3 条并等选定**（不能只给一条、不能替用户挑）；用户选定后才输出 L4、才归档。

## §4 L3.5 口语门禁（强制 · 输出旁白前执行）

顺序是硬的：旁白写完后先在内部跑完这一关，**再**把旁白发给用户。〔裁定〕用户看到的第一版必须已过审。

**方法**：出声念每页中文，一口气念完 + 六查。

1. **一口气念完**：中途换气、卡壳、或心里想换个说法，都算不合格，这句重写。
2. **目标词是否融入句意**：按 `rules.md` §4 六审；释义与英文在需要认读时自然对应，不逐页机械复述，也不为避开释义写出指代不明的句子。
3. **整词跟读口令**：用「跟我读」「再读一遍」这类短口令引导完整词，不在词内停顿。
4. **书面词 / 方言词 / 术语 / 画面效果（四类一起过）**：
   - 书面词：里、中、之上、以及、因此、进行、呈现 → 里头、上面、和、所以、做、画着；书面实词同判（年幼→还小、碎屑→瓜子壳、一撮→一点）。
   - 方言词不算口语：带明显地域色彩的说法不写（渣渣、香得很）；判据是普通话儿童读物里出现过没有。
   - 术语/部位名换成孩子的话：椅腿→椅子脚、脚爪→脚、哪一处→哪里。
   - 不写画面效果：照出脚爪、亮得发光、反着光——那是给画师的渲染说明；写结果本身（地上真干净、亮晶晶的）。
   - 具体实物名优先于笼统词：能点名就点名（瓜子壳、小纸片）；同一本里同一个东西只用一个名字。
5. **衔接与节奏**：连读发现「接不上」时按 §3 第二步「连读三诊」定位处置（缺一句话/缺一个画面/页选错素材）。三诊之外仍须自查：同一起手句/主语/判断句连用时，改从该页动作、声音或细节开口；批量稿再横看各本首个语境页查跨书重复。相邻页按「上一页发生了什么 → 本页变了什么 → 下一页怎么接」核对动作、道具位置与状态程度。
6. **语气助词适度**：只在句尾本来就会带的地方出现（啦/喽/呀/哦/呢），全书散着几处就够，一页最多一个。

> 前五条（第 5 条含三诊指针）是「哪儿听着不对」的抓手，不是打分表，不许逐条打勾交差。唯一标准：念出来像不像大人蹲下来跟孩子说话。未过 → 重写该句；改标点、换同义词不算修好。

**主模型收稿复核（收稿出口，2026-11-24 所有者裁定；①于同日创作方法更新收窄为衔接连读，④为同日新增；2026-11-24 晚二次明确：①②③查简介与旁白正文，④只核旁白表；2026-11-24 深夜三诊版：旁白分支①扩为连读三诊——见 §3 第二步）**：创作子代理交稿后、端给所有者前，主模型除朗读复核外逐条查——
- **对简介**：①**衔接连读**（逐句连读孩子能否跟上；单瞬间手法首二句同画面按手法条款；简介不套三诊的「换素材」处置——简介没有分镜）、②**事实全部在书内**、③**用词**（小字病扫描 + 孩子口语判据）。
- **对旁白表**：①扩为**连读三诊**（按 §3 第二步：缺一句话/缺一个画面/页选错素材，定位后判「改旁白/改分镜（旁白分镜一起改+更新结构表+回报）/换页素材（整条退回创作槽重做该页）」）；②③同上逐页核，**另核④第四列口径**——领读列必须是成人带读提示（`可带读 <词>` / `停一下…` / `—`），出现叙述形态标签（如「叙述（惊讶）」「团团（兴奋）」）即退；且在**目标词首次与实物对上的页面**，领读提示应把目标词带出来（`可带读 <目标词>`），让孩子第一次对上时成人就把词念给他。⑤**核心词按认读需要出现**（2026-11-25 所有者裁定）——推进情节的页面（如写信、积木倒塌、走向某处）不需要念出核心词时，旁白应把动作讲顺而非硬加词；发现纯推进页被硬加核心词即为退回理由（附认读判断：此时念出这个词，孩子会把它和什么对上？没有对上→退回重写该页）。每页都有旁白，英文核心词按当页内容和认读需要出现；出现次数和省略页数由这本书决定。⑥**人物关系自然成立**（2026-11-25 所有者裁定）——核对动作能否完成之外，还要核对故事里的关系能否从人物和画面上自然成立：普通睡前家庭故事选人类亲子或同种动物亲子；跨物种拼亲属（熊爸爸+兔儿子式）且无设定支撑即退回；故事有明确设定支撑时允许其他关系。判例：B572 旧版（熊爸爸+兔儿子）应退回、新版（人类父子）应通过——拿旧版负控跑此条判不出 FAIL = 规范没抓住病灶。
- 任一不过 → 整条退回创作子代理，不自行代改。被否过的稿子留作负控：新规范上线后先拿它判 FAIL，判不出 FAIL 说明规范没抓住病灶（三诊负控判例：B683 打磨记录中的 P2 旧句「这是什么呀」须被判出诊一、词族页旧稿须被判出诊三）。
