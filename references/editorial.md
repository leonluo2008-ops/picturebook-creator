# 创作与审稿

## 需求和结构

- 确认已有设定与当前交付范围。领读明确目标词、词性、当本义项、年龄、角色和画风。台账词型与目标义项冲突时，先核对再决定。用户给了风格或参考图，直接沿用已确认选择。
- 领读常规为封面加 8 个内页，按内容可在 8–16 个内页内安排。首个内页直接出现一个可画的语境。动作适合用起点、变化与收尾串起来；感官和状态词也可以用独立场景反复呈现同一词义。不要为保留旧页位补两张教学页。
- 可选词族拓展只收适龄、可画，且符合共同词尾拼写与读音的完整词；条件只用于内部选词。候选不足时用语境页。互动页提出画面能回答的问题，答案数量按题意与画面设计一致，答案不靠颜色或位置提示。
- 故事模式先定角色想做什么、如何遇到变化、最后怎么收尾。情节通过行动和画面推进。需要参考图时，只确认对外形、动作可行性或风格有影响的差异。

## 标题、旁白和简介

- 标题以题材及已确认词义为主。感官状态用中性、简洁直白的儿童语言。需要用户选稿时提供三个真正有区别的选项；沿用已确认标题时直接进入后续工作。
- 双语旁白用 `页码 / 英文 / 中文` 三列 Markdown 表格。封面行照录选定中英文书名。英文遵循正常语法，可按句意变形；中文用孩子会说的话，领读落点可用词头，与入画标签对齐。角色部位用儿童口语，例如「爪子」。领读英文含目标词时，中文也要有完整目标词。
- 一页讲一个能被听懂、看见的变化。用当页的动作、声音、物件或关系起句。中英分别连读全书，批量再横看各本的开场；发现重复的起手句或判断句，改从具体画面切入。有意设计的反复可以保留。
- 对照前后页的动作、道具位置和状态程度。刚缓解和完全消失都要有对应画面；只换说法而没有新信息时，回看页面是否必要。改一句时同时顺读前后句，但按用户指定范围改稿。
- 领读简介在旁白定稿后写，从真实画面选一个最贴近孩子的瞬间，用一两句自然口语点出词义。旧稿简介逐项核对动作、道具和结果；吻合则沿用，有出入只调整失配处。
- 写完出声顺读。领读稿运行 `python3 tools/grammar_check.py <旁白文件> --word <目标词>`。词形或双语缺失须修正，标点数量差异按实际朗读判断。

## 可选 BGM

用户要求时，按年龄、场景和情绪写可直接用于生成的背景音乐提示词。指定主要乐器、速度感、时长和从开场到收尾的变化；配乐应给旁白留空间。
