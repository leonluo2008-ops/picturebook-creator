# 创作规范

阶段与确认顺序只在 SKILL.md 定义。本文件用于结构、标题、完整文稿和简介的创作与审稿。

## 需求与结构

领读先定一个核心词、当本义项、年龄和篇幅。常规内页规格为短篇 8–10、中篇 11–14、长篇 15–16，封面另计。既有页数直接沿用；全新需求未指定时给出适合题材的建议供确认，不自行宣称用户选了某档。用户明确另定页数则按其要求。

先判断什么画面能让孩子明白这个词：

- 物件与动作可用连续体验：开始、发生变化、完成；道具与动作承接自然。
- 感官、状态可用多物件或多场景：每页都明确体现所教状态，不为剧情让词义离开画面。
- 位置关系必须说清主体与参照物，选择能看清关系的视角；遮挡仍应让主体可辨认。避免把“后面”画成下面、旁边或里面。
- 故事模式围绕角色想做什么、遇到什么变化、怎样回应和收尾；不强制逐页出现教学词。

结构表包括封面及逐页任务、可画瞬间。翻页应带来动作、观察、程度、视角或互动的变化；只是换了物件名而没有阅读价值的页，合并或重设计。多场景不必硬加故事冲突，连续故事也不必每页更换地点。

末页可安排找、指、数等画面互动，旁白带清楚的行动邀请，让孩子知道要做什么。按题意设计答案数量：问“哪一个”则唯一，问“哪几个”可有多个。实际画面与问句对应，不用箭头、角色手势或特殊配色泄露答案。拓展页可选，使用适龄、可画的完整词；不为了固定页位加入词族或共同词尾教学。

## 标题

提供三组中英文候选，简洁、好懂且有实际区别。领读标题体现词义并包含目标词；感官和状态优先中性直白，不凭空增加厌恶、抱怨或夸张情绪。故事标题服务情节。

正式英文书名按正常书名习惯确定大小写与标点。选定后封面旁白、提示词中的英文书名和台账一致；用来标记入画文字的外层引号不算书名的一部分。不要为了对齐检查器擅自改用户选定标题。

## 完整文稿

标题选定后，交付中英文书名、封面画面构想、完整三列表格。第一行必须是封面，英文列与中文列分别照录已选书名，随后顺序写 P1 至末页。封面构想说明标题载体、主体及词义如何被看见，不提前代替整本 L4。

| 页码 | 英文 | 中文 |
| --- | --- | --- |
| 封面 | 已选英文书名 | 已选中文书名 |
| P1 至末页逐行写全 | 当页可朗读的英文 | 同一画面、同一状态的中文 |

上表仅说明格式，正式稿不能保留占位词或合并页码。

### 写得像孩子愿意听的绘本

- 先想这一页发生或看见了什么，再写一句自然的话。从动作、声音、物件、发现或关系切入；不要先复制句型再替换名词。
- 中英表达同一事实和程度，允许自然语序、句长及句界不同。中文像家长指着图说话，使用“爪子”等完整儿童口语，不为节奏省成生硬单字。
- 领读英文让目标词自然出现，可按语法屈折。中文内页用完整的小写认读词头，封面跟随已选书名；独立标签也可沿用词头。不要为了标签一致而破坏英文主谓、数或时态。中文认读词自然承接当页话语，不在每页另附同一句词义翻译口号；用户明确要求的韵律反复另按其要求。
- 中文认读词放在完整意群结束处，通常在页末；不插在状语和主谓、动作和对象之间打断中文。互动页先把中文问题自然问完整，再读目标词，避免把英文词硬塞到中文问号前。
- 角色采用自然称谓；没有用户指定名字时，英文按普通名词及其冠词表达，不擅自把物种名大写当人名。已有角色名称按用户设定。
- 每页通常一两句短话，长度随年龄与画面调整。短句与稍长句、观察与动作可以自然交替；不要用不断加“Look!”掩盖同一骨架。
- 有意的反复能帮助认读，但反复应带来新的理解或节奏。检查全书句式及系列开头，避免每本同一句开场。
- 旁白描述当前状态。缓解、仍然存在和完全结束有区别；既然已完全解除，就不要同时用原状态给角色贴标签。若核心词必须继续出现，可设计仍符合该状态的场景，而非让人物说相互矛盾的话。
- 数量、主体、方向和行为必须画得出来；动作符合角色身体能力。一个静态页面选一个主要瞬间，不能同时画连续多步的全部结果。

### 交稿前审核

1. 按英文列、中文列分别连读全书，检查自然口语与节奏。每页只换名词时，返回画面任务重写，不能只替换同义词。
2. 对照结构逐页核实词义、人物、数量、动作、道具、空间关系和前后状态。状态变化须有动作或场景依据，不能让已经停止或完成的事情无故重新发生。中文和英文必须能对应同一张图。
3. 检查封面行、连续页码及总页数，书名与选定版本一致。全文展示给用户后等待确认。
4. 若使用工具校验，报告它实际检查的范围。文本结构检查不等于英语语法、文学质量或图片验收。

有 Python 时运行 [check_book.py](../scripts/check_book.py) 检查完整页序与书名：`python scripts/check_book.py --narration <稿件文件> --word <目标词> --pages <内页数> --cover-en <选定英文书名> --cover-cn <选定中文书名>`。故事稿不传 `--word`；局部修订不把单行片段当作整本运行。该工具不检查语法和语言质量。

## 简介

完整文稿确认后再写三条候选，每条一两句儿童口语，从实际定稿画面选一个具体瞬间，简洁地引出词义或体验。目标词自然落在结尾即可，不固定为疑问句或叹号。

每条都能指出取材页；不虚构动作、物件或结果，不强迫每本“好玩”“舒服”，不向家长解释教学方法或承诺学习效果。问句必须承接前句，孩子看图能作答；牵强时改为自然陈述。

修订已有稿时核对简介的主体、动作和结果，仍吻合就保留；失配才改，不为“更新”重写所有简介。用户否定简介时先改失配处，不擅自推翻已确认旁白。

## 可选配乐

用户需要时提供与年龄、情绪和阅读节奏匹配的器乐提示词，写明乐器、速度感、时长与变化，给旁白留出空间；不默认附赠配乐流程。
