# 无固定角色目标词反小动物套路模式

## 概述

无固定角色目标词（疑问代词/抽象名词/物体类）需要避开"小动物成主角"的反模式。本文件归集已观察到的反小动物套路、修复模板和自检清单。

**适用范围**：用户明确说"图中没有固定的角色" / "不用有固定角色" / 目标词本身是无生命的（what/who/where/why 等疑问代词 + 抽象名词 + 物体类）。

## 已观察反模式

### 反模式 1 · 小动物抢占焦点（最常见）

- ❌ what 绘本每页塞一只小狐狸站在那里看盒子 → 狐狸喧宾夺主，"what"是什么反而看不清
- ❌ who 绘本每页塞一只小兔子提问 → 主体不是 who（被问的事物），而是小兔子

### 反模式 2 · 抽象词硬塞小动物打比方

- ❌ love 绘本硬塞小动物抱抱 → 失去抽象概念传达
- ❌ peace 绘本硬塞小动物打坐 → 失去抽象概念传达

### 反模式 3 · 物体类目标词被小动物陪衬

- ❌ school 绘本每页塞一只小狐狸参观 → 学校特征反而不明显

## 正确做法（无固定主角路径）

### 路径 A · 纯物体特写（首选）

每页主体就是目标事物本身（盒子/树/花园/池塘里的"what"），**完全不出现任何小动物**。

适用：物体类目标词（book/pencil/school/cafe 等）

### 路径 B · 完整动物 + 大问号（疑问代词专用，2026-07-19 实测升级）

**重要**：疑问代词（who/what/where）的"局部悬念"画法（只露半张脸/一只耳朵）在 2026-07-19 实测中失败——AI 渲染半截动物效果丑，3-6 岁孩子也看不懂"是悬念设计"。

**正确画法**：每页主体是一只**完整**的小动物（瓢虫/小猫/小鸟/小鸭/青蛙/小鱼，6 种稳定模板），旁边放一个**大亮黄色/亮红色问号**做主角。

- who：完整动物 + 大问号"是谁"
- what：完整物体 + 大问号"是什么"
- where：完整场景 + 大问号"在哪里"

**6 种稳定动物模板**（ECP 风渲染稳定）：
1. 瓢虫（半圆红翅+7 黑斑+6 条腿）
2. 小猫（圆头三角耳+圆眼+4 腿+尾巴）
3. 小鸟（圆身体+小圆眼+尖嘴+翅膀+2 腿）
4. 小鸭（圆身体+扁嘴+翅膀+脚蹼）
5. 小青蛇（圆头+长身体+蛇信）
6. 小鱼（椭圆身体+三角尾+背鳍）

**L4 模板示例**：

```
画面中央是一只完整的红色瓢虫停在翠绿叶子上,瓢虫半圆形亮红色翅膀有 7 个黑色圆斑,黑色小脑袋两只触角,六条腿完整可见,翅膀完整。瓢虫旁边有一个大亮黄色问号。
```

### 路径 C · 远景剪影（次选）

如果一定要有动物，动物只在背景中（远处/远景剪影），不能抢焦点。

适用：场景类目标词需要营造氛围时（forest/garden/sea）

## L4 反小动物套路提示词模板

```text
本绘本无固定主角,每页围绕被问的"谁/什么"(画面中心神秘事物)来呈现,让孩子去猜。主体是画面视觉焦点,不允许任何小动物(狐狸/兔子/小熊等)出镜抢占焦点。如果一定要有动物,仅作为远景剪影。
```

## L4 输出前自检

```
[ ] 主体是被问的事物，不是小动物？
[ ] 神秘事物是否故意只露局部（悬念设计）？
[ ] 是否避免了"小狐狸站在那里问"的套路？
[ ] 反混淆清单已就位（what 不是随便什么物体，而是 L3 旁白里指的事物）？
[ ] 每页 L4 提示词的主体部分，主语是不是目标事物本身？如果是小动物，必须重写。
```

## 修复反模式的 5 步重写

1. **列出每页"被问的事物"是什么**（what = 盒子里/天上/花园里/树上/海底的什么具体事物）
2. **主体词改为该具体事物**（不是"小狐狸看盒子"，而是"盒子里露出一件物体"）
3. **加悬念设计**（"只露半张脸/一只耳朵/尾巴尖"）
4. **加反混淆清单**（不是随便什么物体，而是 L3 旁白明确指的事物）
5. **每页末尾确认**主体是该事物，不是小动物

## 历史教训

- **2026-07-18 what/who**：用户明确说"不用有固定角色" → L4 默认串场小狐狸 → 用户没说不行但 L4 提示词里加了"默认主角是橙红色小狐狸"是错的（虽然用户没纠正，但模式不对）→ 应该让每页主体就是"被问的事物"
- **2026-07-14 long 实测**：用户原话"不需要有固定角色小狐狸出镜的就不要有" → 长短物体目标词不需要小狐狸陪衬
- **2026-07-14 village 实测**：用户原话"我不想要有人物" → village 类场景类目标词不需要小动物
