**用户原话**（olive + peach 双实测）：
- 第 1 次（olive）："中文旁白后面的英文部分只有核心词，请修改旁白"

**用户原话**（peach）："**兄弟，请你给旁白加上正确的标点符号**"

**升级原因**：用户两次反馈（一次"加标点"，一次"记住了不要再强调"）。

**默认执行**：
- P1 封面：可 `!`（首字母大写）
- P2 认知页：永远不带 `!`（OSMANTHUS TREE / PEACH TREE 无尾标点）
- P3-Pn：陈述句加 `。` / `.`，收束/感叹句加 `！` / `!`

## 5. 失败案例 / 用户反馈教训

### 5.1 olive tree "修改的不好，请重新修改"
- 用户原意："中文末尾英文部分只有核心词" = 每行末尾统一为 `Olive Tree`
- agent 误读："核心词" = 每行绑完整短语（如 `silver-green olive leaves`），"只"= 只绑这一个，不要绑其他短语
- 教训：**用户的"核心词"指主题词本身**，不是"每行短语里的中心名词"。下次默认即按"主题核心词全表统一"理解

### 5.2 osmanthus "请你直接发在对话框"
- agent 输出 L4 后说"完整版我留在 /tmp/osmanthus-l4.md"
- 用户立刻回"请你直接发在对话框"
- 已沉淀到第二十五类陷阱

### 5.3 peach tree 连续 3 轮修改
- 用户一次说完所有修改指令（"第4句换成...第5句换成...把第8句换到第4句后面"）
- agent 第 1 轮没同时执行所有指令 → 用户继续细化
- 教训：**用户一次给多个修改指令时，要全部并行执行，不要挑一个先改**
