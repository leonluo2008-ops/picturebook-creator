# 海产/水生领读系列批量模式（seafood-series-batch-pattern）

> 适用于 3-6 岁蜡笔手绘童趣风海产/水生单词：shrimp（虾）、fish（鱼）、hairtail（带鱼）等。
> 触发词：虾、鱼、带鱼、海鱼、shrimp、fish、hairtail 等水生可食用生物。
> 沉淀时间：2026-07-12 shrimp/fish/hairtail 三本实测。

## 一、风格锚点（已实测稳定）

**蜡笔手绘童趣风** = 色块鲜明 + 粗蜡笔笔触 + 童趣可爱 + 边缘有粗蜡笔笔触感

L4 全局设计约定必备字段：
- 目标单词 + 目标年龄
- 风格：蜡笔手绘童趣风,色块鲜明,粗蜡笔笔触,童趣可爱
- 文字风格：完整拼写呈现为一个整体彩色文字块，紧挨着英文正下方写中文
- 构图要求：主体居中,远离画面左右边缘,每个场景使用不同视角
- ⚠️ 文字严格控制：每张图只允许英文目标词 + 中文释义两个文字

## 二、目标词标准化中文译名（2026-07-12 强制）

中文旁白必须用**标准译名**，禁用"儿化/昵称/通称"变体：

| 英文 | ✅ 标准中文 | ❌ 禁用变体 |
|------|---------|----------|
| shrimp | 虾 | 虾儿、虾虾、小虾 |
| fish | 鱼 | 鱼儿、小鱼、鱼鱼 |
| hairtail | 带鱼 | 鱼、带鱼儿 |

通用禁用清单（其他海产目标词也适用）：
- 禁用"X儿"（虾儿/鱼儿/蟹儿）
- 禁用"小X"（小鱼/小虾/小蟹）— 除非原文是 `little X`
- 禁用"X X"叠字（鱼鱼/虾虾）
- 唯一允许的"儿"：口语固定搭配如"没事儿""一会儿"，**目标词本身禁用**

## 三、页面结构通用框架（已实测 9 页模板）

| 页码 | 类型 | 教学目标 | 视觉要素 |
|------|------|---------|---------|
| 封面 | 封面页 | 书的门面 | 绘本标题（仅首字母大写）+ 目标海产插画 |
| P1 | 认知页 | 建立"单词=海产"第一印象 | 目标词全大写 + 大海产完整展示 |
| P2 | 形态特征页 | 独有外形 | 极近景特写 + 标志性特征 |
| P3 | 形态特征页 2 | 颜色或动作 | 不同维度的特征（颜色/动作） |
| P4 | 表面特征页 | 鳞/壳/须/尾 | 局部特写 |
| P5 | 动作示范页 | 标志动作 | 游/跳/潜/弹 |
| P6 | 场景页 | 生长环境 | 池塘/大海/水草 |
| P7 | 数量页 | 数数互动 | 几条鱼/几只虾 |
| P8 | 结尾互动页 | 引导收束 | 寻找/对比/总结型 |

注：海产类目标词天然无强词族（-IMP/-ISH 都冷门），跳过词族扩展页，全部用语境页。

## 四、shrimp/fish/hairtail 已沉淀的独有特征

### shrimp 独有特征
- **身体**：弯弯 C 形
- **颜色对比**：灰色生虾 → 红色熟虾（变色关键）
- **触角**：两根长须
- **动作**：游动 + 跳跃弹动（尾巴一蹬）
- **场景**：海里游 → 餐桌盘里
- **避免**：附生树上等不常见版本（不在海产场景里）

### fish 独有特征
- **身体**：胖椭圆 + 鳞片闪闪
- **动作**：摇尾巴 + 吹泡泡（双动作标志）
- **场景**：池塘 + 水草
- **群居**：几条一起游
- **餐桌**：红烧鱼/煎鱼

### hairtail 独有特征
- **身体**：长长 + 扁扁（双形态特征）
- **颜色**：银光闪闪（生）+ 灰青
- **尾巴**：尖尖细长如丝
- **场景**：成排陈列 + 海洋群居
- **关键**：带鱼是双音节复合词，无强词族，必须用特征页撑满 8 页
- **避免**：混入餐桌/吃鱼场景（用户明确要求"我们不要吃鱼了，就写鱼在海里面"）

## 五、shrimp/fish/hairtail 三本共用的旁白陷阱

| 陷阱 | 实测触发 | 修复方案 |
|------|---------|---------|
| 用"小X"作为认知页主语 | shrimp 用户原话"去掉旁白中的小" | 认知页用"一只 X"或"一条 X"，不加"小" |
| 用"X儿"变体 | fish 用户强制"鱼儿"改回"鱼" | 全程用标准译名，无儿化 |
| 末尾"我爱 X"空喊 | shrimp 用户原话"我爱吃虾" | 情感收尾必须有具体动词：吃/摸/看/抱 |
| 形容词+量词倒装 | "弯弯一只虾""闪闪一条鱼" | 改为"主语+形容词"自然语序 |
| 介词短语 + 叠词代替 | "灰色虾游啊游""鱼跳呀跳" | 改为"主语+在+地点+动词"自然陈述 |
| 7-8-9 句模板化 | hairtail P7/P8/P9 用户连续 3 次"换语境" | L3 输出前必须跑末句二次检测，不能等用户纠正 |
| 末句重复主语 | "我爱 fish"（fish 像中文词） | 情感型结尾改"我爱吃 X"或"X 真有趣" |

## 六、L3 输出前强制末句检测（hairtail 实测沉淀）

**触发条件**：当 P7-P9 是连续 3 页同类内容（成群/动作/情感）时，**L3 输出前**必须自检：

```
P7 维度 = ?    P8 维度 = ?    P9 维度 = ?
```

如果 P7/P8/P9 三个维度都相同（连续 3 句都是"动作型"或"情感型"），就是模板化高危信号。

**修复策略**：
1. 三个维度必须分布在 [形态/动作/场景/社交/数量/情感] 中至少 3 种
2. hairtail 修复示例：P7 群游（动作）→ P8 躲海草（场景）→ P9 真有趣（情感总结），三维度区分
3. 每次"换语境"后必须再扫一次最近 5-8 本已用结尾类型清单

## 七、shrimp/fish/hairtail L4 已验证的角色外观模板

### 蜡笔虾主角模板
虾：蜡笔手绘童趣风，弯弯 C 形身体，半透明粉橙/橘红/灰青色壳（生灰熟红），粗蜡笔笔触纹理，圆圆黑色小眼睛，细长触角向斜上方伸展，多对小脚，扇形尾巴。

### 蜡笔鱼主角模板
鱼：蜡笔手绘童趣风，胖椭圆身体，圆圆黑色大眼睛亮亮的，小三角嘴巴微微张开，粗蜡笔笔触的亮片鳞片带闪闪高光，背鳍胸鳍尾鳍圆润小扇形，橙红色或金黄色。

### 蜡笔带鱼主角模板
带鱼：蜡笔手绘童趣风，长长侧扁身形（极长 + 极扁），银光闪闪带小斑点（生）或金黄带酱红（熟），圆黑色小眼睛，尖尖细长如丝的尾巴，多对小背鳍密布脊背。

## 八、shrimp/fish/hairtail L4 已验证的场景锚点

| 锚点 | 用途 | 关键元素 |
|------|------|---------|
| 池塘/海底浅滩 | 海水场景 | 浅蓝绿色水面，几根水草，鹅卵石，温暖明亮 |
| 餐桌木盘 | 餐桌场景（可选） | 浅木色盘子，白色桌布，几片蔬菜，温暖米色背景 |

每个场景必须使用不同视角（仰视特写/侧面45度/顶部俯视/极近景/全景展开），禁止连续多页用同一视角。

## 九、海产系列的"无人物"原则

- 海产类纯物体展示 + 形态特征 + 动作页面**默认不出人物角色**
- 只有结尾互动页（如"数一数有几只虾"）才考虑加小孩
- 严禁在封面上画"小孩抱虾"等比例失调画面
- 与花卉系列"无动物原则"对称
