# 动物主角路径 B 生图提示词反混淆模板（2026-07-17 v1 · 11 本实测）

> **触发条件**：目标词是动物/昆虫/水产 → 走路径 B（动物作为主角全书出镜）
> **覆盖本本（v1 沉淀）**：ladybug / dragonfly / caterpillar / seagull / magpie / white crane / swan / crow / pigeon / woodpecker / Arctic fox / sika deer / brown bear / black bear / cheetah / marmot

## 1. 路径 B 通用反混淆模板（每页开头固定段落）

```
⚠️ 动物主角外观一致性（路径B-无参考图，每页文字重复）：
[主角中文名]: [主体颜色块描述] + [标志特征 1] + [标志特征 2] + [身体细节 1] + [身体细节 2] + [头部特征] + 圆眼睛黑白分明有神采 + [尾巴/角/喙/耳朵等关键部位]
⚠️ 动物主角反混淆：[目标词] 是 [独有特征 1]（不是 [易混物种 1]），[独有特征 2]（不是 [易混物种 2]），[独有特征 3]（不是 [易混物种 3]）
⚠️ 出现场景：[生态场景锚点]（区别于 [其他场景]）
```

**关键设计原则**：
- **反混淆 3-5 项**：每页都强制写"不是 X，不是 Y，不是 Z"——这是路径 B 防画错最有效的手段
- **同色不同物种必区分**：例如海鸥（白+灰翅+黑翅尖）vs 白鹤（通体白+黑飞羽+黑长腿+红头顶）vs 天鹅（圆润胖+橙黄短喙+黑面罩+黑蹼脚）—— 颜色相近的鸟必须区分
- **同生态不同物种必区分**：例如白鹤（湿地）vs 海鸥（海边）vs 鸽子（城市）vs 乌鸦（田野）—— 生态场景是认知基础
- **身体结构反例（绝对禁止混淆）**：
  - 腿数量：哺乳类 4 条 / 鸟类 2 条 / 昆虫 6 条 / 蜘蛛 8 条 / 蜈蚣 15+ 对
  - 尾巴长度：长尾 / 短尾 / 无尾
  - 耳朵形状：尖耳 / 圆耳 / 长耳 / 短耳 / 圆耳朵

## 2. 11 本反混淆实战清单（直接复用）

### 2.1 ladybug 瓢虫（昆虫类）
```
⚠️ 反混淆：身体是圆滚滚半球形（不是扁平甲虫/不是长条形昆虫/不是红色圆球无斑点/不是带条纹的瓢虫），
斑点圆形（不是条纹/不是星星/不是数字），6 条腿（昆虫铁律不能 4/8 条），有触角（不是无触角的球）
⚠️ 场景：花园/叶子/花朵（不是天空/不是水里/不是沙漠）
```

### 2.2 dragonfly 蜻蜓（昆虫类）
```
⚠️ 反混淆：身体细长（不是蝴蝶翅膀主导/不是甲虫圆滚滚/不是小飞虫短粗），
眼睛巨大占满头部（不是蝴蝶小眼/不是其他昆虫小眼），4 片透明翅膀（不是 2 片大翅膀蝴蝶/不是 4 片硬壳甲虫），触角短
⚠️ 场景：池塘/荷花/荷叶（不是花丛蝴蝶/不是草地甲虫）
```

### 2.3 caterpillar 毛毛虫（致敬 Eric Carle《好饿的毛毛虫》）
```
⚠️ 反混淆：身体是长长分节（不是光滑蚯蚓无节段/不是蜈蚣很多很多腿/不是短粗小虫），
腿是 5-6 对小短腿（不是无腿蚯蚓/不是蜈蚣 15+ 对腿），颜色以红头+绿身为主（不是纯绿色/不是纯黑色），有触角
⚠️ 场景：花园/叶子/花丛（不是水里/不是沙漠/不是雪地）
⚠️ 致敬 IP 造型（重写版）：红色大圆头+多色节段（红/橙/黄/绿/蓝/紫循环）+5-7 节饱满大圆球+白色圆点装饰
```

### 2.4 seagull 海鸥（鸟类海边生态）
```
⚠️ 反混淆：白身体+浅灰色翅膀+黑色翅膀尖（不是纯白鸽子/不是纯灰海燕），
翅膀长长尖形（不是鸭子短圆翅膀/不是鸽子圆翅膀/不是鹈鹕大嘴+短翅），喙橙黄尖喙（不是鸭子扁嘴/不是鹈鹕大嘴）
⚠️ 场景：海面/沙滩/港口船（不是陆地鸽子/不是淡水鸭子）
```

### 2.5 magpie 喜鹊（中国文化主线）
```
⚠️ 反混淆：黑白对比强烈（不是纯黑乌鸦/不是纯白鸽子/不是灰褐色麻雀），
尾巴长长阶梯形（不是乌鸦扇形短尾/不是鸽子短圆尾），白斑分布明确（肩斑+翅尖+尾梢）
⚠️ 场景：梅花枝/朝阳/屋顶/天空（中国传统意象）
⚠️ 安全场景铁律：避开墓地/枯树/黑夜
```

### 2.6 white crane 白鹤（鸟类湿地生态）
```
⚠️ 反混淆：身体雪白修长（不是白鹭粗壮/不是天鹅圆胖/不是鸭子矮扁），
腿黑色细长（不是白鹭黄腿/不是天鹅橘黄短脚/不是鸭子橘黄蹼脚），脖子细长 S 形（不是天鹅粗短/不是鸭子短），
喙长尖黄色（不是鸭子扁嘴/不是鹳粗黑喙/不是天鹅橘黄短喙），头顶有红点（区别于纯白鹭）
⚠️ 场景：芦苇荡+浅水+沼泽（不是天鹅湖面/不是鸭子池塘）
```

### 2.7 swan 天鹅（鸟类水上滑行）
```
⚠️ 反混淆：身体圆润胖（不是白鹤修长/不是鸭子矮扁/不是海鸥瘦长），
脖子 S 形弯曲（不是白鹤 S 形但腿超长/不是鸭子短脖子），喙橙黄短粗+黑面罩（不是白鹤黄长尖喙/不是鸭子扁嘴/不是海鸥黄尖喙），
脚黑色蹼脚（不是白鹤黑细腿/不是鸭子橘黄蹼），头小圆头（不是鹰的尖头）
⚠️ 场景：湖面+水面波纹+倒影（不是白鹤湿地/不是鸭子池塘）
```

### 2.8 crow 乌鸦（鸟类田野生态 · 安全场景）
```
⚠️ 反混淆：通体黑色（不是喜鹊黑白对比/不是乌鸫黑+黄喙/不是八哥黑+白斑+黄喙），
喙粗壮黑色尖喙（不是喜鹊短喙/不是八哥黄喙），眼睛中等圆眼（不是喜鹊小眼），羽毛蓝紫金属光泽（shiny feathers，区别于普通黑色小鸟）
⚠️ 场景：栅栏/田野/天空/树枝（避开墓地/枯树/黑夜/骷髅等不祥意象）
⚠️ 安全策略：旁白全程围绕"乌黑发亮+聪明+会叫+在城市/乡村生活"，避开不祥意象
```

### 2.9 pigeon 鸽子（鸟类城市生态）
```
⚠️ 反混淆：身体圆润胖（不是海鸥瘦长/不是乌鸦精瘦/不是麻雀小巧），
颜色灰羽毛+白腹+彩虹颈环（不是纯白海鸥/不是纯黑乌鸦/不是棕色麻雀），
喙短小黑色尖喙（不是海鸥黄长喙/不是乌鸦粗喙），脚红色小脚（不是海鸥橙红脚/不是乌鸦黑脚），头小圆头（不是鹰的尖头）
⚠️ 场景：城市广场+公园+屋顶（不是海鸥海边/不是乌鸦田野/不是麻雀乡间）
```

### 2.10 woodpecker 啄木鸟（鸟类森林生态）
```
⚠️ 反混淆：红头顶（不是纯黑乌鸦/不是黑白喜鹊），黑白对比身体（不是纯黑乌鸦/不是喜鹊带白翅斑），
长尖直喙（不是乌鸦粗短喙/不是喜鹊短喙），对趾足+尾巴撑树干（不是普通树枝站姿）
⚠️ 场景：树干+森林+树洞（不是城市鸽子/不是田野乌鸦/不是湿地白鹤）
```

### 2.11 sika deer 梅花鹿（哺乳类森林生态）
```
⚠️ 反混淆：棕黄色+白斑点（不是驯鹿灰褐色无斑/不是麋鹿深褐色/不是马单色），
鹿角分支角（不是驯鹿大长角/不是麋鹿掌状角/不是马无角），腿细长腿（不是马粗腿/不是驯鹿中等腿），
尾巴短短小尾（不是马长尾/不是驯鹿短尾但粗），眼睛大而圆（不是马长脸小眼）
⚠️ 场景：森林+草地+溪边+夕阳（不是驯鹿雪原/不是麋鹿沼泽）
```

### 2.12 brown bear 棕熊（哺乳类森林生态）
```
⚠️ 反混淆：通体棕色（不是黑熊黑色/不是北极熊白色/不是熊猫黑白/不是小熊玩偶彩色），
身体圆滚滚胖（不是北极熊修长/不是熊猫圆但黑白），爪子大爪子（不是小熊玩偶小爪），耳朵圆耳朵（不是狐狸尖耳）
⚠️ 场景：森林+河+洞穴（不是北极熊极地/不是熊猫竹林）
```

### 2.13 black bear 黑熊（哺乳类森林生态 · 区别棕熊）
```
⚠️ 反混淆：通体黑色+胸前白月牙斑（不是棕熊棕色无胸前斑/不是熊猫黑白/不是黑猫瘦长），
耳朵大圆耳朵（不是棕熊小圆耳/不是狐狸尖耳/不是猫三角耳），身材中等（不是棕熊巨大/不是熊猫圆胖），
特别会爬树（区别于棕熊不会爬树）
⚠️ 场景：森林+树+河+洞穴（不是棕熊草原/不是熊猫竹林）
```

### 2.14 cheetah 猎豹（哺乳类草原生态）
```
⚠️ 反混淆：斑点是实心圆点（不是豹/美洲豹玫瑰花瓣斑纹/不是老虎条纹），
脸上有泪痕（猎豹独有，区别于其他猫科），腿是长细腿流线型（不是狮子粗壮/不是老虎短腿），身材流线型修长（不是狮子粗壮/不是老虎短粗）
⚠️ 场景：非洲草原+金合欢树（不是森林豹/不是雪山雪豹）
```

### 2.15 Arctic fox 北极狐（哺乳类极地生态）
```
⚠️ 反混淆：通体雪白蓬松（不是普通狐狸红棕色尖嘴/不是白猫短尾纤细/不是北极熊巨大白色），
尾巴蓬松大尾巴（不是白猫细长尾/不是普通狐狸小尖尾），耳朵是小圆耳朵（不是普通狐狸大尖耳），身材中等（不是北极熊巨大/不是白猫小巧）
⚠️ 场景：雪原+冰山+极光（不是普通狐狸森林/不是白猫家）
```

### 2.16 marmot 土拨鼠（哺乳类草原地下生态）
```
⚠️ 反混淆：圆滚滚胖墩墩（不是松鼠瘦长+大蓬松尾/不是仓鼠小巧/不是兔子长耳长腿/不是田鼠细长），
尾巴短小（不是松鼠大蓬松尾/不是田鼠细长尾），耳朵小圆耳朵（不是兔子长耳/不是松鼠尖耳），腿短短腿（不是兔子长腿/不是松鼠长腿），门牙大板牙（啮齿类标志）
⚠️ 场景：草原+土堆+洞口（不是松鼠树上/不是仓鼠笼子/不是兔子草/不是田鼠田地）
```

## 4. 视角轮换清单（避免连续同视角，参考 16 本实测）

| 页码 | 推荐视角 | 适用场景 |
|------|---------|---------|
| 封面 | 倾斜站立 / 平视全景 | 主角站立姿态或全景 |
| P1 认知页 | 仰视特写 / 大特写 | 建立视觉冲击 |
| P2-P3 | 平视全景展开 / 正面平视近景 | 颜色 / 整体特征展示 |

## 6. 11 本色彩使用禁忌（实测错误模式）

- ❌ 黑白混淆：海鸥 vs 白鹤 vs 天鹅（都是白色主调）→ 必须区分翅膀/腿/喙/蹼 4 项
- ❌ 黑色混淆：乌鸦 vs 黑熊 vs 喜鹊（都有黑色）→ 必须区分胸前斑/叫声/尾巴
- ❌ 棕色混淆：棕熊 vs 梅花鹿 vs 鼹鼠 → 必须区分斑点/爪子/腿长
- ❌ 同色生态混淆：海鸥（海边）vs 白鹤（湿地）vs 鸽子（城市）vs 乌鸦（田野）→ 场景锚点必须明确
