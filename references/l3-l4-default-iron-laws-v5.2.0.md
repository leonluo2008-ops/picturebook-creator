## 铁律 1：L3 中文末尾英文仅核心词

- 默认压成纯核心词（如 `Peach Tree` / `Lychee Tree` / `Olive Tree` / `Hawthorn Tree`）
- 不再绑定完整短语（不要再写 `A small green peach grows` / `An old olive tree` 那种重复每行英文）
- 用户原话："中文旁白后面的英文部分，只有核心词" + "兄弟，不要我再强调了"
- 反模式：每行末尾英文绑完整短语 → 应简化为统一核心词
- 适用所有"主题物系列"（树木/动物/物体/地点词）

## 铁律 2：L3 默认加标点

- P1 封面 `!` / P2 认知页无标点（视觉认知页规约）
- P3-Pn 陈述句加 `。`
- Pn 主题收束加 `!`
- 中英标点一一对应
- 默认加，不要等用户提醒

## 铁律 3：L3 核心词嵌入中文要自然（像 4 岁小孩指着画面说话）

- 每行读起来要像 4 岁小孩跟妈妈指着画面说的话
- 主谓/介宾/主系表自然
- 用户原话："核心词出现的位置要符合中文语境，不能读起来别扭"
- 句式避免模板化（不要连续 6 行都是"X 树开 Y / X 树有 Z / X 树长出 W"）
- L3 输出前必须逐行大声朗读自检
- ✅ OK: "春天来了，山楂树醒了" / "石榴树撑开大绿叶" / "蜜蜂飞进石榴花里"
- ❌ BAD: "小青柿挂在柿子树上" / "红苹果挂满苹果树" / "X 树上 Y 树"

## 铁律 4：L4 文字-剪影-场景图 5 条铁律

### 4.1 三档首字母规则（osmanthus 反例）

- 封面 = Title Case `Osmanthus Tree`（首字母大写非全大写）
- 认知页 = 全大写 `OSMANTHUS TREE`（无 `!`）
- 内页 = 小写 `osmanthus tree`
- 用户原话："封面的标题文字应该只有首字母大写，不能是全大写"

### 4.2 场景图文字位置 + 大小铁律（apple tree 反例）

- 所有场景图中英文字块必须放大：字号高度占画面纵向 1/6-1/5、横向 1/2-2/3 宽
- 放置中上方居中
- 文字绝对不可缩小成字幕
- 用户原话："场景图片中的英文标题文字太小了，不够醒目"

### 4.3 标题大小+颜色铁律（apple tree 反例新增）

- 英文用高饱和撞色块字：玫红/明黄/翠绿/橙红/克莱因蓝/明橙/草绿 任选 2-4 色彩虹色块
- 每字母或每词一色
- 中文字为黑色粗蜡笔字，字号约为英文的 1/2-2/3
- 紧挨英文单词正下方
- 绝对禁用白字/灰字
- 不再每本问/被 user 纠正

### 4.4 反剪影铁律

- 所有人物角色都必须以清晰、可爱、漫画感的形式呈现
- 绝不允许用剪影
- 用户原话："图中的人物不能用剪影"

### 4.5 场景图非必要不加人物铁律

- 纯自然场景（香气飘散/花瓣飘落/夜空）绝不强加人物
- 只有"互动/收束"页才放人物（且非剪影）
- 用户原话："可以不用人物角色的就不要强加人物"

## 铁律 5：默认用动物角色替代小孩（07-23 lychee tree 反例）

- 绘本图中默认角色用动物（小鸟/松鼠/小猴/蜜蜂/小狐狸/小蚂蚁/小青蛙 等）替代小孩
- 封面 + 认知页 + 收束页都默认动物主角
- **例外**：用户明确说"我喜欢一个穿XX的小孩"或职业类（gardener/teacher/doctor/farmer 等）才用人形
- 用户原话："图中的角色用动物"
- 已沉淀到 picturebook-creator 记忆 + 本铁律清单

## 铁律 6：L4 ⚠️ 反混淆铁律必须显式列 3-5 条核心标志

- 每个主角必须有 3-5 条**反混淆核心标志**列在引导语段
- 防止 AI 把目标树画成其他树（如把柚子画成橙子、把龙眼画成荔枝）
- 例：樟=常青+红果 / 榕=下垂气根+独木成林 / 白桦=白底+黑皮孔 / 桂花=圆头冠+橙黄小花 / 杉=塔形冠+红褐笔直干 / 椰=细长弯曲干+羽状大叶 / 橄榄=灰白扭曲干+银绿细叶 / 桃=张开姿态+翠绿披针叶+毛桃 / 荔枝=棕褐色光滑壳（vs 红色粗糙刺壳）/ 龙眼=棕褐色光滑壳无刺突 / 柚子=巨大圆柚（vs 圆橙）/ 果园=木栏围栏围绕+多种果树混合种植
- 例：地点词 orchard 必须强调"木栏围栏+混合 3 种果树+春花秋实"
- ⚠️ 反混淆铁律放在引导语段，不放在生图提示词字段之后（v5.0.0 反例已踩坑）

## 铁律 7：L4 引导语段每页都要写"每页遵守"的强约束

- 每页生图提示词中都要重复"字号大/醒目/中上方居中/玫红明黄翠绿橙黄彩虹色块"等强约束
- 不是只写在【全局设计约定】就够
- 强约束要在每页生图提示词中再次出现（避免 AI 模型遗漏）

## 铁律 8：L3/L4 末句处理协议

### 8.1（v5.2.1 升级版 · 2026-07-24）末句翻译不对位 → 默认改英文匹配中文，不再 3 选项反问

**触发场景**：用户给"第 X 句换成 XX 中文"且中文与英文主题/语义不对位（cozy vs pretty / stars vs grows 等），或末句翻译对位失败。

**协议（v5.2.1 升级）**：
1. **不要再 A/B/C 反问用户**——longan/pomelo/bush 三本实测：用户偏好"字面给的中文就保留"，agent 应自动改英文匹配中文
2. **默认走法**：保持中文 + 自动改英文匹配中文对位（让英文迁就中文）
3. **不要机械"只改中文"**——会导致 8/9 行中英主题错位

**实测案例（2026-07-24）**：
| 用户指令 | 原英文 | 改后英文 | 原因 |
|---------|-------|---------|------|
| `bush P9 换成灌木丛真漂亮` | `Bushes are cozy!` | `Bushes are so pretty!` | cozy ≠ pretty，改英文匹配 |
| `cactus P8 换成仙人掌长在沙漠里` | `Stars shine in the desert sky` | `Cactus grows in the desert!` | 整句主题反了，改英文 |

### 8.2 L3 末句主语跳跃冲突处理

- 如果末句突然换了主语（如 banana P8 "小猴子剥开香蕉吃"——猴子做主语，跟"香蕉树"主题脱节），要主动出 3 选项：
  - 改成"X 来到/访问 Y 树"（来访结构，主体仍是树）
  - 改成"X 树带来/送给 Z"（树做主语）
  - 改成"X 树下好热闹"（场景描述，主语省略）
- 例：banana P8 触发过这条

### 8.3 L3 末句必须直接显示在表格里

- 严禁任何占位符（如 "末句直接生成好" / "(待选)"）
- 用户 07-22 两次明确：将最后一页生成显示出来

## 铁律 9（NEW · v5.2.1 · 2026-07-24 gardener 实测）：L4 带人物必加手部细节铁律

**触发场景**：L4 生图涉及人物角色（园丁/老师/医生/农民/parent 等职业类，或穿特定服装的小孩等具体人形）。

**协议**：
1. L4 引导语 ⚠️ 段必须加"手部细节铁律"固定话术
2. 每页生图提示词对人物动作必须用 5 指细化模板描述
3. 蜡笔童趣风格下也必须保持 5 根分离指节结构

**用户实测原话**：
> "查看了刚刚生成的图片，发现所有图中的人物角色手部细节有残缺（手指数量不对）请你修改提示词"

**L4 提示词固定话术（必加 · 放在反丑化铁律之前）**：
```
⚠️ 手部细节铁律（请严格执行，每页人物手部必须遵守）：
- 人物每只手必须正好 5 根手指（**拇指 + 食指 + 中指 + 无名指 + 小指，全部存在，全部清晰可辨**）
- **绝不允许 4/6/7/8/9 根或任何畸变指节**
- **绝不允许手部简化为"棒棒糖状球形手"或"连指手套状"**——必须画出真实的五根分离指节
- **绝不允许手指融合或短小齐根**——每根手指应有明确的指身与指尖
- 蜡笔童趣风格下也必须保持"5 根分离指节结构清晰可见"，可以简化指甲/关节细节，但五指数量与分离度不能少
- 当人物"握着水壶/铲子/剪刀/工具"时，必须能数出包裹工具柄的 5 根手指（拇指与其他 4 指绕柄呈 5 个独立轮廓）
```

**每页生图提示词中"手部动作"5 指细化模板**：

| 动作 | 5 指细化模板 |
|------|-------------|
| 握工具柄 | "5 根手指——拇指贴柄一侧 + 食指中指无名指小指绕柄另一侧，四指分离可见" |
| 叉腰 | "5 指轮廓清晰可见，拇指在前贴腰 + 其余 4 指并排往后" |
| 扶帽檐 | "5 指完全清晰可见——拇指贴帽边 + 食指中指无名指小指依次分布" |
| 对捏小物件 | "拇指 + 食指呈 V 形对捏之势，其余 3 指自然弯曲" |
| 张开轻抚 | "5 指自然张开呈扇形——拇指向上 + 其余 4 指依次展开" |

## 反模式 vs 正模式（鸟瞰）

| 反模式 | 正模式 |
|--------|--------|
| 每行英文绑完整短语 | 每行末尾英文 = 纯核心词 |
| 中文末句"X 树挂满 X 树" | 中文末句"X 树挂满红 X" |
| 场景图文字小到看不见 | 场景图文字大、中上方居中、彩虹色块 |
| 人物角色用剪影 | 人物角色清晰可爱 |
| 场景图硬塞小孩 | 场景图默认动物主角（除非用户要小孩） |
| 末句翻译不对位反问 A/B/C | 末句翻译不对位 → 默认改英文匹配 |
| 末句主语跳跃到其他角色 | 末句保持核心词做主语或来访结构 |
| 末句占位符"(待选)" | 末句必须直接显示在表格里 |
| 人物手部画"棒棒糖状球形"或手指融合 | 人物手部必须 5 根分离指节清晰可见 |
| 园丁/老师等职业类不强调手部 | 职业类绘本 L4 引导语段必须加 ⚠️ 手部细节铁律 |
