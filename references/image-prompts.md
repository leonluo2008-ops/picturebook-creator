# 整本批量生图提示词

只在完整文稿与简介已经确认，或用户明确授权重写已有提示词时执行。先核对文稿页数、角色/画风、参考资产与选定书名。

## 批次与文字

L4 最终回复只输出一个连续代码块，包含全局约定、封面及全部内页，代码块外不加开场、简介复述或确认提醒。操作人员一次复制整本使用；不要拆成多个代码块或逐页任务。代码块不夹入审计过程、版本说明或旧规则。需要说明实际缺口时在生成成稿之前处理。

- 旁白只作语义参考。封面入画文字为正式英文书名；内页明确列出实际要画的完整词标签。中文、完整旁白句子、页码和内部标签默认不渲染。
- 标签取本书确认的词形和大小写，独立领读词通常为小写词头。英文旁白中的复数或其他屈折不自动复制到标签；每页写一次准确标签，不展开逐字母校对清单。
- 词形连续、自然字距、轮廓清楚。颜色随画风选择，整词单色或自由多彩装饰都可；不指定每个字母、音节或词尾的颜色。复杂页面优先减少文字和装饰，只保留理解必要的内容。
- 每页说明标签所在的可读载体或留白区及大致大小，避免小字幕。按画面选择位置，不要求全书固定一种牌子、颜色或坐标。词不被主体或道具遮挡。

## 全局设计

只放全书共同必要的事实：核心词及义项、风格、主要角色外观、反复出现的道具和场景、文字原则、参考图对应关系。具体配色属于本书设计，不作为后续书的规则。

参考图按实际输入编号说明角色、场景或物件用途。保留已确认外观、五官、服装及比例；白底定妆图的背景不照搬到正文。没有真实参考图时不要虚构“图像1”。用文字设定时如实写文字设定。读取资产文字不等于看过图片。

## 每页写什么

明确页号、旁白、比例、入画文字、具体画面。默认封面 3:4，内页 16:9；用户明确指定则沿用其规格。页内用简洁描述完成：

1. 镜头与主体位置，主体的当页动作、表情及必要物件关系。
2. 本页语义的视觉证据；位置、数量、程度及互动答案应可直接辨认。
3. 实际入画词与载体、字体可读性。标题/词标签与旁白分别写，避免模型误画整句。
4. 本页角色与场景对全局设定的继承，变化具体说明，不机械复制大段外观。
5. 关键元素完整入镜，背景铺满边缘，标题两端、五官、脚部等留裁切余量。需要遮挡表达位置时，保留可辨认轮廓；不要同时要求角色毫无遮挡。

动作需要站立、够取或持物时，写清支撑面和可达关系；不把固定机位角度、固定左右站位、固定道具强加给所有题材。

## 可复制结构

下面是编写结构，不是可直接交付的成稿。正式输出替换全部占位内容，写全封面和每个内页。

```text
请按以下逐页描述一次生成整本绘本，保持角色、画风和重复物件一致。旁白用于理解情境，仅渲染每页明确列出的入画文字。

【全局设计约定】
目标词及义项：本书实际内容
画风与主角：已确认的视觉设定
重复场景与物件：必要锚点
文字：完整连写、自然字距，清楚易读，单色或与画风协调的多彩装饰。
参考图：实际有参考图时列出编号与用途，否则省略这一项。

【封面】
旁白：封面（已选中文书名 / 已选英文书名）
比例：3:4
入画文字：已选英文书名全文
生图提示词：具体封面设计，明确用引号标记书名，写出完整书名；表现词义的角色与场景、文字层级和裁切余量。

【P1】
旁白：确认的英文 / 确认的中文
比例：16:9
入画文字：当页完整词标签
生图提示词：当页实际画面与标签设计。
```

## 封面

封面需在缩略图中读出英文书名与主题，书名是主要视觉焦点，角色动作解释词义。书名放在与场景相容的可读载体或留白区；按构图安排层级，不套“横幅＋大字＋站立角色”固定模板。完整书名中的目标词承担视觉焦点即可，不额外重复一组巨大文字。

封面只渲染英文。提示词将正式书名用外层引号界定；书名自身标点保持原样。标题与角色均清楚可辨，保留原有五官，背景服务于主题，不堆无关装饰。

## 最后核对

逐页比对旁白与提示词，检查页号、书名、标签词形、数量和状态。互动问句与答案数量一致；单词完整，不多字母、不少字母，无拆词指令或颜色映射残留。修改旁白时同步更新提示词引用；修改提示词时完整交付新批次。

提示词检查只能说明约束是否合理。真实图片还需另验：完整拼写、角色一致性、五官、背景、语义、裁切与答案数量。允许合理字色偏差，不把配色逐字一致当成重出条件。

使用 [check_book.py](../scripts/check_book.py) 时，在完整文稿检查命令加 `--prompt <含代码块的整本提示词文件>`，核对页序、封面、标签和旁白引用。按本文件格式输出即可使用；它无法判断画面是否好看、英语是否自然或颜色约束是否过量，仍需逐页审阅。
