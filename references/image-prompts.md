# 整本生图提示词

## 输出结构

整本一次批量生成，每页一张。交付使用一个连续的纯文本代码块。先写全书画风、角色、参考图用途、道具和场景锚点，再按实际页序逐页写以下四个字段。归档文件保存代码块正文。

```text
旁白: [封面标题或当页定稿旁白]
比例: [封面 3:4，内页 16:9]
页面类型: [认知页、语境页、互动页等实际类型]
生图提示词: [镜头、动作、实际入画英文、载体与布局] 场景锚点: [本页场景]。构图要求: [人物、关键道具及文字的安全留白]。
```

## 写法

- 旁白帮助模型理解画面。用引号写清楚实际需要出现在图中的英文。封面纯英文，正式书名保持大小写、标点和书名内引号；详见[封面设计](cover-design.md)。
- 领读各页写出确认的完整目标词形。保持自然字距和字序，单色或多彩装饰以清楚易读为准。多词同框让每个词各有载体或间隔。整词检查涵盖标题、标签、拓展词与单复数。
- 一页一个可辨的瞬间，先写人物站位、接触面、姿势和手脚动作。用本页场景锚点保持跨页一致，避免指代成「上一页那样」。调整画风或角色时同步核对参考图、全局设定和涉及的所有页。
- 区分定稿参考与灵感参考，明确参考图只提供哪些特征。选用与角色肢体匹配的动作；保留完整五官。道具位置、镜头和动作各说清一次。关键主体与英文留在安全区，背景延伸到边缘。

## 终检

- 核对页数、页序、比例、旁白表与各页动作。检查标题和实际英文标签确实出现在场景描述里，安全区文字里的词不算入画。检查简介提到的场景仍在定稿中。
- 领读稿运行 `python3 tools/l4_case_check.py <提示词文件> --word <目标词>`。它辅助发现拆写和大小写问题；完整词是否实际入画仍需逐页检查。
- 用户指定整本重生图时，从封面到末页交付同一份提示词。实际出图后看封面层级、拼写、人物五官、角色一致性、主要动作和裁切。成图验收后按[标准交付](standard-delivery.md)办理。
