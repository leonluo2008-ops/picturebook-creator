## ⚠️⚠️⚠️ orchid 长在树上事实错误（2026-07-10 用户实测关键纠正）

> 用户在 orchid 第 5 句 "Orchid grows on a tree" 明确纠正：**"兰花长在大树上错误了"**。

**根因**：orchid 是属名（25000+ 种），包含附生兰（蝴蝶兰/石斛兰）和地生兰（国兰/兜兰/虾脊兰等）。多数家庭和小朋友见到的兰花都是**盆栽**，不是树上。

**修复规则（适用范围：全部领读绘本）**：

1. L2/L3 设计生长环境时，**先查证目标词的常见形态**（非典型生长形态需明确标注）
2. 绘本面向 3-6 岁，**优先选小朋友能见到的形态**（盆栽 > 附生/野生）
3. 如果必须讲特殊形态（附生/野生），需明示"有些兰花长在树上"而非"兰花长在树上"

**禁止事实错误清单**：
- ❌ 把"附生兰"写成"兰花都长在树上"
- ❌ 把"水生植物"写成"长在沙漠里"
- ❌ 把"热带水果"写成"长在寒带"
- ❌ 把"家养动物"写成"野生"
- ✅ 拿不准时优先讲**最普遍/最常见/3-6 岁可观察**的形态

**用户纠正触发器**：L4 生图提示词**必须**与旁白同步修正（不能保留旧描述）。

## 15 本花朵强反混淆规则

> AI 生图模型只认"花瓣+颜色" = 画一朵红花 = 全部混淆。**必须在【食物外观约定】字段中按"独有结构"显式排除相似物**。

| 花卉 | 关键识别特征 | 必须写入排除性描述 |
|------|------------|------------------|
| **rose 玫瑰** | 层层叠叠柔顺花瓣 + 茎有圆刺 | ❌ 不是超蓬松（牡丹）❌ 不是杯状（郁金香）❌ 不是瓣稀疏（百合）。✅ 玫瑰花瓣层叠柔顺像绸缎 + 茎上有圆圆的浅绿色小刺（不要尖锐） |
| **tulip 郁金香** | 杯状/酒杯形 + 长剑叶 | ❌ 不是层叠多瓣（玫瑰/牡丹）❌ 不是 6 瓣规整（百合）❌ 不是唇瓣奇特（兰花）。✅ 3 片外瓣+3 片内瓣组成杯状 |
| **peony 牡丹** | 超蓬松大花头 + 羽状复叶 | ❌ 不是柔顺层叠（玫瑰）❌ 不是规整星形（百合）❌ 不是杯状（郁金香）。✅ 花瓣超多层超蓬松像彩色大球 |
| **violet 紫罗兰** | 5 瓣小花 + 贴地丛生 | ❌ 不是穗状（薰衣草）❌ 不是圆锥花序（紫丁香）❌ 不是羽状叶。✅ 5 瓣平面小花 + 贴地丛生 + 心形小叶 |
| **orchid 兰花** | 奇特唇瓣（3 萼片+2 花瓣+1 唇瓣） | ❌ 不是规整瓣状（玫瑰/牡丹/百合/郁金香/紫罗兰）❌ 不是同一形状重复。✅ 蝴蝶兰唇瓣像展翅的蝴蝶 + 长条革质叶 + 盆栽 |
| **lily 百合** | 6 瓣喇叭形 + 长雄蕊 + 茎立高挑 | ❌ 不是层叠（玫瑰/牡丹）❌ 不是杯状（郁金香）❌ 不是唇瓣（兰花）❌ 不是 5 瓣贴地（紫罗兰）。✅ 6 瓣星形展开 + 长雄蕊伸出花外 + 茎立高挑 |
| **carnation 康乃馨** | 褶皱纸杯状 + 密集锯齿/波浪花瓣 | ❌ 不是柔顺层叠（玫瑰）❌ 不是超蓬松（牡丹）❌ 不是规整喇叭（百合）。✅ 密集锯齿/波浪褶皱花瓣像蛋糕纸杯 |
| **daisy 雏菊** | 白瓣黄心放射规整（小太阳造型） | ❌ 不是球形（绣球）❌ 不是圆锥（丁香）❌ 不是唇瓣（兰花）❌ 不是蓬松（牡丹）。✅ 白瓣黄心像小太阳/小星星 |
| **lilac 丁香** | 圆锥花序（4 瓣小花聚成葡萄串） | ❌ 不是球形（绣球）❌ 不是放射单花（雏菊）❌ 不是规整杯状（郁金香）。✅ 4 瓣小花聚成葡萄串/锥形 |
| **hydrangea 绣球花** | 球形花序（4 瓣小花聚成完美大圆球） | ❌ 不是圆锥（丁香）❌ 不是放射（雏菊）❌ 不是单花（玫瑰/牡丹/百合）。✅ 4 瓣小花聚成完美大圆球 |
| **iris 鸢尾花** | 6 瓣上扬下垂 + 旗帜形 | ❌ 不是规整 6 瓣（百合）❌ 不是蓬松（牡丹）❌ 不是唇瓣（兰花）。✅ 3 上扬 + 3 下垂 = 旗帜造型 |
| **lotus 莲花** | 多层尖瓣 + 大圆荷叶 + 水生 | ❌ 不是 6 瓣规整（百合/鸢尾）❌ 不是蓬松（牡丹）❌ 不是层叠柔顺（玫瑰）❌ 不是圆球形花序（绣球）。✅ 多层尖瓣围绕中心莲蓬 + 大圆荷叶浮水面 + 从水里长出（唯一水生花） |
| **camellia 山茶花** | 层叠规整 + 革质厚叶 + 蜡质厚瓣 + 冬季开放 | ❌ 不是柔顺层叠（玫瑰）❌ 不是超蓬松（牡丹）❌ 不是褶皱纸杯（康乃馨）。✅ 5-7 大瓣围绕中心小瓣簇规整层叠 + 革质深绿卵形厚叶 + 蜡质厚瓣 + **冬季开放**（雪中盛开） |
| **lavender 薰衣草** | 穗状花序（长茎顶端密集小花像麦穗）+ 干花用途 | ❌ 不是圆锥（丁香）❌ 不是球形（绣球）❌ 不是放射单花（雏菊）❌ 不是唇瓣（兰花）❌ 不是规整杯状（郁金香）。✅ 长茎顶端密集小花排列成穗状像麦穗 + 干花用途（香包/助眠） |
| **gardenia 栀子花** | **螺旋形花瓣**（从中心向外旋涡展开）+白色+浓郁清香 | ❌ 不是平面层叠（camellia）❌ 不是超蓬松（牡丹）❌ 不是规整 6 瓣喇叭（百合）❌ 不是杯状（郁金香）❌ 不是褶皱纸杯（康乃馨）。✅ 多层花瓣从中心向外旋涡形展开 + 革质深绿卵形叶 + 蜡质厚瓣 |

**特别说明 - camellia vs gardenia**：两种花都是白色+层叠+灌木+革质叶，极易混淆。
- **camellia**：层叠规整（平面，5-7 大瓣围绕中心小瓣簇）+ 红色+ **冬季开放**
- **gardenia**：**螺旋形**（3D 旋涡从中心向外展开）+ 白色+ **春夏开放**
- 反混淆 prompt 必须显式区分这两个花的层叠造型差异

**反混淆 Prompt 写法示范**（以 orchid 为例）**：
```
⚠️ 食物外观约定:兰花(orchid)是奇特唇瓣结构(3萼片+2花瓣+1唇瓣像张嘴小脸,蝴蝶兰唇瓣像蝴蝶),
花瓣厚实蜡质,叶子长条革质簇生。多数家庭常见兰花是盆栽(蝴蝶兰/国兰/兜兰等),不是附生在树上。
颜色变体有白/粉/紫/黄。
```

**camellia 雪景警示（camellia 实测新增）**：
- L4 生图提示词的结尾页（P8）必须画冬日雪景，否则被默认渲染成春夏季背景 → 失去 camellia 唯一"冬季花"的核心差异化
- 必须在 P4 季节页（"Camellia blooms in winter"）和 P8 结尾页都强调冬日雪景（否则被默认渲染成春夏背景）
- 这是本系列 15 本里**唯一被强调需要雪景的花**（其他 14 本都是春夏花园）

## 花卉页面结构模式（与食物/家具/水果系列对比）

**花卉与食用菌/蔬菜/水果的关键区别**：花卉的"做法变体"维度弱（不像食物有蒸/煮/炒/凉拌/汤多种），强的是"形态/颜色/生长/触感/文化定位"维度。

**9 页结构公式**：

```
9 页 = 1 封面 + 1 认知 + P2-P6 维度-walk（5 页：形态 ×2 + 颜色 ×2 + 生长 ×1 或触感 ×1）+ P7 互动 + P8 收尾
```

**典型范例（orchid 2026-07-10 实测）**：

| 页码 | 维度 | 旁白 | 内容 |
|------|------|------|------|
| 封面 | 封面 | 兰花 Orchid | 标题 + 蝴蝶兰主角 |
| P1 | 认知 | ORCHID! | 超大单词 + 蝴蝶兰大图 |
| P2 | 形态·颜色 | A white orchid. | 白色经典色 |
| P3 | 形态·蝴蝶 | Orchid looks like a butterfly. | 蝴蝶兰唇瓣像蝴蝶 |
| P4 | 形态·6 瓣（lily 范例） | Lily has six petals. | 6 瓣数字识别 |
| P5 | 生长·环境 | Orchid grows in a pot. | 盆栽（**注：必须查证事实准确性**） |
| P6 | 触感 | Orchid is thick and waxy. | 蜡质花瓣 |
| P7 | 颜色变体 | A pink / purple orchid | 多色 |
| P8 | 结尾 | Pretty orchid! | 优雅型 |

## 写作节奏与用户高频指令模式（15 本实测沉淀）

用户在花卉系列的口味（与食用菌/可食用花蕾/水果系列一致）：

### 用户修改指令模式表

| 用户原话 | 指令类型 | 操作 |
|---------|---------|------|
| "第 X 句换成 Y 句子" | **改中文** | 只改中文，英文不动（如 lily P5 "高高的"→"长得高"）|
| "第 X 句换语境" 或 "太模板化了换语境" | **换语境** | 英文+中文都换 |
| "把第 X 句改成 X" | **重组语言** | 重新构思整句句式 |
| "最后一句换成 X" | **结尾换型** | 影响全书结尾去模板化 |
| "请从 X、Y、Z 来写" | **指定维度重写** | 旁白结构按维度重新组织（如 peony "从颜色形态来写"、taro "从形状颜色/味道/生长环境"） |
| "加上合适标点符号" | **标点对应纠正** | 跑 ⚠️中英文标点一一对应铁律，逐行核对句号/感叹号/问号 |
| "第 X 句错误了/不对了/不准确" | **事实准确性纠正** | L4 生图提示词必须同步修正（orchid 长在树上案例） |
| "旁白有点模板化了，请你重写" | **整体去模板化重写** | 跑下方 5 维检测表 + 五步重写法（peony 第一版触发） |
| "第 X 句与前面重复了" | **撞句自检纠正** | 必须找出重复页并修改其中一句 |
| "加上合适标点符号" | **标点补齐** | 中英标点严格一一对应 |

**执行规则**：
- 收到任何修改指令 → **立刻执行，先输出完整修改后表格**（包含自检：双语同现/标点/末尾绑定/目标词次数/避撞型），不要反问
- 修改一句话不影响其他句的结构，只动该行
- 结尾换型属于"换语境"类，**必须**扫已用列表避免撞型
- 事实准确性纠正 → L4 生图提示词必须相应修正（不能保留旧描述）

### 5 维检测表（L3 输出前必跑 · 用户说"模板化"后必跑）

> **触发信号**：用户说"旁白有点模板化了"/"太重复了"/"和之前一样"/"第 X 句与前面重复了" → **整体结构**模板化

| # | 维度 | 检测什么 | 反模板化做法 |
|---|------|---------|------------|
| 1 | **形态 vs 颜色 vs 触觉** | 连续多页是否都在讲同一属性 | P3 讲形态 → P4 跳触觉 → P5 跳场景 |
| 2 | **静态 vs 动态 vs 动作** | 是否有 3 页以上都是"是…的"系表句 | 用"它做了 X"动作句替换至少 1-2 页 |
| 3 | **物体 vs 社交 vs 场景** | 是否整本都聚焦物体本身？缺少"送朋友"等互动 | 至少 1 页用社交/赠送/邀请类句式打破纯展示 |
| 4 | **形容词总量** | 全书形容词是否 > 3 处 | 形容词控制在 3 处以内；用具体特征替代形容词 |
| 5 | **结尾独立维度** | 末句是否又回到"特征描述"或"我喜欢"情感型 | 末句必走"互动引导/场景收束/社交分享/数字数/对比"之一 |

**5 步重写法（peony 实测验证有效）**：

| 步骤 | 动作 | peony 第一版 → 第二版示例 |
|------|------|----------------------|
| 1 | **列出原版每页维度** | P3 颜色 / P4 层叠 / P5 环境 / P6 香 / P7 蓬松 / P8 白 |
| 2 | **找出连续同维度页** | P3+P4 同为外观静态 / P6+P7 同为花香或蓬松静态 |
| 3 | **把同维度合并或换维度** | P3 形态·大 + P4 形态·球状 = 形态递进；P6 触感 + P7 社交 = 跳出静态 |
| 4 | **新增动态/社交维度** | 引入"送奶奶"社交场景（P7）打破"花朵→花朵"线性推进 |
| 5 | **末句独立维度** | 末句必须与 P3-P8 任一句式都不相同 |

**自检**：跑完 5 步后逐项过 5 维检测表，5 个 ✅ 才能输出。

### ⚠️⚠️⚠️ P3 vs P7-P8 颜色变体三句相似自检（15 本反复触发）

> 这是花卉系列**最高频自检失败点**，因为花卉天然有 P3 颜色 + P7-P8 多色变体的双层结构。

**问题**：连续 3 句都是 "A [颜色] [noun]" 句式（A white tulip / A pink tulip / A yellow tulip；或 A red orchid / A pink orchid / A purple orchid 等），读起来像流水产品。

**自检时机**：每次输出 L3 旁白表格前**必须**先扫一遍"颜色变体集中度"。

**修复策略**（任选其一，不要多项都用）：

1. **合并到 P3**：把 P7-P8 颜色变体合并到 P3 的多色展示页（一页多色比三页单色更生动）
2. **拆分维度**：P3 单色，P7-P8 改为其他维度（如触感/声音/数字/拟声）
3. **改句式**：P7-P8 不用 "A [adj] [noun]"，换为 "[adj] [noun] in the garden" 或 "Some [adj] [noun]" 等
4. **承认接受**：3 句同结构如果每句都引出不同子特征（颜色 A/颜色 B/特殊属性 C），用户可能接受 → L3 输出时预警，等用户判断

**L3 输出模板改进**：每次输出旁白表格后**附"P3 vs P7-P8 自检"段**，如：
```
【P3 vs P7-P8 自检】
- P3 A white tulip / P7 A pink tulip / P8 A yellow tulip
- 同结构 ⚠️ 已预警，可能需要重组
- 候选修复：合并到 P3 多色 / P7-P8 换触感 / 改句式
```

**camellia 实测案例（推荐学习）**：用户反馈 P3/P7/P8 颜色变体相似 → 通过将 P4 改为 "blooms in winter"（季节维度）打破同质化，而不是改 P3-P8 颜色结构。这是用**新增维度**而非**修改颜色**来解决撞型的范例。

**lavender 实测反例（不算撞型）**：P3 "This is a field of lavender" 已是场景引入页面，化解了 P3 单色变体撞型问题。这是用**场景维度**作为 P3 输入的范例。

**新花结尾建议**（避免撞型）：
- ❌ **不要再用 `X is so [adjective]!`** — 已用 5 次，饱和
- ❌ **不要再用 `X(s) smell so sweet!`** — 已用 2 次，饱和
- ✅ 推荐新句式：
  - 互动采摘型：`Pick a [flower]!`（未用）
  - 对比型：`Big [flower], small [flower]!`（未用）
  - 互动欢呼型：`Hooray for [flower]!`（未用）
  - 互动送花型（扩展对象）：`A [flower] for grandma!` / `A [flower] for dad!`（carnation 已用 for mom）

  - 互动品尝型：⚠️ 仅适合食用花/水果（不适合观赏花）
  - **完美/纯净/漂亮 so-感叹型 → 用户偏好，需用户主动要求时再用**

**gardenia 与 lavender 末句新模式**（15 本新趋势）：
- **晚安祝福型**（lavender）：`Sweet dreams, lavender!` — 利用花卉的助眠功效
- **动作祈使型**（gardenia）：`Water the gardenia!` — 利用花卉的浇水/触感动作
- 这两类新句式**比 so-感叹型 更适合互动页**，且能避开句式饱和

**ios 与 lily 末句同型**：用户两次不同花朵都要求"X 真漂亮"，属用户表达偏好模式，**接受但应附自检预警**。

**末句二次检测机制（升级 · gardenia/lavender 实测新增）**：每次"换语境"后必须再扫一次最近 5-8 本已用结尾类型清单，确认新末句**结构 + 形容词 + 维度**三者都不撞型。**5 步二次检测流程**：
1. 查 `## 句式已用饱和度统计` 表格 → 看是否撞已用句式
2. 查 `## 结尾类型轮换跟踪表` → 看是否撞已用结尾类型
3. 查 `## 句式 / 形容词 / 维度` 三个维度 → 至少一个不撞
4. 如果三个全撞 → 必换型
5. 末句确认后输出表格时**附"末句自检段"**（如："末句 'X is so Y' 撞 lily/iris ⚠️"）

- "smell so sweet"句式也已被用 2 次，下次应避开或改用其他感觉维度（taste/feel/see）

## 花卉类批处理已知风险（19 本全天连做沉淀 · 2026-07-10）

> 一天集中做 5+ 本花卉 = 用户在快速批处理模式。在快批模式下用户会高频触发修改指令（L3 修改频率 = 平均每本 5-7 次用户回复）。

| 风险 | 应对 |
|------|------|
| **用户连续"换语境"指令** | 每换一次必扫已用清单二次检测 |
| **L3 反复修改导致 L4 输出时机错判** | 必须等"标题 + 简介"明确才进 L4，不要自作主张提前 |
| **用户输入"还在嘛"+ 确认组合** | 用户在批处理模式，不想听解释，直接进下一步 |
| **撞型警告输出冗长** | 把"已用 X / 当前 Y / 撞型？"作为短结论，不展开分析过程 |
| **花卉类同质化问题** | 每本主角度必须不同（茎刺/球状/超蓬/贴地/盆栽/高挑/褶皱/放射/圆锥/球形/旗帜/尖瓣/规整/穗状/螺旋 15 个独有结构）|
| **orchid 类事实错误** | 所有生长环境设计前必须查证，详见 §事实纠正 |
| **so-感叹型结尾饱和** | X is so [adj] 已用 5 次，新花必须避开，已建清单监督 |
| **smell so sweet 结尾饱和** | smell so sweet 已用 2 次（violet/lilac），新花应避开 |
| **lavender 类实用功效错失** | "Sweet dreams" 末句 = 利用花卉的助眠功效 = 用户表达偏好 |
| **gardenia 类动作互动错失** | "Water the X!" 末句 = 利用花卉的浇水动作 = 用户表达偏好 |
| **P3 vs P7-P8 颜色变体撞型** | 15 本全数触发，已标注**必自检**（实测 100% 失败率）|
| **lavender P3 + This is field化解** | 把 P3 设计成场景引入句（"This is a field of lavender"）化解单色变体撞型问题 |
| **gardenia 叶子维度重复** | P4 + P6 都涉及叶子（暗绿叶+亮叶）→ 用户实测纠正，需要拆分为不同叶子特征（颜色 vs 光泽） |
| **主角顺序可预测** | 15 本主角先列出再选，避免每次都自动选小蜜蜂/小鸟这种"最常见"选项 |
