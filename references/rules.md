## §1 标题（教学定义的第一锚点）〔裁定 R13〕

**标题只干一件事**：把「英文核心词 ↔ 标准中文释义」1:1 钉死。它不是书名文案，是孩子在本书里对这个词的第一个语义锚点。写得漂亮不是目标，**不能教错**才是目标。〔裁定 R13〕

**输入三件（L1 锁定，缺一不进 L3）**

1. 核心词（台账 `核心词`）
2. 词型（台账 `词型`：名词 / 动作动词 / 形容词 / 颜色·数字 / 位置介词 / 人称代词 / 疑问词）
3. 中文释义（台账 `中文释义`：该词型下的**唯一**标准义项，写成词典义项——不带量词、不带括注、不带词性标记）

**唯一形态**

- 中文：`[量词或口语虚词]<中文释义>[口语虚词]，<核心词>`
- 英文：沿用现行规则（简短口语、含核心词、封面用 Title Case）
- **不再出 3 备选**：释义锁定后没有合规变体；所有者的确认对象是「这个义项对不对」，不是挑措辞。

**七条判据（全机检，缺一即红）**

| # | 判据 | 会红的例子 |
|---|---|---|
| E1 | 英文列含核心词 | `Up the Hill` 不含 high |
| E2 | 中文列含核心词形态 | 「星星」配 `Star` |
| E3 | 中文列无括注 | 「扇子（Phonics），fan」 |
| E4 | 含词后中文 ≤12 字 | — |
| E5 | 无方法论禁词 | 「自然拼读」 |
| G1 | 中文列必须含台账释义**逐字** | 释义「小声说」→「凑近一点，Whisper」红 |
| G2 | 去掉释义与核心词后，只许留量词/指代/口语虚词 | 「小锅煮汤」→ 残留「小汤煮」红 |
| P1 | 词型非动作类时，英文不得用核心词动词屈折形或祈使尾 | `Fan it!`、`Fanning` 红 |

**小字病**：标题与物件名里滥用「小X」（小锅、小硬币）是所有者长期在防的毛病；`小/大/好/真` 这类修饰**不在白名单**，G2 会判红。**角色指代不算**：「小猫」「小女孩」按 `SOUL.md` 允许——该豁免适用于旁白/简介正文；标题走唯一形态、不出现角色指代，G2 照判（2026-11-24 补口径）。

**本判据不证明什么（必须知道）**

1. 只证明「标题与锁定字段一致」；释义本身对不对、词型与释义是否匹配、标题与画面是否同一义项，**都不机检**。
2. 释义与标题由同一个模型产出时是自证循环——L1 必须让所有者**逐字确认释义原话**，并把它与写进台账的释义做逐字对账。
3. 判据只报「不合规 + 命中哪条」，**不规定改成什么**；措辞是创作层的事。

**机检**：`python tools/title_intro_check.py --file <02-title-intro.md> --word <词> --gloss <释义> --pos <词型>`，EXIT=0 才端给所有者。校准集（13 条历史标题 + 5 条错例）见 `docs/证据-标题判据校准-2026-11-22.md`。

## §2 简介

**简介是读给孩子听的一两句短话。** 孩子还不会自己读简介，念的人是你。所以简介只干一件事：让他跟着你的句子，先一步跑进画面里。〔裁定〕

- **一句把他拉进画面**：书里正在发生什么——谁在跑、谁在够、什么被风吹起来了。
- **需要第二句时**：接住同一个感觉，可以说一句自然的观察，也可以问一句孩子看图就有话可答的问题。
- **不承诺效果**：「念几遍就会」「认了就能读」这类话不写——承诺是说给家长的，画面才是说给孩子的。
- **教哪个词、适合几岁、用什么方法**，由标题、封面和封底的说明承担，不进简介。
- **每条简介必须含台账中文释义**〔裁定 R16·2026-11-23〕：孩子的中文核心词锚点必须落在简介文字里——只写英文目标词收尾 = 中文语义锚缺失（B711/B715 两度返工的根因）。机检：`title_intro_check.py` 传 `--gloss` 时逐条断言，缺释义即红。

> 判据（一句话）：把简介念给一个五岁孩子听，他要是问「然后呢？」，就成了；他要是没反应，或者你觉得自己在向家长汇报，就重写。

### 立意：孩子凭什么认出这个词〔2026-11-24 创作方法更新，替换原「第一感觉」口径〕

义项确认后，先回答一个问题——**一个孩子听完这本书，再在生活中遇到这个物件、动作或特征时，凭什么能认出来、知道它在这里是什么意思？** 这个答案就是本书的立意线索，一切选材从它出发。

从孩子熟悉的经验里找答案，三条路都合法：
- **一个物件解决了一个具体问题**（手帕擦掉眼泪、防晒霜挡住暴晒）；
- **一个动作带来了看得见的结果**（卷笔刀转一转，钝铅笔变尖）；
- **同一个词在几个不同情境里都能认出来**（手帕能擦汗、能捂鼻、能递给哭了的伙伴）。

创作线索可以落在触感、声音、情绪或气氛上——**前提是它能帮孩子认识这个词**（soap 的滑溜溜帮助孩子认出「该用它搓洗了」）；题材更适合通过用途、变化、对照或动作结果来理解时，就让这些内容决定立意（coin 的立意是「它是钱：攒起来能换东西」，不是「硬硬的、叮当响」——后者已是被否判例）。〔历史判例〕towel「毛茸茸贴到脸上那一下，水就没了」、grape「一咬，汁水在嘴里炸开」——这两条仍成立，因为它们正是孩子认出「毛巾用来擦、葡萄是吃的」的那个瞬间；判据从来不是「必须是触感」，而是「孩子能从这句话认出这个词」。

### 词型参考视角〔原「先判词型定第一感觉落点」，降级为参考，不再是强制映射〕

词型提示孩子理解这个词的**可能路径**，供立意时参考；立意最终由「孩子凭什么认出」决定，不按词型硬套落点：

| 词型 | 例 | 孩子通常经由什么认出（参考） |
|---|---|---|
| 感官型 | towel / soap / soup / grape | 接触或入口那一瞬的质感 + 结果 |
| 动作型 | stack / bounce / climb | 这个动作做出来的结果（叠高的塔、弹出去的球、爬到的终点） |
| 功能·社会型 | coin / wallet / key / ticket / money | 它是什么、用来干什么 |
| 维度型（形容词） | long / tall / heavy / wide | 义项是**两个端点的距离**：落在「两个端点」或「一次没完成的量」；不用具体长物件（长颈鹿脖子、大象鼻）反推定义——那是举例不是义项（假设，详见 §10 H3） |
| 关系型（位置介词） | behind / on / under / in | 义项是**两个东西的空间关系**：落在**遮蔽的后果**（看不见 / 只露一点 / 找到啦）；方向词写进首句效果好（假设，详见 §10 H4） |

### 写作规则

- **立意锚点落在孩子能认出的场景/结果上**：判据是他听到时能不能对上自己见过的情形——对不上就换素材；不预设正面或负面（安全教育题材同样可立意）。「汤烫嘴」让孩子躲着汤这种反例的教训仍在：锚点要落在孩子对这件东西的真实经验上。
- **一句话只装一个信息**。
- **立意线索先过「画得出来」这一关**：必须能直接变成一张图，图上还得是孩子一眼认得的动作和结果。靠细微粒子、线条、质感才成立的（灰尘排成一条线、奶酪拉丝、玻璃反光）一律不当地基；换成「垃圾被赶着跑、最后一头钻进簸箕」这种一个动作带一个结果的写法。
- **整本书由立意派生**：封面怎么摆、各页语境页写哪个瞬间、简介落在哪里，全部从「孩子凭什么认出这个词」长出来。
- **动笔前先把当本旁白表调出来读一遍**：简介只能写表里真实存在的瞬间；凭页面清单凭印象写，必然把旁白按顺序复述成事件流水账。
- **首句不写场景布置**〔裁定〕：开头不写「桌上」「碗里」「架子上挂着」这类放置动词 + 物体存在。「布置」与「结果状态」要分清——「桌上摆着一碗汤」（摆/放/挂这类放置动词 + 物体存在）算违规；「碗里的汤是煮出来的」（句子重心在结果）放行。〔证据〕26/26 本首句无场景词。
- **首句一句说完，20 字上下**：立意落在读者身上，一句收住；写长了就从「进画面」变成铺陈或流水账。
- **先想孩子会怎么答，再决定要不要问**：答案应来自首句和同一画面，并能自然带回本书的义项。速度词可以请孩子判断角色爬得快还是慢。若答案只剩「什么时候到」「先碰到什么」，话题已经转成时间或顺序。提问对象留在画面里。
- **目标词只在结尾出现一次**〔证据〕：26/26 本满足，均值 1.00 次；作为独立认读语时，按 §4 中文标点处理问句和认读词各自的句末标点。
- **简介被否就回查旁白和立意**：先定位是取错了画面、偏离了核心词，还是收尾不自然。若首句合适而问句生硬，重写收尾或直接读出核心词。只有定稿旁白没有能承载立意的画面时，才提出修改旁白。

### 用词

- 用孩子在家里会说的话，叠词后面带「的」（热热的、软软的、滑溜溜的），一句话最多一个叠词。
- 不用书面词：「摞→叠」「卡手→扎手」「盛→装满」。
- **一句里只挑一个词说，不叠近义词**：「亮得发光」→「亮晶晶的」；「又亮又发光」「干干净净很干净」同判。
- **用户指定场景时照他给的动作顺序写**，不另起场景（此处「动作顺序」指用户给定的素材顺序，非旧创作口径）：他给的是素材（水痕／抹布／一擦就干净），节点一个不落，只在词面上做口语化；开头仍落在被作用的那件东西上（那道水痕），不写「桌上有…」的布置句。
- **用词只取孩子嘴里会说的那一个**：说具体那几件东西（不写「全套」「9 本」这类集合概念）；发音只写孩子读得出的完整词（不写 IPA 音标、不加方法论括注）；开场直接进画面（不写「X 怎么学？」）；称呼用日常词（不写启蒙／进阶／体系／入门这类产品术语）。
- **「小X」三档边界（旁白/简介正文与标题同口径）**〔2026-11-24 所有者裁定「小字病泛滥了」〕：①**角色指代**允许（小猫、小女孩、小浣熊）；②**身体部位**允许（小手、小脚尖——现行正例 rules.md「两只小爪」同档）；③**物件名一律不加「小」**（小鞋子、小硬币、小锅——要写就写鞋子、硬币、锅）。三档外的情形按物件名从严。禁令清单落点见 SKILL.md 反模式。
- **主语**：句子挂在核心词那件东西上；动作词（stack、bounce）挂在那个动作叠出来、扔出来的那件东西上。配角可以出场，只当对手，不展开它自己的反应和心情。

### 交稿前逐条验收

1. **画面和义项**：能指出首句对应哪一页吗？拿掉句尾英文，听完还能说出这条在写什么感觉吗？
2. **问与答**：有问句就先用孩子会说的话答一遍，答案应扣住首句和义项；只为凑问句的，改成观察或直接领读。
3. **亲子口语**：当面念一遍，凡像考试、催促或让孩子和角色比表现，按日常说法重写再读一次。

**写歪了的四种形状**（用户否掉时通常只说一句「都不好」，不给理由）：

- **事件流水账**：把旁白按顺序复述一遍（躺在那→掉进水里→搓出泡→变小），没有立意。
- **场景铺陈**：开头先交代位置和状态（「一碗汤盛满到碗口」），正文还没开始就耗掉半句。
- **信息超载**：一条简介塞三四个动作和两层转折，念起来要换气。
- **家长口吻**：写吸水、拧干、加热这类使用流程，或写「念几遍就会」这类效果承诺。

### 替换性检验（写稿自检，不是机审门禁；假设，详见 §10 H2）

把目标词换成同类的另一个词，这句话还成立吗？还成立 ⇒ 没抓住这个词的核心，重写。

- 反例：「丢进罐子会叮当响」→ 换成 button / bead / stone 也成立 ⇒ 不通过（那是存钱罐的动作，不是硬币的语义）。
- 正例：「把硬币存进小猪罐，攒够了能买东西」→ 换成 button 不成立 ⇒ 通过。
- 副作用（声音、颜色、硬度）只有在**它们本身就是该词的功能**时才能当地基（bell 的响、mirror 的反光）。

### 创作方法（从选定成品提炼；是怎么写出来的，不是机检条款）〔2026-11-24 所有者裁定〕

下面这套是从被选中的简介里反推出来的**创作路径**，不是 checklist。写的时候按这个路径走，写完再用上文判据验收；两者分工，不要拿验收单当创作法。

**写简介的原则〔2026-11-24 所有者裁定，方法论级〕**：先看整本书带孩子经历了什么，再用大人愿意念给孩子听的话，让孩子尝到一点这本书的味道。参考定稿：B681「出汗了擦一擦，打喷嚏捂一捂。朋友哭了递过去，手帕，handkerchief！」——它能代表全书，因为它写出了这本书反复发生的事：**遇到不同的情况，同一块手帕有不同的用法**；三个动作各自成立，合起来让孩子明白手帕能做什么；三个短拍念起来像童谣，还让孩子在听到「手帕」之前，就有机会从动作里猜到它。这一步与上节「**立意**」**叠加使用**：立意给语言的地基（落在哪种体感/功能上——即「孩子凭什么认出」的答案），本步定选材方向（全书记住什么、怎么组织），不二选一。

**写简介的方法〔2026-11-24 所有者裁定〕**：

1. **先用一句直白的话，说清这本书给孩子什么**。通读整本书，想象孩子听完后，会认出什么、发现什么，或者最记得哪件事。这句话先用来帮助自己选材。手帕这本可以说「孩子会看见，一块手帕在几种熟悉的情况下都能用得上」。成稿把「用得上」写成了孩子听得懂的动作。
2. **看内容在全书里是怎么组织的，再决定简介怎么写**。饭盒那本有一个明确的去向：扣好盖子，就要拎着饭盒出门（→ 用下方「单瞬间」手法）。手帕这本靠同一件物品在不同情境中的用途展开，「擦一擦、捂一捂、递过去」就能让孩子听见这种变化（→ 用下方「动作排比」手法）。有的书也可能靠一个疑问、一次发现，或角色前后的变化撑起来。**从样本里学的是怎么找到这本书的组织方式。排比、拟声、问句和转折都可以按需要选用。**
3. **选能代表全书的细节，按说话的节奏写**。「能擦汗、能捂鼻子、能擦眼泪」和入选稿包含相近的信息，念出来的感觉却不同。「出汗了擦一擦」先让孩子碰到一个熟悉的情况，紧接着就有了动作。「朋友哭了递过去」又让孩子看见，手帕还可以递给别人。写完顺口念一遍，听听哪些词让孩子看见了东西，哪些词只是在替读者总结。
4. **拿简介回到全书核对**。想象孩子只听了简介，他会以为接下来要读到什么？这个预期和全书主要给他的体验吻合吗？「手帕弄脏了，得赶紧洗洗」会让孩子以为重点是洗手帕。入选稿让孩子期待看到手帕在不同时候怎么用，这个预期才和全书对得上。洗晒和最后的辨认页可以留到翻书时再发现。

**给创作 Agent 的指令模板〔2026-11-24 所有者裁定，委派简介任务书时使用；「分镜」=页面结构表与双语旁白表两份文件〕**：

> 先通读整本绘本的分镜和旁白。想象孩子读完，会认出什么、发现什么，或者记住哪件事？用一句直白的话把它说清楚。再看看，全书是怎样让孩子得到这个发现的？从书里挑能代表这种体验的细节，用大人会当场念给孩子听的口吻写简介。句数、节奏和写法由这本书的内容决定。
>
> 写完念一遍，再回到分镜核对：只听这段话，孩子会以为接下来要读一本怎样的书？整本书能给到这个体验吗？如果某个细节很生动，却把孩子的期待带到一页支线上，就换素材。交三条候选——各条走不同入口或组织角度，并标注哪一条是你最愿意念的稿。

**交稿数量口径〔2026-11-24 所有者裁定 A 案，统一 R18 与本节〕**：简介一律交 **三条候选**（R18 维持有效），每条走不同入口/组织角度，并由创作子代理**标注其中最愿意念的一条**供所有者优先审阅——三条保选择权，标注保效率。所有者可直接从标注条看起，也可看完全部三条再定。

**输入前置检查〔所有简介起草任务的第一步〕**：若旁白表未定稿、或任务书未附范文附录与台账中文释义，先回报暂停，不开始起草（依据：flow.md §3 硬顺序「先旁白后简介」+ SKILL.md 反模式「委派创作不带范文附录」）。

**边界（防止过推）〔2026-11-24 所有者裁定〕**：不能从一个好稿推出「简介只能写成排比」。B681 这个案例证明的是，**在全书采用并列情境时，简介可以直接写出这种并列的乐趣**。下次遇到另一种绘本，仍然从全书重新判断——单瞬间（饭盒蓝本，见下）、排比（手帕定稿）、疑问、发现、角色变化都可能成立，由这本书的组织方式决定。

**两种手法通用动作〔全局，不随手法变〕**：
- **三条候选走三个不同入口**（如：听觉声音入口 / 期待悬念入口 / 分享感情入口 / 不同组织角度），让所有者选**气质**，不选措辞；措辞雷同的两条等于少给一条。
- **先喂范文再写，示范按本轮问题选取**〔2026-11-24 创作方法更新，替换固定清单口径〕：动笔前先读与本轮要解决的问题对应的已入选简介原文（如组织方式判断题附 B680 单瞬间稿 + B681 排比稿对照；叙述形态题附对白/提问示范），条数以能说明取舍为准、不设固定清单；随台账推进，新定稿（如 B681）即时入池。与 executor.md §2「示范按本轮问题选取」同源，两处口径一致。
- **写完必须自复读清理**〔2026-11-24 所有者裁定，适用于一切面向孩子的文本；与 SKILL.md 全流程纪律 5 同源〕：成稿后出声念一遍，逐句排查并删改——**拗口的**（绕口、拗、念两遍才通顺）、**不像孩子讲故事的**（书面词、成人腔、广告腔、家长汇报腔、抽象评价词）。判据只有一条：一个 5 岁孩子听一遍能不能跟上、会不会觉得在跟他说话。改完再念一遍，直到顺口为止；简介尤其如此；旁白另有 `flow.md` §4「口语门禁」兜底。

**手法一：单瞬间（饭盒蓝本）**——蓝本取自主线/去向型书；判定以本书内容为准，不是固定映射（全条 ≤30 字，两句号断开可过机检；首句 20 字上下）：

**总纲（动笔前第一句话先想清楚）〔2026-11-24 Codex 交接包口径 00:18、01:原话四〕**：先顺读已确认的分镜与旁白，用一句话回答——**这本书里，孩子最值得来看、来试或来发现的是什么？** 从书里真实存在的画面开口，把那个发现说清楚。写完自检一次：**这段话是在邀请孩子听一本书，还是在教他完成一个步骤？** 只写了某页的小动作、不能代表全书 ⇒ 回去看总纲重写。

**反例（Eraser 失败样本，Codex 交接包 01:37）**：橡皮擦那本重试时写出「橡皮擦挪开以后，你猜，哪条线还在？」——模型执行了减条数，却把局部镜头写成猜题；「铅笔一滑，多画了一条线」才是能试读的开口。问句可用，前提是书里真有值得猜或等的事。

**以 B680（lunchbox，所有者选定「咔哒！盖子关好啦。我们要拎着饭盒去公园喽，lunchbox！」）为蓝本：**

1. **只取一个瞬间**：整本书里挑「张力最大、离结局最近一步」的那一页——不是开头、也不是高潮落幕，而是「将启未启」处（饭盒扣好、要出门）。简介不复述全书，只站在这一个瞬间上喊一嗓子。
2. **首句用耳朵接住孩子**：拟声词/触感/气味开头（咔哒！/ 噼里啪啦 / 好香），让孩子一听就知道在演什么；一句话说完这件事，不铺陈。
3. **第二句往前推一步，且与首句同属一个可读瞬间**〔本条为单瞬间手法专属；旁白与其它手法按「衔接连读」判据，见下〕：「同一瞬间」源自 2026-11-24 所有者对 B708 病句的裁定：不向后总结已发生的事，而是指向「马上要发生什么」（我们要去公园喽）——钩子永远朝前看，让人忍不住想翻开书。首句与第二句必须是同一画面里连得上的两句话：B708 被否例「鞋子排好了，可以快快跑向客厅」「鞋子找回来了，明天穿哪双出门」——首句一个瞬间、第二句跳到另一场景或另一时间，前言不搭后语，一律重写。问句可以（B717「他是谁呀？」），不是必须。
4. **不剧透**：最好吃的一口（打开饭盒、树下分着吃）留到书里，简介只递到门口。
5. **句尾落点不变**：中文释义 + 英文目标词收尾（饭盒，lunchbox！），全书目标词只出现这一次。
6. **口吻**：大人口语短句 + 语气词（喽/呀/啦），一口气念完；读出来像招呼人，不像介绍书。
7. **事实只取自书里**：人物、道具、声音都必须能在旁白里找到出处；为了勾人可以放大声响和语气，不能新增人、物、事。

**手法二：动作排比（手帕蓝本 B681 定稿）**——蓝本取自同一物件/同一件事在并列情境中展开的书；判定以本书内容为准，不是固定映射：三个（或至多三个）具体动作短拍并列，每拍「熟悉的情况 + 促成的动作」（出汗了擦一擦）；拍与拍之间是**并列关系**，不需要因果——它们本来就在书里并列发生；全篇不出现抽象总结（「能帮我们做很多事」「这就是手帕」类一律禁），「帮手」的意味让孩子从动作里自己得出；目标词仍只在句尾出现一次；全句受 30 字上限约束（两拍一句号断开即可过 `title_intro_check`）。**反例警戒**：排比是并列情境书的写法，不是万能体——单主线的书硬套排比会丢掉去向感（饭盒的「要去公园喽」就是排比装不下的）。

**被否掉的四类体例（B681 判例口径；与上文通用病灶「写歪了的四种形状」互补——那边是通用病灶，这边是本轮判例）**（前两类 2026-11-24 所有者两次否决原话：「这些简介都不好啊，读起来根本就不像是简介」；后两类同日 B681 六轮打磨沉淀）：
- **旁白复述体**：把动作按页序写一遍（「我把午饭装进饭盒。盖子咔哒一声盖好，lunchbox。」）——像梗概，不像简介。
- **评价口号体**：替孩子下结论（「分着吃才开心」「味道好极了」式广告腔）——读起来像说教，没勾住人。
- **中途总结体**：第一句在动作进行中，第二句跳出来给物件贴标签（「递给他擦擦眼泪。现在它是你的好帮手了」）——动作断了，标签孩子听不见画面。
- **无因果拼接体**：拿书里没有先后因果的两页硬拼因果（B681 的 P5 递手帕与 P6 泥点——手帕不是擦眼泪弄脏的）。两页并用时必须写清它们原本有什么联系；书里没交代原因的，不许拼出一条因果。

**附：B681 六轮打磨判例链**（供复用与回溯，不是流程要求）：单页特写 → 否（太片面）；全弧线 → 否（应提纲挈领）；功能清单+定义句 → 否（说明书腔）；硬套饭盒句式 → 否（钩子没围绕手帕第一印象）；传递瞬间+总结标签 → 否（中途总结体）；无因果拼接 → 否（P5→P6 书里没交代原因）；**定稿=动作排比**。落点：简介的骨架必须长在这本书自己的组织方式上，别人的好句式搬不动。

判据只有一条：念给一个 5 岁孩子听，他会不会伸手去拿书。

## §3 旁白

### 基本要求

- 领读绘本首先是**一本绘本**——读起来好听、朗朗上口、节奏连贯、便于记忆；教学工具是它的第二身份。
- **每页 1–10 个英文词，硬上限 10**〔证据〕（领读 27 本 243 页，最长 10 词、超 10 的 0 页）；**单句建议 ≤8**〔裁定〕。
- **中文列与英文列同档，不是简介**〔裁定〕：内页中文 8–14 字（含标点），一句写完就收；「中文单句不超过 30 字」是硬上限不是目标。自检：这一页单独拎出来能不能当简介用，能，就是写长了。
  - 反例：`小碗的碗沿还挂着泡泡，水一浇，泡泡顺着碗壁滑下去了，rinse。`（27 字，两句描写＋收尾，这就是简介的形状）
  - 正例：`碗沿的泡泡，一冲就没了，rinse。` / `两只小爪，泡泡全冲跑，rinse！`
- 目标词在自然的短句和语境中复现，开头和句型按当页画面变化。
- **成稿出口动作（2026-11-24 晚三诊版；同夜所有者收窄：三诊是定位方法，不是交稿格式）**：整本旁白按页序出声念一遍——遇到接不上/听丢处先按连读三诊定位（缺一句话/缺一个画面/页选错素材），发现真实问题就修；必要时说明孩子原来在哪儿跟不上、改了什么。验证或需要展示效果时，用明确的改前→改后呈现。「哪句念着别扭」是起点，不是终点，不逐句打磨。细则与判例见 `flow.md` §3 第二步「连读三诊」。
- **旁白表第四列「领读」（2026-11-24 所有者裁定 D2=A）**：表结构为 `| 页码 | 英文 | 中文 | 领读 |`——领读列写给带读的成人：`可带读 <词>`（第一次让孩子把词和画面对上，以及孩子可以自己认出来的新变化处）／`停一下，让孩子先看或先说`／`—`（无额外提示）。领读提示独立于正文，孩子读物本体里不出现成人指令。目标词的带读时机由内容决定：第一次对上画面必须带读，之后新变化或孩子能自己认出时再考虑。
- **目标词出现次数：由这本书决定，无统一下限**〔2026-11-25 所有者裁定〕：每个内页都有旁白，英文核心词按当页内容和认读需要出现。起稿时先写这一页值得让孩子听到的话，再问：此时念出这个词，孩子会把它和什么对上？第一次清楚地把词和画面对上时自然念出并提示成人带读；后面在词有实际作用的地方（能带孩子一起说的有意重复）可以再次出现；画面正在推进另一个动作时，让旁白把那个动作讲顺，不硬加核心词。
  > 历史分布参考（2026-11-23 统计，不再作门禁依据）：每页场景段出现核心词在 29 本中 28 本（按 27 本领读口径＝27/27，见 `docs/证据-29本盘点.md` §1）。2026-11-25 所有者进一步裁定：**出现次数和省略页数都由这本书决定**，不再引用任何历史下限。
- **词族伙伴词只在词族拓展页集中出现一次**：伙伴词在语境页反复出现会抢核心词的戏。

### 目标词双语同现〔裁定〕

领读绘本的核心价值：通过第一语言（中文）让读者习得第二语言（英文）。**用到目标词的页面**（即英文列含目标词的页面），中文列必须同现该词，不能在翻译里消失——双语同现只在用到目标词的页面触发；英文旁白自然用到核心词、中文漏掉该词时，`grammar_check.py` 仍会报错。两边都能自然讲清、没有安排认读的页面，交完整的中英文旁白即可，无需在中文句尾贴词。

| 出现方式 | 例 |
|---|---|
| 标题/展示类：直接拼接 | `Yellow!` → 「黄色 Yellow」；`Cat` → 「猫咪 Cat」（展示行 Title Case，中文列跟随同形态） |
| 句子类：调句使目标词成为自然成分 | `A yellow sun` → 「太阳是黄色的 yellow」 |

**句式一致性**：中英句式保持类型一致，不为迁就目标词添加原句没有的成分——祈使句 `Drink water` → 「喝水 water」（不是「喝一些水 water 吧」）；陈述句 `The water is blue` → 「水 water 是蓝色的」；名词句 `Cool water` → 「凉凉的水 water」。

**判据**：改写后的中文读起来仍通顺，像正常的中文句子，只是同时包含了目标词。机检硬闸：英文列含目标词的行，中文列必须同现该词（封面行豁免），`grammar_check.py` 会拦。

### 封面行 = 选定标题〔裁定〕

旁白表第一行（封面）**不是**目标词本身，而是用户选定的标题：

| 页码 | 英文 | 中文 |
|---|---|---|
| 封面 | Learn "leg" | 学单词 leg |

（示例表为节选，省略领读列；完整工作表为四列，封面行领读通常写 `可带读 <词>`，见本节「第四列领读」。）

- 英文列 = 标题里的英文部分；中文列 = 标题里的中文部分，**逐字照抄**，不缩写不改写。
- 封面是标题唯一出现的地方。写成孤零零一个词（`leg` / 「腿，leg」），整本书的标题就丢了。
- L4 封面条与封面行同步，见 `l4-spec.md` §2、§6。

## §4 语法与文字规范（标题 / 简介 / 旁白全覆盖）

> 三处都过，缺一处等于没查。这一步查「写对了没有」，不是「写得好不好」。

### 一、英文大小写

- 句首字母大写，`I` 永远大写；`Mom` / `Dad` / `Grandma` 当名字用时大写。
- **中文旁白行首不要直接摆小写拉丁字母**——中文不因位置大写，行首孤零零一个 `ey` 会被看成漏字。改写成带主语的句式，或加引号：`两个字母 ey 读 ee，钱，money！` / `「ey」读 ee，钱，money！`
- 目标词按句中小写写，不为显眼把整词大写；同一页内风格统一。

### 一·二、中文列夹用英文的大小写（CY/T 154—2017 第 7 节）

- 中文句内夹用的普通英文词，无论句首、句中、句尾，首字母一律小写（7.1）——中文句不承担英文句首大写职能。
- 例外只有两种：专有名词/全大写缩略保留大写（7.2）；**封面行（书名）整行按展示性文本处理**——中文列跟随书名里目标词的形态（书名写 `A Soft Towel`，中文列就写「软软的毛巾，Towel」）。
- 正例：英文 `The cat sits on the floor.` → 中文「小猫坐在地上，这就是 floor。」
- 反例：英文 `Sit on the floor.` 中文写「Sit 在 floor 上」（把英文句首大写带进中文句）；内页句式行写成 Title Case。

### 一·三、封面行的句末标点（GB/T 15834—2011 附录 B.4）

- 标题末尾**通常不用标点**，需要时才可用问号、叹号或省略号——语气助词（喽/啦/呀）已承载语气时不再叠叹号。
- 中英两列各自独立决定，**不作标点对应要求**：英文 `Party Time!` 配中文「开派对喽，party」是合规组合。
- 机审相应豁免：`grammar_check.py` 对封面行不查句末标点对应。

### 二、英文标点

- 每句必须有句末标点（`.` `!` `?`）；一页多句用句号断开，不用逗号把几句连成一条长句。
- 破折号前后各留一个空格：`ey says ee — money!`；感叹号一页最多一个。

### 三、中文标点

- 一律全角：`，。！？：；「」`。
- 目标词融入中文句子时，前用中文逗号，逗号后与英文之间留一个半角空格：`钱，money`。
- **句末独立认读词另行收尾**：完整中文问句先在「吗／呢」落问号，再放独立认读词，认读词也按语气带全角句末标点。例：「你也这么开心过吗？happy！」（`happy！` 是独立认读感叹语，不作为完整英文陈述句）。目标词本身属于句意或称呼时，仍按整句语法标点。
- 不出现半角逗号混进中文（`我笑了, money` 错）。

### 四、语法

- 主谓一致（`The cookies are too high`，不是 `is`）；单复数与冠词（`an apple` / `the piggy bank` / `two coins`）。
- 时态全书统一，领读绘本默认一般现在时。
- 句子完整，主语不能省略到读不懂（祈使句除外）；**词族拓展页的词表行例外**（`Pot, hot, dot, cot.` 不是句子，不受本条约束）。

### 五、整词读法

- 英文旁白按自然语法和句意写完整词；中文用适龄口语，认读落点按本书的核心词形。英文句中可按语法使用单复数等变形；画面标签使用该页确认的完整词形。
- 读法核对留在内部。成品直接给自然的完整词或短句，音标、发音口诀、字母名及词内分段说明均不进旁白或画面。

### 六、中文旁白目标词落点

- 先写一句孩子听得懂、与画面相符的话，再让目标词承担认读、指代或称呼的作用。句尾是可选的自然落点，不是每页必贴的标签；双语同现要求仍有效。
- 不把英文卡进完整中文短语中间（「回家的 way」），也不写完无关动作后追加一个词。删掉目标词再读：正文若没有指向它的实体、动作或性质，就要重写句意。
- 例：`Thank you, soap.` →「小手干净啦，谢谢你，soap。」目标词承接称呼；「泡泡破了，soap。」只把词贴在另一件事后面，不成立。
- 中英文允许顺口的转述，但核心事件、先后关系和语气应对应——不能英文只说位置、中文另讲滑落或冒泡。

### 七、朗读自检

每页出声读一遍，卡住的字就是句子的问题。

## §5 画风

### 画风优先对齐角色参考图（优先级最高）〔裁定〕

- **只要本本的角色来自一张参考图，画面风格一律以那张参考图的画风为准**，不沿用系列既有锚点、不按题材另推风格。角色和画风同源，出图才是一套；角色严格锚图、背景沿用旧风格，得到的就是「彩铅角色坐在拼贴背景上」两张皮。
- 做法固定三步：① 参考图下载到本地 → 压缩 → 视觉识别（直接丢链接/大原图会超时）；② 按媒介技法 / 线条 / 色彩 / 纹理 / 光影 / 构图 / 造型 / 氛围 / 风格标签**九维度**提取；③ 锚点压缩必须同时含**技法层**（如「纯色平涂无渐变，粗黑闭合描线」）、**色彩层**（如「高饱和冷暖撞色：主体暖橙、背景明亮湖蓝渐变，零脏色」）与**感觉层**（如「干净明快、贴纸般活泼」）——只写「某某动画风格」等于没写，模型会给一版灰扑扑的通用稿。
- 提取串写进【全局设计约定】的画风行，并逐页替换旧风格关键词，归档前 grep 旧锚点词残留必须为 0。
- **风格换到与旧锚点冲突时，旧锚点词必须整本清除**：扁平矢量参考图上写「水彩晕染/纸张颗粒/细密绒毛笔触」，模型会画回旧风格——场景、道具、声音波纹等一切元素都改成新风格同款。
- 资产图库「使用定位」只约束**角色外形**是否严格复刻（灵感参考＝提气质与配色重画，制作基准＝严格按图）；**画风一律严格**，与使用定位无关。
- **一张图只能当一种锚：风格锚或角色锚，不能兼当**。海报、封面截图、成品插画里往往带标题文字、厂牌标识和它自己的主角——从中只取画风（光线/材质/配色/景深/笔触），图里的角色、文字、标识一律写进【参考图约定】的排除项；要让它的主角进书，另走多视角参考图。判据：这张图是「一张完整成品」还是「一个角色的三视图」——前者只能取风格。
- **提示词里不写具体片名或工作室 IP**：写片名等于邀请模型把授权角色搬进画面；写「3D 皮克斯动画电影级渲染风格」这类描述即可。

### 风格库

备选库在 `style-library.md`：17 种预设，按 5 类分组（经典画家 S01–S05 / 绘本插画家 S06–S09 / 动画与工作室 S10–S12 / 艺术流派与技法 S13–S15 / 验证新增 S16–S17）。S03 伦勃朗标注「不适合独立使用，需融合」；S04 克利姆特、S13 水墨、S15 北欧极简标注「待验证」。部分条目含锚点文字、色彩特征、适配题材、验证状态。推荐时优先从已验证的里选；用户发参考图时按九维度提炼后可新增入库。

## §6 角色指代

- 只用物种/类型称呼角色（「爷爷」「小女孩」「卡通老虎」）。〔裁定〕
- 不起名字（「贝贝」「乐乐」这一类型）；不指代混乱（一会「小熊」一会「熊熊」）。
- **有参考图时不写受版权保护的角色名**（如跳跳虎）：用其最大、最明显的特征指代（「卡通老虎」），不写外观长篇描述——生图模型能直接看图，具体特征与画风靠一句「严格以图像1为准」交给模型执行。资产链接独立成块，不进提示词正文。〔裁定〕

## §8 边缘安全区（裁切保护）

生成图可能被后期裁切成其他比例，任何主体贴边都会在裁切时被切掉。每条生图提示词末尾必须附「构图要求」，三个要素齐全。〔裁定〕

1. **安全区**：所有主体完整位于画面中央约 80% 的区域。
2. **四边净空 + 危险点点名**：上下左右各预留约 10% 净空，并把当页主体最容易贴边的具体部位写进禁令（耳朵常是最高点、脚常是最低点、横排字母两端、网格四角）——点名具体部位比笼统写「主体」约束力强。
3. **背景铺边**：背景自然延伸填充到画面边缘——空出来的边是背景的延续，不是留白死边。

**固定句式**（部位按当页实际主体替换）：

```
构图要求:[所有主体]完整位于画面中央约80%的安全区域内,画面上下左右各预留约10%的净空,[当页主体的具体高危部位:耳朵(最高点)/脚部(最低点)/字母两端/网格四角]都不得进入预留区,背景自然延伸填充到画面边缘,任何主体不得触碰或被画面四边裁切
```

- **三要素都是硬要求，但不是机器门禁，逐页人工核**：交稿前做**负向断言**——该页「构图要求」句里必须出现「背景…边缘」或「自然延伸填充」这半句，缺即不合格。注意这只是**文本代理**，画面是否真铺边仍需成图验收。〔证据〕243 页：① 243/243、② 232/243、③ 背景铺边 207/243。
- 封面同样适用，安全区字样要把标题载体（如白云、木牌）一并纳入保护范围。
- 净空比例写「约 10%」量级即可——过大主体被压小、画面变空。
- 该句式是生成提示词的一部分，归档与交付时不得省略。

## §9 边界条件与异常

| 情形 | 处置 |
|---|---|
| 用户中途改主题/主角 | 回 L1 重新确认 |
