## §1 标题

**核心原则**：自然流畅优先，用最适合题材的方式表达。

- **必须包含目标单词**，按它在句中的自然大小写写，不为显眼强行大写。〔裁定〕
- **目标词是标题的主角**：整体围绕它点题，中文部分自含它的中文意思、目标词在自然落点显性出现，一眼看出「词—义」对应（「举高高，high」「小小的，little」）——不是把词藏进英文列当陪衬，也不是让它打断中文句子。
- **简洁**：中文 3–8 字为主，整条含目标词不超过 12 字。
- **英文简短、口语**，目标词用引号包裹。
- **英文列也必须把目标词写进去**〔证据〕：有英文标题的 27/27 本都含核心词。中文含词、英文不含（书名 `Soft and Warm` 配「软软的毛巾，towel」）等于标题缺词——封面核心词的形态只认文稿里出现过的写法，英文标题没有那个词，封面就出不了 Title Case，机审当场判红。改法是把词收进英文标题（`A Soft Towel`）。
- **中文列里的目标词按封面形态写，备选阶段就这样写**：中文列跟英文标题里那个词的形态对齐（英文标题 `Rinse It Clean` → 中文列「冲一冲呀，Rinse」）。`grammar_check.py` 以英文标题形态判封面行中文列，大小写不齐当场 EXIT=1；内页句式行仍一律小写。
- **两种句式都成立，按需轮换**：
  - 直给式「学单词 X」「一起学 X」——上口、一眼看清教什么，可以用；但别连着几本都是同一种。
  - 口语式：一句孩子会说的话 + 逗号 + 目标词（「举高高，high」）——从书里真实的动作、场景长出来。
- **三种起法**：三条备选换三种骨架（动作一条、状态一条、对话一条），不许换个形容词交第二条。
- **画得出来**：标题只能从这本书真实拥有的动作、场景、人物关系里长出来；不编造书里没有的情节或比喻。
- **不用「形容词 + 指代」的空转句式**：「甜甜的这一颗」这类句子没有具体东西——甜画不出来，「这一颗」也指不明；写看得见的事实（挂得高、够不着、掉进水里）。

**自检三问（逐条过）**：① 念出来顺口吗？念给 5 岁孩子听，他会不会跟着说一遍？② 一眼看明白这本书教什么吗？③ 它像话吗——「学单词 high」像，「gh 不出声」不像。

**机检**：`tools/title_intro_check.py` 核「中英两列含词 / 无括注 / 含词后 ≤12 字」。〔证据〕27/27 含核心词、0/29 含括注、0/29 含方法论禁词。

## §2 简介

**简介是读给孩子听的一两句短话。** 孩子还不会自己读简介，念的人是你。所以简介只干一件事：让他跟着你的句子，先一步跑进画面里。〔裁定〕

- **一句把他拉进画面**：书里正在发生什么——谁在跑、谁在够、什么被风吹起来了。
- **需要第二句时**：接住同一个感觉，可以说一句自然的观察，也可以问一句孩子看图就有话可答的问题。
- **不承诺效果**：「念几遍就会」「认了就能读」这类话不写——承诺是说给家长的，画面才是说给孩子的。
- **教哪个词、适合几岁、用什么方法**，由标题、封面和封底的说明承担，不进简介。

> 判据（一句话）：把简介念给一个五岁孩子听，他要是问「然后呢？」，就成了；他要是没反应，或者你觉得自己在向家长汇报，就重写。

### 地基：先定核心词的第一感觉

动笔前先写一句话——这件东西落在孩子身上的第一感觉是什么。不写定义、不写用途、不写功能。〔裁定〕

| 核心词 | 第一感觉 |
|---|---|
| towel | 毛茸茸贴到脸上那一下，水就没了 |
| soap | 滑溜溜的，一搓就冒泡，抓都抓不住 |
| soup | 一勺下去从嗓子滑到肚子里，暖暖的 |
| stack | 一块压一块，越叠越高，高到晃 |
| grape | 一咬，汁水在嘴里炸开 |

### 先判词型，再决定第一感觉落在哪里〔裁定〕

| 词型 | 例 | 「第一感觉」必须落在 |
|---|---|---|
| 感官型 | towel / soap / soup / grape | 接触或入口那一瞬的质感 + 结果 |
| 动作型 | stack / bounce / climb | 这个动作做出来的结果（叠高的塔、弹出去的球、爬到的终点） |
| 功能·社会型 | coin / wallet / key / ticket / money | **它是什么、用来干什么**——不是声音、颜色、硬度这类副作用 |
| 维度型（形容词） | long / tall / heavy / wide | 义项是**两个端点的距离**：落在「两个端点」或「一次没完成的量」；不用具体长物件（长颈鹿脖子、大象鼻）反推定义——那是举例不是义项 〔假设〕 |
| 关系型（位置介词） | behind / on / under / in | 义项是**两个东西的空间关系**，不是东西本身：落在**遮蔽的后果**（看不见 / 只露一点 / 找到啦）；**必须把方向词写进首句** 〔假设〕 |

### 写作规则

- **第一感觉必须是正面的**：孩子愿意再来一次的那种舒服或好玩。烫、疼、扎、脏、臭、吵都不能当地基（安全教育题材除外）——「汤烫嘴」不算汤的第一感觉，「汤暖到肚子里」才是。
- **一句话只装一个信息**。
- **候选第一感觉先过「画得出来」这一关**：必须能直接变成一张图，图上还得是孩子一眼认得的动作和结果。靠细微粒子、线条、质感才成立的（灰尘排成一条线、奶酪拉丝、玻璃反光）一律不当地基；换成「垃圾被赶着跑、最后一头钻进簸箕」这种一个动作带一个结果的写法。
- **整本书由它派生**：封面怎么摆、各页语境页写哪个瞬间、简介落在哪里，全部从这一句长出来。
- **动笔前先把当本旁白表调出来读一遍**：简介只能写表里真实存在的瞬间；凭页面清单凭印象写，必然把旁白按顺序复述成事件流水账。
- **首句不写场景布置**〔裁定〕：开头不写「桌上」「碗里」「架子上挂着」这类放置动词 + 物体存在。「布置」与「结果状态」要分清——「桌上摆着一碗汤」（摆/放/挂这类放置动词 + 物体存在）算违规；「碗里的汤是煮出来的」（句子重心在结果）放行。〔证据〕26/26 本首句无场景词。
- **先想孩子会怎么答，再决定要不要问**：答案应来自首句和同一画面，并能自然带回本书的义项。速度词可以请孩子判断角色爬得快还是慢。若答案只剩「什么时候到」「先碰到什么」，话题已经转成时间或顺序。提问对象留在画面里。
- **目标词只在结尾出现一次**〔证据〕：26/26 本满足，均值 1.00 次；作为独立认读语时，按 §4 中文标点处理问句和认读词各自的句末标点。
- **简介被否就回查旁白和义项**：先定位是取错了画面、偏离了核心词，还是收尾不自然。若首句合适而问句生硬，重写收尾或直接读出核心词。只有定稿旁白没有能承载第一感觉的画面时，才提出修改旁白。

### 用词

- 用孩子在家里会说的话，叠词后面带「的」（热热的、软软的、滑溜溜的），一句话最多一个叠词。
- 不用书面词：「摞→叠」「卡手→扎手」「盛→装满」。
- **一句里只挑一个词说，不叠近义词**：「亮得发光」→「亮晶晶的」；「又亮又发光」「干干净净很干净」同判。
- **用户指定场景时照他给的动作链写**，不另起场景：他给的是素材（水痕／抹布／一擦就干净），节点一个不落，只在词面上做口语化；开头仍落在被作用的那件东西上（那道水痕），不写「桌上有…」的布置句。
- 禁：集合概念（全套／9 本）、IPA 音标、方法论括注、「X 怎么学？」开场、产品术语（启蒙／进阶／体系／入门）。
- **主语**：句子挂在核心词那件东西上；动作词（stack、bounce）挂在那个动作叠出来、扔出来的那件东西上。配角可以出场，只当对手，不展开它自己的反应和心情。

### 交稿前逐条验收

1. **画面和义项**：能指出首句对应哪一页吗？拿掉句尾英文，听完还能说出这条在写什么感觉吗？
2. **问与答**：有问句就先用孩子会说的话答一遍，答案应扣住首句和义项；只为凑问句的，改成观察或直接领读。
3. **亲子口语**：当面念一遍，凡像考试、催促或让孩子和角色比表现，按日常说法重写再读一次。

### 替换性检验（写稿自检，不是机审门禁）〔假设〕

把目标词换成同类的另一个词，这句话还成立吗？还成立 ⇒ 没抓住这个词的核心，重写。

- 反例：「丢进罐子会叮当响」→ 换成 button / bead / stone 也成立 ⇒ 不通过（那是存钱罐的动作，不是硬币的语义）。
- 正例：「把硬币存进小猪罐，攒够了能买东西」→ 换成 button 不成立 ⇒ 通过。
- 副作用（声音、颜色、硬度）只有在**它们本身就是该词的功能**时才能当地基（bell 的响、mirror 的反光）。

## §3 旁白

### 基本要求

- 领读绘本首先是**一本绘本**——读起来好听、朗朗上口、节奏连贯、便于记忆；教学工具是它的第二身份。
- **每页 1–10 个英文词，硬上限 10；单句建议 ≤8**〔证据〕〔裁定〕：领读 27 本 243 页，最长 10 词、超 10 的 0 页。
- **中文列与英文列同档，不是简介**：内页中文 8–14 字（含标点），一句写完就收；「中文单句不超过 30 字」是硬上限不是目标。自检：这一页单独拎出来能不能当简介用，能，就是写长了。
  - 反例：`小碗的碗沿还挂着泡泡，水一浇，泡泡顺着碗壁滑下去了，rinse。`（27 字，两句描写＋收尾，这就是简介的形状）
  - 正例：`碗沿的泡泡，一冲就没了，rinse。` / `两只小爪，泡泡全冲跑，rinse！`
- 目标词在自然的短句和语境中复现，开头和句型按当页画面变化。
- **目标词全书 ≥8 次**〔证据〕：每页场景段都出现核心词在 28/29 本成立（每本 9 页），`l4_structure_check.py` 按「原形 + 复数」同口径断言。封面按书名形态计。
- **词族伙伴词只在词族拓展页集中出现一次**：伙伴词在语境页反复出现会抢核心词的戏。

### 目标词双语同现〔裁定〕

领读绘本的核心价值：通过第一语言（中文）让读者习得第二语言（英文）。目标词必须在中文列出现，不能在翻译里消失。

| 出现方式 | 例 |
|---|---|
| 标题/展示类：直接拼接 | `Yellow!` → 「黄色 Yellow」；`Cat` → 「猫咪 Cat」（展示行 Title Case，中文列跟随同形态） |
| 句子类：调句使目标词成为自然成分 | `A yellow sun` → 「太阳是黄色的 yellow」 |

**句式一致性**：中英句式保持类型一致，不为迁就目标词添加原句没有的成分——祈使句 `Drink water` → 「喝水 water」（不是「喝一些水 water 吧」）；陈述句 `The water is blue` → 「水 water 是蓝色的」；名词句 `Cool water` → 「凉凉的水 water」。

**判据**：改写后的中文读起来仍通顺，像正常的中文句子，只是同时包含了目标词。机检硬闸：英文列含目标词的行，中文列必须同现该词（封面行豁免），`grammar_check.py` 会拦。

### 封面行 = 选定标题〔裁定〕

旁白表第一行（封面）**不是**目标词本身，而是用户选定的标题：

| 页码 | 英文 | 中文 |
|---|---|---|
| 封面 | Learn "leg" | 学单词 leg |

- 英文列 = 标题里的英文部分；中文列 = 标题里的中文部分，**逐字照抄**，不缩写不改写。
- 封面是标题唯一出现的地方。写成孤零零一个词（`leg` / 「腿，leg」），整本书的标题就丢了。
- L4 封面条与封面行同步，见 `l4-spec.md` §2、§6。

## §4 语法与文字规范（标题 / 简介 / 旁白全覆盖）

> 三处都过，缺一处等于没查。这一步查「写对了没有」，不是「写得好不好」。

### 一、英文大小写

- 句首字母大写，`I` 永远大写；`Mom` / `Dad` / `Grandma` 当名字用时大写。
- **中文旁白行首不要直接摆小写拉丁字母**——中文不因位置大写，行首孤零零一个 `ey` 会被看成漏字。改写成带主语的句式，或加引号：`两个字母 ey 读 ee，钱，money！` / `「ey」读 ee，钱，money！`
- 目标词按句中小写写，不为显眼把整词大写；同一页内风格统一。

### 一·二、中文列夹用英文的大小写（CY/T 154—2017 第 7 节）

- 中文句内夹用的普通英文词，无论句首、句中、句尾，首字母一律小写（7.1）——中文句不承担英文句首大写职能。
- 例外只有两种：专有名词/全大写缩略保留大写（7.2）；**封面行（书名）整行按展示性文本处理**——中文列跟随书名里目标词的形态（书名写 `A Soft Towel`，中文列就写「软软的毛巾，Towel」）。
- 正例：英文 `The cat sits on the floor.` → 中文「小猫坐在地上，这就是 floor。」
- 反例：英文 `Sit on the floor.` 中文写「Sit 在 floor 上」（把英文句首大写带进中文句）；内页句式行写成 Title Case。

### 一·三、封面行的句末标点（GB/T 15834—2011 附录 B.4）

- 标题末尾**通常不用标点**，需要时才可用问号、叹号或省略号——语气助词（喽/啦/呀）已承载语气时不再叠叹号。
- 中英两列各自独立决定，**不作标点对应要求**：英文 `Party Time!` 配中文「开派对喽，party」是合规组合。
- 机审相应豁免：`grammar_check.py` 对封面行不查句末标点对应。

### 二、英文标点

- 每句必须有句末标点（`.` `!` `?`）；一页多句用句号断开，不用逗号把几句连成一条长句。
- 破折号前后各留一个空格：`ey says ee — money!`；感叹号一页最多一个。

### 三、中文标点

- 一律全角：`，。！？：；「」`。
- 目标词融入中文句子时，前用中文逗号，逗号后与英文之间留一个半角空格：`钱，money`。
- **句末独立认读词另行收尾**：完整中文问句先在「吗／呢」落问号，再放独立认读词，认读词也按语气带全角句末标点。例：「你也这么开心过吗？happy！」（`happy！` 是独立认读感叹语，不作为完整英文陈述句）。目标词本身属于句意或称呼时，仍按整句语法标点。
- 不出现半角逗号混进中文（`我笑了, money` 错）。

### 四、语法

- 主谓一致（`The cookies are too high`，不是 `is`）；单复数与冠词（`an apple` / `the piggy bank` / `two coins`）。
- 时态全书统一，领读绘本默认一般现在时。
- 句子完整，主语不能省略到读不懂（祈使句除外）；**词族拓展页的词表行例外**（`Pot, hot, dot, cot.` 不是句子，不受本条约束）。

### 五、整词读法

- 英文旁白按自然语法和句意写完整词；中文用适龄口语，认读落点按本书的核心词形。英文句中可按语法使用单复数等变形；画面标签使用该页确认的完整词形。
- 读法核对留在内部。成品直接给自然的完整词或短句，音标、发音口诀、字母名及词内分段说明均不进旁白或画面。

### 六、中文旁白目标词落点

- 先写一句孩子听得懂、与画面相符的话，再让目标词承担认读、指代或称呼的作用。句尾是可选的自然落点，不是每页必贴的标签；双语同现要求仍有效。
- 不把英文卡进完整中文短语中间（「回家的 way」），也不写完无关动作后追加一个词。删掉目标词再读：正文若没有指向它的实体、动作或性质，就要重写句意。
- 例：`Thank you, soap.` →「小手干净啦，谢谢你，soap。」目标词承接称呼；「泡泡破了，soap。」只把词贴在另一件事后面，不成立。
- 中英文允许顺口的转述，但核心事件、先后关系和语气应对应——不能英文只说位置、中文另讲滑落或冒泡。

### 七、朗读自检

每页出声读一遍，卡住的字就是句子的问题。

## §5 画风

### 画风优先对齐角色参考图（优先级最高）〔裁定〕

- **只要本本的角色来自一张参考图，画面风格一律以那张参考图的画风为准**，不沿用系列既有锚点、不按题材另推风格。角色和画风同源，出图才是一套；角色严格锚图、背景沿用旧风格，得到的就是「彩铅角色坐在拼贴背景上」两张皮。
- 做法固定三步：① 参考图下载到本地 → 压缩 → 视觉识别（直接丢链接/大原图会超时）；② 按媒介技法 / 线条 / 色彩 / 纹理 / 光影 / 构图 / 造型 / 氛围 / 风格标签**九维度**提取；③ 锚点压缩必须同时含**技法层**（如「纯色平涂无渐变，粗黑闭合描线」）、**色彩层**（如「高饱和冷暖撞色：主体暖橙、背景明亮湖蓝渐变，零脏色」）与**感觉层**（如「干净明快、贴纸般活泼」）——只写「某某动画风格」等于没写，模型会给一版灰扑扑的通用稿。
- 提取串写进【全局设计约定】的画风行，并逐页替换旧风格关键词，归档前 grep 旧锚点词残留必须为 0。
- **风格换到与旧锚点冲突时，旧锚点词必须整本清除**：扁平矢量参考图上写「水彩晕染/纸张颗粒/细密绒毛笔触」，模型会画回旧风格——场景、道具、声音波纹等一切元素都改成新风格同款。
- 资产图库「使用定位」只约束**角色外形**是否严格复刻（灵感参考＝提气质与配色重画，制作基准＝严格按图）；**画风一律严格**，与使用定位无关。
- **一张图只能当一种锚：风格锚或角色锚，不能兼当**。海报、封面截图、成品插画里往往带标题文字、厂牌标识和它自己的主角——从中只取画风（光线/材质/配色/景深/笔触），图里的角色、文字、标识一律写进【参考图约定】的排除项；要让它的主角进书，另走多视角参考图。判据：这张图是「一张完整成品」还是「一个角色的三视图」——前者只能取风格。
- **提示词里不写具体片名或工作室 IP**：写片名等于邀请模型把授权角色搬进画面；写「3D 皮克斯动画电影级渲染风格」这类描述即可。

### 风格库

备选库在 `style-library.md`：16 种预设，按 5 类分组（经典画家 S01–S05 / 绘本插画家 S06–S09 / 动画与工作室 S10–S12 / 艺术流派与技法 S13–S15 / 验证新增 S16+）。S03 伦勃朗标注「不适合独立使用，需融合」；S04 克利姆特、S13 水墨、S15 北欧极简标注「待确认」。每种含锚点文字、色彩特征、适配题材、验证状态。推荐时优先从已验证的里选；用户发参考图时按九维度提炼后可新增入库。

### 没有参考图时的风格选择

- 用户指定大师/风格名 → 从 `style-library.md` 匹配锚点；库里没有就按九维度自行提炼并请用户确认。
- 用户没指定 → 按题材从下面四条里推荐 2–3 种，等用户选（领读模式推荐池）：

| 风格 | 适合的题材 |

| S06 Eric Carle 拼贴风 | 色块鲜明、图形简洁，最适合低幼认知 |
| S10 迪士尼经典动画 | 角色圆润亲和、色彩饱和，主角需要清晰对称双眼时优先 |
| S14 波普艺术 | 高对比撞色、视觉冲击力强，适合字母展示 |

- 风格确认后把锚点文字记下，L4 作为「全局风格锚点」使用。

## §6 角色指代

- 只用物种/类型称呼角色（「爷爷」「小女孩」「卡通老虎」）。〔裁定〕
- 不起名字（「贝贝」「乐乐」这一类型）；不指代混乱（一会「小熊」一会「熊熊」）。
- **有参考图时不写受版权保护的角色名**（如跳跳虎）：用其最大、最明显的特征指代（「卡通老虎」），不写外观长篇描述——生图模型能直接看图，具体特征与画风靠一句「严格以图像1为准」交给模型执行。资产链接独立成块，不进提示词正文。〔裁定〕

## §7 比例

- 封面 **3:4**（竖版）；内页 **16:9**。〔证据〕29/29 本满足。
- **成图后处理裁切**：若最终排版比例与生图比例不同（排版 16:10、生图 16:9），生成图需经裁切——构图必须为裁切预留余量，见 §8。

## §8 边缘安全区（裁切保护）

生成图可能被后期裁切成其他比例，任何主体贴边都会在裁切时被切掉。每条生图提示词末尾必须附「构图要求」，三个要素齐全。〔裁定〕

1. **安全区**：所有主体完整位于画面中央约 80% 的区域。
2. **四边净空 + 危险点点名**：上下左右各预留约 10% 净空，并把当页主体最容易贴边的具体部位写进禁令（耳朵常是最高点、脚常是最低点、横排字母两端、网格四角）——点名具体部位比笼统写「主体」约束力强。
3. **背景铺边**：背景自然延伸填充到画面边缘——空出来的边是背景的延续，不是留白死边。

**固定句式**（部位按当页实际主体替换）：

```
构图要求:[所有主体]完整位于画面中央约80%的安全区域内,画面上下左右各预留约10%的净空,[当页主体的具体高危部位:耳朵(最高点)/脚部(最低点)/字母两端/网格四角]都不得进入预留区,背景自然延伸填充到画面边缘,任何主体不得触碰或被画面四边裁切
```

- **三要素都是硬要求，但不是机器门禁，逐页人工核**：交稿前做**负向断言**——该页「构图要求」句里必须出现「背景…边缘」或「自然延伸填充」这半句，缺即不合格。注意这只是**文本代理**，画面是否真铺边仍需成图验收。〔证据〕243 页：① 243/243、② 232/243、③ 背景铺边 207/243。
- 封面同样适用，安全区字样要把标题载体（如白云、木牌）一并纳入保护范围。
- 净空比例写「约 10%」量级即可——过大主体被压小、画面变空。
- 该句式是生成提示词的一部分，归档与交付时不得省略。

## §9 边界条件与异常

| 情形 | 处置 |
|---|---|
| 用户中途改主题/主角 | 回 L1 重新确认 |
| 用户只想换风格 | 回 L1 风格选择，不重做标题旁白 |
| 用户想改旁白内容 | 回 L3 重创旁白（简介随之重验） |
| L2 之后换目标单词 | 回 L1 重新确认，已有文案作废 |
| 内页不足 8 页 | 加语境页（不同句式与画面）直到 8 页 |
| 内页超过 16 页 | 先收敛语境页，保留封面、语境页与互动练习页 |
| 目标词过长或过短 | 仍按完整词呈现；长词用宽载体、充足留白和自然字距；只有一个字母时直接呈现该完整词 |
| 参考图模糊/分辨率过低 | 请用户重传更清晰的图 |
| 参考图风格与题材严重不匹配 | 说明风险并建议切换 |
| 参考图含不适宜内容 | 拒绝使用并说明原因 |
| L4 之后发现风格明显不适合 | 说明问题 → 推荐 1–2 种替代 → 用户确认后只重出 L4，不重做旁白 |
| 词族拓展找不到合适候选 | 用额外语境页补足 |
