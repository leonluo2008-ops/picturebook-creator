# Caterpillar Eric Carle 经典造型生图提示词（2026-07-17 实测重写版）

## 原始失败版 vs 修正版对照

| ❌ 原版（用户反馈"太丑"） | ✅ 修正版（致敬 ECP 原作） |
|---|---|
| 单一绿色身体 + 红色头部 + 黑白对比弱 | 多色节段循环（红/橙/黄/绿/蓝/紫 6 色串珠糖葫芦） |
| 瘦长形（头身比 1:6）+ 5-8 节细长节段 | 萌系大头（头身比 1:5）+ 5-7 节饱满大圆球 |
| 身体单色无装饰 | 每节色块带**白色圆点装饰** |
| 腿模糊笼统 | 5-6 对腿，每对腿**三段折线**清晰可数 |
| 像普通绿色肉虫 | 像彩虹串珠糖葫芦，胖嘟嘟，圆滚滚 |

## ECP 经典彩虫造型铁律（caterpillar 必备 6 条）

1. **多色节段循环**：身体由 5-7 节饱满大圆球色块串联，节段颜色循环 = 红/橙/黄/绿/蓝/紫（6 色循环，避免相邻节段同色）
2. **萌系大头比例**：红色大圆头占身体 1/5 体积（不是普通头身比 1:6/1:7）
3. **每节白色圆点**：每节大圆球色块上点缀 2-3 个白色小圆点装饰（ECP 原作封面彩虫标志特征）
4. **弯弯触角**：两只黑色细触角**向上翘起或微微颤动**，不是僵直向两侧
5. **三段折线腿**：每对腿用"大腿-小腿-脚"三段折线呈现，5-6 对腹足清晰可数
6. **一拱一拱弯曲姿态**：身体自然弯曲成 S 形或拱桥形（毛毛虫蠕动典型动作），不是僵直平躺
