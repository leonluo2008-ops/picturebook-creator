# Lychee 8 行范本格式 — 水果/食物/植物类领读旁白

> **来源**: 2026-07-09 用户给 Lychee 8 行旁白范本,要求"按照范本格式重新写出黑莓/树莓的旁白"。本文件是该范本的标准化归档,作为 SKILL.md P6 沉淀位置的支撑文件。

## 范本原文 (Lychee)

```
1 Lychee! 荔枝 Lychee!
2 Look! A lychee. 看,荔枝 Lychee!
3 A red lychee. 红红的荔枝 Lychee。
4 The lychee is round. 圆圆的荔枝 Lychee。
5 The lychee has bumps. 荔枝有疙瘩 Lychee。
6 The lychee is white! 荔枝白白的 Lychee!
7 The lychee is sweet. 荔枝甜甜的 Lychee。
8 I like lychee! 我喜欢荔枝 Lychee!
```

## 8 行结构骨架

| 行号 | 类型 | 教学内容 | 中文翻译模板 |
|------|------|---------|------|
| 1 | 强化页 | `[TARGET]!` | `[中文词] [TARGET英文全大写]!` |
| 2 | 引入页 | `Look! A [target].` | `[完整中文翻译(含 Look)], [target英文]` |
| 3 | 颜色页 | `A [颜色] [target].` | `[中文颜色描述+名词], [target英文]` |
| 4 | 形状页 | `The [target] is [形状].` | `[中文形状描述], [target英文]` |
| 5 | 触感页 | `The [target] has [触感特征].` | `[中文触感描述+名词], [target英文]` |
| 6 | 内里页 | `The [target] is [特殊颜色]!` | `[中文颜色描述+名词], [target英文]!` |
| 7 | 味道页 | `The [target] is [味道].` | `[中文味道描述+名词], [target英文]` |
| 8 | 收尾页 | `I like [target]!` 或 `Find the [target]!` | `[完整中文翻译(含动作)], [target英文]!` |

## 核心格式铁律

### 中文末尾绑定格式

每行中文末尾 = `[完整中文翻译] [目标词英文]`

- 正确: `红红的树莓, raspberry`
- 错误: `红红的树莓, a red raspberry`(绑了完整英文句)
- 错误: `树莓 raspberry`(省略中文翻译)

### 中文翻译完整性

- 中文必须主语/动词/宾语齐全,不能省略
- 正确: `一颗黑黑的黑莓,blackberry.`
- 错误: `黑黑的黑莓,blackberry.`(缺量词)
- 错误: `一颗黑的,blackberry.`(缺名词)

### 大小写规则

- 第 1 行(强化页):目标词全大写 `BLACKBERRY`
- 第 2-8 行(正文):目标词正常大小写 `blackberry`
- 中文一律正常,不区分大小写

### 标点对应

- 英文 `.` → 中文 `。`
- 英文 `!` → 中文 `!`
- 英文 `?` → 中文 `?`
- 中英文之间用 `,`(中文逗号)分隔

## 适用边界

| 类型 | 是否用 8 行范本 | 备注 |
|------|------|------|
| 水果 (apple/banana/grape/...) | 优先用 | 用户 07-09 实测偏好 |
| 食物 (bread/rice/cake/...) | 优先用 | 结构同水果 |
| 植物/花卉 (sunflower/tree/...) | 优先用 | 8 行可调整为植物专属(开花/结果/落叶) |
| 蔬菜 | 谨慎 | 蔬菜多用蜡笔手绘童趣风,见 vegetable-series-batch-pattern.md |
| 动物 | 不建议 | 动物走 6 级句式骨架 + 性格路线,见 animal-series-batch-pattern.md |
| 职业/家庭称谓 | 不建议 | 走原文 6 级骨架 + 多样性轮换 |
| 短语/感叹词 | 不适用 | 短语类有专门规则,见 phrase-series-batch-pattern.md |

## 与其他规则的关系

- 与 P1 关系: P1 是"只绑目标词"的格式铁律(本范本 100% 遵守)
- 与 P7 关系: P7 规定内页 ≥ 8 页,本范本正好 8 行 = 8 内页 = 全书 9 页,天然合规
- 与去模板化铁律关系: 8 行骨架是结构框架,具体每行的"独有特征"必须围绕目标词设计(如 raspberry 的空心 vs blackberry 的聚合果),不能每本都套同一个形容词

## 反模式 (禁止)

- 每本水果都用同一组 8 句,只换目标词 -> 模板化错误
- 中文翻译省略主语/动词/宾语 -> 违反"完整中文翻译"铁律
- 中文末尾绑定完整英文句 (a red apple) -> 违反 P1
- 叠词堆叠 (高高的/红红的/甜甜的 连用 4+ 次) -> 幼稚化
- 结尾永远是 `I like [target]!` -> 4-6 本后用户会腻,需轮换 (Find/Count/Compare/I like)
