# L1-L4 严格格式模板（2026-07-21 sunshine/many/get 实测沉淀）

> **核心结论：** agent 在 L1/L2/L3/L4 都曾自由发挥,被用户多次用图示范例强制对齐。本文件固化"严格模板",**禁止自由发挥**。
>
> **触发场景：** 用户发图(如 sunshine 范例图)说"格式不对,应该是如图这样的" → 必须立刻参照本文件 + sunshine 范例重新输出。

## L1 领读绘本需求确认（严格 7 字段）

```markdown
【领读绘本需求确认】
目标单词: many
中文释义: 很多/许多
目标年龄: 3-6岁
自然拼读级别: Sight Word（many 是 sight word，不是 CVC 也不是词族可拆解型）
词族: 无独立词族（many 整体作为视觉整体认读）
画面风格: S06 Eric Carle 拼贴风（色块鲜明,最适合低幼认知）
路径分支: many 是抽象数量词，无合适固定主角 → 走路径B无人称版（每页主体即为"很多X"群体本身）
```

❌ 反模式（2026-07-21 many 实测用户批评）：
- 在代码块外再写"⚠️ many 是核心词重复型——每行英文必须以 many 开头"等说明
- 在代码块外写"many 不属于动物/家庭称谓/职业,无需走 A 加主角"等展开段落
- 在代码块外加"路径分支说明"段落

✅ 修正：严格 7 字段 + 路径分支字段内嵌 1 行说明（路径名 + 原因 + 后果） + 末尾 → 箭头推进

> ⚠️ **L2 推进链方向（v5.6.0 新增 · 质感锚定②的落点）**：设计页面结构时在内部先定全书推进链方向（近→远 / 小→大 / 物→人 / 特征→动作→情感，任选其一），每页教学内容 = 链上顺次一站；L3 出稿后按「推进」自检回看。方向选择属内部执行，不在 L2 表格中展示（遵守 L2 无表格外段落纪律）。方向之外，内部再定**一句话事件线**——这本书从头到尾发生的一件事，每页教学内容=线上一站；出稿后用朗读测试验线：把全部页的教学内容连起来讲给 4 岁孩子听，需要「另外还有…」才能接上的页=离线页，回 L2 重排。有因果债务的线索（某页开了后果/悬念：丢了/忘了/许了）必须安排收回页；无债务的平行列举（many/颜色/节气型）仍是合法结构，勿逼改成故事书。全部为语义判据（2026-09-22 forget 事故新增，见 incident-20260922-forget-storyline.md），内部执行不在表格中展示。

## L3 备选标题 + 备选简介 + 双语旁白（严格三块结构）

### 3.1 标题备选（1-3 条 + 《中文 · English》格式）

```markdown
**【标题备选】**

1. 《很多 · Many》
2. 《好多好多 · Many》
```

❌ 反模式（2026-07-21 sunshine 范例明确）：
- ❌ `1. 阳光 Sunshine / English: Sunshine`（带 / English 标签）
- ❌ `《Many 很多》`（中英顺序错）
- ❌ `《Sunshine!》`（没中英 ·）

✅ 修正：纯编号 + `《中文 · English》`（中英之间用 · 分隔）
（范例第 2 条《好多好多》= 铁律 4 慎用变体示例；实际输出默认只出 1 条主译，有合规变体才加）

**⚠️ 标题内容铁律（领读模式 L3 · 2026-09-18 do/I'm Back 实测补 · 闸门2 R1 修订）**

1. **标题中文 = 核心词的正译**（准确直译），默认只出 1 条：do→《做 · Do》、I'm back→《我回来了 · I'm Back》（用户定版「正译就是我回来了」）、many→《很多 · Many》、中秋节→《中秋节 · Mid-Autumn Festival》。短语/寒暄型核心词的正译本身可为多字（nice to meet you→很高兴认识你），不属扩展。
2. **禁止扩展成句子/口号**：新主语（我/我们）、能愿词（会/要）、范围词（样样都）、新对象/新场景（推门喊妈妈）一律 ❌——回译后不再是核心词本身（❌《我会做》《样样都来做》实测被否）。
3. **变体不是默认生成器**：最多 1 条；双判据（任一不过=砍）：①该说法能整句出现在真实亲子口语或儿童读物标题中；②回译测试落回核心词词义（《好多好多》回译落回 many→过；《做一做》口语虽有"我们一起做一做"用例，但回译落回"试一下"≠do→砍），出前再大声读终检。
4. **叠词叠用形态（做一做/跳呀跳/好多好多）慎用**：默认不用；仅当叠用形态比正译更贴合该词的儿童口语时才可作为变体（叠用仅可变体、禁作主标题），同一批最多 1 处，禁堆砌。
5. **历史病灶勿回退**：❌《数不清的 · Many》（回译 countless≠many，非正译）、❌《回家啦 · I'm Back》（非正译，用户 2026-09-18 判词）。
6. **回译测试**：标题中文回译英文必须落回核心词词义；落不回=砍。
7. 第三十二类「根据旁白重写标题」同守本铁律（主题词只提示变体方向，标题主体仍是正译）。
8. **适用范围：仅约束领读模式 L3 标题备选（含第三十二类重写标题）**；简介、旁白列、故事模式标题均不受限。

### 3.2 简介备选（严格 1·2·3·4 + 方向命名）

```markdown
**【简介备选】**

1. 金色的阳光洒在草地上，照着花朵，照着猫咪——sunshine 真温暖！（方向一：具象发现）
2. 阳光 Sunshine！清晨、中午、午后，到处都是 sunshine！sunshine 真明亮！（方向二：动作互文）
3. 黄色的阳光，照着草地、花儿、小狗、小朋友——sunshine 到处都是！（方向三：数宝贝）
4. 阳光照在我身上暖暖的，sunshine 真好！（方向四：情感自信）
```

❌ 反模式：
- ❌ `A = 数字视角版：一只、两只……`（用字母 A/B/C/D + 自由标签）
- ❌ `1. 翻一翻：天上多少星？海里多少鱼？数不清的——many,很多!（方向一：具象动作）`（"方向一：xxx"太长）
- ❌ `A = 改成 [推荐词 1]`（用字母 + 风险词包装选项）

✅ 修正：纯数字编号 + 1-2 行短句 + "方向X：标签" 短命名

> ⚠️ 句式提醒（2026-09-03，2026-09-23 更新）：L3 备选简介的四方向只是切入点，每条本身必须是一句话叙事（有性格主角+连接词串事件链+故事化收尾），❌ 元素列举排比（"X、Y、Z——真X！"）/ ❌ 动词任务清单，最终 40 字简介以 `picturebook-story-description` skill v3.0 为唯一权威。**每条简介备选生成前必读 story-description v3.0 全文**（2026-09-23 事故沉淀：生成会话 35 次 skill_view 零次读该权威导致挂空简介成批出稿；全库 v2.0 指针已清零，见 T9/T10）。

**⚠️ 简介备选 ⊆旁白 软闸过滤（2026-09-23 Start/Stop/Win 批事故新增）**

> **过滤范围（软闸边界，显式声明防误杀+护选择权）**：简介备选四条在**生成时即自滤**——含旁白无实拍元素（道具/角色/事件三查失败，判据=narration-quality-anchor 出稿自检表 ⊆旁白 项）的备选直接重写，**不交用户选**；过滤**仅限 ⊆旁白 客观失败**这一条硬判据，形状偏好/句式风格/方向标签差异**不过滤**（人工选择形状即终审——ending-diversity-pattern 同惯例）。三问终检（下节）继续全量跑，不在本闸替代范围。
>
> **病灶实证（2026-09-21 创作批）**：Start 1号「小兔子喊一声 Start」/Stop 1号「举着小停牌喊一声」/Win 1号「哨声+彩带」——三本书 1号备选全部挂空（旁白无实拍），且固定排在 1号位，用户选 1号 无从分辨。回归样本=testset T1-T3。

**⚠️ 四方向模板（2026-09-23 措辞修正）**：方向标签仅是切入点命名，**任何方向下的具象元素都必须取自旁白实拍，禁发明场景钩子**——原「方向一：具象发现」的「发现」易诱导发明式钩子（哨声/彩带/小停牌即此病灶），理解为「旁白实拍聚焦」：从旁白已拍画面里选最有画面感的一站做钩子，而非另编开场。

**⚠️ 简介三问终检（L3 每条备选出句前强制自答 · 2026-09-18 do 实测补 · 闸门2 三轮放行 score 8）**

三问独立拦截不同病灶类；问②为冲突时最高裁决（自然语压过一切铁律），非①③的上司：
1. **素材问**：先通读旁白再动笔——每个事实成分能在旁白里找到吗？旁白没有的人物/格言/新评价词禁入。
2. **自然语问**：整句大声读——是孩子嘴里说得出的孩子话吗？大人评价/议论腔（递进论证、夸奖论述、书面成语腔）不是孩子话。
3. **落点问**：收尾情绪禁落在旁白外新引入的人物上；可落叙事主体、核心词或主题语义。

病灶记录（勿回退）：越做越能干=递进议论腔（②拦）｜妈妈笑眯眯（若妈妈未入旁白）=旁白外人物落点（①③拦；妈妈入旁白时同形句 PASS，见 narration-review 回归集 #6 锚点）｜件件事=量词叠用（②拦）。三问=L3 现场触发器，不替代重写模式双闸门。

## L4 生图提示词（严格 plaintext 引导语 4 段 + 7 段结构）

### 4.1 引导语段（严格 4 段 plaintext）

```
plaintext

我会给你一段文字，是领读文案和对应的生图提示词，请提取出生图提示词，并生成图片；

注意：不要在图片中显示领读文案中的中文翻译，这些仅供参考；
```

## 反模式 vs 正模式（sunshine 范例对照）

| 步骤 | 反模式 | 正模式（sunshine 范例） |
|------|--------|------------------------|
| L1 | 7-8 段说明文 + 表格 + ⚠️ 段落 | 严格 7 字段代码块 |
| L2 | 表格 + 视角动线段 + 反混淆段 + 末句逻辑段 | 表格 + 箭头推进 |
| L3 标题 | `1. Many / English: Many` | `1. 《很多 · Many》` |
| L3 简介 | `A = 数字视角版：…` | `1. 中文短句——方向命名` |
| L3 旁白 | 列序 `中文 \| 英文 \|` | 列序 `英文 \| 中文 \|` |
| L4 引导语 | 3 段省略 ⚠️ | 严格 4 段 + ⚠️ 段 |
| L4 末尾 | 50+ 字符长说明 + 末页提示 + 页数说明 | 1 行精简 |
| L4 代码块外 | 加"末页提示""说明""备注" | 无任何文字 |
