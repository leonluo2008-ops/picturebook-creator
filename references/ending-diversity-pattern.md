# L3 末句备选制与轮换账本（2026-09-18 get/do/make 实测新增）

> 触发背景：用户反馈「最后一句出现了绝对的公式化，这是不可接受的」——三本末句全部长成「我X啦，target！」（我得到啦/我做成啦/我做好啦，三连击同构）。

## 一、末句备选制（主机制）

**出 L3 双语旁白时，末句（旁白表最后一行；8 行书=row 8，10 行书=row 9/10）同简介一样出 3-4 个备选：**

1. **形态互不相同**：汇总收束 / 互动CTA / 惊喜揭示 / 寻找互动 / 情感落点 / 收获致敬 / 声音互动——按本书内容取最贴合的 3-4 个，不默认套用任何一种。**可选用形态须先过铁律13（主题物型书）/铁律16路径分治（路径B 禁人称）约束过滤**，见 §三A。
2. **每个备选 = 英文 + 中文**，从本书旁白素材长出（过素材问），标注形态短名（—— XX收束）。
3. **交互协议与简介备选一致**：回复编号或原文 = 锁定，直接进 L4，不再追问。
4. **「我X啦，target！」不是默认形状**，只作为备选之一参与竞争；连续多本在账本中同形 = FAIL。

## 二、轮换账本（辅助防撞）

skill 仓 `references/ending-form-ledger.md`：每做完一本记一行（日期｜书｜末句形态｜末句）。写新本前读最后 2-3 行，新书末句形态与之不同；形态选择仍先过素材问（从本书内容长出，不为换而换）。

## 三、判定关系

- 形态选择 = L3 现场触发器（自答 + 停等用户确认，不强制 spawn 闸门2）。
- 账本比对 = 跨本防撞检查，随 skill 修复流程「先动仓再同步 ~/.hermes」维护。
- 与铁律 16 分工：铁律 16 管单本末页槽位职责（L2 时点）；本文件管 L3 末句（旁白表最后一行，页号随行数：8 行书=row 8，10 行书=row 9/10）的形态多样性与用户选择权。

## 三A、形态约束上游闸门（冲突优先级）

1. **铁律 13 优先**（主题物型绘本）：末句备选的主语必须满足「末两页主语回归主题物」——互动CTA/声音互动等含人称或无主语形态，对主题物型书不得生成（备选生成时即过滤，不交用户选）。
2. **铁律 16 路径分治优先**（无人称群体路径B）：互动CTA/情感落点等含「我/我们」人称形态不得出现在路径B书的末句备选中（路径B 硬塞人称 = FAIL）。
3. 调色盘 7 形态 = 合法形态全集；具体书可选用形态 = 全集 ∩ 铁律13/16 约束后的交集，非全部可选。

## 四、账本维护触发

- 每本 L3 定稿（用户锁定末句备选编号/原文）后，即向本仓账本追加一行；落盘随当次 skill 修复流程走仓提交+同步（无修复流时按批次收尾统一落盘+推送）。
- 账本只追加不回写旧行（历史病灶勿回退原则）。

## 五、病灶记录（勿回退）

- 三连击「我X啦」：把单本已验收答案当通用模板复制，逐本填空未问区别——根因 = 默认形状挤掉调色盘其他 6 种合法形态。
- 账本制单独使用不可行（用户判词：单本制作时无同批可比，且选择权应在用户）——账本仅作防撞辅助，主机制 = 备选制。
