# 执行者分工与委派（R14 · 2026-11-22）

> 主模型可能文笔强但工具弱（会拼错 MCP 参数、漏填委派参数、把「没写成」报成「已完成」）。
> 本文件回答一个问题：**每件事由谁执行、委派怎么派、派完怎么核对**。
> 裁定依据：R14（三类任务强制分工）、R15（台账写入走脚本一条命令）；模型坐标见 `docs/项目适配包.md` §8。

## §0 执行者与「弱工具」判定（外部静态条件，不许自评）

| 执行者 | 承担 | 判定来源 |
|---|---|---|
| **主模型** | 创作（标题/旁白/简介/L4 文案）、对话、跑本地脚本一条命令 | 会话主模型 |
| **子代理（重活槽）** | B 类：方案 / 决策分析 / 审计；**归档后的独立回读核对** | 适配包 §8 `heavy_model` |
| **子代理（轻活槽）** | C 类：L4 整本装配 + 五道门禁连跑；审计第二路 | 适配包 §8 `light_model` |
| **脚本** | 所有台账写入（归档/改写/状态/备注/释义） | `scripts/notion_archive.py` |

**按弱工具走的判定是静态的**：会话主模型 = 适配包 §8 标注「创作型/工具弱」的模型（当前 = `gemma4:31b`）→ 本会话全程按 §1 委派。**不因为「这次没出错」就升级为主模型自干**（自评判定无效——审计 B7：被判定者不能判定自己）。

## §1 三条强制分工（所有者裁定，不可条件化）

| 类 | 任务 | 执行者 | 说明 |
|---|---|---|---|
| **A** | **台账写入** | 主模型直接跑 `notion_archive.py` 一条命令 | 脚本是确定性调用，不套子代理（审计 B7：多一层 LLM 判断只会增加失败面）；**写完的独立回读核对委派给重活槽子代理**（执行者与核对者分离） |
| **B** | **方案 / 决策分析 / 审计** | 子代理（重活槽；第二路轻活槽） | 判断力密集；主模型只汇总结论 |
| **C** | **L4 整本装配 + 五道门禁连跑** | 子代理（轻活槽） | 长链路、多工具调用，弱工具主模型最容易中途错参 |

不在清单上的（日常查台账、跑门禁单条命令、写创作稿）主模型自己干。

## §2 委派任务书模板（参数逐字字面量）

```
subagent(
  description="一句话说清交付物（必填，缺了工具直接拒绝）",
  name="短横线小写名",
  provider="ollama-cloud",          # provider id，来自适配包 §8 槽位
  model="deepseek-v4.1-flash:1017", # 只写 model id，不带 provider/ 前缀
  prompt="GOAL/CONTEXT/FILES/CONSTRAINTS/VERIFY/REPORT 六要素；任务书里每个值写字面量"
)
```

- `provider` 与 `model` **分开写**，`model` 带 `provider/` 前缀会静默回退主模型（2026-10-10 实证）。
- 报告首行要求子代理写 `MODEL: <provider>/<model>`——**这只是声明，不作证据**（实测发生过「实跑 gemma4 却回报已用 deepseek」）。

## §3 委派后必做两件事（缺一不算完成）

1. **路由核对走一条命令**：
   `python tools/model_probe.py --newest 3 --expect "<provider>" "<model>"`
   它从会话档读 `agentProvider/agentModel`（真值），EXIT=0 才算路由生效；本机没有 `zstandard` 库时打印 SKIP——**SKIP ≠ 通过**，此时明示「路由未核」。
2. **产物独立读回**：文件用 read、台账用 MCP fetch 或 `--locate`、命令看退出码。子代理「成功」自述不算证据；外部副作用必须亲自复核句柄（page_id / 文件路径 / 哈希）。

路由不符（probe 命中但模型 ≠ 期望）→ 当轮登记「路由未生效」，产物仍按读回判定，不当作废。

## §4 降级纪律

没有 `subagent` 工具的宿主（云端等）→ **停下该操作并告知所有者**，不由主模型自行降级接手（审计 B3：强制委派不许被「工具不在」悄悄绕过）。

## §5 红线

- **已出图的书不得改画风 / 角色设定**——只改文字层；L4 里与画面绑定的行改完必须标「需重生成」。
- **授权由主模型向所有者要**；子代理只执行已授权动作，不得自行找所有者要授权或扩大范围。
- 台账写入只有脚本一条路（R15）；MCP 写接口留给脚本失效时人工兜底，不在常规流程使用。
