# 蜡笔手绘童趣风 领读绘本批量模式

适用范围：标单词系列 + 蜡笔手绘童趣风 + 3-6 岁目标年龄 + 单一实物/动物类目标词。

已沉淀 7 本：shrimp / fish / hairtail / foot / head / face / hair。下一本起按此模式批量复用。

---

## ⚠️ 页面数铁律（用户两次实测纠正）

> **旁白数量 = 内页数，封面另算。总图数 = 旁白数 + 1（封面）。**

实测触发：
1. 第一次给 9 句旁白 → 输出 9 张内页（少 1 认知页）→ 用户纠正"差一张认知页"
2. 第二次给 9 句旁白 → 仍然按 1 封面 + 8 内页 → 用户纠正"缺少一页认知页"

执行规则：
- 旁白表格有几行（含 P1 认知句），内页就有几张 + 1 张封面
- 认知页必须有（P1，全大写目标词），不要为了凑数删掉
- 结尾互动页必须有（P末），不要省

L2 页面结构设计阶段就要锁定：1 封面 + N 旁白内页，L3 旁白表与 L4 提示词条数必须严格对齐。

## 全局风格锚点（每本必带）

```
风格: 蜡笔手绘童趣风,色块鲜明,粗蜡笔笔触,童趣可爱
文字风格: 场景图中目标单词以正确的完整英文拼写呈现为一个整体彩色文字块，
        紧挨着英文单词正下方展示中文释义，色彩鲜明，
        文字作为大型彩色图形元素融入画面，文字即图形
```

**封面标题：仅首字母大写**（如 `Hairtail`，不是 `HAIRTAIL`）
**认知页标题：全大写**（如 `HAIRTAIL`）
**内页正文：小写**（如 `hairtail`）

⚠️ 实测纠正：第一版输出时封面用全大写 → 用户纠正"封面的标题文字应该只有首字母大写"。

---

## 文字控制铁律（每本必带）

⚠️ 文字严格控制：每张图只允许出现两个文字——英文"xxx"和中文"yyy"，紧挨配对，英文在上中文在下。绝对不允许出现任何其他英文或中文文字。

颜色约定：英文=珊瑚红粗蜡笔字体，中文=黑色粗蜡笔字体。

---

## 构图铁律

1. **孤头陷阱（head/face 实测纠正）**：只展示头部会非常诡异，必须全身/半身 + 头部清晰可见，身体自然承接
2. **动物+配饰去模板化**：每个角色服装/配饰/动作各异，不要每页"小朋友+连衣裙+叉腰"
3. **视角动态化**：封面倾斜/动态 → P1 仰视特写 → 内页轮换侧面/俯视/极近景 → 结尾全景展开
4. **场景锚点复用**：海洋系/草地系/室内系 锚点可在多本间复用，统一感强

## 句式骨架

| 序号 | 句式 | 示例（hair 为例） |
|------|------|-----------------|
| P1 认知 | [全大写目标词] | HAIR! |
| P2-P8 语境 | 这是 X 的 [身体部位/特征] | 这是黄色的头发，hair |
| P9 结尾 | 各种 X / 我认识 X | 各种各样的头发，hair |

注意：
- "这是 X 的 Y" 句式适配：face / head / hair / foot 等身体部位类目标词
- "X 长 [形容词]，[目标词]" 句式适配：实物类（hairtail 长长，shrimp 弯弯，fish 胖胖）
- 动作类目标词（wash / comb / swim）用 "动词 + 名词，目标词" 句式

## 旁白修改场景原则（用户多次实测）

### 三类修改指令
1. **"X 句换成 Y"**（指定句号）→ 只改该句，其他不动
2. **"X 句换语境"** → 整句替换（英文+中文一起换），不是只改中文翻译
3. **"模板化了换语境"** → 整本扫描连续同维度页面，重写至少 1 页打破模板

### 核心词位置规则（反复纠正）
- 中文旁白中核心词必须出现在主语/宾语自然位置
- 不要"我爱 lion"（孤立）→ "我爱小狮子，lion"
- 不要"慢慢 go"（不通顺）→ "慢慢走，go slow"

### 末尾英文绑定（v5.0.19 起新模式）
- 中文旁白末尾 = `中文 + 逗号 + 核心词 + 中文标点`
- 只绑定 1 个英文单词 = 目标词本身
- ❌ `圆圆的黄皮，a round wampee!` → ✅ `圆圆的黄皮，wampee!`

## 已踩坑清单（更新于 2026-07-12）

- ❌ 封面用全大写 → 用户纠正首字母大写
- ❌ 漏认知页 → 用户两次纠正"缺少一页认知页"
- ❌ 只展示孤零零的头部 → 用户纠正"图中只出现头部很诡异"
- ❌ 旁白 9 句但生图 9 张 → 用户纠正"图片也应该有 9 张加上封面一共是 10 张"
- ❌ 模板化连续多页"X 长得 [形容词]" → 用户多次要求"换语境"
- ❌ 中文孤立放目标词 "我爱 lion" → 用户纠正核心词位置
