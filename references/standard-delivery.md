# 项目标准交付 · Codex

## 自动触发

用户要求制作或生图且未限制交付范围时，完成成图验收后自动执行本规范，不另请用户确认。仅预览、暂停等明确指令优先。

验收包括：页数齐全，采用最新选定版本，封面布局合格，关键文字拼写正确，角色五官完整、跨页一致，背景无明显异常。质检报告作为辅助；互动页按真实设计设置多主体，避免误判。字母配色允许合理偏差，不因细微差异反复重出。

## 交付形态（2026-11-23 起：只存 Eagle，不上传 Notion）

〔裁定·2026-11-23 所有者原话：「以后我会把生成的图片放到 Eagle 素材库里，Notion 里就不需要再放素材库的图片，也不需要上传了。你只需要标注好状态就可以了」〕

1. **生成图一律存 Eagle 素材库**：按项目在 `儿童绘本/` 下建文件夹（如 `A Napkin`、`pen绘本成图`），成图按 `0`（封面）、`1`…（内页）命名放进去。
2. **Notion 只标注状态**：归档时把状态推进到 `已生图`，并在「备注」写清 Eagle 文件夹位置与页数；**不再**打包 ZIP、**不再**上传图片或交付包、**不再**写「交付文件」属性（历史已挂的保留，不删）。
3. **本地不再必须留交付包**：需要对外发送时才临时打包（口径见下），打完即可删；不把打包当成交付的前置条件。

### 需要临时打包时（按需，不默认执行）

- 从 Eagle 取成图 → 转 RGB JPEG（封面 3:4、内页按书的比例，默认 16:9）→ 每张 ≤300KB（质量从 90 递减）→ 按阅读顺序命名 `0.jpg`、`1.jpg`… → ZIP DEFLATED，文件名 `<排产号>.zip`。
- 打包后重新打开 ZIP，验证成员数量、顺序、格式与可读性。
- 打包产物只作临时件，用完即删，不进版本库。

## 状态推进与回读

- 成图在 Eagle 里确认齐全（张数 = 封面 + 内页数，尺寸比例对得上）后，把台账状态推到 `已生图`。
- 独立 GET 页面回读：状态 = `已生图`、备注含 Eagle 位置、正文骨架完好。
- 失败时保留现状并说明失败环节，不宣称已交付、不提前推进状态。

## 完成汇报

汇报：排产号、页数、Eagle 文件夹位置、Notion 页面链接、「已生图」状态。不搬运长图到聊天。
