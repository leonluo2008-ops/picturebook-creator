# 成图验收与标准交付

仅在用户要求制作成图且工具可用时生成图片。只写提示词、仅预览或暂不上传时按该范围停止。工具由宿主提供，本 skill 不依赖固定的生图仓库路径。

## 验收

按最终定稿核对封面和全部页：数量齐全、正确版本、文字拼写和词形清楚、角色外观与五官完整、背景合理、语义准确、互动答案数量对应问句、关键部分未裁切。字母装饰色允许合理偏差；提示词检查或机器报告不能替代看图。

发现问题时定位实际页与原因；全书批量提示词作为统一源，按用户授权的生成工具能力修复。未看到图片不得称验收通过。

## 打包与上传

已验收成图且任务未限制交付时，自动继续打包和回传，无需用户再说一次上传。

1. 按真实页序选最终图，联系表、参考资产和旧稿不入包。
2. 使用用户或项目确认的交付尺寸。未另定时本项目标准为封面 RGB JPEG 960×1280，内页 RGB JPEG 1920×1200，每张不超过 300×1024 字节。生成画幅与交付画幅有差异时先检查构图和裁切余量，不静默拉伸或切掉主体；无法保全关键内容就报告需修图。
3. 命名 0.jpg 为封面，后续 1.jpg 起顺序递增，ZIP 名为实际排产号。压缩后重新打开，检查页数、顺序、格式、尺寸、大小与可读性。
4. 按[台账操作](notion-ledger.md)精确定位对应行。使用可用上传工具，确认文件已上传后挂入“交付文件”；保留原有附件。同名不等于同内容，有更新用明确的新版本文件名。
5. 附件挂载成功后更新“已生图”，再独立读取附件与状态。中断先回读，只补未完成步骤，避免重复上传。

缺工具或上传失败时保留本地包，说明未完成的环节。成功报告真实图片数、本地包位置、Notion 页面链接和已核验状态。
