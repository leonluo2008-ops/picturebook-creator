# 角色与画风

用户指定角色、参考图或系列时优先沿用，不每次重选。没有指定时，按年龄、词义及所需动作提出合适方案，让用户确认。画风名称不代替可执行外观描述。

常用方向可包括清楚圆润的卡通插画、柔和有纸感的彩铅水彩、大色块拼贴。按题材推荐有区别的少量选项，不宣称任何一种画风一定保证模型画对。

使用既有资产前读取资产记录；能查看图片时直接观察毛色、五官、身形、服装和标志特征。无法看图就说明依据只有文字，不能声称已完成视觉核对。参考图与已选画风冲突且影响外观时，具体指出差异供用户决定。

动作审查随具体页面进行：角色能否握持、够到道具、站稳、张开翅膀等。儿童旁白用物种或清楚称谓；用户指定的角色身份保留在视觉设定，不擅自替换。

只有需要新建可复用角色且没有足够参考时，才提出定妆步骤。可制作一张 2×3 六视图，保持五官、服装、比例统一；已经有可用参考图则复用，不强迫再生成。六视图不是所有创作的前置条件。

更换角色或参考图时，检查受影响的动作、标题画面和提示词锚点；未变的定稿内容保留。仅凭文件名称不能证明新图符合要求。
