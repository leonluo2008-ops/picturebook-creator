# L3 旁白质感锚定（v5.6.0 · 小羊上山参照 · 2026-09-18）

> **定位**：本文件是 L3 中文旁白的**正面质感标准**——先读锚，再写句。
> 现行规则体系（vividness 8 铁律 / 各批次禁令 / 字数上限）回答的是「什么不能做」；本文件回答「好句子长什么样」。两者冲突时，以本文件四条标准 + 自然语境终检为准。
>
> **依据**：《小羊上山儿童汉语分级读物》（孙蓓主编，销量破 1 亿册）第 1 级第 1 册《小小的，大大的》全文实证调研（2026-09-18，三信源交叉，全文 86 字/15 个不同汉字经程序复算验证）。调研全档：`~/文档/picturebook-creator-调研/`。

## 启发优先原则（skill 的作用方式 · 2026-09-18 用户定版）

**skill 重要的作用是启发模型按照想法来创作，而不是一味地禁止。**

1. **好样本 > 禁令**：激发创作靠少量高质量范例点燃（本文件参照原文 + 少量过检样例），不靠穷举禁止清单。写旁白时：先读参照原文找感觉 → 自由创作 → 用规则做边界检查。禁止清单只在越界时兜底，不是创作时的思考起点。
2. **样本要少而精**：范例的作用是小样本激发，不是提供模仿库存。见到范例时吸收它的「为什么舒服」，不复制它的句子形状（见反模板化总纲）。
3. **该删的删**：过时的禁令、历史批次的否决记录、与现行标准矛盾的旧条款一律删除或归档——规则库的信噪比直接影响创作质量。

## ⚠️ 反模板化总纲（先读这段 · 2026-09-18 用户定版）

**用户原话**：「之前的规则集肯定很多都是有问题的，包括他必须使用一个转折号，后面加一句什么这种标准的模板化，非常的糟糕……我希望是用小羊上山这个系列的这种风格，而不是严格的模板化。」

1. **本文件教的是质感（怎么读起来舒服），不是形状（句子长什么样）**。四条标准全部是「朗读感受」层面的判据，**不含任何必须出现的句式器件**——没有必须的破折号、没有必须的转折句式、没有必须的叠词骨架。
2. **禁止把参照书的具体形状当模板复用**：「小小的/大大的」「不，不，不是」「X→Y 递进」是小羊上山**那一本书**的形状，从它的内容里长出来。你的书的形状必须从**你的内容**里长出来。判断模板化：把 A 书的旁白句式骨架抽出来能原样套进 B 书只换词 = 模板化，重写。
3. **每本书的句式形状应当独特**：对比参照（小小的/大大的）、问答（吗？不！）、重复递进（爬呀爬，爬呀爬）、平铺直叙后突然一转——都是合法形状，选最贴本书内容的一种，不预设。
4. **范例的示范力 > 条文**：见到的所有范例（含本文件参照原文、story-description 定稿范例）都只是「过检样本」，不是「标准答案」。多条范例形状同构时，同构是巧合不是要求（破折号连接即此类：小羊上山 8 句 0 破折号，story-description 10 条范例 10 破折号——两本好书，两种形状，都不模板）。

## 参照原文（写旁白前先朗读一遍）

> 小草小小的，大树大大的。
> 大树小小的，大山大大的。
> 大山小小的，天空大大的。
> 天空大大的，太阳小小的。
> 不，不，不是。天空小小的，太阳大大的。
> 太阳小小的，星星大大的。
> 我小小的，爸爸大大的。
> 不，不，不是。爸爸小小的，我大大的！

它用 86 个字讲完一个有起伏、有情感的完整故事——证明**舒服感不靠词藻，靠节奏、推进、转折、落点**。

## 四条质感标准（出 L3 旁白前逐条自检）

### ① 双短句节奏（句内）
- 每句中文 = **2 个短单元**，单元 3-6 字，逗号分节，念出来有节拍
- ❌「可爱的小猫咪正在草地上面慢慢地走着」（一口气念不完，无节拍）
- ✅「小猫咪走呀走，走进深深的草丛」（4+6 节拍）
- 与字数上限（≤11 字左右）叠加执行；目标词英文挂在自然中文之后，**不得破坏节拍**（❌「草地上的小草是很小的 grass」）

### ② 句间推进链（句间）
- 8-12 句是一条**递进链**，不是随机并列：近→远 / 小→大 / 物→人 / 特征→动作→情感
- **L2 页面结构设计时先定方向**，写进页面类型的脉络里（每页教学内容 = 链上的一站）
- 自检：把每句的教学内容拎出来排队，能看出「在往一个方向走」
- 现行「出场顺序逻辑」（先登场→特征→行为→互动→收束）是本条的特例，本条将其升级为「方向先行」

**每句必有推进功能，禁「介绍站/信息站」（2026-09-18 think 实测用户定版）**：8-12 句是稀缺资源，每一句都必须是推进链上的一站；只交代设定不推进的句子（人物介绍/背景说明）删除——主角设定交给画面（图文分工），旁白不承担。实测：think 首版 row2「小猫头鹰，夜里想」被用户整句砍掉后故事更顺。

**五站链参照（链的形状每书自定，禁跨书复用）**：起（核心词定调）→ 问/展（问题或对比展开，可多站）→ 蓄（重复蓄力）→ 转（顿悟/反转）→ 落（答案确认/情感/互动三选一；「互动」仅限非主题物型书——铁律13/16 在备选生成时即过滤，见 ending-diversity-pattern）。**五站是功能检查表（写完检查每句是否有功能），不是叙事必经站**：缺站合法、顺序可换、强制凑站 = 模板化。**句数不够时展开「转」与「落」**（写出顿悟的内容、答案的验证），禁止回头加介绍站注水。小羊对比链与 think 问题链形状不同，共同点是每句功能性。

### ③ 全书 1-2 处趣味转折（起伏）
- 中段（row 4-6 附近）安排一次**认知冲突**：问答反转（是吗？不是！）/ 以为是 A 其实是 B——全书最好玩、孩子会抢着念的那句
- 硬约束不变：转折句仍含目标词（过自检 #1 双语同现）；句型形态走备选制（用户选定，防新公式化）
- ⚠️ 转折是**调味料不是主菜**：一本书最多 2 处；「不，不，不是」式否定转折连用 2 册以上 = 进病灶速查

### ④ 结尾情感落点（升华）
- 最后 1-2 句从教学内容升华到**情感/关系**：比大小收在「我在爸爸眼里最大」，认动物收在「它是我的好朋友」
- 与结尾类型轮换规则兼容：选情感型收尾时，按本条校准「有没有落点」——「我爱 X！」若无落点铺垫就是空喊
- 与铁律 13（末两页主语回归主题物）叠加执行：落点挂在主题物与孩子的关系上

## 双语适配原则

**核心词外英文最小化·三许可（2026-09-18 think 实测用户定版）**：领读对象是低幼儿童，一本只消化一个核心词。非核心英文**内容词**（指认词+功能词）全书 ≤10 个；the/is/are 等语法胶水词不计入但尽量少。只许三类：①画面可指认词（moon/stars/sleeping——指着图就懂）②核心词形态变体（think/THINK/I think——教学点本身）③必要疑问/功能词（where/why/do/and/you——疑问结构是教学点）。**禁口语装饰词**：aha/know/fun 等画面指认不了、词族不沾、纯情绪填充的英文——信息量纯增（实测：aha/thinking is fun 被用户点名超载后砍）。

**问后必有真答案（2026-09-18 think 册审查补）**：问句提出的「为什么/去哪儿了」必须被后句真回答（可由画面+中文共同完成），重述现象不算答案——实测：问「星星为什么眨眼」答「星星在眨眼睛」被审查判空转，改为「星星也困了呀」才兑现因果。

**绑定形态唯一性（2026-09-18 4样本实测用户定版）**：全书中文列末尾绑定的核心词英文形态必须是**同一个常用整块**，整本书只教这一个形态——孩子跟读 8 遍同一块，才能脱口而出。禁：①拼装块（can run / want an apple 这类情态/短语拼装——孩子记不住也不常用，实测 run 册 can run 被判『根本不是常用词』）②语法变体连教（big/bigger/biggest 三级变体、每页换动词框架 pick/wash/bite the apple——实测 big/apple 册被判『变体太多难度过大』）。变体只能有一个且必须本身是常用问候/短语（如 good night）；语法变化留给高阶书目。

**中英对齐（自检补充）**：中文列与英文列语义必须对齐（主语/动作一一对应），漏译主语即错——实测：run 册『Run home, little dog!』中文漏『小狗』被判对不上。

**中文核心词同现率·盲听强化（2026-09-18 peekaboo册用户定版）**：核心词的**中文翻译**也必须全书高频同现（每句都有，或仅末句蓄力句可省）——家长朗读时中英对应同步进耳朵，盲听（不看画面）也能强化记忆；实测：peekaboo 册首版仅 2/8 句有『躲猫猫』被判『盲听无法强化记忆』。中文翻译放句首自然位置，不与『中文列末尾只绑英文』冲突。

**排产标题三备选（2026-09-18 测试批用户定版）**：排程/排产场景中每册必须给 **≥3 个标题备选**（用户唯一指定"至少要有三个标题"；此为排产场景对单书 L3 流程「主译1条+变体≤1」上限的覆盖，单书流程不变）。原因：库内是否已有同名单词标题（如 water 已做过《Water》）只有用户知道，Agent 扫库判不准——备选是用户审核排程时的选择权，不是撞名才给的补救。备选 1 = 正译主标题《X · Word》；备选 2/3 必须换结构角度（数量式《一个X》/场景式/拟声式/对话式/动作式轮换），禁同构换词；用户选定后该册标题锁定，再过 §3.1 回译+朗读终检。**每条备选都必须显示核心词**（英文词字面，忽略大小写；2026-09-19 用户审核定版：拟声式《滴答滴答 · Tick Tock》、场景式等一律不得隐去——旧「允许隐去避撞名」豁免**作废**）。避撞名的手段=换中文侧结构（拟声/场景/数量/对话轮换），不是隐去英文词；机械检查 `title_check()`（bin/narration_quality_check.py），任一备选违规=重写该条。

**批量开场句查重（2026-09-18 测试批用户定版）**：批量生产（同批 ≥5 册）时各册 row1 的**句式骨架同批内禁复用**——实测：测试批 5 册名词全部「X呀X，word!」开场被用户判「严重的模板化」。排产/批量清单的意义就是批量视角下看清单一模板（单册创作时 Agent 看不出，5/10/500 册同批一眼看穿）。执行：每册开场从开场原型库取不同型（感叹提名/场景引入/悬念提问/声音开场/对话召唤/动作进行等），批量交付前必须跨册比对 row1 骨架，同批零复用。

**结束感·落幕句（2026-09-18 run册v3用户定版）**：末句必须给故事『合上』的感觉，禁『回到进行时』——主角动作已闭环（跑回家）后，末句再回到进行时态（loves to run）会把场景拉回去，画面接不上，实测被判『缺少结束感』。落幕三型：①收束否定（No more running! 跑够啦——否定句式天然带合上感）②归位（Good night, my baby! 宝宝睡啦）③交给孩子（Do you think? 你觉得呢）。

**三许可不是删除许可（2026-09-18 二次实测用户定版）**：砍装饰词时**禁止连带丢掉核心词**——每句双语同现（自检 #1）是底线，违反即返工。实测：think 首轮修订把 row6/7 的 I think 连带砍掉，用户判词「不能粗暴丢掉，应该想办法融合」。正确融合方式：装饰词承担的语义（顿悟确认/猜测语气）改由**核心词形态变体**实现（I think = 地道推测句式），可平行 refrain 重复（两连 I think，如小羊「小小的/大大的」对比重复），既守住每句有核心词，又教了真用法。

**两列绑定范围澄清（防旧规则错杀）**：L3 表「英文」列 = 完整英文原句（含目标词，供孩子跟读——领读旁白核心原则 §旁白结构），始终是完整句；「只绑目标词、禁完整英文句」约束的是**中文列末尾**的英文挂载（如反面例：这是我的叔叔，this is my uncle）。目标词的短语形态（I think / think and think / I am back）视同目标词本身——形态变体是教学点（三许可第②类）。
小羊上山是纯中文读物；领读绘本中文旁白 =「完整自然中文 + 目标词英文」。质感四条作用于**中文部分**：
- 中文自身有节拍、有推进、有落点；目标词英文以现有锚定格式（逗号并列/句尾绑定）附加，选不破坏节拍的位置
- 中文读不顺 = 重写，与英文无关（自然语境终检同样只裁决中文）

## 写前 30 秒流程（并入 L3 开工）

1. 朗读参照原文一遍（找节拍感）
2. 定本书推进链方向（近→远？物→人？特征→情感？）
3. 标出转折句计划位置（≤2 处）与结尾落点
4. 逐句写作 → 出稿后过四条标准 + vividness 自检清单
