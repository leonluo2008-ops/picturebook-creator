## 两种模式

### 故事模式（Story Mode）
讲一个有叙事弧线的故事，适用于：故事绘本、冒险绘本、情感绘本、睡前故事。

**工作流**：需求确认 → 标题+简介 → 旁白 → 生图提示词

**路径分流**：
- 路径A（无固定角色）：需求确认 → 标题+简介 → 旁白 → 生图提示词
- 路径B（有固定角色）：需求确认 → 标题+简介 → 旁白 → 角色定型 → 定妆确认 → 生图提示词

---

### 领读模式（Phonics Mode）
教孩子认读、拼写特定单词，适用于：自然拼读绘本、单词认读、phonics、学单词。

**工作流**：L1需求确认 → L2页面结构 → L3标题+简介+双语旁白 → L4生图提示词

**逐步确认，禁止跳步**——信息齐了也必须从 L1 顺序走。

---

## 触发词

| 故事模式 | 领读模式 |
|---------|---------|
| 绘本创作、画绘本、故事绘本 | 领读绘本、单词绘本、phonics绘本 |
| 儿童绘本、picturebook | 自然拼读绘本、认字绘本 |

---

## 领读模式核心能力

1. **L1 需求确认**：目标单词、年龄、中文核心词、画面风格
2. **L2 页面结构**：6-10页教学结构（认知页→语境示范→语境强化→词族扩展→互动练习），除封面与认知页外统一用语境页，不设字母拆解
3. **L3 标题+简介+双语旁白**：简介三方向（学什么／怎么学／学完能做什么），目标词必须为绝对主角
4. **L4 生图提示词**：四字段结构（旁白:比例:页面类型:生图提示词），全局风格锚点，**主角外观只写一行、不逐页复述**

---

## 双语旁白结构（核心）

| 旁白 | 内容 |
|-----|------|
| 英文旁白 | 完整原句（含目标词），供孩子跟读 |
| 中文旁白 | 完整中文翻译句 + 目标单词并列 |

- 中文旁白格式：`[完整中文翻译] [目标词]`，例：`这是我的叔叔，uncle`
- **只绑定目标单词本身**，不绑定完整英文句
- 目标词位置以**中文自然**为准：句尾最常见（逗号分隔），句中亦可；**不得孤立成词**，也不要为凑句尾把中文掰拗口
- 中英文意思一一对应，中文不得多加英文没有的内容
- 标点严格对应：英文 `.` → 中文 `。`；`!` → `！`；`?` → `？`

## L4 角色描述的写法（本版最重要的一条）

```
✅ 正确：主角外观: 一只浅棕色的小棕熊，穿天蓝色白条纹短袖上衣、浅黄色短裤、橙红色小凉鞋
        5. 角色一致性: 统一外观描述

❌ 已废弃：每条提示词中主角外观描述必须完整重复，不能省略
          （每页复述整段五官 → 逐页漂移 + 手部结构崩坏）
```

**不要写**：虹膜渐变、上睑睫毛线、眼睛占脸比例、牙齿、腮红、肢体粗细。
**要写**：物种 + 主色 + 服装三件（上衣/下装/鞋），一行写完，只出现在【全局设计约定】。
**表情**：每页只写 2–3 个具体小动作（眉毛/嘴角/脸颊），不复述五官结构。
