## 两种模式

### 故事模式（Story Mode）
讲一个有叙事弧线的故事，适用于：故事绘本、冒险绘本、情感绘本、睡前故事。

**工作流**：需求确认 → 标题+简介 → 旁白 → 生图提示词

**路径分流**：
- 路径A（无固定角色）：需求确认 → 标题+简介 → 旁白 → 生图提示词
- 路径B（有固定角色）：需求确认 → 标题+简介 → 旁白 → 角色定型 → 定妆确认 → 生图提示词

---

### 领读模式（Phonics Mode）
教孩子认读、拼写特定单词，适用于：自然拼读绘本、单词认读、phonics、学单词。

**工作流**：L1需求确认 → L2页面结构 → L3标题+简介+双语旁白 → L4生图提示词

**逐步确认，禁止跳步**——信息齐了也必须从 L1 顺序走。

---

## 触发词

| 故事模式 | 领读模式 |
|---------|---------|
| 绘本创作、画绘本、故事绘本 | 领读绘本、单词绘本、phonics绘本 |
| 儿童绘本、picturebook | 自然拼读绘本、认字绘本 |

---

## 领读模式核心能力

1. **L1 需求确认**：目标单词、年龄、中文核心词、画面风格
2. **L2 页面结构**：6-10页教学结构（认知页→语境示范→语境强化→词族扩展→互动练习），除封面与认知页外统一用语境页，不设字母拆解
3. **L3 标题+简介+双语旁白**：简介三方向（学什么／怎么学／学完能做什么），目标词必须为绝对主角
4. **L4 生图提示词**：四字段结构（旁白:比例:页面类型:生图提示词），全局风格锚点，**主角外观只写一行、不逐页复述**

---

## 双语旁白结构（核心）

| 旁白 | 内容 |
|-----|------|
| 英文旁白 | 完整原句（含目标词），供孩子跟读 |
| 中文旁白 | 完整中文翻译句 + 目标单词并列 |

- 中文旁白格式：`[完整中文翻译] [目标词]`，例：`这是我的叔叔，uncle`
- **只绑定目标单词本身**，不绑定完整英文句
- 目标词位置以**中文自然**为准：句尾最常见（逗号分隔），句中亦可；**不得孤立成词**，也不要为凑句尾把中文掰拗口
- 中英文意思一一对应，中文不得多加英文没有的内容
- 标点严格对应：英文 `.` → 中文 `。`；`!` → `！`；`?` → `？`

## L4 角色描述的写法（本版最重要的一条）

```
✅ 正确：主角外观: 一只浅棕色的小棕熊，穿天蓝色白条纹短袖上衣、浅黄色短裤、橙红色小凉鞋
        5. 角色一致性: 统一外观描述

❌ 已废弃：每条提示词中主角外观描述必须完整重复，不能省略
          （每页复述整段五官 → 逐页漂移 + 手部结构崩坏）
```

**不要写**：虹膜渐变、上睑睫毛线、眼睛占脸比例、牙齿、腮红、肢体粗细。
**要写**：物种 + 主色 + 服装三件（上衣/下装/鞋），一行写完，只出现在【全局设计约定】。
**表情**：每页只写 2–3 个具体小动作（眉毛/嘴角/脸颊），不复述五官结构。

## L5 Notion 排产台账归档（v10.1.1 可执行化）

领读模式 L4 生图提示词确认后**自动触发**，把创作产出回填到 Notion「绘本排产中控台 → 排产台账」。

行处理规则（用户 2026-10-23 纠正）：

| 情况 | 行为 |
|---|---|
| 台账**已有**该核心词的行 | 直接复用该行，**绝不重复建行**（幂等） |
| 台账**没有**该核心词的行 | **自动建行**：排产号取全库最大 `B###` +1，词型可选，状态列留空交给排产流水线 |
| 该行正文已有「📚 创作产出」 | **默认拦截**防重复归档；确认补档（L4 重出）加 `--force` |
| 命中多行 | 停下，用 `--page-id` 指定，禁止猜 |
| 状态列 | 一律不动 |

```bash
python3 scripts/notion_archive.py --word day --locate                    # ① 只读定位行
python3 scripts/notion_archive.py --word day \                          # ② 归档正文
    --title '选定标题' --brief '选定简介' \
    --narration /tmp/narration.md --l4 /tmp/l4.md
# --dry-run 干跑 / --page-id 指定行 / --attr-title --attr-brief 属性回填（默认关闭）
# --no-create 禁止建行 / --force 允许重复追加 / --word-type 词型 / --sched-no 指定排产号
```

写入结构（脚本内置，末尾自动回读校验，缺失即 exit 1）：

| 顺序 | 块 | 内容 |
|---|---|---|
| 1 | `heading_2` | `📚 创作产出（YYYY-MM-DD 归档）` |
| 2 | `paragraph` | 选定标题 / 选定简介 |
| 3 | `heading_3` + `table` | 双语旁白（3 列，首行表头） |
| 4 | `heading_3` + `code` | L4 生图提示词全文（>1900 字按行切块） |

前置条件：`NOTION_API_KEY` 在 `~/.hermes/.env`（frontmatter 已声明为必需环境变量），台账库已 Connect 到该 integration。

> 台账定位三段式（中控台页 → child_database → `GET /v1/databases/{id}` → `data_sources[].id`）已内置于脚本并带自动重新发现；`child_database id ≠ data_source_id`，拿前者直接 query 必 404。
