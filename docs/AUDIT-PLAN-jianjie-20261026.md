## 二、根因（按传导强度排序）

1. **结构性诱因：三条落点模板**（E1）。① 的措辞就是「讲全书正在发生什么」，模型照做即得到综述；② 的措辞就是「孩子会跟着做」，模型照做即得到使用说明。**模板本身在生产废稿**，不是执行时不听话。
2. **规则自相矛盾**（E2）：落点③要求「合上书…」，作废形状禁止「合上书…」→ 模型在两种指令间随机取舍，用户反复看到同一种废稿形态。
3. **示例即污染源**（E6）：唯一示例的两条正好踩中现在的两条禁令（使用说明 + 剧透互动页），模型模仿示例的收益远高于遵守抽象禁令。
4. **逐页对账三次叠加**（E3/E4/E5）：三处「对回旁白/取自真实页」把简介转成覆盖率任务，页数压力直接变成综述压力。
5. **缺少正面可执行结构**：全篇只有一句判据藏在作废形状末尾（第 611 行「必须有一个还没发生的事」），没有「一条简介 = 一个瞬间 + 一个未知」这种可照做的句式规格；skill 自家红线也写着「靠示例引导模型，不靠禁令清单堆约束」。
