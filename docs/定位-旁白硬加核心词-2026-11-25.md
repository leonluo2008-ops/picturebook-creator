## 3. 「写信/积木倒了」是谁加的

- **B689 P1**（英文 `Ellie writes a letter.`）：写信是情节动作，与「邮局=场所」的认知无关。子代理收到「≥8 次」后为凑数，把 post office 硬加进中文列「艾力写了一封信，post office。」——**入口 = 委派任务书行 5**
- **B693 P6**（英文 `Oh! The blocks fell down.`）：积木倒塌是推进情节的趣味点，子代理为凑数在中文列贴「toy store」——**同上入口**
- **没有任何脚本或收稿环节把它们退回**：grammar_check 只查双语同现（不查合理性）；`l4_structure_check` 的「≥8 次」已降级为提示；`l4_presence_check` 按需模式只提示缺页。

## 4. 新口径（所有者本轮指令逐字）

> 每个内页都有旁白，英文核心词按当页内容和认读需要出现。双语同现只在用到目标词的页面触发。核心词出现次数和省略页数都由这本书决定。

这一口径与 `flow.md` 行 237（2026-11-23 所有者改口径「不强制每页」）**一致**——不是新规则，而是**已改口径被任务书模板的 ≥8 次覆盖了**。修复 = 把模板和 skill 中的残留恢复到 2026-11-23 口径，并新增「认读需要」判断法。
