## 合格判据（修订 SKILL.md L3 简介要求时并入）

### 差异根因：执行密度（v6 双句模板，逆向自用户改写）
1. **比喻即讲解**：比喻与学习方法严格同构（两段↔两步）；AI 比喻只是气氛装饰
2. **能力获得=具体动作**：「学会把长单词拆成两段来拼读」可执行；「见到长单词不害怕」是情绪
3. **年龄定位后置融入**：删「5-6岁拼读进阶：」标签头，句尾自然带出「轻松迈出拼读进阶的一步」
4. floor 例：场景句直陈书内真实情节（坐/滚），收尾「指着地板自信说出FLOOR」= 指+说双具体行为
