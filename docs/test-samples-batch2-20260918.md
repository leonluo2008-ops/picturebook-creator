# think 公式回归测试样本·第二批（2026-09-18 · 5 词型 × 5 链形）

> 用途：全套规则的泛化压测（第一批：run/big/apple/good night + think）。
> 本批覆盖规则：五站链（功能检查表非必经站）、禁介绍站、三许可（内容词≤10、禁装饰词）、绑定形态唯一性（同一常用整块）、中英对齐、问后必有真答案、结束感·落幕句（禁回到进行时）、形状不跨书复用。

## 样本5：jump（动作动词 · 跨主体接力链：起→展×2→问→答→蓄→落·交给孩子）

| 1 | JUMP! | 跳呀跳，JUMP! |
| 2 | The bunny can jump! | 小兔子跳，jump! |
| 3 | Jump over the log! | 跳过小木头，jump! |
| 4 | Jump into the leaves! | 跳进落叶堆，jump! |
| 5 | Who can jump? | 谁还会跳，who can jump? |
| 6 | The frog can jump! | 青蛙会跳，jump! |
| 7 | Jump, frog, jump! | 青蛙快跳，jump! |
| 8 | Can you jump? | 你也跳一个，can you jump? |

落幕型：③交给孩子（与 run 的收束否定错开）

## 样本6：moo（拟声词 · 声音问答反转链：起→问→答→蓄→错位问→反转→真答→落·收束否定）

| 1 | MOO! | 哞哞哞，MOO! |
| 2 | Who says moo? | 谁在哞哞叫，who says moo? |
| 3 | The cow says moo! | 奶牛哞哞叫，moo! |
| 4 | Moo, moo, moo! | 哞，哞，哞，moo! |
| 5 | Does the cat say moo? | 小猫也哞哞叫吗，moo? |
| 6 | No! No! No moo! | 不对不对，no moo! |
| 7 | Meow! Not moo! | 小猫喵喵叫，not moo! |
| 8 | No more moo! | 都睡觉啦，no more moo! |

反转借小羊「不，不，不是」范式；meow/cat 画面可指认；落幕型：①收束否定（声音书终于安静）

## 样本7：rain（天气名词 · 自然循环链：起→落×2→问→停→答（变彩虹）→落·告别归位）

| 1 | RAIN! | 下雨啦，RAIN! |
| 2 | The rain falls down! | 雨点落下来，rain! |
| 3 | Rain on my umbrella! | 雨打小雨伞，rain! |
| 4 | Rain on the flowers! | 花儿喝雨水，rain! |
| 5 | Where does rain go? | 雨去哪儿了，where does rain go? |
| 6 | The rain is gone! | 雨停啦，rain! |
| 7 | The rainbow was rain! | 彩虹是雨变的，rain! |
| 8 | Bye-bye, rain! | 雨点拜拜，rain! |

row7 是「雨去哪儿了」的真答案（彩虹是雨变的）；落幕型：②归位（告别）

## 样本8：peekaboo（游戏互动词 · 藏找游戏链：起→藏→找→找到×2→落·拥抱归位）

| 1 | PEEKABOO! | 躲猫猫，PEEKABOO! |
| 2 | Peekaboo, baby! | 宝宝玩躲猫猫，peekaboo! |
| 3 | Where is baby? Peekaboo! | 宝宝在哪儿，peekaboo! |
| 4 | Peekaboo! I see you! | 看到你啦，peekaboo! |
| 5 | Peekaboo, teddy! | 泰迪熊也玩，peekaboo! |
| 6 | Where is teddy? Peekaboo! | 泰迪在哪儿，peekaboo! |
| 7 | Found you! Peekaboo! | 找到你啦，peekaboo! |
| 8 | Peekaboo! I love you! | 最爱你呀，peekaboo! |

落幕型：②归位（游戏收在拥抱）

## 样本9：mummy（人称名词 · 空间寻找链：起→问→找✗→找→线索→找到→落·拥抱归位）

| 1 | MUMMY! MUMMY! | 妈妈，MUMMY! |
| 2 | Where is mummy? | 妈妈在哪儿，where is mummy? |
| 3 | Is mummy in the garden? | 妈妈在花园吗，is mummy? |
| 4 | Mummy is not there! | 不在花园呀，mummy! |
| 5 | Is mummy in the kitchen? | 妈妈在厨房吗，is mummy? |
| 6 | Mummy! I smell cake! | 闻到蛋糕香，mummy! |
| 7 | There is mummy! | 找到妈妈啦，mummy! |
| 8 | Mummy hugs me! | 妈妈抱抱，mummy! |

row6 香味线索让「找」有推进（不是原地重复问）；落幕型：②归位（拥抱）
