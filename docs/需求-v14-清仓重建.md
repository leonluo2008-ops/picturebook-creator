### R13 标题＝教学定义，取消 3 备选（2026-11-22 补裁）

- **用户原话（口述）**：「标题要围绕核心词来写，你这个把中文释义都丢掉了」「我们这个标题，包括我们所有绘本最底层的核心，是不能教错误的东西」「标题直接有力」。
- **用户原话（选项回复）**：「A 极简定义式，取消 3 备选（推荐）」；义项来源选「A 台账加「中文释义」字段 + L1 写标准义项 + 机检（推荐）」；标题形态选 **「B 释义逐字 + 量词/口语虚词白名单（推荐）」**（2026-11-22 第二轮，双路审计后）。
- **裁定**：
  1. 标题的唯一形态 = 中文 `[量词或口语虚词]<台账中文释义>[口语虚词]，<核心词>` + 英文沿用现行规则（简短口语、含核心词、Title Case 封面）；白名单只放量词与口语虚词（实现见 `tools/title_intro_check.py` 的 `CN_WHITELIST`）；
  2. **不再出 3 备选**：义项由 L1 锁死、释义写进台账后，标题没有合规变体可言；所有者的确认对象变成「这个义项对不对」；
  3. 判据七条（含 **G1 释义逐字在场 / G2 去掉释义与核心词后只许留白名单 / P1 词型非动作类时禁动词屈折与祈使尾**）；但**判据只证明「标题与锁定字段一致」，不证明义项正确**——释义与词型—释义—画面三者一致由 L1 逐字确认 + 审计复核；
  4. 台账新增 `中文释义` 字段（写入走 `notion_archive.py --gloss`）；`词型` 或 `中文释义` 缺一，该书不得进 L3。
- **术语**：**小字病** = 标题/物件名里滥用「小X」修饰（小锅、小硬币…），所有者长期在防；白名单因此**不含任何形容词性修饰**。角色指代（「小猫」「小女孩」）不属小字病（`SOUL.md:24` 允许）。
- **代价（所有者拍板时已知）**：台账 13 条历史标题按新判据红 11 / 绿 2；但历史标题**不是基准**（其中「一枚小硬币」本身含小字病），该表只作「哪些书要改」的清单，不规定改成什么。明细见 `docs/证据-标题判据校准-2026-11-22.md`。
- **依据**：2026-11-22 实测 3 条备选三选三错（`Cool Down, fan` 语义扩充 / `Fan it!` 名词被教成动词 / `Cool Fan` 语义扩充）；新判据对 5 条错例 5/5 命中。
