## 2. 冲突点

1. **视角数**：六视图（S1）vs 三视图（S2）vs 单张全身像（S3）。三者互不兼容——用户按哪个去即梦生成，出来的定妆图完全不同。
2. **背景**：六视图未规定；三视图规定纯白背景；S3 规定「干净的纯色背景」。
3. **画风锚点**：S2 未要求追加风格串；S3 要求每次必须追加「全局风格描述」。
4. **使用定位取值**：`SKILL.md:231` 写 `灵感参考 / 定稿参考`，而资产库实际 select 选项是 `灵感参考 / **制作基准**`——规则与库 schema 不一致。
5. **L4 的引用锚点**：SKILL.md 用「图像1 / 图像2」，S3 用「[角色核心定义字符串]」+ 全局风格描述串——两套引用机制。

## 3. 待所有者裁定

1. **定妆图规格以哪一份为准？**（六视图 / 三视图 / 单张全身像 / 以资产库实际在用图为准）
2. **「使用定位」词表**：是改规则跟库（`制作基准`），还是改库跟规则（`定稿参考`）？
3. **L4 的引用机制**：用「图像1 为准」（视觉引用），还是「角色核心定义字符串 + 全局风格描述」（文字串引用）？或两者并置（引用 + 关键特征串）？
4. 资产库是否需要补「定妆图规格」字段（记录该资产是三视图还是单张），让 agent 取图前就知道规格？

## 4. 目视核对结果（2026-11-21，已下载 7 张资产图逐张看）

| 资产（使用定位） | 实际形态 | 与「三视图」规则的关系 |
|---|---|---|
| 3D皮克斯小女孩（制作基准） | 三视图：正面 / 四分之三侧 / 背面；站姿统一、脚底对齐、浅暖白底 | 完全符合 |
| 卡通松鼠-01（制作基准） | 三视图；坐姿、抱橡果；纯白底 | 部分（姿态/道具不符） |
| 卡通小熊-01（制作基准） | 三视图；正面坐姿 + 抱松果 + 围巾；复用说明已登记「坐姿正面/站姿侧背，L4 补齐」 | 部分 |
| 斑点猫（制作基准） | 8 姿态表（正/背/左/右/坐/俯视…），浅灰底、无文字 | 超出三视图，信息更全 |
| 蜜桃猫-二创（制作基准） | 3×3 变体角色表 + 中文标注文字 + 细节图 | **不符**（带文字、设定表而非参考图） |
| 金枪鱼 / 橙纹小老虎（灵感参考） | 非定妆规格，不计入 | — |

**结论（5/5 制作基准样本）**：实际在用图不是统一规格，共同点只有四条——
同一角色同一画风 / 纯浅色背景无场景 / 无文字（蜜桃猫例外）/ **多视角而非单角度**。
因此规格应写成「**多视角参考图**（至少 正面·四分之三侧·背面，允许扩成姿态表）」，而不是死写三视图或六视图。

**已据此改写 SKILL.md（模块 A，10 处）**：六视图→多视图（4 处，读回残留 0）；使用定位「定稿参考」→「制作基准」（对齐库 schema，残留 0）；领读模式补【参考图约定】模板；L4 一致性改为「图像引用 + 2–4 关键特征串」。
