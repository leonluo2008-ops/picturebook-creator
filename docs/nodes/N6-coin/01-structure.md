# B620 · coin /kɔɪn/ · 领读模式 L2 页面结构表

## L1 锁定项（本表与 L3/L4 全程照此执行）

| 项 | 值 |
|---|---|
| 核心词 | coin（**名词**，义项：硬币 —— 与台账「词型」一致，只教这一个义项） |
| 目标年龄 | 4–5 岁 |
| 领读方式 | 整词跟读（不做拆音、不做词内停顿） |
| 第一感觉 | 硬硬的小圆片捏在手心，丢进存钱罐会「叮当」响一声，孩子想再丢一次 |
| 画风 | **严格跟随参考图**：3D 皮克斯动画电影级渲染（不用 S16 水彩、不沿用系列既有水彩锚点） |
| 主角 | 资产库「3D皮克斯小女孩」（使用定位＝制作基准＝严格按图） |
| 内页结构 | 8 页 ＝ P1–P7 语境页 + P8 互动练习页 |
| 目标词复现 | 全书 9/9 页出现完整目标词 coin（封面为书名形态 Coin） |

**为什么没有词族拓展页**：coin 的可拓展词族只有 -oin 一组（coin / join / loin），join 是动词、loin 是肉类部位名，对 4–5 岁都不适龄，按规则「无合适拓展时换语境页」，故 8 个内页 = P1–P7 语境页 + P8 互动练习页。

**动作链（先定动作链再分页）**：硬币滚到脚边 → 蹲下捡起来 → 捏在手心感到硬和凉 → 拿着走到矮桌前 → 踮脚对准罐口 → 撒手投进去「叮当」 → 抱起罐子摇一摇，硬币在里头响 → 互动页：桌上四样圆东西里找出哪一个是硬币。
