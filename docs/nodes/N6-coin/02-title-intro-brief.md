## 二、简介备选（v2：三条都落在「硬币是钱」这个核心上）

**A（功能起 · 存钱 · 买）**
> 把一枚硬硬的硬币塞进小猪罐，它就住进去了。攒够了能买什么呢？coin！

> 这枚圆圆的小硬币是钱，能换东西，也能存起来。你想把它存进罐子吗？coin！

**C（数量起 · 数钱）**

## 三、与旁白的衔接（检查结论）

现有旁白链「滚过来 → 捡起 → 捏一捏 → 拿到桌前 → 对准 → 投进 → 摇一摇 → 指一指」本身就是**存硬币**的动作链，与 v2 简介的「存进小猪罐」一致，**旁白与 L4 无需改动**。
唯一改动是把 P3「硬币硬硬的，还有点凉」这页的中文从「触感」偏转一下——但触感在这里是**孩子确认「这是硬币」的实感**，且它是钱、拿在手里才有实体感，保留；若所有者要求更贴钱义，可改为「硬币是钱，能存起来，coin。」
