## 三、替换性检验与逐条验收

**判据（形容词版，先写清口径再逐条判）**：v13 的替换性检验原式是"把目标词换成同类的另一个词，这句话还成立吗"。形容词本落成可操作的一步——

把句尾的 `long` **原地**换成 `tall`（高）或 `heavy`（重），**其余文字一字不动**，读整句，再问两个问题：

1. 改写后的搭配在汉语里通不通？
2. 这一句的骨架（"一头到那头 / 拉了老半天 / 走了好多步"）讲的到底是长度，还是高度、重量？

- 通顺 **且** 骨架不跟画面冲突 ⇒ **仍成立 ⇒ 不合格**（说明义项没锁死）。
- 搭配不通、或骨架与画面（横铺在地板上的那条围巾）冲突 ⇒ **不成立 ⇒ 通过**。

### 逐条验收

| 判据 | A（采用） | B | C |
|---|---|---|---|
| 目标词出现次数（应恰好 1 次，且在句尾） | 1 ✅ | 1 ✅ | 1 ✅ |
| 首句是否写场景布置（桌上/碗里/手里/地上…） | 否（"短的那条"是对照，不是布置）✅ | 否（"拉呀拉"是动作）✅ | 否（"一步、两步、三步"是数数）✅ |
| 地基是否落在「长度」这一个维度 | 是（拉完 / 没到头＝两个端点的距离）✅ | 是（拉不到头＝端点还没到）✅ | 是（步数＝沿着长度走出来的量）✅ |
| 是否拿具体物件反推定义（长颈鹿/大象鼻/火车） | 否 ✅ | 否 ✅ | 否 ✅ |
| 替换性检验①（→ **tall / 高**） | "还没**到顶**"搭配不成立（拉的是手里的布，不是往高处拉）；画面是横铺在地上的围巾 ⇒ **不成立 ✅（强判据）** | "拉不到**顶**"同样不成立 ⇒ **不成立 ✅（强判据）** | "还没走**到顶**"勉强可通，但"一步、两步、三步"数的是横着走的步数，往高处走才到顶 ⇒ 与画面冲突 ⇒ **不成立 ✅（中判据，如实登记）** |
| 替换性检验②（→ **heavy / 重**） | 全句没有任何"压/沉/拿不动"的落点，换成 heavy 后句子失去所指 ⇒ **不成立 ✅（强判据）** | 同上 ⇒ **不成立 ✅（强判据）** | 步数与重量无关 ⇒ **不成立 ✅（强判据）** |
| 首句能否指到某一页 / 某一画面 | P1–P3（短的那条在柜面上、长的这条越拉越长） | P2（拉呀拉、拉不到头） | P5（沿着围巾走好多步） |
| 单句 ≤30 字（最长句） | 12 字 ✅ | 17 字 ✅ | 22 字 ✅ |
| 叠词 ≤1 个 | 0 个 ✅ | 0 个（"拉呀拉"是重复不是叠词）✅ | 0 个 ✅ |
| 问句答案是否扣住义项 | 有："想不想也拉一拉"——拉的动作直接对回长度 ✅ | 有："再拉一段"——"一段"就是长度单位 ✅ | 有："数数"——步数就是长度的度量 ✅ |
| 家长汇报口吻 / 方法论 / 效果承诺 | 无 ✅ | 无 ✅ | 无 ✅ |

**关于 C 对 tall 判据强度的如实登记**：C 的失败靠的是"数步数是横着走、到顶要往上走"这一层冲突，属于**中判据**，不像 A/B 那样靠搭配直接不通。这是形容词在替换性检验上的固有弱点：**tall 与 long 共享"一个维度上的延伸"这个骨架**，区别只在轴的朝向（竖 vs 横），所以单靠句式很难把两者彻底分开，必须靠画面上的轴（本书的围巾全程横铺在地板上）来兜底。本轮按上面的口径判为**通过**；这也是本书封面与全部内页都把围巾压在地板平面上的原因（见 `06-adj-path.md` §五）。

**推荐顺序：A → B → C**
- A 最短、起句就把"长 / 短"两条并排摆出来，4–5 岁孩子一听就知道在比什么；句尾"想不想也拉一拉"是可照着做的邀请。
- B 节奏最好念（两个"拉呀拉"），但只有一条线，短参照要等到内页才出现。
- C 的"数步数"是最能落地的度量方式，但 22 字偏长，且对 tall 的判据只是中判据。
- **本轮采用：A**（简介不进 L4、不上封面；若改选只改归档正文，无需重跑机审）。

## 四、与旁白的衔接（检查结论）

定稿旁白（`03-narration.md`）的动作链是「抽屉里拉出来 → 一直拉 → 铺平在地上 → 绕过沙发 → 沿着它走 → 围上脖子还剩一截 → 词族页 → 互动页认出哪条是长的」，三条简介的落点全部对得上：

| 简介 | 对得上的旁白页 |
|---|---|
| A | P1 `A long scarf comes out.` / P2 `I pull and pull. It is so long.` / P3 铺平（短的那条＝锚点5 的短围巾） |
| B | P2 `I pull and pull. It is so long.` / P3–P4 |
| C | P5 `I walk and walk along the long scarf.` |

三条简介都**不提**具体长物件（长颈鹿、大象鼻、火车）、也**不提**"高 / 重 / 很久"——"地基只落在长度"这一条在旁白链里同样成立：全书九页没有一个画面以高度或重量为教学落点，围巾始终横铺在地板平面上。
