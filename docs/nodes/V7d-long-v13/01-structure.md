## 二、两条形容词本特有的结构决定（先说清，后面才好读）

### 1. 为什么这一本**设**词族拓展页（与 whisper 相反）

- v13 的词族入选是**双条件**：共同词尾**拼写一致** + **发音同韵**，再叠加**适龄**、**可画**（SKILL:363、:1789）。
- long 的词尾是 `-ong`，候选 `song / gong / strong` 三条全部满足拼写一致（`-ong`）与同韵（/ɒŋ/）；再逐条过适龄与可画，**四条全部通过**（逐条判据与反例见 `06-adj-path.md` 第四节）。
- 反过来：`whisper` 的词尾 `-isper` 在儿童适龄词汇里没有任何成员（双条件第一条就断）；`coin` 的 `-oin` 只有 `join` / `loin`，对 4–5 岁不适龄（见 `V7-coin-v13` 01 文件）——这两本都因此不设词族页。**所以词族页设不设，由「词尾候选能不能同时过拼写、同韵、适龄、可画」决定，与词性无关**：名词本 pot 有、名词本 coin 没有、动词本 whisper 没有、形容词本 long 有。四个样本正好把这个结论钉住——不是「名词必有词族页」，也不是「形容词不该有」。
- 设了词族页后，8 个内页＝P1–P6 语境页 ＋ P7 词族拓展页 ＋ P8 互动练习页，语境页仍占 6 页，够走完「拉出来 → 拉 → 铺开 → 绕过沙发 → 沿着走 → 围上脖」这条动作链。

### 2. 为什么每一页都必须有一个「短的同类/尺度物」同框

| 理由 | 说明 |
|---|---|
| **义项纯度（最重要）** | 名词只要有那件东西在画面里就成立（coin 只要那枚硬币）；动词只要有那个身体关系就成立（whisper 只要嘴凑近耳朵）。**形容词没有这个便宜**：一条带子单独出现，孩子只会读成「围巾」，读不出「长」。「长」是**比出来的**——必须同时在场一个明显更短的东西，长短差才构成义项。 |
| **反义词不上画面文字** | 短的那一条**不写任何字**、不给英文词形、旁白也不提它的名字。「short」这个英文词全书一次都不出现——本书只教 long 一个词（一页一概念），短只作为**画面的对照**存在。 |
| **和互动页打通** | P8 的干扰物就是三条短围巾；如果前六页没有反复建立「短的一截在旁边」这个视觉习惯，P8 的题目会变成突如其来的考较。 |
| **出图可控** | 参照物都写成具体可数的东西（一小截同款短围巾 / 沙发扶手 / 矮柜宽度 / 她张开的双臂），不写「旁边有个更短的东西」这种让模型自己猜的句子。 |

**代价（如实登记）**：每页都带一件对照物，画面元素比名词本多一件；P7 词族页与 P8 互动页不需要这个对照（P7 是四张卡片、P8 本身就是三条短围巾），已在结构表里写明。

## 三、动作链（先定动作链，再分页面）

```
抽屉里拉出一头 → 一直拉、越拉越长 → 在地板上抖开铺平 → 绕过沙发扶手 →
沿着它走、走好多步还没到头 → 围上脖子绕一圈还剩一大截 → 词族页 → 互动页：认出哪一条是长的
```

> 起点是「抽屉里那条东西是什么」，收尾是「围上脖子还剩一截」——同一件事（把一条长围巾从抽屉里拉到身上）从头做到尾，没有掉落、寻找、重来这类岔路。全书没有一页把「高」「重」「久」当教学落点。

## 八、本书自定口径（登记为待裁定假设，不改任何规则）

> 这两条是「形容词」这一类书需要的写法，v13 正文没有明写；本轮按 SKILL 的「先证后写」纪律只登记为**假设**，不据此改 SKILL.md。

- **H-Adj-1 短参照同框**：形容词的每一页，画面必须同时出现「被指称的那一个」与「一个明显更短的同类或尺度物」，否则静态画面里 long 读不出来（只读成那个物件的名字）。名词本没有这条压力（coin 只要那枚硬币在画面里），动词本也没有（whisper 只要有嘴与耳朵的关系）。
- **H-Adj-2 形容词的词形载体**：目标词的图形化由**「词沿它所指的那个维度铺开」**承担——词的走向 = 长度轴的走向，词铺在长围巾被拉直的那一段布面上，随布面弯而弯。它既不是贴在某件东西正面的标签/木牌/纸牌（名词本），也不是从人身上飘出的痕迹（动词本）。
- **H-Adj-3 反义词不上文字**：形容词本的对照物（short）只作为**画面元素**存在，不给英文词形、不进旁白——两个形容词同时上文字会抢走唯一教学轴。互动页的干扰项因此也只能是「同样没有字的短围巾」，答案由长短差判定，不由字判定。
