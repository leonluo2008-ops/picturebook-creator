# B110 · long · 与 coin / pot / whisper 三本的对比

> 对比对象：`V7-coin-v13`（coin，名词，8 内页＝P1–P7 语境页 + P8 互动页，**无词族页**）、`V7b-pot-v13`（pot，名词，8 内页＝P1–P6 语境页 + P7 词族页 + P8 互动页）、`V7c-whisper-v13`（whisper，动作动词，8 内页＝P1–P7 语境页 + P8 互动页，**无词族页**）、本本 `V7d-long-v13`（long，形容词，8 内页＝P1–P6 语境页 + P7 词族页 + P8 互动页）。
> 四本共用：同一主角（资产库「3D皮克斯小女孩」，图像1 锚定）、同一画风（3D 皮克斯电影级渲染）、同一页数口径（封面 3:4 / 内页 16:9 / 封面+8 内页）、同一五道门禁。
> 下面 6 条是**形容词本独有**的差异，每条都给本书的实证。

## 一、词形载体：三类词写在三个完全不同的地方

| 词型 | 载体 | 书的实证 | 方向承担语义吗 |
|---|---|---|---|
| 名词 | **被指物件的表面**（标签 / 木牌 / 卡片 / 锅身） | pot：小锅锅身正中一块橙色小标签写 `pot`；台面立奶油白小木牌 | **不承担**——物件在哪，词在哪 |
| 动作动词 | **动作的产物或轨迹**（气流字云） | whisper：从她嘴边升起、朝熊耳去的一小团暖白气流，云里是整词 | **承担**——气流方向 = 「说给谁听」 |
| **形容词** | **它所指的那个维度的轴**（长围巾被拉直的那一段布面） | long：`long` 写在布面上，字的基线顺着围巾长轴；围巾弯，字跟着弯 | **承担**——走向 = 长度轴走向，这是形容词唯一能自证的一维 |

> 一句话：名词的词长在**东西上**，动词的词长在**痕迹里**，形容词的词长在**维度上**。

## 二、义项靠什么「读」出来：形容词必须多一件东西

| 词型 | 静态画面里读出词义，最少需要什么 | 本书处理 |
|---|---|---|
| 名词 | **那件东西在场**（pot 只要那只锅在画面里） | 单件道具，一页一物 |
| 动作动词 | **一对身体关系**（嘴凑到耳朵、手拢在嘴边） | 布熊当听者，嘴/耳/手每页可见 |
| **形容词** | **两个可比的东西**（长的那条 + 明显更短的一条/尺度物） | **每页强制同框一件短参照**：同款短围巾（约她一手长、不写字）/ 沙发扶手 / 矮柜宽度 / 她的双臂 |

- 这是本轮最实的发现：名词本的画面元素**可以少到一件**，形容词本**不能**——只有一条长带子，画面读成"围巾"，读不出"长"。差异已登记为 `01-structure.md` §八 `H-Adj-1`。
- 代价也如实登记：形容词本每页比名词本多一件对照物；P7（四张词族牌）与 P8（四条围巾本身就是长短对照）例外。

## 三、简介地基：三种写法，替换性检验的强度也不同

| 本 | 地基类型 | 地基句 | 替换性检验的对象 | 判据强度 |
|---|---|---|---|---|
| coin | 功能 / 社会型 | 它是钱：存进小猪罐、一枚一枚攒起来、攒够了能买东西（`V7-coin-v13` 02 文件的地基行） | → button / bead | **强**（"能不能买东西"是事实判断） |
| whisper | 动作结果型 | 把声音收到最小、凑到耳朵边，只有那一个人听见 | → shout / sing | 对 shout **强**、对 sing **中** |
| **long** | **维度型（本轮自定，SKILL 三档里没有这一档）** | 短的那条一下就拉完了，这条拉了老半天还没到头 | → tall / heavy | 对 heavy **强**、对 tall **中** |

- **形容词的固有弱点**：`tall` 与 `long` 共享"一个维度上的延伸"这个骨架，区别只在轴的朝向。光靠句子判不死，必须把**横向动作词**（拉 / 铺 / 走 / 绕）写进句子、并让**画面上的轴**永远横着（本书围巾全程铺在地板上，没有一页立起来）。→ 与 whisper 本"把『话/说』写进句子才能判死 sing"是同一类补救。
- SKILL 的「第一感觉」表只有感官型 / 动作型 / 功能社会型三档，**没有形容词档**（缺口登记为 `G-Adj-1`，未改规则）。

## 四、词族页：四本四种结果，正好证明它跟词性无关

| 本 | 核心词 | 词尾 | 候选能否过「拼写 + 同韵 + 适龄 + 可画」 | 设词族页？ |
|---|---|---|---|---|
| V7-coin | coin | `-oin` | join（动词）/ loin（部位名）→ 不适龄、不可画 | **否** |
| V7b-pot | pot | `-ot` | hot / dot / cot 全过 | **是（P7，4 词）** |
| V7c-whisper | whisper | `-isper` | 儿童适龄词汇无成员 | **否** |
| **V7d-long** | **long** | **`-ong`** | song / gong / strong 全过（六道闸，见 `06-adj-path.md` §五） | **是（P7，4 词）** |

- 若按"名词有词族页、动词没有"的直觉推，coin 会推错（它是名词却没有）；若按"形容词不该有"的直觉推，long 会推错。**词族页由词尾候选决定**，不由词性决定。
- 落地差异：设了词族页的这两本，机审要加 `--page-words "7=…"` 与 `--family-words …`；不设的两本用 `--word` 逐页即可。

## 五、互动页：干扰物的性质与问法，三类三种

| 本 | 干扰物是什么 | 问题 | 答案靠什么判定 |
|---|---|---|---|
| pot | **同类的别的物件**（锅铲 / 隔热手套 / 鸡蛋） | 找一找，哪一个是 pot | 物件**身份** |
| whisper | **相邻 / 对立的动作**（喊 / 唱 / 隔远说） | 哪一张在 whisper | 身体**关系** |
| **long** | **同类的不同长度**（同款围巾三条短、一条长） | 找一找，哪一条是 long | **长短差**（且字被挪到中立立牌上，不能靠字的位置泄题） |

- 形容词本**不能**问"哪一条更长"：比较题要两两比、透视图里常说不清；"三短一长"是**辨认题**，唯一答案不依赖比较技巧（SKILL:364）。
- 反义词 `short` 全程**不给词形**（不写、不贴、不进旁白）——只当画面里的短参照。名词本的互动页没有反义词概念，动词本没有，这条是形容词本独有的。

## 六、句法与机器盲区

| 本 | 典型句式（各页起法） | 最容易被机器放过、却最伤教学的一句 | 机审表现 |
|---|---|---|---|
| pot | 存在 / 领属：`This is my little pot.` / `I pour water into the pot.` | 把词贴在错误物件上（如贴在锅铲上） | **全绿**——`l4_presence_check` 只查字在不在 |
| whisper | 主 + 动作：`I lean in close and whisper.` | `I whisper quietly.`（副词说明代替动作） | **全绿**——副词不是任何门禁的断言对象 |
| **long** | 定语 / 系表 + 可见的量：`A long scarf comes out.` / `It goes past the sofa, still long.` / `it is still long` | **`This is long.`（定义句）**、以及**缺短参照** | **全绿**——定义句、短参照都不在任何断言范围内 |

- 三本的盲区形状不同，但共同点一样：**门禁只校字，不校义**。三本书各有一句"能过机器、不能过孩子"的话，只能靠人读。
- 形容词本的盲区最多（定义句 + 短参照 + 载体走向），因为它没有"东西"和"动作"替文字兜底。
