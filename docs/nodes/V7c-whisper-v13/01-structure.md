## 二、两条动作动词本特有的结构决定（先说清，后面才好读）

### 1. 为什么没有词族拓展页

- v13 的词族入选是**双条件**：共同词尾**拼写一致** + **发音同韵**，再叠加适龄、可画（SKILL:363、:1789）。
- whisper 的词尾是 `-isper`，儿童适龄词汇里**没有任何成员**；`wh-` 是**词首字母组合**，不是共同词尾，不构成词族；`whisper / whispers / whispering` 是同一个词的**屈折形态**，不是词族（词族要的是「同尾不同词」）。
- 按 SKILL「找不到合适候选时，以额外语境页补足」，8 个内页＝P1–P7 语境页 ＋ P8 互动练习页。
- **动词的结构性差异（本轮实测结论，供 07 对比）**：名词的词族来自「同尾名词」（pot/hot/dot/cot），动词的可拓展词族天然稀缺——`-ed/-ing/-s` 都是屈折不是词族，言说类动词更难凑出同尾家族。**动作动词本应默认为「无词族页」**，硬凑就是拿屈折形式冒充词族。

### 2. 为什么听者是一只布偶熊，而不是人、也不是小动物

| 理由 | 说明 |
|---|---|
| **义项纯度（最重要）** | 只要有第二个**活物**在场，「小声」就会被读成「怕吵醒它 / 不想打扰它」，义项立刻从「小声说话」滑向 v13 明令禁止的**「怕吵到人」这类环境或情绪替代**。布熊是玩具，不存在「打不打扰」，画面只能靠**贴近耳朵 + 说话**本身来解释小声。 |
| **参考图合规** | 【参考图约定】里只有图像1（小女孩）。加一个活物配角，就得给它第二套外观锚点；无参考图的角色按 SKILL 要**每页抄全套外观**，每页多一个漂移入口。布熊按【主要场景锚点】当**道具**写一次，全书同一只、同一大小。 |
| **可画性** | 熊耳朵是清楚的圆形听觉器官、耳朵上的绒毛可以被一小口气吹歪——「声音钻进耳朵」这个结果有可见落点，比「对着人说话」更容易和「喊」区分开。 |
| **互动落点** | 布熊可以坐在对面、被举起来、被抱住，能撑起 8 页的连续动作而不引入第二个角色的戏份。 |

**代价（如实登记）**：布熊不会真的「听见」，P6「它听见啦」是孩子的过家家逻辑。4–5 岁读者对此毫无障碍，但如果所有者要求「结果必须是可验证的物理反应」，这一页要改成「熊耳朵的绒毛被一小口气吹动」。

## 三、动作链（先定动作链，再分页面）

```
把布熊扶坐好面对自己 → 凑近（鼻尖快碰到熊耳朵）→ 小手拢在嘴边 →
把声音收到最小（一小口气）→ 话贴着耳廓钻进去 → 它听见了（举起来看、笑）→
再说一句、抱紧它 → 互动页：四张画里认出哪一张是在 whisper
```

> 起点是「布熊坐好，我要跟你说」，收尾是「说完这一句，把你抱紧」——同一件事（一次完整的悄悄话）从头做到尾，没有掉落、寻找、重来这类岔路。全书没有一页把「安静 / 神秘 / 怕吵醒谁」当教学落点。

## 八、本书自定口径（登记为待裁定假设，不改任何规则）

> 这两条是「动作动词」这一类书需要的写法，v13 正文没有明写；本轮按 SKILL 的「先证后写」纪律只登记为**假设**，不据此改 SKILL.md。

- **H-Verb-1 动作可见性**：动作动词的每一页，画面必须看得见「嘴 / 耳 / 手」中的至少一处身体关系，否则 whisper 在静态画面里与 stand / look / say 无从分辨。名词本没有这条压力（coin 只要那枚硬币在画面里）。
- **H-Verb-2 动词的词形载体**：目标词的图形化由**动作留下的痕迹**承担（从嘴边升起/飘出的气流、字云），不贴在物件表面（标签、木牌、纸牌——那是名词本的画法）。载体形状随当页动作变（拢手时从掌边挤出、贴耳时压成细长一缕、说完时散成两团），字形始终是同一套整词。
