# B624 · whisper · 动作动词在 v13 里怎么落地（实测报告）

> 本轮目的：补测 v13.0.0 尚未被验证的**维度——动作动词**。前两本 `V7-coin-v13`（coin）与 `V7b-pot-v13`（pot）都是名词。
> **结论先给**：动作动词能完整走通 L1→L4，**五道门禁首轮全绿、0 返工**；但有 **5 处「名词本不需要、动词本必须自己做」的落地差异**，其中 2 处（图形化载体、简介地基的写法）v13 正文没有明写，只能靠写稿人现场定口径——本轮已按「先证后写」纪律把它们登记为假设（`01-structure.md` §八、本文 §八），**不据此改 SKILL.md**。

## 二、① 动词的「目标词图形化」怎么画

### 名词本的做法（已有两本实测）

载体 = **被指物件的表面**：coin 写在木牌 / 小卡片 / 罐身标签上；pot 写在锅身标签 / 台面木牌上。词的位置、方向都不承担语义——硬币在哪，词就在那件东西的表面上。

### 动词本的困难

动作**没有表面**。硬把词贴到物件上会立刻产生错误语义：

- 贴在小熊耳朵上 → 读者读到的是「耳朵」这个词，不是「悄悄说」；
- 贴在矮柜 / 地毯上 → 变成一件无主物上的标签，与当页动作失去关系；
- 按名词本封面惯例「飘在头顶的大字」→ 画面拿到字，却丢掉了「说给谁听」这个方向语义。

### 本轮采用的写法：载体 = **动作留下的痕迹**

whisper 的词形画成**从她嘴边出来、朝布熊耳朵去的一小团暖白气流**；气流本身就是字云，云里是完整的一个词 `whisper`。四条落地细则（都写进了 `04-L4.txt` 的【目标词图形化约定(动词专用写法)】）：

| 细则 | 写法 | 为什么 |
|---|---|---|
| **载体形状随动作阶段变** | 拢手时从掌边挤出 → 凑近时压成细长一缕 → 贴耳时弯成一条弧 → 说完后散成两小团 | 动作在推进，痕迹也跟着变；8 页不会变成同一张图 |
| **字形恒定** | 同一套暖橙字面、整词一行连写、字距自然、不逐字母分色（SKILL:886） | 变的是承载它的气流，不是词本身；气流可以分成两缕，字不能被拆开 |
| **方向承担语义** | 气流**必须**从嘴边指向布熊耳朵（"从她嘴边一直连到熊耳朵"） | 方向就是「说给谁听」的语法；这是名词本完全没有的一维 |
| **字要够大、不被气流切碎** | 「气流是半透明的暖白，字面在气流里必须清楚可读、边缘不被气流切碎；字云整体要够大，是画面里的一件图形，不是小字幕」 | 否则模型会把字画成一团雾里的小字，直接踩 SKILL:946「目标词以小字幕形式出现」 |

### 封面：动词本多一档可用的概念

名词本的封面只能把大字**架在**某个载体上（墙上木牌、树上牌子、画布）。动词本的封面可以让书名**被说出来**：她刚说完一句悄悄话，一小团气流从嘴边升起、在她头顶前方展开成字云，书名 `"Come Close and Whisper"` 逐字渲染在字云上（分行：`Come Close and` 小 / `Whisper` 超大）。这套概念满足 `references/cover-design.md` 的「文字与场景共同设计」——载体与主题动作是同一件事，不是把内页加个标题。

### 可迁移判据（一句话，供后续动词本用）

> **动词的词形由「动作的产物或轨迹」承担，且方向、大小、形态跟着动作走；名词的词形由「物件的表面」承担，方向不参与语义。**
> 迁移示例：sweep → 扫帚掠过留下的弧形轨迹里浮出词；bounce → 球弹跳的弧线串成词；climb → 手脚交替的印子排成词。

## 三、② 动词的简介首句怎么起

### 通用约束（两种词型都适用）

首句不写场景布置（「桌上 / 碗里 / 手里 / 架子上」一律删，SKILL:616）；目标词只在结尾出现一次；单句 ≤30 字；口语；不承诺效果。

### 动词本多出的两条

1. **首句必须是动作，不是意图、不是情节。** 「她有一个小秘密要告诉你」是情节，「她想跟小熊说句话」是意图——两者都还不是动作。
2. **首句必须已经把「怎么接近 + 怎么出声」之一摆出来。** 少了这个，读者听不出它和「说 / 喊 / 唱」的差别，替换性检验必挂。

### 反例 → 正例（本轮实际比过）

| 反例 | 挂在哪 |
|---|---|
| 「屋子里很安静，她想跟小熊说句话」 | 地基滑向**环境**（v13 明令禁止「安静」当义项替代） |
| 「她有一个小秘密要告诉你」 | 滑向**情绪/情节**；而且换成 `tell` 也成立 → 替换性检验不过 |
| 「她张开嘴说话」 | 换成 `shout` / `sing` 都成立 → 不合格 |
| **正例 A**「凑到耳朵边，把声音收到最小，一句话轻轻说进去。听见了吗？whisper！」 | 首句是动作（凑）+ 两个要件（收小声音、说）→ 对 shout 强判据、对 sing 中判据 |
| **正例 C**「不是喊，也不是唱，是把话凑到耳朵边轻轻说。你也想试试吗？whisper！」 | 直接把义项边界说白 → 对 shout / sing 都是最强判据（但句式偏定义，朗读不如 A 像说话） |

（三条定稿见 `02-title-intro.md` §二；本书采用 A。）

### 为什么动作型的「第一感觉」必须落在结果

`SKILL:598` 把动作型的地基指定为「动作做出来的结果」。whisper 的结果句是「**话进了那只耳朵，只有一个人听见**」——这句话换成 `shout` 会自相矛盾、换成 `say` 会丢掉「声音小」、换成 `sing` 会丢掉「是话不是歌」。**结果句自带判别力**，这正是动作型地基好用的地方。

### 动词本简介的固有弱点（如实登记，不是本轮写坏了）

`sing` 与 `whisper` 的边界在「**言语 vs 旋律**」，不在音量——轻声唱同样只有旁边人听见。所以对 `sing` 的替换性检验只能是**中判据**：它靠「一句话 / 说」与「唱」的词类冲突（「一句话」不能被唱），而不是靠音量矛盾。名词本没有这个问题：`coin → button` 是「能不能买东西」的事实判断，干脆利落。→ 写动词本时，**把「话 / 说」写进句子**是让 sing 检验成立的必要条件。

## 四、③ 动词的旁白如何体现动作而不靠文字说明

四条做法（本轮 8 个内页逐页执行），每条附当页实证：

| # | 做法 | 本书实证 | 反例（不许这么写） |
|---|---|---|---|
| 1 | **只用动作的可见面**，不用副词当主承载 | `I cup my hand and whisper.`（手拢在嘴边 = 看得见） | `I whisper quietly.` —— quietly 是说明，不是动作 |
| 2 | **每页换一个动作阶段/身体部位**，让动作链自己说话 | 扶坐（手）→ 凑近（腰+鼻尖）→ 拢手（掌）→ 气声（嘴+呼吸）→ 贴耳（耳廓）→ 举起（双臂）→ 抱住（手臂+下巴） | 8 页都写「她小声说话」——动作链消失 |
| 3 | **结果句代替定义句** | `It heard me! I whisper again.` | `Whisper means to speak softly.` —— 教材句（违 SKILL:124） |
| 4 | **祈使句把动作交给读者做** | `Find the whisper. Point to it.` | `Now you know whisper.` —— 汇报式收尾 |

- **为什么这四条对动词是硬要求**：名词页可以靠「物件出现在画面」完成教学（coin 页只要硬币在，`This coin is money.` 就够）；动词页一旦写成定义句或副词说明，画面立刻退化成识字卡——因为动作**不在物件上**，没有可指的实体替文字兜底。
- **数字（自检脚本实测，见 `05-gates.txt` 附加证据 B）**：8 个内页英文 **5–6 词**、最长句 **6 词**（≤8 建议线内）；中文 **7–9 字**；8 页用了 **8 种不同起句**（`My bear…` / `I lean…` / `I cup…` / `Just a little…` / `Right into…` / `It heard me!` / `I whisper once more…` / `Find…`），没有套同一开头（SKILL:374）。
- **反例的机审表现值得记一笔**：把 `I whisper quietly.` 写进去，五道门禁**全部绿灯**——副词说明不是任何门禁的断言对象。动词本的「不能靠文字说明」这条，只能靠人读，机审帮不上。

## 五、④ 动词有没有词族页需求

**结论：whisper 没有；而且动作动词本**默认**不该有词族页。**

判据链（逐条可复核）：

1. 词族要求**共同词尾拼写一致 + 发音同韵**双条件（SKILL:363、:1789）。
2. `whisper` 词尾 `-isper`：儿童适龄词汇里**没有成员**（`crisper` 是厨具/更脆，超龄且不常用）。
3. `wh-` 是**词首字母组合**，不是共同词尾 → 不构成词族（`when / where / white / wheel` 属自然拼读的 onset digraph，不是词族）。
4. `whisper / whispers / whispering / whispered` 是**同一个词的屈折形态**，不是词族——词族要的是「同尾不同词」。拿屈折形式充词族，等于把「一个词」当「四个词」教。

结构性原因（这一点比 whisper 一个个案更重要）：

- 名词的词族来自「同尾名词」群：`pot / hot / dot / cot`——英语里同尾短名词天然多，容易凑出 3–5 个适龄可画词。
- 动词的同尾位置基本被**屈折词尾**（`-s / -ed / -ing`）占住；能凑出「同尾不同词」的动词本来就少，言说类（speak / talk / whisper / shout）更是各走各的词根。
- 所以：名词本常有词族页（pot 实测有），**动词本应默认无词族页**，按 SKILL「找不到合适候选时以额外语境页补足」处理。

本轮落地：8 个内页 = **P1–P7 语境页 + P8 互动练习页**（与 coin 同构，与 pot 不同构）。

> 若所有者要求「动词也要词族页」：**不能拿屈折形式充数**（SKILL 把伙伴词限定为完整词）；可考虑的替代是 `wh-` 词首页，但那不是词族页（没有共同词尾），属另一种页型，需另立口径——本轮不做，登记为缺口 G-Verb-Family。

## 六、本轮实测的机审行为（动词 vs 名词）

- **五道门禁对动词一视同仁**：首轮全绿、0 返工，没有出现「动词比名词更难机审」的情况。
- 但有一处**盲区对动词更危险**：`l4_presence_check` / `l4_case_check` 只查「字在不在、形态对不对」，**查不出字被画在错误载体上**。名词本把词写在木牌上 = 语义正确；动词本如果把词写成「飘在头顶的大字」（名词本的封面惯例），**机审照样全绿**，画面却丢掉了方向语义。→ 本轮把载体与方向写死在提示词里（「从她嘴边一直连到熊耳朵」），并在 `05-gates.txt` 注 3 把它列为必须成图目视的项。
- 第二处：**标题字数预算被长词吃掉**。`Whisper` 7 个字符位，占满「含词后 ≤12 字」的一半以上，中文主体只剩 3–4 字（名词 `Coin` 剩 5–7、`Pot` 剩 7–9）。这条对长词本（whisper / umbrella / butterfly）都成立，详见 `07-vs-noun.md`。
- 第三处：**`l4_structure_check` 的「目标词」一项要求「目标词图形化」块名 + 词字面同时在场**。动词本如果只写「画面里有 whisper」而没写载体，机器过、画面空——这条脚本 v2 已经堵住（块名 + 字面双条件），本轮实测每页都过。

## 七、可复用的动词本检查清单（9 条，勾选式）

1. [ ] L1 锁词型＝动作动词；旁白里不把动词当名词标签用（不写 `a whisper` 贴在物件上）
2. [ ] 第一感觉落在「动作做出来的结果」，不落在质感 / 声音副作用 / 情绪 / 环境
3. [ ] 图形化载体＝动作的产物或轨迹，**且有方向**（指向接受者）
4. [ ] 每页画面看得见「嘴 / 耳 / 手」中至少一处**身体关系**（否则静态图分不出 stand / look / say）
5. [ ] 每页一个不同的动作阶段，8 页不套同一开头
6. [ ] 不用副词、定义句、否定式说明承载义项
7. [ ] 互动页干扰物是**相邻或对立动作**（喊 / 唱 / 隔远说），不是同类物件
8. [ ] 词族页默认不设；要设必须过「共同词尾拼写 + 同韵」双条件，不许拿屈折形式充数
9. [ ] 标题字数预算先扣掉目标词字符数（7 字母的词只剩 3–4 个汉字位）

## 八、本轮不确定 / 未验证（不装懂）

1. **成图未跑**：气流字云会不会被画成一团雾、字会不会被气流边缘切碎，只有出图才知道。所有门禁都是**文本代理**。
2. **布熊当听者是否削弱「结果可信度」**：P6「它听见啦」是过家家逻辑，4–5 岁读者能否毫无障碍接受——**未做读者实测**。若所有者要求「结果必须是可验证的物理反应」，P6 应改成「熊耳朵的绒毛被一小口气吹动」。
3. **「动作动词默认没有词族页」是推论，不是统计**：本轮只有 whisper 一个动词样本；名词侧的 `-ot` 家族结论来自 pot 单本 + 构词常识。按项目纪律，这条只能登记为**假设 H-Verb-3**，**不得据此改 SKILL.md**（要改需跑全语料动词本统计）。
4. **简介对 sing 的判据强度中等**：见 §三末尾，属言说类动作词的固有弱点，不是本轮个例。
5. **`%TEMP%` 里的两个自检脚本不进仓**：它们能在同口径下被别人复现，但**不会在下次交付时自动跑**——这正是把关键断言抄进 `05-gates.txt` 留档的理由。
