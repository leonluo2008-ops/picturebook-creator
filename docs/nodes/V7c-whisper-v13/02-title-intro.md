# B624 · whisper · v13.0.0 L3 标题 3 备选 + 简介 3 备选

> **地基（L1 锁定，v13 口径）**：whisper 的第一感觉 ＝ **把声音收到最小，凑到耳朵边，一句话轻轻说进去——说的人和听的人贴在一起，只有那一个人听见。**
> 义项：**凑近小声说话，不是喊、不是唱**（动作动词；台账「词型」＝动作动词）。
> **v13 硬口径**：**禁止**把「安静 / 神秘 / 怕吵到人 / 屋子很静」这类**环境或情绪**当地基，也**不许**拿声音大小以外的东西当义项地基——地基只能落在「声音收小 + 凑近 + 说话」这个动作本身和它做出来的结果上。

## 二、简介 3 备选（三条都落在「把声音收到最小、凑到耳朵边说」这个动作上）

> 凑到耳朵边，把声音收到最小，一句话轻轻说进去。听见了吗？whisper！

> 我有一句话，得凑到你耳朵边说，声音小得只有你听见。你听懂了吗？whisper！

> 不是喊，也不是唱，是把话凑到耳朵边轻轻说。你也想试试吗？whisper！

**替换性检验的判据（先写清口径，再逐条判）**：把句中**承载义项的动词性表达**改写成 shout（大声喊）或 sing（唱）的对应说法，**其余文字不动**，看整句还说不说得通。

- 判 **不成立**（＝通过）：改写后出现自相矛盾，或改出来的搭配在汉语里说不通。
- 判 **仍成立**（＝不合格）：改写后还是一句通顺、和原句意思不冲突的话。

### 逐条验收

| 判据 | A | B | C |
|---|---|---|---|
| 目标词出现次数（应恰好 1 次，且在句尾） | 1 ✅ | 1 ✅ | 1 ✅ |

**关于 sing 判据强度的如实登记**：三条对 shout 的失败都是**强判据**（距离与音量直接矛盾）；对 sing 的失败是**中判据**——它靠的是「一句话／说」与「唱」的词类冲突，而不是音量冲突。如果把句中的「一句话」也一并改写成「一首歌」，轻声唱是可以成立的。**这是言说类动作词在替换性检验上的固有弱点**，不是这三条的个别问题：whisper 与 sing 的差别在「言语 vs 旋律」，而 sing 也可以小声，所以单靠「声音大小」区分不了唱与说（详见 `06-verb-path.md` §三）。本轮按上面的判据口径判为**通过**。

**推荐顺序：A → B → C**
- A 最短、首句就是动作，4–5 岁孩子听完能立刻照着做（凑过去、把声音收小、说一句）。
- C 把义项边界（不是喊、不是唱）直接说白，是最贴教学的一条，但「不是…也不是…」的句式偏定义，朗读时不如 A 像大人蹲下来说话。
- **本轮采用：A**（简介不进 L4、不上封面；若改选只改归档正文，无需重跑机审）。

## 三、与旁白的衔接（检查结论）

定稿旁白（`03-narration.md`）的动作链是「布熊坐好 → 凑近 → 拢手 → 声音收到最小（气声）→ 话进耳朵 → 它听见了 → 再说一句、抱紧 → 互动页辨认」，与三条简介的落点全部对得上：

| 简介 | 对得上的旁白页 |
|---|---|
| A | P2 `I lean in close and whisper.` / P4 `Just a little breath: whisper.` |
| B | P2 凑近 / P5 `Right into its ear, I whisper.` / P6 听见 |
| C | P3 `I cup my hand and whisper.` / P4 收小声音 / P8 辨认哪张在 whisper |

三条简介都**不提**「屋子很安静 / 怕吵醒谁 / 这是个秘密」——「不拿环境或情绪当义项替代」这一条在旁白链里同样成立：全书九页没有一页以安静、神秘、怕打扰为教学落点。
