# B293 · behind · 与 coin / pot / whisper / long 四本的对比

> 对比对象：`V7-coin-v13`（coin，名词，8 内页＝P1–P7 语境页 + P8 互动页，**无词族页**）、`V7b-pot-v13`（pot，名词，8 内页＝P1–P6 语境页 + P7 词族页 + P8 互动页）、`V7c-whisper-v13`（whisper，动作动词，8 内页＝P1–P7 语境页 + P8 互动页，**无词族页**）、`V7d-long-v13`（long，形容词，8 内页＝P1–P6 语境页 + P7 词族页 + P8 互动页）、本本 `V7e-behind-v13`（behind，位置介词，8 内页＝P1–P7 语境页 + P8 互动页，**无词族页**）。
> 五本共用：同一主角（资产库「3D皮克斯小女孩」，图像1 锚定）、同一画风（3D 皮克斯电影级渲染）、同一页数口径（封面 3:4 / 内页 16:9 / 封面 + 8 内页）、同一五道门禁。
> 下面 5 条是**位置介词本独有**的差异，每条都给本书的实证。

## 一、词形载体：四类词写在四个完全不同的地方（介词是第五个）

| 词型 | 载体 | 书的实证 | 载体承担语义吗 |
|---|---|---|---|
| 名词 | **被指物件的表面**（标签 / 木牌 / 卡片 / 锅身） | coin：硬币下的木牌；pot：小锅锅身正中一块橙色小标签 | **不承担**——物件在哪，词在哪 |
| 动作动词 | **动作的产物或轨迹**（气流字云） | whisper：从她嘴边升起、朝熊耳去的一小团暖白气流，云里是整词 | **承担**——气流方向 = 「说给谁听」 |
| 形容词 | **它所指的那个维度的轴**（长围巾被拉直的那一段布面） | long：`long` 写在布面上，字基线顺着围巾长轴；围巾弯，字跟着弯 | **承担**——走向 = 长度轴走向 |
| **位置介词** | **遮挡物之后那片还能看见的平面**（木地板 / 墙脚 / 门后走廊地板），词行从前景物轮廓外露出来 | **behind：纸箱右侧棱后、沙发圆扶手下缘后、门扇立边后的那行字**——她露出的丸子头 / 眼睛 / 半张脸 / 裙子一角 / 一只手，与这行词用的是**同一条遮挡边缘** | **承担**——**词与前景物之间的前后关系**就是语义，不是词的位置、走向或字形 |

> 一句话：名词的词长在**东西上**，动词的词长在**痕迹里**，形容词的词长在**维度上**，**介词的词长在"后面那片空间"里——由它被前景物压住的那条边负责说话**。
>
> 这一条是五本里最难的一格：前四种载体都能"独立成立"（把周围清空，词照样有落点），**介词的载体必须依附于一件前景物**——拿掉前景物，载体就退化成普通地板上的普通字。所以介词本的"载体"与"前景遮挡物"是**共生**的，不能分别设计。

## 二、义项靠什么「读」出来：介词本要三件东西，而且机位一错就归零

| 词型 | 静态画面里读出词义，最少需要什么 | 本书处理 |
|---|---|---|
| 名词 | **那件东西在场**（pot 只要那只锅在画面里） | 单件道具，一页一物 |
| 动作动词 | **一对身体关系**（嘴凑到耳朵、手拢在嘴边） | 布熊当听者，嘴 / 耳 / 手每页可见 |
| 形容词 | **两个可比的东西**（长的那条 + 明显更短的一条 / 尺度物） | **每页强制同框一件短参照**（同款短围巾 / 沙发扶手 / 矮柜宽度 / 她的双臂） |
| **位置介词** | **遮挡三件套 + 固定机位**：①靠近镜头的前景物 ②被它轮廓切断一部分的主体 ③同一条边缘下露出的词；且机位必须锁在遮挡物一侧 30–45 度侧前 | 三件大遮挡物轮换（大纸箱 / 沙发靠背 + 圆扶手 / 半开的门）；7 个语境页把"露出量"从最少（只露丸子头）推到最多（探出上半身），**关系一路不变** |

- 这是本轮最实的发现：**名词本的画面元素可以少到一件**，形容词本要两件，**介词本要三件——而且那三件里的词必须是"被同一件东西挡住的"**，光是三件在场、彼此无关，照样读不出 behind。
- **机位是介词本独有的"结构替代文字"手段**：把机位绕到沙发背面，"她躲在沙发后"就变成"她坐在沙发旁"；把机位摆到正前方，就只剩"一个人头浮在靠背上方"。前四本的机位可以换（硬币转个角度还是 coin；围巾换个角度还是 long），**介词本换机位等于换义项**。
- 代价也如实登记：介词本每页比名词本多两件画面元素（前景物 + 词所在的"后面那片平面"），且全书机位自由度几乎为零（`01-structure.md` §二·1、`06-prep-path.md` §三）。

## 三、简介地基：四本四种写法，替换性检验的强度也不同

| 本 | 地基类型 | 地基句（节录） | 替换性检验的对象 | 判据强度 |
|---|---|---|---|---|
| coin | 功能 / 社会型 | 它是钱：存进小猪罐、一枚一枚攒起来、攒够了能买东西 | → button / bead | **强**（"能不能买东西"是事实判断） |
| whisper | 动作结果型 | 把声音收到最小、凑到耳朵边，只有那一个人听见 | → shout / sing | 对 shout **强**、对 sing **中** |
| long | 维度型（自定档） | 短的那条一下就拉完了，这条拉了老半天还没到头 | → tall / heavy | 对 heavy **强**、对 tall **中** |
| **behind** | **关系型（本轮自定，SKILL 三档里也没有这一档）** | 一躲到后头，前面那件东西就把我挡住了，怎么找都看不见我 | → on / under | 对 on **强**、对 under **强**（A / C 两条）／**中**（B 一条） |

- **介词本的固有弱点与形容词本不同**：形容词的弱点是 `tall` 与 `long` **共享"一个维度上的延伸"这个骨架**；介词的弱点是 `behind` 与 `under` **共享"被挡住"这个后果**——区别只在**遮挡来自前面还是上面**。
- 补法：**把遮挡方向词（"前面那件东西"）写进首句**，并让画面上的机位永远把遮挡物放在她**正前方**（不压在她头顶）。这与 long 本"把轴的方向写进动作词"、whisper 本"把『话/说』写进句子"是同一类补救——**每类词都要把那个词的"判据特征"写进句子，否则替换性检验判不死。**
- SKILL 的「第一感觉」表只有感官型 / 动作型 / 功能社会型三档，**没有形容词档、也没有介词档**（缺口登记为 `G-Adj-1`、`G-Prep-1`，未改规则）。

## 四、词族页：五本五种结果，把"词性决定论"彻底否掉

| 本 | 核心词 | 词尾 | 候选能否过「拼写 + 同韵 + 适龄 + 可画（+ 不抢轴 + 结构放得下）」 | 设词族页？ |
|---|---|---|---|---|
| V7-coin | coin | `-oin` | join（动词）/ loin（部位名）→ 不适龄、不可画 | **否** |
| V7b-pot | pot | `-ot` | hot / dot / cot 全过 | **是（P7，4 词）** |
| V7c-whisper | whisper | `-isper` | 儿童适龄词汇无成员 | **否** |
| V7d-long | long | `-ong` | song / gong / strong 全过（六道闸，见 `06-adj-path.md` §五） | **是（P7，4 词）** |
| **V7e-behind** | **behind** | **`-ind`** | **双条件（拼写 `ind` + 同韵 /aɪnd/）四个候选全过，但断在第三、四闸：`kind` / `mind` 抽象不可画、`bind` 书面低频；只有 `find` 过闸，且 `find` 是动词、会把轴拉到"找东西"** | **否** |

- **这一本是五本里最"可惜"的一本**：`-ind` 是唯一一个**双条件全过、却因为适龄+可画折损到只剩一个成员**的词尾。它把结论钉得比前四本更死——
  - 若按"名词有词族页"推：coin 会推错（名词却没有）；
  - 若按"动词/介词没有"推：long 会推错（形容词却有）、pot 会推错（名词有）；
  - 若按"双条件过了就该设"推：behind 会推错（双条件全过，仍然不设）。
  → **词族页只由六道闸决定，与词性、与"双条件是否全过"都无关**；双条件只是前两道闸。
- 落地差异：设了词族页的两本（pot / long）机审要多传 `--page-words "7=…"` 与 `--family-words …`；不设的三本（coin / whisper / behind）用标准原式即可。本书因此**少一处"参数传错就静默零校验"的风险**（SKILL:902 记过这个坑）。

## 五、互动页：干扰物的性质从"身份 → 关系 → 长度 → 位置"，介词本靠"谁被挡住"

| 本 | 干扰物是什么 | 问题 | 答案靠什么判定 |
|---|---|---|---|
| coin | **同类的别的物件**（纽扣 / 瓶盖 / 小饼干） | 找一找，哪一枚是 coin | 物件**身份** |
| pot | **同类的别的物件**（锅铲 / 隔热手套 / 鸡蛋） | 找一找，哪一个是 pot | 物件**身份** |
| whisper | **相邻 / 对立的动作**（喊 / 唱 / 隔远说） | 哪一张在 whisper | 身体**关系**（嘴贴耳朵） |
| long | **同类的不同长度**（同款围巾三短一长） | 找一找，哪一条是 long | **长短差** |
| **behind** | **同类的不同位置**（三只**完全同款同大小**的大布熊：沙发前面 / 坐垫上 / 靠背后面） | 哪一只在沙发后面 | **谁被挡住了一部分**（遮挡的有无；另两只整只完整可见） |

- **反义词处置方向相反**：long 本**必须**每页同框一件短参照（"长"是比出来的），behind 本**不需要**同框"在前面"的东西（遮挡是正面证据，自证）。介词本因此少一件画面元素，但多一条硬约束：**四项近远证据必须写进提示词**（前景物更大 / 接地投影落在后面地板上 / 远景略柔 / 前景轮廓切断主体）——缺了，两个物体就塌成"并排"，题目失去唯一答案。
- **零词形纪律一致**：long 本的 `short` 全书不上文字；behind 本的 `in front of` / `on` / `under` 全书同样一次词形都不出现——它们只作为画面里的位置存在。
- **字不能泄题**：两本都把互动页的整词挪到中立小立牌上（long 是地毯前沿的小立牌，behind 也是），候选物一律不写字。
