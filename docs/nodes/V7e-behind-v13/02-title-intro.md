# B293 · behind · v13.0.0 L3 标题 3 备选 + 简介 3 备选

> **地基（L1 锁定，v13 口径）**：behind 的第一感觉 ＝ **前面那件东西一挡，我就整个不见了；只露出一点点、探头看你的那一瞬最好玩。**
> 义项：**在某物后面／被某物挡住**（位置介词；台账「词型」＝位置介词，排产号 B293）。
> **v13 硬口径**：地基必须落在**「遮挡关系」**上——**不许**拿「沙发后 / 树后 / 门后」这类**具体物件**当义项的定义（那是举例，不是义项）；也**不许**拿「落后（behind in the race）/ 支持（behind you）」这两个邻接义项顶替。
> 三条简介逐条过**替换性检验**（判据与逐条结论见 §三）。

## 三、替换性检验与逐条验收

**判据（位置介词版，先写清口径再逐条判）**：v13 的替换性检验原式是"把目标词换成同类的另一个词，这句话还成立吗"。介词本落成可操作的两步——

把句尾的 `behind` **原地**换成 `on`（贴在……上面）或 `under`（在……下面），**其余文字一字不动**，读整条，再问两个问题：

1. **遮挡方向**：首句给的遮挡证据是"前面的东西挡在它和看的人之间"（＝behind），还是"贴在上表面"（＝on）、"上方的东罩住它"（＝under）？
2. **换词后是否自相矛盾**：句子里出现的方向词（前面 / 挡住 / 露出来）与替代介词的方位是否打架？

- 换词后**仍然通顺、且首句的遮挡证据照样成立** ⇒ **不合格**（说明义项没锁死）。
- 换词后方向词冲突、或首句证据只支持"被前面的东西挡住" ⇒ **不成立 ⇒ 通过**。

### 逐条验收

| 家长汇报口吻 / 方法论 / 效果承诺 | 无 ✅ | 无 ✅ | 无 ✅ |

**关于 B 对 under 判据强度的如实登记**：B 的失败只靠"on 不产生遮挡"这一条（强），对 under 只是**中判据**——under 同样能"被罩住、只露一只眼睛"。这是介词在替换性检验上的固有弱点：**behind 与 under 共享"被挡住"这个后果，区别只在遮挡来自"前面"还是"上面"**。补法有两条：① 首句写进方向词（"前面那件东西"，A / C 都写了）；② 靠画面兜底（全书机位与小孩同高、遮挡物始终在她正前方，没有一页把东西压在她头顶上）。→ 写介词本时，**把遮挡方向写进首句**是让 under 检验成立的必要条件（与 long 本"把轴的方向写进动作词"、whisper 本"把『话/说』写进句子"是同一类补救）。

**推荐顺序：A → C → B**
- A 最短、起句就给出"被挡住 → 看不见"这条因果，句尾"想不想躲一回"是可照着做的邀请，4–5 岁听完会真的往沙发后面钻。
- C 的"一、二、三，找到啦"节奏最好，但第二条 22 字偏长，且"找到啦"预设了一个找的人（本书里找的人是读者，勉强成立）。
- B 最温柔，但对 under 只有中判据，且没有把遮挡方向写进首句。
- **本轮采用：A**（简介不进 L4、不上封面；若改选只改归档正文，无需重跑机审）。

## 四、与旁白的衔接（检查结论）

定稿旁白（`03-narration.md`）的动作链是「纸箱后蹲好 → 箱沿上露出眼睛 → 沙发背后蹲低 → 从沙发边探头 → 门后只露裙子一角 → 从门后伸出手 → 回纸箱探出上半身 → 互动页认出哪只熊在后面」，三条简介的落点全部对得上：

| 简介 | 对得上的旁白页 |
|---|---|
| A | P1 `I hide behind the big box.` / P3 `Nobody sees me behind the sofa.` / P5 `Behind the door, only my skirt shows.` |
| B | P2 `Two eyes peek from behind the box.` / P4 `Half my face peeks out behind the sofa.` / P6 `My hand comes out from behind the door.` |
| C | P7 `I pop up from behind the big box.` |

三条简介都**不提**任何一件遮挡物的名字（沙发 / 纸箱 / 门）、也**不提**"落后 / 支持"——"地基只落在遮挡关系"这一条在旁白链里同样成立：全书九页没有一个画面以"距离落后"或"支持"为教学落点，`in front of` / `on` / `under` 三个词形全书一次都没出现。
