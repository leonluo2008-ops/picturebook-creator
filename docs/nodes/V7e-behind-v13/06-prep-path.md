## 二、① 介词「目标词图形化」怎么画（既无物件表面、无动作痕迹、又无形维度轴）

### 前三本各占一个载体，介词一个都不占

| 词型 | 载体 | 词的位置/形态承担语义吗 |
|---|---|---|
| 名词（coin / pot） | **被指物件的表面**：硬币下的木牌、锅身标签、台面小卡 | **不承担**——硬币在哪，词就贴在哪 |
| 动作动词（whisper） | **动作留下的痕迹**：从嘴边升起、朝熊耳去的一小团气流字云 | **承担**——气流的方向就是「说给谁听」 |
| 形容词（long） | **它所指的那个维度的轴**：长围巾被拉直的那一段布面，字沿长轴排 | **承担**——走向 = 长度轴走向 |
| **位置介词（behind）** | ？（本节要答） | ？ |

### 介词为什么三头都不靠

- **没有表面可贴**：把 `behind` 贴到沙发正面 / 靠垫上 / 纸箱箱身上，机审全绿，但画面读出来只有「沙发」「靠垫」「箱子」——**词跟着物件走，介词就被读成了名词**（这正是 coin 的写法硬套到介词上）。
- **没有痕迹可跟**：介词不表示「做了一件事」，没有过程，出不了气流、脚印、弧线。硬画成字云，就是动词本的皮、介词本的骨——气流方向对 `behind` 不承担任何语义（往哪个方向飘都还是 behind）。
- **没有轴可铺**：`long` 能靠"走向"自证，因为长度就是一个方向；**`behind` 没有方向**，它是一句话——「甲挡在乙和看的人之间」。**关系没有形状**，所以任何"用字形本身演它"的路（拉伸、倾斜、透视变形）都会撞上 SKILL:886 的可读性与字距要求，且演不准。

### 弃用的四种写法（逐条给理由，不是凭感觉）

| 写法 | 机审表现 | 判死的理由 |
|---|---|---|
| **A 标签式**：`behind` 贴在前景物正面（沙发靠背布面 / 纸箱箱身 / 门板正面） | 全绿 | 与名词本同构，词不承担语义；画面读成「沙发」，介词义项没出来。**唯一例外是互动页**——那里必须让字不泄露答案，字只能写在不属于任何候选物的中立立牌上 |
| **B 字云式**：把 `behind` 画成从遮挡物后飘出的一小团字云 | 全绿 | 与动词本同构；"飘"不表示前后，去掉遮挡物这团云照样成立 ⇒ 义项没落地 |
| **C 字形演纵深**：把字母按透视拉斜、近大远小排开，用字形自己演"后" | 全绿 | 直接踩 SKILL:886（整词一行连写、字距自然、清楚轮廓）；且"斜排"在 2D 里既可读成"往后"也可读成"往上"，方向不可判 |
| **D 词被前景物整段盖住、只露半截** | 全绿 | 读感最强的一条，但它与 SKILL:886「清楚可读」直接冲突，成图上极可能出现"字母被切成两半、认不出词"。**本轮把它降级折中**：词整行全部可读，被前景物压住的只是**词行的外侧留白 + 一条边缘线**（见下） |

### 本轮采用的写法：**载体 = 「遮挡物之后那片还能看见的平面」，词与角色共用同一条遮挡边缘**

`behind` 不写在任何一件东西的**正面**，而是写在**前景遮挡物之后的那片平面**上（木地板 / 墙脚 / 门后走廊地板），并且**词的整行从前景物的轮廓外侧露出来**。更关键的一条是**同构**：

> 她露出半个丸子头 / 两只眼睛 / 半张脸 / 裙子一角 / 一只手，`behind` 这一行就从**同一条边缘**后面露出来。**画面里同时有"一个人被挡住"和"一个词被挡住"，而且是同一件东西挡住的两个。**

| 细则 | 写法 | 为什么 |
|---|---|---|
| **载体** | 遮挡物之后的木地板 / 墙脚（不是任何物件的正面） | 词必须待在"后面的位置"上，介词才有落点 |
| **被压的那一线** | 前景物的某条棱 / 边缘压住词行的**外侧留白**，不压字母主干；整行仍完整可读 | 把"被遮挡"读感留下，同时守住 SKILL:886 的可读性 |
| **共用边缘** | 她露出的部位与词行露出的部分，用同一条轮廓线 | 让"关系"变成一眼可见的东西：**同一个遮挡，同时作用在人和词上** |
| **字形恒定** | 奶油白字面 + 暖橙描边、整词一行连写、字距自然、不逐字母分色、字面平贴平面、正对镜头铺开不被地板透视压扁 | 变的只是它所在的那片平面与那条边缘，不是词本身 |
| **互动页例外** | 字挪到地毯前沿的中立小立牌上，三只候选熊与沙发都不写字 | 与 long 本 P8 同一条理由：答案不能靠字的位置泄露 |
| **封面例外** | 书名从沙发靠背后面**探出来**，靠背上沿压住书名的下沿一线 | 标题与角色做**同一个探头动作**——书名自己就在演 behind |

### 一句判据（可核）

> **把前景遮挡物从这一页拿掉——她的身体和这行词会同时完整暴露在空地上，这一页的 `behind` 就没有证据了。**

这条判据比"词写得漂不漂亮"硬得多：它把"载体选对没有"变成了一个可回答的是非题。九页逐页核对见 `05-gates.txt` 附·3。

### 封面：介词本多一档可用的概念——**书名与角色做同一个动作**

名词本的封面只能把大字**架在**载体上；动词本能让书名**被说出来**；形容词本能让书名**沿被拉长的东西铺过去**。介词本可以让书名**和主角一起从后面探出来**：书名排在沙发靠背之上的墙面，靠背上沿正压住书名下沿一线；她蹲在靠背后面，只露丸子头和两只扒着靠背的手，位置就在书名下方偏左。**第一眼读到的"书名从后面探出来"就是 behind 本身**。这套概念满足 `references/cover-design.md` 的「文字与场景共同设计」——标题的排布位置与义项表达是同一件事，不是"顶部横幅 + 大字 + 居中角色"的识字卡。

### 可迁移判据（一句话，供后续介词本用）

> **位置介词的词形由「词与被前景物之间的前后关系」承担——词必须待在它所指的那片空间里，并被前景物的轮廓压过一线；名词靠物件表面、动作词靠痕迹、形容词靠轴，三者的"位置/走向/字形"都不承担介词的语义。**

迁移示例（**推论，本轮未实测**）：

| 目标介词 | 载体该放哪 | 词被什么压住 |
|---|---|---|
| `on` | 承托面（桌面 / 地板）被那件东西压着的那一块 | 被物体**从上往下**压住词行 |
| `under` | 下方空间（桌面底下 / 桌腿之间）的地面或墙面 | 被上方平面**压住词行上沿**，词从桌沿之下露出来 |
| `between` | 两个东西之间那道缝的平面 | **两端同时被两件东西压住** |
| `in front of` | 遮挡物与镜头**之间**的近侧平面 | 遮挡方向与 behind **恰好镜像**：词把后面的东西挡掉一部分 |

## 三、② 关系不是东西：怎么保证画面读得出「遮挡 / 在后面」，而不是只看到两个物体

### 最小证据：遮挡（occlusion）是 2D 里唯一可靠的前后线索

2D 画面里判"谁在前面"只有四类线索：**边缘遮挡、近大远小、接地投影、清晰度/景深差**。其中**只有边缘遮挡**能单独成立（另外三条都会被透视风格、画风、构图习惯稀释）。所以介词本的画面必须把遮挡做成**主证据**，另外三条当**辅证**写进提示词。

### 遮挡三件套（每页缺一件就废）

| # | 三件套 | 缺了会怎样 |
|---|---|---|
| 1 | **前景遮挡物**（靠近镜头：更大、下沿更靠近画面下沿、边缘清楚、可带轻微景深虚化） | 没有"挡住"的来源，两个物体变成并排 |
| 2 | **被切断的主体**（只露丸子头 / 两只眼睛 / 半张脸 / 裙子一角 / 一只手，**永远不是整个人完整暴露**） | 她整个人完整 ⇒ 读成「她和沙发在一起」 |
| 3 | **同一条边缘下的词** | 词若贴在前景物正面，孩子学到的是「沙发的名字」——名词本写法硬套介词 |

### 机位锁定：这是介词本唯一可以用"结构"替代"文字解释"的地方

同一页内容，机位一换，读法就变（这是本轮实测出来的最硬的一条）：

| 机位 | 画面上看到什么 | 孩子读成 |
|---|---|---|
| 她躲在沙发靠背正后方，机位正前方 | 只看见一个丸子头浮在靠背上方 | 「一个人头在沙发上」——读不出前后 |
| 机位绕到沙发**背面** | 看见她整个人靠着靠背坐着 | 「她坐在沙发旁边」——**behind 的证据消失** |
| **机位在遮挡物一侧约 30–45 度侧前** | 靠背剪影切断她的身体 **+ 靠背之后那块平面也看得见** | 「她在那件东西后面」——关系成立 |

第三种机位是介词本的关键：它同时**保住遮挡**（前景物切断主体）和**露出载体的位置**（遮挡物之后那块平面）。正前方机位保不住后者，背面机位保不住前者。→ 全书机位锁死在同一侧，同一件遮挡物的页保持同一侧同一高度（`04-L4.txt`【站位与机位约定】已写死）。

### 与前三本的对照：四类词"读到词义最少需要什么"

| 词型 | 静态画面里读出词义，最少需要什么 | 本书处理 |
|---|---|---|
| 名词 | **那件东西在场**（pot 只要那只锅在画面里） | 单件道具，一页一物 |
| 动作动词 | **一对身体关系**（嘴凑到耳朵、手拢在嘴边） | 布熊当听者，嘴/耳/手每页可见 |
| 形容词 | **两个可比的东西**（长的 + 明显更短的） | 每页同框一件短参照 |
| **位置介词** | **三件套 + 固定机位**：前景物 / 被切断的主体 / 同一条边缘下的词，且机位锁在侧前 | 纸箱、沙发、门三件大遮挡物轮换；7 个语境页把"露出量"从最少推到最多 |

### 旁白层面的一条：不许写定义句

`She is behind the sofa.` / `The girl is behind the box.` 这种句子 6 个词、五道门禁**全绿**，但它是字典释义，不是绘本句子——与形容词本的 `This is long.`、动词本的 `I whisper quietly.` 是同一类盲区（门禁只校字，不校义）。

| # | 做法 | 本书实证 | 反例 |
|---|---|---|---|
| 1 | **写动作，不写位置判断** | `I hide behind the big box.` / `I pop up from behind the big box.` | `I am behind the box.` |
| 2 | **写"露出来的那一部分"** | `Two eyes peek from behind the box.` / `My hand comes out from behind the door.` | `The girl is behind the door.` |
| 3 | **写"看不见"这个后果** | `Nobody sees me behind the sofa.` | `I am behind the sofa now.` |
| 4 | **祈使句把任务交给读者** | `Which bear sits behind the sofa? Point to it.` | `Now you know behind.` |

### 数字（自检，可从 `03-narration.md` / `05-gates.txt` 逐条复核）

- 7 个语境页英文 **6–8 词**、最长句 **8 词**（≤8 建议线内，≤10 硬上限）；互动页 9 词（两句：6 + 3）。
- 7 个语境页用了 **7 种不同的起句**（`I hide…` / `Two eyes…` / `Nobody…` / `Half my face…` / `Behind the door…` / `My hand…` / `I pop…`）；其中两句都以 `I` 开头，但动词与句型不同（hide / pop up from），没有套同一开头（SKILL:374）。
- 中文内页 **11–14 字**（机审实测，见 `05-gates.txt` 门 4），全在 8–14 建议区间内。
- 目标词全书 **9 次**（封面书名 1 + 内页 8），≥8 次硬要求满足。

## 四、③ 介词的简介首句怎么起（怎么避免「用两个名词解释方位」）

### 陷阱长什么样

```
❌ 沙发后面，她躲起来了。                 ← 两个名词 + 一个方位词 = 给方位下定义
❌ 她躲在那件东西的后面，你看不见她。      ← 还是「甲在乙后面」的句式，只是把名字换成了代词
```

这两句的毛病一样：**它要求孩子在脑子里摆两个名词再摆一个方位**——那是成人查词典的动作，不是孩子躲猫猫的经验。而且把句尾的词换成 `on` / `under`，这两个句子**照样成立**（"沙发上面，她躲起来了"也说得通），替换性检验当场判不合格。

### 三条可复用的骨架（本书三条备选各占一种）

| 骨架 | 长什么样 | 本书对应 | 换成 on / under 会怎样 |
|---|---|---|---|
| **后果型**（遮挡的后果：看不见） | 「一躲到后头，前面那件东西就把我挡住了，怎么找都看不见我」 | **A（采用）** | 「前面那件东西挡住我」与「贴在它上面」互斥 ⇒ on 不成立；「前面」与「在下面」方向冲突 ⇒ under 不成立 |
| **边缘型**（遮挡的边缘：只露一点） | 「只露出一只眼睛，剩下全被挡住了」 | B | on 不产生遮挡 ⇒ 不成立；under 也能"被罩住只露一点" ⇒ **中判据，靠画面兜底** |
| **发现型**（遮挡解除的一瞬：找到啦） | 「一、二、三，找到啦！刚才前面那件东西把我挡得死死的，你才看不见我」 | C | 因果链（挡→看不见）与 on 互斥 ⇒ 不成立；「前面」与「在下面」方向冲突 ⇒ under 不成立 |

**共同点**：三条首句都从**身体经验**开口——**看不见 / 只露一点 / 被找到**，没有一条从「甲在乙后面」开口。这是"避免用两个名词解释方位"的可操作做法：**把方位写成后果或边缘，不要写成两个名词的排布。**

### 介词简介的固有弱点（如实登记，不是本轮写坏了）

`behind` 与 `under` **共享"被挡住"这个后果**——两者的区别只在**遮挡来自前面还是上面**。所以对 under 的替换性检验，光靠"被挡住"是判不死的。本轮能判死，靠两件事：① 首句里写进了**遮挡方向词**（"前面那件东西"，A / C 都写了）；② **画面上的机位**（全书与小孩同高、遮挡物始终在她正前方，没有一页把东西压在她头顶上）。

→ 写介词本时，**把遮挡方向写进首句**是让 under 检验成立的必要条件（与 long 本"把轴的方向写进动作词"、whisper 本"把『话/说』写进句子"是同一类补救）。

### 机审表现

三条简介在 `title_intro_check` 下全过（目标词各 1 次、首句无场景词、单句 ≤30 字、无禁词）；但**"地基是否落在遮挡关系"这一条机审完全查不到**——它是语义判断，只能人读。这也是本报告 §四 要写清骨架的原因：机审绿了不等于简介对了。

## 五、④ 介词本有没有词族页需求：`-ind` 家族（bind / find / kind / mind / behind）判据与结论

**结论：不设词族拓展页。** 判据不是"觉得配不上"，而是下面 6 道闸门逐条可复核；四条候选里只有 1 条过闸，连"同族词至少 2 个"都不够，按 SKILL:1789「找不到合适候选时，以额外语境页补足」改不设。

### 先澄清一件事：`-ehind` 不存在同族，真正要判的是 `-ind`

`behind` 的拼写尾巴是 **`-ind`**（b-e-h-**i-n-d**），不是 `-ehind`。它是双音节词（历史上是 be- + hind），但**末音节的 rime 拼写与读音都落在 `-ind` 上**：`behind /bɪˈhaɪnd/` 的韵尾是 **/aɪnd/**，与 `find /faɪnd/`、`kind /kaɪnd/`、`mind /maɪnd/`、`bind /baɪnd/` 完全同韵。所以**双条件（G1 拼写 + G2 同韵）是过的**——这一本断在后面的适龄与可画，不是断在"没有同族"。

## 六、⑤ 反义词 / 邻接介词（in front of）的干扰物问题

**结论：位置介词本与形容词本相反——全书既不需要「同框反义装置」，也必须让 `in front of` / `on` / `under` 三个词形一次都不出现。** 但要处理两种"否定形态"的干扰。

### 为什么介词本不需要同框反义装置（与 long 本的关键分野）

| 词型 | 义项靠什么成立 | 要不要同框对照 |
|---|---|---|
| **形容词 long** | 「长」是**比出来的**——只有一条长带子，画面读成「围巾」 | **要**：每页必须有一件明显更短的同类/尺度物（否则义项读不出） |
| **位置介词 behind** | 「在后面」由**遮挡自证**——前面的东西切断它，这本身就是证据 | **不要**：遮挡是**正面证据**，不依赖与"在前面"的对比 |

加一个"在它前面"的对照物会付两笔代价：① 一页同时出现两个位置概念，破 SKILL:144「一页一概念」；② 孩子会把注意力放到"哪个在前面"，而本书要教的是"**被挡住的那个在后面**"——比较题会劫持教学轴。

### 但反义词有两个真实干扰点

**干扰点 1：互动页的干扰项就是"非 behind 的位置"。** 三只同款大熊：一只坐在沙发前面地板上（完整可见）、一只坐在坐垫上（完整可见）、一只坐在靠背后面（只露头和两耳、一只爪扒着靠背顶）。后两只干扰项在语义上就是"不在后面"的位置——**但它们不给词形**：不写 `in front of`、不写 `on`、不贴标签、不进旁白。判据：答案由"哪一只被挡住了一部分"决定，不由字决定。这与 long 本「`short` 只当画面元素、不给词形」同源，但比它更严——介词本连"反义装置"都不需要，遮挡本身就是全部。

**干扰点 2（真正危险的那个）：画面没给近远线索 ⇒ 两个物体塌成"并排"。** 这不是"孩子会想到 in front of"的问题，而是**画面根本没读出前后**的问题。补法是把四项近远证据写进提示词（见 §三），并在成图上逐页做反向判据（拿掉前景物还成立吗）。**这一项任何脚本都查不到**——`l4_structure_check` 只数块名存在性。

### 落地五条规则

| # | 规则 | 为什么 |
|---|---|---|
| 1 | **反义 / 邻接介词零词形**：`in front of` / `on` / `under` 全书不写、不贴、不进旁白 | 一页一概念；三个介词同时上文字，唯一教学轴被抢 |
| 2 | **干扰项必须"同类不同位置"**：三只**完全同款同大小**的大布熊，只有位置不同 | 若换成"一只熊 + 一个球 + 一本书"，孩子比的是**类别**（哪个是熊），题目就废了 |
| 3 | **问"哪一只在沙发后面"，不问"哪一只更靠后"** | 比较题（A 比 B 靠后）在 4–5 岁要两两比、且透视图里常说不清；"两只完整可见 + 一只被挡住"是**辨认题**，唯一答案不依赖比较技巧（SKILL:364） |
| 4 | **遮挡差要夸张到缩略图也看得出**：被挡住的那只只露头和两耳，另两只整只完整 | 差一点点（挡到胸口 vs 挡到腰）在小尺寸下无法判读，答案变成看运气 |
| 5 | **前七页把"被挡住"练成视觉习惯**：7 个语境页全是"她只露一点" | P8 只是把这条暗线**变成可选项**，不是突然考较 |

### 与三本互动页的对照

| 本 | 干扰物是什么 | 问题 | 答案靠什么判定 |
|---|---|---|---|
| pot | **同类的别的物件**（锅铲 / 隔热手套 / 鸡蛋） | 找一找，哪一个是 pot | 物件**身份** |
| whisper | **相邻 / 对立的动作**（喊 / 唱 / 隔远说） | 哪一张在 whisper | 身体**关系** |
| long | **同类的不同长度**（同款围巾三短一长） | 找一找，哪一条是 long | **长短差** |
| **behind** | **同类的不同位置**（同款大熊三只：前面 / 坐垫上 / 靠背后面） | 哪一只在沙发后面 | **谁被挡住了一部分**（遮挡的有无） |

## 七、本轮实测的机审行为（介词 vs 前三类）

- **五道门禁一视同仁**：首轮 5/5 exit 0、0 返工。没有出现"介词比名词/动词/形容词更难机审"的情况；相反，介词句是全五本里最短的（6–9 词），中文 11–14 字也全部落在 8–14 建议区间内（前四本按同一口径重数：coin 7–9 / pot 6–15 / whisper 7–9 / long 8–11）。
- 结构上唯一与前四本不同的地方：**不设词族页 → 门 3 / 门 4 不需要加参**。pot / long 两本因为词族页要多传 `--page-words` 与 `--family-words`，本书用标准原式就跑全绿——少一个参数，也少一处"参数传错就静默零校验"的风险（SKILL:902 记过这个坑）。
- 但有三处盲区对介词更危险：
  1. **遮挡到底有没有画成**：机审查不出。少了前景物或主体没被切断，画面塌成"她和沙发在一起"，所有脚本照样全绿 → 只能看成图（`05-gates.txt` 附·3 已逐页登记反向判据）。
  2. **词有没有贴错载体**（贴在前景物正面 vs 写在遮挡物之后的平面）：机审全绿，语义已从介词退化成名词。→ 载体已写死在【目标词图形化约定（位置介词专用写法）】里。
  3. **定义句**（`She is behind the sofa.`）：机审全绿，教材化。→ 见 §三末四条做法。
- **标题字数预算比前三本最宽松也最紧**：`Behind` 占 6 个字符位（whisper 的 `Whisper` 7、`Coin` 5、`Pot` 3、`Long` 4），词头较长；但介词标题天然短（"谁躲在后面呀"），本轮三条含词总长 6 / 4 / 4 字，都很松。

## 八、本轮不确定 / 未验证（不装懂）

1. **成图未跑**：写在木地板上的 `behind` 会不会被地板透视压扁、被前景物压住的那一线会不会压过字母主干、字距会不会被模型重排——只有出图才知道。所有门禁都是**文本代理**。
2. **「遮挡三件套」是推论，不是统计**：本轮只有 behind 一个介词样本。29 本语料里位置介词本有几本、它们怎么写画面、有没有做遮挡，**本轮未统计**（未跑）→ 按项目纪律只能登记为**假设 H-Prep-1**，**不得据此改 SKILL.md**。
3. **「机位锁定 30–45 度侧前」也是推论**：它来自本轮对三种机位读法的推演（§三表），**没有做读者实测**——4–5 岁孩子在这三种机位下的实际读法**未验证**。
4. **G3「适龄」是人工判定**：没有可查的 4–5 岁词汇量表，"`bind` 孩子会不会说"这条没有数据支撑（**未统计**）。`kind` / `mind` 的抽象度判断同理。
5. **「露出量由少到多、关系不变」这条链**是本轮的设计意图，4–5 岁是否能读出"露出更多也还是在后面"**未做读者实测**。若所有者认为反而会造成混乱（P7 露出最多），可把 P7 改成"只探出半个头"（但会与 P4 重复）。
6. **P8 三只大熊的"唯一答案"依赖尺寸关系**：熊要齐腰高、沙发靠背要刚好挡住坐在地上那只熊的下半身——这两个尺寸只在提示词里写死，成图上是否成立**未验证**；若熊太小或太大，答案会变成零个或多个。
7. **封面上书名被靠背压住一线**：`cover-design.md` 要求缩略图里能先读出书名。压一线的做法读感强，但**是否影响缩略图可读性未验证**；若成图书名难读，退路是把书名整体上移、只让"Behind"的字母下沿轻触靠背上沿。
8. **§二末的迁移示例（on / under / between / in front of）全是推论**，本轮一个都没实测。
