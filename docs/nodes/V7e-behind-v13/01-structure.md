## 二、位置介词本特有的三条结构决定（先说清，后面才好读）

### 1. 为什么全书机位必须**锁死在同一侧**（这是介词本与前三本最大的结构差异）

名词本的机位可以随便换——硬币转到哪个角度都还是 coin；动词本换个机位也还是「嘴凑近耳朵」；形容词本只要那条长东西还在画面里，long 就在。

**介词不行。** `behind` 命名的不是一件东西、也不是一个动作，而是**「谁挡在谁前面」这个前后顺序**。而 2D 画面里的前后顺序**全部由机位决定**：

| 机位 | 画面上看到的 | 孩子读成 |
|---|---|---|
| 她躲在沙发靠背正后方，机位在正前方 | 只看见一个丸子头浮在靠背上方 | 「一个人头在沙发上」——读不出前后 |
| 机位绕到沙发背面 | 看见她整个人靠着靠背坐着 | 「她坐在沙发旁边」——**behind 的证据消失** |
| **机位在沙发扶手一侧、约 40 度侧前** | 靠背剪影切断她的身体 + 靠背之后那块地板也看得见 | 「她在那件东西后面」——**遮挡关系成立** |

所以本表把机位写成**硬约定**（L4【站位与机位约定】）：全书机位固定在**遮挡物的一侧、与她同高、约 30–45 度侧前**，不绕到遮挡物背后、不俯拍、不换到她背后。这样每一页都同时看得见三样东西——**前景遮挡物的轮廓 / 被它切断的主体的那部分身体 / 遮挡物之后那块能放词的平面**。第三样是介词本独有的画面需求：**词得有一个「后面的位置」可以呆**。

### 2. 为什么每页都必须凑齐「遮挡三件套」

名词本画面元素可以少到一件（pot 只要那只锅）；形容词本必须多一件短参照；**介词本必须凑齐三件**：

| # | 三件套 | 缺了会怎样 |
|---|---|---|
| 1 | **前景遮挡物**（靠近镜头：更大、下沿更靠近画面下沿、轻微景深虚化、边缘清楚） | 缺了就没有「挡住」的来源，两个物体变成并排 |
| 2 | **被切断的主体**（她只露出丸子头 / 两只眼睛 / 半张脸 / 裙子一角 / 一只手） | 她整个人完整暴露 ⇒ 读成「她和沙发在一起」，读不出「她在后面」 |
| 3 | **同一条边缘下的词**（`behind` 这一行与她的身体用**同一条遮挡边缘**从后面露出来） | 词若贴在前景物正面，孩子学到的就是「沙发的名字」——正是名词本写法硬套到介词上的错 |

**反向判据（每页可自检）**：把前景遮挡物从这一页拿掉——她的身体和 `behind` 这一行就会同时完整暴露在空地上，这一页的 behind 就没有证据了。**一页只要拿掉前景物还照样成立，这一页就是废页。**

### 3. 为什么这一本**不设**词族拓展页（8 内页＝P1–P7 语境页 + P8 互动页）

- v13 的词族入选是**双条件**：共同词尾**拼写一致** + **发音同韵**，再叠加**适龄**、**可画**（SKILL:363、:1789）。
- `behind` 的拼写尾巴是 `-ind`（b-e-h-**i-n-d**），读音尾巴是同韵 /aɪnd/——**双条件本身是过的**：bind / find / kind / mind 与它拼写与音韵全对。
- 断在第三、四道闸（适龄 / 可画）：`kind`（抽象的「友善」）、`mind`（抽象的「介意/心思」）4–5 岁读不出、也画不出；`bind`（捆、绑）是书面低频词，不是孩子嘴里的话；**四个候选里只有 `find` 过闸**——「同族词至少 2 个」都不够，且 `find` 是动词、本书教学轴是「关系」，混进来会把唯一教学轴从「在后面」拉到「找东西」。
- 按 SKILL:1789「找不到合适候选时，以额外语境页补足」，**P7 改为第 7 个语境页**。逐条判据与逐词判定表见 `06-prep-path.md` §四。
- 结构上的收益：7 个语境页正好把「同一关系在三件遮挡物上 × 露出量由少到多」这条链走完（§三），不是为凑页。

## 三、动作链（先定动作链，再分页面）

```
纸箱后蹲好（只露丸子头 + 两只手扒箱沿）→ 站高一点（箱沿上露出两只眼睛）→
换到沙发背后蹲低（只剩半个丸子头）→ 从沙发边上探出半张脸 →
换到半开的门后（只露裙子一角 + 一只鞋尖）→ 从门后伸出一只手 →
回到纸箱后站起来探出上半身（"看见你啦"）→ 互动页：认出哪一只大熊躲在沙发后面
```

> 起点是「躲到一件东西后头」，收尾是「从同一件东西后头探出来」——同一件事（躲猫猫）从头做到尾，没有掉落、寻找、重来这类岔路。**露出量一路变化（少 → 多），`behind` 这个关系一路不变**——这正是介词本要让孩子看见的事：藏在后面不等于「看不见」，只要还在这件东西后面，就是 behind。

## 八、本书自定口径（登记为待裁定假设，不改任何规则）

> 这三条是「位置介词」这一类书需要的写法，v13 正文没有明写；本轮按 SKILL 的「先证后写」纪律只登记为**假设**，不据此改 SKILL.md。逐条论证与反例见 `06-prep-path.md`。

- **H-Prep-1 遮挡三件套**：介词的每一页，画面必须同时具备「前景遮挡物 / 被它的轮廓切断一部分的主体 / 同一条边缘下露出的词」；缺任一件，静态画面里的 behind 就读不出来（只剩两个并排的物体）。名词本没有这条压力（coin 只要那枚硬币在画面里），动词本没有（whisper 只要有嘴与耳朵的关系），形容词本有但只差一件（短参照）。
- **H-Prep-2 介词词形载体的「后面那片空间」**：目标词的图形化由**「词处在遮挡物之后的可见平面上、词行从遮挡物轮廓外露出来」**承担——词与角色共用同一条遮挡边缘。它既不是贴在物件正面的标签（名词本），也不是从人身上飘出的痕迹（动词本），也不是沿某个维度轴铺开的字（形容词本）——**承担语义的是词与被前景物之间的前后关系，不是词的位置、走向或字形**。
- **H-Prep-3 机位锁定 + 反义词/邻接介词零词形**：① 全书机位锁在遮挡物一侧 30–45 度侧前，一旦换到背面视角，behind 的证据就消失；② `in front of` / `on` / `under` 全书**一次词形都不出现**（不写、不贴、不进旁白），它们只作为画面里的位置存在（互动页的干扰项就是「完整可见」的位置）——与形容词本「short 不上文字」同源，但比它更严：介词本连反义**画面装置**都不需要，遮挡自证。
