## 附：五道门之外的几个人眼检查（机审查不到，本轮已逐页做，附独立命令输出）

机审只校「字在不在、形态对不对、块齐不齐、词数超没超」，下面四项是本轮**人工+独立命令**补的：

### 1. 封面书名三处逐字一致（`l4_presence_check` 不读书名）

```text
02 采用条: **本书采用：#1（谁躲在后面呀，Behind / "Who Is Hiding Behind?"）**
03 封面行: | 封面 | Who Is Hiding Behind? | 谁躲在后面呀，Behind |
04 封面旁白行: 旁白: 封面（谁躲在后面呀，Behind / Who Is Hiding Behind?）
04 封面提示词引号内书名: Who Is Hiding Behind?
```

三处逐字一致（含问号、Title Case 的 `Behind`）✅

### 2. 画面文字形态的负向断言（大小写 + 无围栏 + 无 URL + 封面无小写词形）

```text
BEHIND(全大写)                    = 0     ← 约定区禁全大写，0 处
behind(内页小写整词)              = 40
Behind(封面书名 Title Case)       = 10   ← 仅出现在封面旁白行 / 封面提示词 / 约定区书名引用
生图提示词行内混入完整英文旁白句   = 0     ← 提示词不搬旁白句，只搬整词
http / www. / notion.so 残留       = 0     ← 提示词纯净，无链接
三反引号围栏                       = 0     ← 纯文本，无围栏（04 是给生图方整块复制的纯文本）
封面提示词内的小写 behind          = 0     ← 封面只认 Title Case Behind
```

### 3. 遮挡三件套逐页核对（**这是介词本最关键的机审盲区**）

`l4_structure_check` 只断言「有 角色一致性 / 场景一致性 / 构图要求 / 目标词图形化 四个块名」，它**查不出**这一页到底有没有画成「前后关系」。逐页反向判据（把前景物拿掉，这一页还成立吗）：

| 页 | 前景遮挡物 | 被切断的主体 | 词与主体共用的那条边缘 | 拿掉前景物会怎样 |
|---|---|---|---|---|
| 封面 | 沙发靠背（横贯画面下半部） | 只露丸子头 + 两只手 | 靠背上沿同时压住书名下沿与她的头顶 | 书名落到空墙上、她整个露出来 ⇒ 关系消失 ✅ |
| P1 | 大纸箱（齐胸高） | 只露丸子头顶 + 两只扒箱沿的手 | 纸箱右侧棱 | 她整个人和词都暴露在地板上 ✅ |
| P2 | 同一个大纸箱 | 箱沿上只露两只眼睛 + 丸子头 | 纸箱左侧棱 | 同上 ✅ |
| P3 | 沙发靠背 | 只剩半个丸子头 | 靠背顶沿 / 圆扶手外缘 | 她蹲在空地上、词贴地 ⇒ 无遮挡 ✅ |
| P4 | 靠背与圆扶手交界 | 半张脸 + 一只手扒扶手 | 扶手下缘 | 她的半张脸无来源 ⇒ 读成"她在沙发旁" ✅ |
| P5 | 半开的门扇（竖直平面） | 只露裙子一角 + 一只鞋尖 | 门扇下缘 / 立边 | 她整条身子暴露在走廊 ✅ |
| P6 | 同一道门扇 | 只有一只手 + 一截橙袖 | 门扇立边 | 手悬在空中、没有"从后面伸出来"的来源 ✅ |
| P7 | 大纸箱 | 腰和腿被挡，上半身探出 | 箱沿/左侧棱 | 她站在空地上举手 ⇒ 无 behind 证据 ✅ |
| P8 | 沙发靠背（只有第三只熊被挡） | 第三只熊只露头 + 两耳 + 一只爪 | 靠背顶沿 | 三只熊都完整可见 ⇒ 题目没有唯一答案 ✅ |

### 4. 遮挡方向的近远证据（2D 里分辨"谁在前面"的全部家当）

四项近远证据（①前景物更大 ②前景物的接地投影落在后面的地板上 ③远景略柔、前景轮廓清楚 ④前景轮廓切断主体）**写在 L4 的【遮挡与前后关系约定】全局块里**；每页正文落地的是其中可逐页改写的两条——机位角度（30–45 度侧前，能同时看见前景物、被切断的主体、主体身后的那块平面）与「前景物的某条棱/边压在这行词的外侧留白上」。缺这四项中任何一项，两个物体就会在画面上塌成"并排"，孩子读成「她和沙发在一起」而不是「她在后面」——这一项**没有任何脚本能查**（`l4_structure_check` 只数块名），只能看出图，`06-prep-path.md` §七把它登记为未验证项。
