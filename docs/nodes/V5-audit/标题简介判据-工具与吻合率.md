# 标题 / 简介判据检查 · 工具与存量吻合率（2026-11-21）

## 为什么做

族1（简介）/ 族2（标题）此前**没有任何机检**——四个门禁只管旁白与 L4。而 v13 里这两族是有硬判据的
（标题含词/无括注/≤12 字；简介目标词 1 次/首句不写场景/单句 ≤30 字）。
本轮把它们固化成 `tools/title_intro_check.py`，并拿 29 本语料量「规则 vs 存量」的吻合率。

## 工具

```
python3 tools/title_intro_check.py --file <02-title-intro.md> --word coin   # 检查新稿
python3 tools/title_intro_check.py --corpus <corpus.json>                    # 统计存量
```
- 只做**文本判据**；简介语义（地基是否落在核心义项）无法机检，脚本已在输出里声明
- 退出码 0=全过 / 1=有违规 / 2=输入错误
