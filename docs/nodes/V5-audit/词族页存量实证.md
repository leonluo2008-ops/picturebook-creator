## 二、两个真问题

### G-Fam-1 · SKILL 的词族条款只写了「同尾族」，没写「首音族」

- SKILL 词族拓展页条款：「认读适龄的完整词族词……每个完整单词配小图，**不单列共同词尾**」——语义上默认是**同尾族**（rime）。
- 存量 B639（robot）实际用的是**首音族**（initial sound, `r-`），且提示词明写「不标任何共同词尾或拼读记号」，说明是**有意的另一种词族形态**。
- 这是**规则缺口**：首音族要不要承认？若承认，条款要写清「同尾族 / 首音族二选一，同一本书不混用」；若不承认，B639 属存量违规（不回填）。

### G-Fam-2 · 「词族拓展页」缺一个「至少两个词族词」的下限断言

- B261（cloud）页面类型写着「词族拓展页」，但整页只有 `clouds` 一个词，其余四朵云无字——**这不是词族页，是语境页**。
- 说明现有四个门禁都没查「词族页是否真的有词族词」（`l4_structure_check.py` 的 `--family-words` 是可选参数，没传就不查；存量回归时也没传）。
- **建议**：把「词族拓展页必须出现 ≥2 个同族词」做成硬断言（传了 `--family-words` 时自动要求 ≥2 个）。

## 三、对 V7d（long）的旁证

V7d 主动为形容词 `long` 用了词族页（`song / gong / strong`），并给出 6 条判据（拼写一致 / 同韵 / 适龄 / 可画 / 不抢教学轴 / 结构放得下）。本轮实测核验：

- 四词均在页面出现（long 42 次含提示词、song/gong/strong 各 8 次）
- 淘汰词 `among` 出现 **0** 次（符合它自己写的 G2「among 的 rime 是 /ʌŋ/，淘汰」）
- 页面类型序列正确（P7 = 词族拓展页）、五道门禁全绿

⇒ V7d 的「词族页由候选词能否过六项检查决定，与词性无关」这一结论，与本节统计方向一致（名词 33% 有、动词 25% 有、形容词这一本有——都不是词性决定）。

## 四、结论

- **词族页不是词性决定的**（存量：名词 7/21、动词 1/4、形/介 0/2；V7d 形容词本主动设页）
- **现存条款有两个洞**：首音族未定义（G-Fam-1）、词族页无「≥2 词」下限（G-Fam-2）
- 两者都**不能凭单本改规则**，登记待裁定；G-Fam-2 可先做成工具断言（属工具层，可做）
