## 二、方法教训（重要，写下来避免下次再错）

**块存在性不能靠「标签匹配」机检**，SKILL 的「六类信息」是**内容类别**，不是标签：

| 类别 | 在提示词里长什么样 | 能靠标签查吗 |
|---|---|---|
| 角色一致性 | `角色一致性: 严格以图像1为准（关键特征：…）` | ✅ 有标签 |
| 场景一致性 | `场景一致性: 锚点2 …` | ✅ 有标签 |
| 构图要求 | `构图要求: …80%…10%…背景…边缘` | ✅ 有标签 |
| 镜头类型+视角 | 散文，如「平视略低机位，镜头略仰向书名」 | ❌ 无标签，只能关键词启发（机位/视角/景别） |
| 场景描述 | 散文，主体/动作/表情/环境混在一句里 | ❌ 无标签 |
| 全局风格锚点 | 散文，如「3D 皮克斯动画电影级渲染风格…」 | ❌ 无标签，只能关键词启发（3D/皮克斯/渲染） |

**这也解释了结构门禁为什么只硬查 3 类**（`l4_structure_check.py` docstring 已写「覆盖六类中的 3 类」）：
另外 3 类没有稳定标签，硬查会产生大量假阴/假阳。

本次用关键词启发式实测：镜头语 9/9、风格语 9/9 —— **可用，但只能作为「有没有」的弱断言，不能作为「写得好不好」的判据**。
