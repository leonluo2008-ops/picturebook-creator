## 三、结论：假设应改写

**正确表述**（有统计支撑）：

> 词族页的**有无取决于「该词有没有适龄同尾词族」**，与词型（名/动/形）**无关**。
> - 动词里：`clap` 有 `-ap` 家族（cap / map / nap / tap）→ 有词族页（B267 实证）；
> - 动词里：`whisper`（-isper）、`squat`、`build`、`spray` 无适龄同尾群 → 无词族页；
> - 名词里：`pot` 有 `-ot`（hot/dot/cot）→ 有；`coin` 有 `-oin`（join/loin 不适龄）→ 无。

**所以 V7c 里那句「动作动词默认无词族页」不能写进规则**——若写进去，会与 B267 clap 冲突。

## 四、再修正一次（全词型统计后）

把「词型 × 是否有词族拓展页」在全 29 本上统计（只统计有页面类型字段的书）：

| 词型 | 有类型本数 | 含词族页 | 占比 |
|---|---|---|---|
| 名词 | 21 | 7（robot/pool/dollhouse/snowflake/omelet/cloud/star） | 33% |
| 动作动词 | 4 | 1（clap） | 25% |
| 位置介词 | 1（behind） | 0 | 0% |
| 形容词 | 1（slow） | 0 | 0% |

**结论再收紧**：
1. 词族页**不是词型决定的**（名词也只有 33% 有）；
2. 也**不是「有适龄同族词」就自动会用**——反例：`slow` 明明有适龄 `-ow` 家族（snow / blow / grow），存量那本（B292）却没用词族页；`pot` 有 `-ot` 就用了；
3. 与 SKILL 原文一致：**词族拓展页本来就是「可选」**，由作者按「有无适龄同族词 + 教学是否真有增益」决定。

⇒ 正确的表述是：**词族页是可选设计项，与词型无关，也不由家族存在性自动触发。** 任何「某词型默认有/无词族页」的说法都不成立。
