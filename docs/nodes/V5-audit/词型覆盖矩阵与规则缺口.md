## 三、两个被实测确认的规则缺口

### G-Adj-1 · 简介「词型分档」表缺**形容词档**（已确认）

SKILL 原文（L593–L600）只列三档：

| 词的类型 | 例 | 「第一感觉」必须落在 |
|---|---|---|
| 感官型 | towel / soap / soup / grape | 接触/入口那一瞬的质感 + 结果 |
| 动作型 | stack / bounce / climb | 动作做出来的结果 |
| 功能 / 社会型 | coin / wallet / key / ticket / money | 它是什么、用来干什么 |

**没有形容词档**。V7d（long）实测给出可用的第四档：

> **维度型**：义项是「两个端点的距离」。地基必须落在**两个端点**或**一次没完成的量**上；禁止拿具体长物件（长颈鹿脖子/大象鼻）反推定义（那是举例不是义项）。

### G-Prep-1 · 缺**关系型（位置介词）档**（已确认，同一张表）

V7e（behind）实测给出可用的第五档：

> **关系型**：义项是「两个东西的前后关系」，不是东西本身。地基必须落在**遮挡的后果**（看不见 / 只露一点 / 找到啦）；且必须把**遮挡方向词**写进首句，否则与 under 分不开。
