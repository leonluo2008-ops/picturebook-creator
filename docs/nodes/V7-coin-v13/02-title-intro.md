## 二、简介 3 备选（三条都落在「硬币是钱」：存 / 攒 / 买）

**A（功能起 · 存钱 → 攒 → 换东西）**
> 硬币存进小猪罐，攒着攒着，就能换一根棒棒糖。coin！

**B（身份起 · 这是钱）**
> 这枚圆圆的硬币是钱，能换来喜欢的东西。你想把它存进小猪罐吗？coin！

**C（结果起 · 攒够了）**
> 小猪罐装满了，硬币倒出来一大堆。这些硬币，够买什么呢？coin！

## 三、与旁白的衔接（检查结论）

定稿旁白（`03-narration.md`）的动作链是「这是钱 → 投进小猪罐 → 一天一枚攒起来 → 数 → 装满 → 够换 → 换到糖 → 找硬币」，与三条简介的落点全部对得上：

| 简介 | 对得上的旁白页 |
|---|---|
| A | P2 `I put the coin in the piggy bank.` / P3 `I save one coin a day.` → P7 `I buy a lollipop with my coins.` |
| B | P1 `This coin is money.` / P2 存进罐 |
| C | P4 `Count the coins with me.` / P5 `Ten coins fill my piggy bank.` → P6 `My ten coins buy a treat.` |

上一版（N6）的问题已在本版消除：N6 的旁白 P3「硬硬的、有点凉」与 P6「Plink!」、P7「摇一摇响」把触感与声音当成了教学落点，属于「副作用当地基」；本版旁白链与简介链都不再出现这类落点（详见 `06-vs-v6-diff.md`）。
