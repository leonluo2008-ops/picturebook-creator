# B620 · coin /kɔɪn/ · v13.0.0 领读模式 L2 页面结构表

> 依据：`picturebook-creator/SKILL.md` v13.0.0（分支 `refactor/v13-20261121`）「步骤L2:页面结构设计」+「步骤L1」+「边缘安全区规则」。
> 页码口径：封面 + 8 内页 = 9 页；封面不计入内页。

## 一、L1 锁定项（本表与 L3 / L4 全程照此执行）

| 项 | 值 |
|---|---|
| 核心词 | coin（**名词**，义项：**硬币 ＝ 钱**；与台账「词型」一致，全书只教这一个义项） |
| 目标年龄 | 4–5 岁 |
| 领读方式 | 整词跟读（不做拆音、不做词内停顿、不做字母名念读） |
| **第一感觉（v13 重定）** | **它是钱：存进小猪存钱罐、一枚一枚攒起来、攒够了能买东西。** 旧版「硬硬的、丢进罐子叮当响」是把副作用当地基，已按所有者 2026-11-21 判词推翻，本版不再沿用。 |
| 画风 | **严格跟随参考图**：3D 皮克斯动画电影级渲染（不沿用系列旧水彩锚点、不用 S16 治愈梦幻） |
| 主角 | 资产库「3D皮克斯小女孩」（使用定位＝制作基准＝严格按图）；外观只在 L4【全局设计约定】写一次 |
| 内页结构 | 8 页 ＝ P1–P7 语境页 + P8 互动练习页 |
| 页面类型词表 | 仅用 `认知页` / `语境页` / `互动练习页`（本书无 `词族拓展页`，理由见下） |
| 目标词复现 | 9/9 页出现完整目标词 coin（封面为书名形态 `Coin`），≥ 8 次硬要求满足 |
| 比例 | 封面 3:4；内页 16:9 |

**为什么没有词族拓展页**：coin 可拓展的 `-oin` 组只有 `join` / `loin` — `join` 是动词、`loin` 是肉类部位名，对 4–5 岁都不适龄。按 SKILL「无合适拓展时换语境页」处理，故 8 个内页 ＝ P1–P7 语境页 + P8 互动练习页。

**动作链（先定动作链，再分页面）**：
知道手里这枚是钱 → 投进小猪罐 → 一天存一枚、攒起来 → 一起数硬币 → 攒满十枚（罐子满） → 够换一份好吃的 → 拿硬币去小店换棒棒糖 → 互动页：四样圆东西里找出哪一枚是硬币。

> **全书没有任何一页把「叮当响 / 硬 / 凉 / 亮」当卖点**：这些属性只在画面上顺带存在（币面有金属反光很正常），不承担任何一页的教学落点，也不进简介地基。收尾落在「硬币换到了糖」，回应起点「这是钱」。

## 二、页面结构表

| 页码 | 页面类型 | 当页内容（教学落点） | 画面 |
|---|---|---|---|
| 封面 | **认知页** | 建立 Coin ＝ 硬币／钱 的第一印象；英文书名 `One Little Coin` 写在木牌上 | 客厅墙角：奶油白圆角木牌分两行写书名（上行小字 One Little / 下行超大 Coin）；木牌下沿一块窄搁板上坐着奶白陶瓷小猪存钱罐；小女孩在左下方踮脚把硬币投进罐背窄缝，硬币的暖光反在书名上，手势与视线把读者引向书名 |
| P1 | 语境页 | **这枚硬币是钱**——手里这枚能存起来，认读 coin | 平视近景：小女孩盘腿坐在地毯上，双手托着一枚硬币低头看；身侧地毯上放着一只空的小猪罐；膝前地毯立着一块奶油白小卡片，写小写整词 coin |
| P2 | 语境页 | **投进小猪罐**——钱要存起来，认读 coin | 平视中景：小女孩踮脚站在矮圆桌前，一手捏硬币对准罐背窄缝、一手扶桌沿；罐肚暖橙标签朝镜头，写小写整词 coin |
| P3 | 语境页 | **一天存一枚，攒起来**，认读 coin | 平视近景（俯角 ≤15°）：桌上浅木盘里并排躺着三枚硬币，她的手正把第四枚放进盘里；木盘前沿立着圆形小纸牌，写小写整词 coin |
| P4 | 语境页 | **一起数硬币**——攒了多少，认读 coin | 平视近景（俯角 ≤15°）：桌面上硬币排成一行，她站在桌边伸食指一枚一枚点着数；桌沿小木牌写小写整词 coin |
| P5 | 语境页 | **十枚硬币装满小猪罐**——攒够了，认读 coin | 平视中景：她双手把小猪罐抱在胸前，罐肚被硬币撑得圆鼓鼓，罐口窄缝还卡着最后一枚硬币的亮边；罐肚标签写小写整词 coin |
| P6 | 语境页 | **十枚硬币够换一份好吃的**——钱能换东西，认读 coin | 平视中景：她把桌上的硬币一枚一枚收进掌心，抬头看向画面右侧的小店方向；桌沿小立牌写小写整词 coin |
| P7 | 语境页 | **拿硬币去小店换棒棒糖**——钱真的换到了东西，认读 coin | 平视中景：小店柜台前她踮脚把硬币放进柜台的小木碟，另一只手已握住彩色棒棒糖；柜台立牌写小写整词 coin |
| P8 | **互动练习页** | 主动回忆：**找一找，哪一枚是 coin？**（只提问不解答） | 桌面近景（俯角 ≤15°）：四样圆形小物件并排——带两孔的木质纽扣 / 湖蓝金属瓶盖 / 圆形小饼干 / 一枚硬币；她站在桌边抬手指向桌面；桌沿小木牌写小写整词 coin |

## 三、每页互动设计（可跟读 / 可指读 / 可互动）

| 页码 | 互动落点 |
|---|---|
| 封面 | 指一指书名里的 Coin，跟读两遍 |
| P1 | 指一指她手里那枚 coin，跟读 coin |
| P2 | 跟读整句，指一指硬币要去的投币缝 |
| P3 | 数一数盘里有几枚 coin（三枚），跟读 coin |
| P4 | 和孩子一起出声数 1–10，指一指桌面上的 coin |
| P5 | 摇一摇想象罐子有多满，跟读整句 |
| P6 | 问一句「你想换什么呀？」，再跟读 coin |
| P7 | 指一指柜台上的 coin 立牌，跟读整句 |
| P8 | **只提问不解答**：找一找，哪一枚是 coin（唯一答案＝最右那枚；纽扣、瓶盖、饼干都不是） |
