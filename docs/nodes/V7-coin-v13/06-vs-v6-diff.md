## 一、核心差异（5 条，按影响排序）

### 1. 词义地基：上一版旁白链仍在「触感 + 声音」上，本版整链改到「钱」

| | N6（上一版） | V7（本版） |
|---|---|---|
| L1 第一感觉（`01-structure.md`） | 「硬硬的小圆片捏在手心，丢进存钱罐会『叮当』响一声，孩子想再丢一次」 | 「它是钱：存进小猪存钱罐、一枚一枚攒起来、攒够了能买东西」 |
| 旁白链 | 滚来 → 捡起 → **捏一捏硬、凉** → 拿到桌前 → 对准 → **叮当** → **摇一摇响** → 指一指 | 这是钱 → 投进小猪罐 → 一天存一枚 → 一起数 → 十枚装满 → 够买糖 → 换棒棒糖 → 找哪一枚 |
| 教学落点里的副作用页 | 2 页（P3 硬度/凉、P6 拟声）+ P7 摇响 | 0 页（币面反光只作画面细节，不承担教学落点） |

**为什么改**：v13 把「功能／社会型」词（coin / wallet / key / ticket / money）的第一感觉明确锁在「**它是什么、用来干什么**」，声音、颜色、硬度这类副作用不许当地基；判据是替换性检验——「硬硬的、凉凉的、叮当响」换成 button / bead / 瓶盖全部成立 ⇒ 不合格。上一版 `02-title-intro-brief.md` 已经写了 v2 的词义改正，但**旁白与 L4 一行没动**（该文件第 49 行原话「旁白与 L4 无需改动」），所以上一版内部是自相矛盾的：简介说「钱」，旁白教「硬、凉、叮当」。本版把四份文件（01/02/03/04）统一到同一口径。

### 2. 简介三条：三条全部落在「存 / 攒 / 买」，并逐条写明替换性检验

| | N6 | V7 |
|---|---|---|
| A | 「把一枚**硬硬的**硬币塞进小猪罐，它就住进去了。攒够了能买什么呢？coin！」 | 「硬币存进小猪罐，攒着攒着，就能换一根棒棒糖。coin！」 |
| B | 「这枚圆圆的小硬币是钱，能换东西，也能存起来。你想把它存进罐子吗？coin！」 | 「这枚圆圆的硬币是钱，能换来喜欢的东西。你想把它存进小猪罐吗？coin！」 |
| C | 「一枚，两枚，三枚……存进罐子里的硬币越来越多。数到几啦？coin！」 | 「小猪罐装满了，硬币倒出来一大堆。这些硬币，够买什么呢？coin！」 |
| 是否带触感（副作用） | A 带「硬硬的」 | 三条都不带 |
| 收尾落点 | A 落在「买」、B 落在「存」、C 落在**数数**（不是钱的功能） | A 落在「换到糖」、B 落在「换东西/存」、C 落在「够买什么」 |

**为什么改**：三条都要过替换性检验，且收尾答案要扣住本本义项。N6 的 C（数到几啦）答案落在数量而不是「钱能买东西」，且 A 又把「硬硬的」带回简介；本版三条都从「存→攒→买」这条钱的功能链上长出来，并把「换成 button / bead / 瓶盖都不成立」写进 `02-title-intro.md` 的验收表（逐条给替换后的原句）。

### 3. 标题 #1：去掉「亮亮的」（光泽＝副作用）

| | N6 | V7 |
|---|---|---|
| 标题 #1 | 亮亮的小硬币，Coin / **One Little Coin** | 一枚小硬币，Coin / **One Little Coin** |
| 起法 | 状态（但用光泽词） | 状态／直给（中性） |
| 标题 #2 / #3 | 捡到一枚硬币，Coin / I Found a Coin；硬币存起来啦，Coin / Save the Coin | 硬币存起来，Coin / Save the Coin；硬币换糖吃，Coin / A Coin Buys a Treat |

**为什么改**：v13 要求标题「只从这本书真实拥有的动作、场景里长出来」且围绕词义点题；「亮亮的」是光泽（副作用），和本版「钱」的地基不同源。英文书名保留 `One Little Coin` 是为了系列连排不跳。三条备选仍是三种起法（状态／动作／功能），不共骨架。

### 4. L4 封面：书名改成「整串引号包裹」+ 封面概念接到「钱」上

| 项 | N6 | V7 |
|---|---|---|
| 书名引号 | 拆成两段：`"One Little"` / `"Coin"`（脚本核对：「封面书名引号包裹 = **False**」） | 整串：`"One Little Coin"` 分两行书写（脚本核对：**True**） |
| 「目标词图形化」块 | 封面页无此块（只在场景句里写「核心词 Coin 是场景里的发光焦点」） | 封面页有独立的「目标词图形化:」块，写明核心词是书名载体上的主视觉、不是顶部大字、不是小字幕 |
| 封面概念 | 女孩双手举起硬币，反光打在木牌上 | 木牌 + 下沿窄搁板上的小猪存钱罐 + 女孩踮脚投币，硬币暖光反在书名上 → 封面第一眼就是「钱→存起来」 |
| 场景锚点 | 3 个（客厅／矮桌+罐／桌面近景） | **5 个**（+ 街角小店柜台、+ 封面墙与木牌） |

**为什么改**：SKILL「封面设计标准」要求「英文标题必须用引号包裹才渲染，正确写法是 `英文标题"<英文标题全文>"`」，v13 的块存在性也要求每页都有「目标词图形化」信息。上一版把书名拆成两段引号，等于让模型分两次渲染书名，且封面页缺目标词图形化块（`参考图约定`/`构图要求` 都在，只缺这块）。本版把书名合成一串（分两行书写、含 Coin 的一行最大），并补上封面页的目标词图形化块。封面概念也从「举币」改成「投币进罐」——封面这一眼就要说出 coin 的用途，而不是展示金属反光。

**为什么改**：v13 要求每页「写出实际入画的完整词、载体和排法」，并提醒特写页也要给目标词落脚载体。上一版 P4–P7 连续四页都靠「罐身标签」带词，翻页下来目标词的呈现变成一个静态标签，画面变化被吃掉；本版按当页场景各给载体（地毯卡片 / 罐标签 / 木盘纸牌 / 桌沿木牌 / 柜台立牌），P8 保留桌沿木牌是因为互动页需要一块不干扰四样干扰物的标识牌。

## 三、一句话总结

上一版（N6）的**格式层**（页数、比例、类型、词数、构图三要素、角色锚定、无 Pn 前缀）已经基本是 v13 的样子——因为它是重构过程中按 v12/v13 草案做的；真正没跟上的是**语义层**：词义地基还留着「硬/凉/叮当/摇响」，简介 A 把「硬硬的」带回来，旁白链有两页专门教副作用，封面把书名拆成两段引号、且没有「目标词图形化」块。本版（V7）把语义层整体重做（钱的功能链：存 → 攒 → 数 → 满 → 够 → 换），并从 L4 的封面、锚点、载体分布上把「钱」这件事贯穿到画面提示词里。
