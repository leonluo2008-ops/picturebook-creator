# B626 · pot · v13 词族拓展页路径实测报告

> 本轮目的：补测 v13.0.0 里尚未被验证的一条路径——**词族拓展页**。
> 结论先给：**词族拓展页能产出、能过现有四道门（四条 exit 0），但机审在这条路径上有两处无断言区**（伙伴词的「在不在」、目标词图形化块），已用临时断言补上并把证据留档（`05-gates.txt` 补充门禁 0 与补充探针）。

## 一、v13 口径下的词族拓展页怎么写（本轮的答案）

本页是 **P7**（固定页位 P(n-1)，n=8；P8 是互动练习页），页面类型行只写 `词族拓展页`（不带 `Pn` 前缀）。

### 1. 每个词族词的四元定位（位置 / 载体 / 颜色 / 可读性）

| 词 | 画面位置 | 入画载体（小图） | 词的载体与颜色 | 可读性做法 |
|---|---|---|---|---|
| **pot** | 2×2 网格 **左上** | 带双耳与玻璃盖的浅口小锅（与全书同一只锅，跨页外观一致） | 同一块小木牌的**下沿**写小写整词 `pot`，**暖橙单色**字面 | 暖橙↔奶油白牌底高对比；整词一行连写、字距自然；单色字面、不逐字母分色 |
| **hot** | 2×2 网格 **右上** | 一只盛着汤的奶油白小碗，碗口上方三条柔和上升的热气曲线 | 牌下沿写 `hot`，**湖蓝单色** | 热气曲线只占上半图区、不压字；湖蓝↔奶油白高对比 |
| **dot** | 2×2 网格 **左下** | 一颗又大又圆的**玫红圆点**（就是 dot 本身） | 牌下沿写 `dot`，**玫红单色** | 圆点属图区、文字属牌下沿，两层分开不打架；同色系（圆点=字色）强化「词↔图」配对 |
| **cot** | 2×2 网格 **右下** | 一张带竖栏杆的浅木色婴儿小床，床头挂一只小布熊 | 牌下沿写 `cot`，**深橄榄绿单色** | 小床画成「有栏杆的床」而非普通床，避免与 dot 的圆、hot 的碗混形；深绿↔奶油白高对比 |

**排布与可读性的硬做法（都写进了提示词）：**

- 每块小木牌 = **上半小图 + 下沿整词**，四块牌**等大**、**2×2**、**均匀空隙**、**不重叠不互相遮挡**；四词**同字号**。
- 四个词全部**小写**（`pot` / `hot` / `dot` / `cot`）——独立展示的词标签取词典词头形态（SKILL:881）。
- **不单列共同词尾** `-ot`，**不逐字母分色**、不按音节/词尾分色（SKILL:870、:886）——四个词各自是「完整的一个词」，类比靠并置，不靠把词尾拎出来。
- **四词四色**是刻意设计：四个词并排时，同色会让「哪个词配哪张小图」变难；四色把「词↔图」的配对视觉化。这是**本轮自定口径**（v13 没有规定多词是否必须同色，见缺口 G7）。
- 温度/热气只作为 hot 的**小图内容**存在，不做整页的视觉主角，也不承担任何教学落点。

### 2. 它与核心词的关系

- **pot 是核心词本体，同时是本页四个词族词之一。** 它在这页的身份是「词族成员」，不是被豁免掉的对象——四个词都要在画面里，它就照常以小锅小图 + `pot` 整词入画。
- **hot / dot / cot 是只在 P7 出现一次的伙伴词**：P1–P6 六个语境页里它们的戏份压到零（SKILL:739 的口径），这样孩子合上书记住的仍是 pot。
- **P7 是全书唯一「词形相似、词义不同」并置的地方**，承担词族页的固有教学任务：认读同一个 `-ot` 家族里的四个完整词。它与「一页一概念」不冲突——本页的**一个概念**是「同一个词尾能长出不同的词」，而不是四个独立概念。
- **教学序列**：P1–P6 整词跟读 pot 一个词 → P7 把家族另外三个词端出来做类比 → P8 回到 pot 本体做检索（找一找哪一个是 pot）。词族页正好卡在「认完」和「考」之间。
- **动作/画面连得上**：P6 的锅已经在餐桌上，P7 回到料理台、台面清空只留四块小牌（场景锚点 1），不引入新房间、新角色。

## 二、本轮实测发现的 v13 规则缺口（逐条带证据）

> 证据口径：SKILL.md 与三个门禁脚本的**实际代码行**、以及本轮 4 条门禁 + 3 个探针的**实际输出**（见 `05-gates.txt`）。

### G1 · 核心词本身属于词族时，豁免条款该怎么落地，SKILL 未明写

- 现象：pot 既是核心词，又是 pot/hot/dot/cot 的一员。SKILL:901 的豁免句只在括号里给了 `ball / tall / wall` 一例（那个例子里 ball 也恰是核心词），但**没有一条规则说「词族页是否必须把核心词本身列为词族成员」**。
- 后果：如果作者把词族页写成 hot/dot/cot 三个词（不列 pot），画面就真的没有核心词，豁免成立、机审也不会报；但教学上就丢掉了「pot 自己和它的家族」这层类比。
- 建议口径：补一句「核心词本身属于该词族时，词族页应把核心词一并列为词族成员（配小图），此时豁免退化为『不额外承担核心词的独立入画要求』」。本轮已按这个口径写（pot 列为左上）。

### G2 · 伙伴词在机审里**零覆盖**（最硬的一条）

- 现象：`l4_presence_check.py` 对词族页 `continue`（:87-90 跳过 + 点名），而 `--word` 词集是**逐页无差别套用**的。于是：
  - **不传** hot/dot/cot → P7 的三个词在「存在性」门禁里完全没被检查；
  - **传了** hot/dot/cot → 除 P7 外每一页都报「场景描述段未出现目标词」（探针 B 实测 **24 处误报、EXIT=1**）。
  两条路都不通，所以词族页的「每个词族词都在位」只能人工核对（SKILL:901 也只说「改按人工核对」）。
- 同理 `l4_case_check.py`：只传 `--word pot` 时，P7 上 hot/dot/cot 的大小写形态也无人校验（探针 A 证明四词一起传可以过、形态门禁支持逐词追加，但**标准命令只传核心词**）。
- 建议：`l4_presence_check.py` 增 `--page-words P7=hot,dot,cot`（只在指定页断言），或单开 `l4_family_check.py`：①取 `页面类型=词族拓展页` 的页；②断言页内列出的每个词都在场景段；③断言没有单列词尾。本轮自建临时断言（`05-gates.txt` 补充门禁 0，四个词各命中 3 次、无 `-ot` 单列），但**这条断言不属于交付门禁，谁都不跑就等于没有**。

### G3 · 结构门禁对词族页的豁免，比 SKILL 正文更宽

- 现象：`scripts/l4_structure_check.py:92`
  `has_word_block = ("目标词图形化" in pr) or (args.word.lower() in pr.lower()) or is_family`
  最后一个 `or is_family` 让词族页**直接通过**「目标词入画」这一项。而 SKILL:837 要求领读模式**每一页**都有「目标词图形化」块（词族页只是把对象换成词族词）。
- 后果：词族页完全不写「目标词图形化」块也能过结构门禁（P7 的 ✓ 有一半是白送的）。本轮按 SKILL 写了该块，机器抓不到缺。
- 建议：`is_family` 这一支改成「必须出现『目标词图形化』」而不是「豁免整项」——词族页要豁免的是**核心词字面**，不是**图形化块**。

### G4 · 词族页英文列形态（小写词表 vs 完整短句）未定一

- 现象：`tools/grammar_check.py:57` 对 `page == 'P7'` 豁免「英文句首应大写」，这意味着**小写开头的词表**（`pot hot dot cot`）也是被允许的形态；而 SKILL:579 又说「旁白带读完整词，可用自然的短句串联」。两种形态都合法，规则没说该选哪种。
- 后果：不同作者会产出两种 P7 英文列，系列内不统一；且词表形态下「双语同现」检查更容易误判。
- 建议：明写一种——倾向「完整短句」（首字母大写），与本书一致；若允许词表，就在 SKILL 里注明脚本豁免对应词表形态。

### G5 · 词族页主角是否必须入画，未规定

- 现象：块存在性要求**每页**都有「角色一致性」（结构门禁硬查，P7 的 ✓ 靠这条），但词族页的教学载体是「词 + 小图」，主角完全可以不出现在这一页。
- 后果：主角不出现时，「角色一致性」块要么写成与画面不符的空话，要么整页违反块存在性。
- 建议：明写「词族页主角可入画也可不入画：入画则角色一致性块照写；不入画则本页不出现角色，角色一致性块改由『道具一致性（小锅等）』承担，并同步调整结构门禁」。
- 本轮选择：**让主角入画**（站台前的矮脚凳上，抬手依次指四块小牌）——同时解决了块存在性和「可指读」互动落点。这个选择本身也是 v13 没规定的自由项。

### G6 · 每页 10 词硬上限 与 词族词数量 的叠加口径缺失

- 现象：词族页天然要放「词族词 × N + 引导句」。pot 家族恰好 4 个适龄词，本页 8 词（4 + 4）刚好落在建议线内；但若某核心词的词族有 6 个适龄词，6 + 引导句就顶到 10 甚至爆表。
- SKILL 只写了「找不到合适候选时以额外语境页补足」（:1789），**没写「候选太多时选几个 / 怎么选」**。
- 建议：补「词族词最多取 4–5 个，按可画性排序取前几个；词族页英文词数仍受 ≤10 约束」。

### G7 · 词族页「多个词怎么配色」没有口径

- 现象：SKILL:870 只说「可用易读的装饰色」、:886 只说「颜色服务画风与可读性、避开按字母/音节/词尾分色」，**没说同页多个词必须同色还是可以各词一色**。
- 本轮选择：四词四色（暖橙/湖蓝/玫红/深橄榄绿），理由是四词并排时颜色承担「词↔小图」的配对提示；每词仍单色字面、不逐字母分色。
- 建议：补一句默认口径（建议默认「同页可用不同颜色区分词↔图配对，但每词必须单色整词」），否则下一次作者会自由发挥成「彩虹逐字母」。

## 三、本轮未验证 / 不确定的地方

1. **成图验收未做**：本报告只到 L4 提示词层。四块小牌的「小图 + 整词」是否真的被画出来、四块牌会不会互相遮挡、`cot` 的小床会不会画成普通床——都要等出图后人工核。机器门禁全是**文本代理**。
2. **`cot` 的适龄用词**：4–5 岁中文说「小床 / 宝宝床」，我用「小床」；旁白中文里没有出现「婴儿床」这种书面词，但「cot」在英式英语里更常指婴儿床——**用哪个中文词更贴目标读者，属人工判断，未验证**。
3. **P7 八词是否仍在 4–5 岁跟读能力内**：四个词 + 一句引导语，出声读过一遍是顺的，但没有真实读者测试。
4. **「四词四色」的教学增益**：配对提示是设计意图，**未做读者实验**，只能说符合「颜色服务可读性」的口径，不能说它比同色更好。
5. **`05-gates.txt` 里的补充门禁 0 是临时脚本**（`%TEMP%\pot_family_check.py`，不进项目仓）：它能被别人按同样口径复现，但它**不会在下次交付时自动跑**——这正是 G2 要求把断言固化进脚本的理由。
