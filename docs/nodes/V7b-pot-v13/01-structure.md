**动作链（先定动作链，再分页面）**：
找到小锅（这是我的小锅）→ 往锅里倒水 → 把胡萝卜和土豆放进锅 → 盖上锅盖 → 锅里煮好一锅汤 → 从锅里舀汤到碗里 → **词族页：pot / hot / dot / cot 四个词各自配小图** → 互动页：四样厨房小物里找出哪一个是 pot。

> 收尾回应起点：起点是「这是我的小锅」，收尾是「这一锅汤就是它煮出来的」（互动页仍以 pot 本体收束）。全书没有任何一页把「咕嘟响 / 烫 / 沉 / 铁」当教学落点。

## 三、页面结构表

| 页码 | 页面类型 | 当页内容（教学落点） | 画面 |
|---|---|---|---|
| 封面 | **认知页** | 建立「pot ＝ 煮东西的小锅」第一印象；英文书名 `My Little Pot` 写在奶油白圆角木牌上 | 厨房：浅湖蓝墙前料理台靠墙立着书名木牌（两行，下一行 Pot 超大）；木牌前方台面上放着带双耳玻璃盖的小锅，锅边露出半根胡萝卜与一块土豆；小女孩踩原木矮脚凳，一手扶木牌、一手捏胡萝卜送向小锅，视线与手势引向书名 |
| P1 | 语境页 | **这是我的小锅**——先认出锅本体，认读 pot | 平视近景：她踩矮脚凳，双手把锅从台面中间往前挪到台沿，锅身正对镜头；锅身贴暖橙小标签，写小写整词 pot |
| P2 | 语境页 | **往锅里倒水**——锅是装东西的容器，认读 pot | 平视近景：她双手斜拎浅湖蓝小水壶往锅口倒水，水面刚积起一层；台面靠墙立奶油白小木牌，写小写整词 pot |
| P3 | 语境页 | **把胡萝卜和土豆放进锅**——东西进锅才煮得成，认读 pot | 平视近景（俯角 ≤15°）：浅色木菜板上有切好的胡萝卜块与土豆块，她捏一块悬在锅口上方；菜板前沿立小卡片，写小写整词 pot |
| P4 | 语境页 | **盖上锅盖**——盖好才煮得熟，认读 pot | 平视中景：她双手捧玻璃锅盖对准锅口放下，身体略后仰；台沿立小木牌，写小写整词 pot |
| P5 | 语境页 | **锅里煮好一锅汤**——放进去的东西变成了汤，认读 pot | 平视近景（俯角 ≤15°）：锅盖被掀开一半，汤是淡橙黄色、浮着软软的胡萝卜和土豆，锅口升起几缕柔和热气；锅身写小写整词 pot |
| P6 | 语境页 | **从锅里舀汤到碗里**——锅里的东西成了能喝的一碗，认读 pot | 平视中景：小锅端到圆木餐桌、垫在藤编餐垫上，她双手握长柄木汤勺舀汤移向奶油白汤碗；桌沿立小木牌，写小写整词 pot |
| **P7** | **词族拓展页** | **四个词族词各自认读：pot / hot / dot / cot**（每词一图，不单列词尾） | 平视近景（俯角 ≤15°）：奶油白台面上 2×2 四块奶油白圆角小木牌，每块＝上半手绘小图 + 下沿一个小写整词：左上小锅=pot（暖橙）/ 右上冒热气的汤碗=hot（湖蓝）/ 左下大圆点=dot（玫红）/ 右下带栏杆的小床=cot（深橄榄绿）；她踩矮脚凳，抬手依次指向四块牌 |
| P8 | **互动练习页** | 主动回忆：**找一找，哪一个是 pot？**（只提问不解答） | 平视近景（俯角 ≤15°）：台面从左到右并排——木头锅铲 / 厚棉隔热手套 / 一颗鸡蛋 / 带双耳玻璃盖的小锅；她抬手指向台面；台沿立小木牌，写小写整词 pot |

## 四、每页互动设计（可跟读 / 可指读 / 可互动）

| 页码 | 互动落点 |
|---|---|
| 封面 | 指一指书名里的 Pot，跟读两遍 |
| P1 | 指一指她手里那只小锅，跟读整句、跟读 pot |
| P2 | 看水柱落进锅口，跟读「倒水」，跟读 pot |
| P3 | 问一句「还要放什么呀？」，再跟读 pot |
| P4 | 学她把锅盖「轻轻放」，跟读整句 |
| P5 | 凑近闻一闻想象的热气，跟读整句（**不把热气当教学落点**，只在画面上顺带存在） |
| P6 | 数一数勺里有几块胡萝卜，跟读 pot |
| **P7** | **逐块指认**：指哪块牌就读哪个词（pot / hot / dot / cot），四个词各读一遍再连读 |
| P8 | **只提问不解答**：找一找，哪一个是 pot（唯一答案＝最右那只有双耳和玻璃盖的锅；锅铲、隔热手套、鸡蛋都不是） |
