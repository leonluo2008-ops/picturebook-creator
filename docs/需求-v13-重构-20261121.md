## 所有者裁定记录（2026-11-21 · v13.1.0）

> 来源：所有者对本项目「待审查清单」第二节的批注原话（Notion 页 `41fa3f92-69aa-8113-bd9fea5824ce00bc`，2026-11-21）+ 同轮对话原话。本节为**已裁定**，与旧版并列时以本节为准。

### R1 词族页英文列形态（G4）

- **用户原话**：「肯定是朗读节奏最优先啊，本来我们做的题材都是单词，你去给我主推短句干什么」
- **裁定**：词族拓展页英文列**用词表**（逗号分隔单词，如 `Pot, hot, dot, cot.`），**不写句子、不加引导句**。朗读节奏优先于句子完整性。

### R2 词族词数量（G6）

- **用户原话**：「最多 4 个，常规2-3个」
- **裁定**：词族词**常规 2–3 个、最多 4 个**（含核心词本身）。

### R3 L4 旁白行形态（G8）

- **用户原话**：「旁白必须是「英文 / 中文」，你特么哪只眼看到纯英文了？」
- **裁定**：**L4 的 `旁白:` 行必须「英文 / 中文」双语**（英文在前、` / ` 分隔）；纯英文行不合规。
- **订正**：agent 此前把「新稿实测是纯英文」当成规则描述写进清单，属**把个例当常态**；该说法作废，实测的 5 本 V7 系产物本身就是不合规样本。

### R4 其余未批注项

- **用户原话**：「其他我没有批注的，可以按你的推荐执行。」
- **裁定**：G1/G5/G7/G9/G-Fam-1/G-Adj-1/G-Prep-1 按 agent 推荐执行；D1/D3 按保守口径登记为**可选自检工具**（不进缺一不过）；D2 三道门加 `--expect-pages`。
