## 1. 交付形态（硬）

1. 整本提示词是**一个连续代码块**，开头一个围栏、结尾一个围栏，代码块外无任何文字。
2. 制作端**整块复制**使用；因此代码块内不许出现链接、URL、取图说明、字号分隔线、第二对围栏。
3. 每页一条记录，页与页之间**一个空行**。

## 2. 段落骨架（四必备 + 两按需）

```
指令头（4 行，固定句式）
【全局设计约定】（9 字段）
【全书文字与配色】
【主要场景锚点】（3–5 个）
【参考图约定】（有参考图时必备）
【站位与机位约定】（按需）
逐页记录 × N
```

### 2.1 指令头（4 行）

1. 任务定义：提取生图提示词，按封面、P1…Pn 顺序生成。

2. 禁令：旁白只供领读参考，中文翻译与内页英文整句不入画；封面只渲染正式英文标题；内页目标词**按本页旁白需要出现**。

3. 文字图形：目标词是大型彩色拼贴图形，整词连写、自然字距，作为插画的一部分，不作为小字幕。

4. 一致性：每次生成前回看已生成页面，保持同一角色 / 同一场景 / 一致画风。

### 2.2 【全局设计约定】9 字段

`目标单词` / `中文释义` / `目标年龄` / `画面风格`（**写到材质级**：技法材质 + 色彩氛围）/ `文字风格` / `主角外观` / `动作约定` / `站位约定` / `机位约定`

- `动作约定` 写"这只角色能用哪些部位做哪些动作"，写正向可画的描述。
- `机位约定` 写同高平视或微俯、俯仰上限（10–15°）、不俯拍头顶。

### 2.3 【全书文字与配色】

- 目标词按页需要出现〔已批准，`rules.md` §0 / `flow.md:183`〕；**不出现的页只画场景、角色与物件本身，画面上没有任何英文字母**。
- 出现时用**独立装饰载体**（画面一角的彩色拼贴字 / 装饰性字母积木 / 环境装饰牌），**整词只出现一次**〔假设 H#：仅 B615、B628 两本样本，见 `rules.md` §10〕。
- **载体纪律**〔已批准〕：目标词不得印在推动情节的**叙事传递类**道具上（纸条、署名处、礼盒缎带、信封、门牌）。
  - 〔待裁定·边界〕**目标物本身**（本书的 `pen` 之于笔）是否豁免？定稿 `L4_pen_v4.txt:50` 写的就是「笔杆侧面印 pen」，且所有者已出图确认可用——按字面禁会误杀这个正确做法。
- 故事道具保持素净：纸条上只有署名与箭头，缎带只有纹理。
- 无中文入画、无音标、无拆字。

### 2.4 【主要场景锚点】

3–5 个，每个写「场景名：外观细节 + 与其它锚点的空间关系」；同一间屋子只立一个锚点。

### 2.5 【参考图约定】（有图时必备）

- 逐个声明：图像1 = 角色A定妆图（一致性最终依据）、图像2 = 角色B定妆图、图像3 = **比例尺场景图**（只用于锁相对大小与笔/纸比例）。
- `外观特征:` 每个角色 2–4 个最易画错项，串成固定文本，逐页「角色一致性」行复用。
- `排除项:` 定妆图的浅底与脚下投影不入书；比例尺图里的家具/书本/绿植等道具一律不入书。
- 比例：相对大小与道具比例以图像3为准，**文字不再另写尺寸倍数**（有图就别用文字压）。

## 3. 逐页记录格式（字段顺序固定）

```
页序: 封面 | P1 …
旁白: 封面（中文标题 / 英文标题） | 内页：英文 / 中文
比例: 3:4（封面）| 16:9（内页）
页面类型: 认知页 / 语境页 / 词族拓展页 / 互动练习页
入画英文: ["…"] | []
生图提示词: 机位 → 主体与动作 → 环境 → 风格 → 角色一致性: → 场景一致性: → 构图要求:（同段末）
```

- `构图要求:` 是 `生图提示词:` 的**末段分句**，不单独占行；每页恰一次；三要素齐全：80% 安全区 / 四边各留约 10% 净空 + 危险点点名 / 背景自然铺边。
- `入画英文:` 与 `页序:` 都**已被 `l4_structure_check.py` 解析**（2026-11-23 实测：`入画英文` 作逐页目标词判据，空数组页放行；`页序` 作页界标记，缺失报违规）。但它们只校**格式与声明层**——画面里有没有那个词、载体是否恰当，仍只能人工核。
  > 订正：本文初稿写"这两个字段没有脚本解析"，是错的；当时写稿早于脚本升级。


## 4. 一致性策略（参考图优先）

| 情形 | 写法 |
|---|---|
| 有参考图〔待裁定：是否升为默认路径〕 | 【参考图约定】+ 逐页 `严格以图像1为准（关键特征：…）`；页内不重复长外观 |
| 无参考图（降级） | 每页必写统一外观描述 |


参考图**按需补，不默认强派**〔已批准 2026-11-23〕：

- 先清点手里已有什么；缺角色定妆才补定妆图，缺相对大小/道具比例依据才补比例尺图；已有可用的直接复用。
- 图像编号按实际张数写（图像1、图像2…），不固定三张；交给生图端时按提示词出现顺序挂。

需要补图时的两类：

1. 角色定妆图：三视角（正面 / 3/4 侧 / 背面）横向并排、等大、脚底对齐；纯浅底；只画角色本身（空手、无道具、无文字、无边框、无投影）。
2. **比例尺场景图**：两个角色 + 目标道具（如笔与纸）同框，用画面锁定相对大小与道具比例；允许有环境道具，但只作比例参考、要写进排除项。


参考图验收四判据：视角一致性 / 结构硬伤（如人手、比例崩）/ 多余物件（文字、边框、投影、渐变底）/ 画风质感（材质是否与书一致）。

## 5. 写法纪律

1. **不用否定式的画面描述**：「不画人手」会被反向执行成"画人手"。改写成正向：「四肢是四趾短爪，握笔时两只前爪一左一右夹住笔身」。
   - 允许正向表达的"渲染开关"：「该页没有任何英文字母」（不要写成"不要渲染英文"）。
2. **不用相对指代**：「另一只爪」「左边那个」依赖前文，模型看不到。
3. **一页一概念**：只教目标词，不夹带第二个新概念。
4. **封面**：英文标题必须用引号包裹才会被逐字渲染；标题要与场景共同设计（字母当装置 / 当环境），不是"顶部横幅 + 大字"。
5. **互动页**：给出可找的候选物与干扰物，干扰物与目标物同大小同清晰度，画面不画答案圈、箭头指示、勾号。

> 注意：第 5 条「不画答案圈」按第 1 条改写为正向后落在提示词里：「所有候选物同样大小、同样清晰度、完整入画，画面只用实物本身区分」。

## 6. 出图与迭代闭环（本轮实际跑出来的）

1. 先出 3 张参考图并逐张按四判据核 → 不合格重生成（人手/文字/投影是最高频）。
2. L4 定稿 → 整块复制给即梦，**参考图按图像1/2/3 顺序挂**，封面 3:4、内页 16:9 逐张切。
3. 先出封面 + 1–2 张内页看效果，所有者确认画风与角色无偏，再整本出。
4. 出图后按四类回看：人手/爪、笔与纸比例、画面上有没有多余的英文字母、叙事道具上有没有被乱印字。
5. 发现问题回改 L4 对应页（不是重写整本），改完重跑门禁。

## 8. 机检覆盖与盲区

| 检查 | 覆盖 | 盲区 |
|---|---|---|
| `grammar_check.py` | 旁白大小写、目标词双语同现 | 画面 |
| `l4_case_check.py` | 画面词形态 ↔ 当页旁白 | 词是否真的出现在画面 |
| `l4_presence_check.py` | 逐页目标词字面（默认按需模式，缺页只提示） | 载体是否恰当（是否塞进叙事道具） |
| `l4_structure_check.py` | 四段骨架、逐页字段、构图三要素、词数、页型 | 载体恰当性、图文是否相符、画风是否跑偏 |
| `title_intro_check.py` | 标题与简介 | 同上 |

**结论：载体纪律、图文相符、画风一致性三件事没有机检，只能人核。**
