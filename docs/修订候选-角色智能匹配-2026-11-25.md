## 1. `flow.md` §1 L1 硬口径追加一条

- **角色按题材智能提案，不跨书沿用**〔裁定 2026-11-25〕：每本书 L1 由创作子代理按「题材 × 故事情节 × 角色动作清单」智能提案主角与配角（物种、形象、数量不限，需过肢体限制表）；主模型收稿复核「角色-题材匹配度」。**禁止把上一本书的角色写进下一本的委派任务书**；同一词群连续排产（如 B683–B688 同为食物）如需沿用同一角色，任务书须显式写明沿用理由，主模型复核理由成立才放行。违反即整本退回重提案。

## 2. `executor.md` §2 委派任务书修正

- 「三件输入」的「②已确认材料」**不再包含主角设定**——主角/配角提案是创作子代理的交付物（REPORT 第⑨项「角色提案：物种、形象要点、与题材的匹配理由、逐页动作清单可行性」）。主模型只锁定：目标词、义项、年龄、画风、页数、（如所有者点名）参考图与特定角色。

## 3. `flow.md` §4 收稿复核追加

- 收稿复核新增第⑤项：**角色-题材匹配核对**——角色是否与题材/情节匹配？是否与近期书目撞角色（连续 3 本以上同一主角组即预警）？角色是否过动作清单（每页动作该角色做得到）？不过即退回创作槽重提案。

## 4. 角色池参考表（可选，供创作子代理提案时参考；非白名单，允许池外提案）

| 题材域 | 适配角色示例 | 理由 |
|---|---|---|
| 食物/厨房 | 小熊团团、小兔雪球（沿用） | 词群连续、拟人饮食自然 |
| 场所（邮局/消防站/警察局/商店） | 拟人职业动物（狗/獾/猫头鹰/鹿/浣熊等从业者） | 职业场景天然配职业动物 |
| 衣着穿戴（腰带/袖子/衣领/睡衣/眼镜） | 拟人小孩或与衣着强关联的动物 | 穿衣主体与人类经验一致 |
| 植物观察（牵牛花等） | 小刺猬/小松鼠等庭院动物 | 庭院视角自然 |
| 水下生物 | 鱼类角色（陆上动物不下水） | 题材硬约束 |
| 电器工具 | 视情节可保留任一角色 | 功能演示类题材角色弹性大 |

> 注：表为「起点参考」不是枚举白名单——创作子代理可提案表外角色，主模型只核匹配度与动作清单可行性。
